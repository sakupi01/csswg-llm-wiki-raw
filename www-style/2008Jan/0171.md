RESOLVED:

   - CSS2.1 Issue 19 (case-sensitivity) proposal accepted, issue closed.
     http://csswg.inkedblade.net/spec/css2.1#issue-19

   - Agreed to spec Firefox 3's behavior on
       http://lists.w3.org/Archives/Public/www-style/2008Jan/att-0089/scroll2.htm
     to resolve issue 27
       http://csswg.inkedblade.net/spec/css2.1#issue-27
     Still need wording, though.

   - Agreed to publish on the website a list of individual members of the
     CSSWG. This will be opt-in, so anyone who doesn't want his/her name
     published or who isn't paying attention won't be listed. List will
     include name and affiliation.

Other notes:

   - Paged Media spec <http://dev.w3.org/csswg/css3-page/> getting close
     to another WD or LC publication. Lots of changes making things much
     more specific.
   - CSSWG charter and centering added to March F2F agenda.
   - Apple's animations and transitions proposal out-of-scope for the
     current charter, but dev.w3.org can be used to make progress for now.
     (Current charter expires this year.)
   - Several open issues for CSS2.1 need proposed text to move forward.
     People encouraged to pick an issue and draft text.
       http://csswg.inkedblade.net/spec/css2.1

~fantasai
