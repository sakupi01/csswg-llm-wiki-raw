CSSOM View
----------

   http://dev.w3.org/csswg/cssom-view/

   RESOLVED: Take CSSOM spec to last call after edits described in the
             minutes are made.
             http://lists.w3.org/Archives/Public/www-style/2008Apr/0029.html

CSSOM
-----

   NOTED:    General agreement that the current CSSOM is badly designed and
             should be extended, but standardizing existing interfaces is
             the priority right now.

   RESOLVED: CSS specs below CR level should add canonicalization info to
             their property definitions.

   RESOLVED: CSSOM should have an interface for editors that does not interfere
             with the existing interfaces.
