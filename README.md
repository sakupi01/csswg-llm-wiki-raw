# csswg-llm-wiki-raw

Raw-data layer of [sakupi01/csswg-llm-wiki](https://github.com/sakupi01/csswg-llm-wiki):
a mirror of public CSS Working Group primary sources (GitHub issues, W3C API status
snapshots, www-style minutes). See [NOTICE.md](NOTICE.md) for provenance, attribution,
and takedown contact.

Files here are generated by the sync scripts in the parent repository
(`tools/sync_issues.py`, `tools/sync_w3c_status.py`) and are never edited by hand.
Layout:

```
github/csswg-drafts/issues/<NNxxx>/<NNNNN>.md   1 issue = 1 file, bucketed by 1000
github/csswg-drafts/pulls/<NNxxx>/<NNNNN>.md    only PRs carrying css-meeting-bot comments
github/csswg-drafts/.sync-state.json            incremental-sync cursors
w3c-api/specifications/<shortname>.json         TR status history snapshots
w3c-api/group/css/                              charters, participants
www-style/minutes/<YYYY>/                       minutes emails (2008-2025)
```
