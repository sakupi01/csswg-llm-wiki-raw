CSS Images 4 seems to be described as a superset of CSS Images 3:
> It includes and extends the functionality of CSS level 2 [CSS2] and in the previous level of this specification [css3-images].

Yet, it doesn't seem to be actually a superset, e.g. `object-position` is not included in level 4.

A specific illustration of this is that its list of terms defined by references includes 16 terms from Level 3: circle,  concrete object size,  contain constraint,  cover constraint,  default object size,  default sizing algorithm,  ellipse,  linear-gradient(),  natural aspect ratio,  natural dimension,  natural height,  natural size,  natural width,  object size negotiation,  object-position,  radial-gradient() 

<!-- comment id=747420357 author=LeaVerou created=2020-12-17T12:50:52Z url=https://github.com/w3c/csswg-drafts/issues/5804#issuecomment-747420357 -->
## @LeaVerou — 2020-12-17

Images 4 is a delta spec, it hasn't yet pulled in all of Images 3, it mainly includes the additions/differences.

Yes, it is certainly worth it for Images 4 to say

1. that is is a delta
