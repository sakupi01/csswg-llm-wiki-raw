both section [3](https://drafts.csswg.org/css-color-adjust-1/#forced) and [3.2](https://drafts.csswg.org/css-color-adjust-1/#forced-color-adjust-prop) of  css-color-adjust are entitled: "Bla bla bla: the forced-color-adjust property".

That "the forced-color-adjust property" part is only appropriate for 3.2, which talks about that property, and should be removed form the broader section, which talks about more than that.

So we should have
> 3. Forced Color Schemes

and 

> 3.2. Opting Out of a Forced Color Scheme: the forced-color-adjust property
