The degenerate syntax for declaring a layer is `@layer name;`. We also have `@layers name1, name2, name3;` for doing multiple at once; I think it should just have the same at-keyword: `@layer`. No reason we can't, and it avoids confusing authors about the 's'.

<!-- comment id=759585910 author=tabatkins created=2021-01-13T17:02:13Z url=https://github.com/w3c/csswg-drafts/issues/5855#issuecomment-759585910 -->
## @tabatkins — 2021-01-13

Well, the degenerate syntax for a single layer is actually `@layer foo {}`.

But yeah, assuming there's no weird parsing quirks in impls with having an at-rule be ended *either* by a block or a semicolon, then I'm fine with this.
