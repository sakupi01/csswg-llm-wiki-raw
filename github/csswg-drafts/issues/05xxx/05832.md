The tests matching the path http://wpt.live/css/css-color/predefined-00*.html  (e.g. http://wpt.live/css/css-color/predefined-001.html) use http://wpt.live/css/css-color/greensquare-ref.html as their reference (via `<link rel="match" href="greensquare-ref.html">`) but that green square is not the same green as the tests want.

The tests want a green of `background-color: #009900`.
The expected (greensquare-ref.html) has a green of `background-color: #008000;`.
