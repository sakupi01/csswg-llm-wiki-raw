## @tabatkins — 2021-02-01

This isn't a problem with ::part(); there's nothing about it that stops things from animating, and no edit to the shadow-parts spec will fix it. This is a problem with Shadow DOM and CSS's name-defining constructs, and the solution is outlined in <https://github.com/w3c/csswg-drafts/issues/1995> (I've just updated the original post to take into account the feedback and compromises from later in the thread, so there's no need to read past the original post unless you want context.)
