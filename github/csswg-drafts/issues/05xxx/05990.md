Fonts have different ascents and descents depending on their baselines. Also, different baselines are used by default in vertical writing mode.

Do we need something like `ascent-override-hanging-baseline`?

These `@font-face` blocks are getting bigger and bigger every day...

## @fantasai — 2021-03-27

If I understand correctly, the ascent metric is with respect to the zero coordinate (which is also the alphabetic baseline). And the baseline table is what defines adjustments that need to be made when using a different baseline.

I think we should keep with that idea, and if we want to provide a baseline table via @font-face, then we can add a `baseline-table` descriptor that takes a list of `<<baseline>> [from-font | <<percentage>>]{1,2}` to override individual baselines, with each value defining the baseline's offset from zero.
