The new version of the pubrules checker (updated to cope with the Sept 2020 Process update) gave a warning when I was checking [CSS Highlight API](https://www.w3.org/TR/2020/WD-css-highlight-api-1-20201022/):

> Please make sure the expressions in document are neutral, "master" found in document. Check W3C Manual of Style for more information.

This relates to https://github.com/w3c/idcg/issues/17

So is it time we just renamed the `master` branch to `main`? Because it wasn't really language used in the spec; it was the name of the GitHub branch.
