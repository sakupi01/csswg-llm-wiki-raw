Presumably https://www.w3.org/TR/CSS2/ will have the same issue when it’s updated.

## @plinss — 2020-07-19

The redirects are in place now. I'm keeping this issue open due to the test links being broken.

Personally, I'm glad for the Bikeshed conversion, and have no issue with a single page spec, but I'd like to see a multipage version with equivalent URLs to the old version.

I accept that's currently blocked by Bikeshed's lack of multipage support.

If we can't generate a multi-page version, then we need to either edit all the CSS2.1 tests links (which would not only be a large amount of work but would also take work to avoid invalidating old test results), or we need to build a system to translate the old URLs into the current form for the test suite build system and Shepherd.

## @plinss — 2020-07-19

Shepherd parses the built specs directly. We don't want to change the Shepherd data because Bikeshed and Respec use it to generate links to CSS2 and those need to be correct.

The build system could get a translation layer so it at least recognizes old CSS2 links and associates them to the appropriate spec sections. The test harness also needs to deal with those changes so the test suite annotations work for CSS2. (It's possible the build translation can simply carry over to the harness, I'd have to check the code.)
