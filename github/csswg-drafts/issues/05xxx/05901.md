## @Crissov — 2021-01-29

A `:role()` proposal is already tracked in #3596. A semantic role selector is certainly better than something like regex selectors, #1008 vs #1010. An open question is whether it makes more sense to introduce, for instance, `:role(heading)` than `:heading`.
