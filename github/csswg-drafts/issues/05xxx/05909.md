This is a direct follow on to https://github.com/w3c/csswg-drafts/issues/908, which decided on the following text:

> Alternately, “all elements except non-replaced inline boxes, table-column boxes, and table-column-group boxes” (blacklist, rather than whitelist, approach) if that is easier.

All browsers currently also apply this to non-replaced inlines _if they're absolutely positioned_. So I think the text needs updating to reflect this.
