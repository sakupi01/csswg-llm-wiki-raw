## @svgeesus — 2020-07-06

I agree. Bear in mind that at the time, the merger of Unicode and ISO10646 was very new and highly political.

The two have been going on in lockstep (per character repertoire) for a long time now and this is no longer contentious. Also, Unicode adds character properties which we normatively depend on, which 10646 does not have, so Unicode is a strict superset of 10646.

I therefore approve of this change.
