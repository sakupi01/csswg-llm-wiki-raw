https://drafts.csswg.org/css-sizing-4/#aspect-ratio defines `aspect-ratio` with

> Animation type: discrete

But https://drafts.csswg.org/css-values/#combine-ratio defines an interpolation for `<ratio>`.
Shouldn't `aspect-ratio` use that interpolation instead of being discrete?
