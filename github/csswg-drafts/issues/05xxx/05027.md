## @fantasai — 2020-05-12

@Loirooriol containing block is a pretty fundamental concept to layout: if we removed positioning entirely from CSS, it would still be needed. So I think the fundamental definition belongs in Display. Position just has the most complicated set of rules, and it crosses through various layout modes, so it's got more text about it than other layout models. So Display should have a cross-reference to css-position, but css-position shouldn't be defining the term.
