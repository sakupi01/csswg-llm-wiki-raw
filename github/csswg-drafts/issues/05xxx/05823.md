# `:transition`

I would like to suggest creating such a useful selector, for styling elements **only** during transition (not *animation*).

A `:transition` selector will take affect if/while *any* property is currently being transitioned,
even if there are several transitions, each at different duration:

In the below example, the `:transition` will take effect twice, only during the periods of properties being transitioned:

```css
/*
 color     top
 [----]    [------------]
 0    1s   2s           5s
*/
.foo{ transition:color 1s, top 3s 2s }
```


### Block the user from toggling a thing during transition 
```css
.foo:transition{ pointer-events:none }  
```

### Hide specific children during transition
```css
.foo:transition > .bar{ display:none }  
```

----

It will also open the door to some interesting effects:

### Every time `.foo` is transitioned, apply a filter
```css
.foo:transition{ filter:blur(2px) }  
```

This can be taken further, optionally allowing to target specific property which is being transitioned:

```css
.foo:transition(top){ ... }  
```
