[Section 4.1](https://drafts.csswg.org/mediaqueries-5/#script-custom-mq) of the media queries spec mentions adding the ability to set custom media queries from Javascript but is lacking in detail. It only contains [Issue 6](https://drafts.csswg.org/mediaqueries-5/#issue-bab99524).

What is the status of 4.1 is it still being considered? I think this adds a lot more flexibility to media queries. The use case I am interested in is to override prefers-color-scheme with a toggle or allow selecting from several color themes. There are workaround for my use case but I feel this would be a more elegant way of dealing with that problem.
