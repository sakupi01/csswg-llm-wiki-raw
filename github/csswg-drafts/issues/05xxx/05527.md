In [7.3.1. Applicability](https://drafts.csswg.org/css-inline-3/#first-most-inline-level) it is stated that a goal is to

> to allow the possibility of multi-character initial letters (such as for first word or first phrase styling),

There is a nice Hindi example of this in the Indic Language Requirements document,  [3.2 Typographic units](https://www.w3.org/TR/ilreq/#typographic-units)

> There are two syllables in this word: SA+VIRAMA+KA+UU and LA. Note, however, that there are three Unicode grapheme clusters here: SA+VIRAMA, KA+UU and LA.

The drop cap applies to the first _syllable_, which contains _two_ grapheme clusters and _four_ characters.

I suggest asking permission to include this example, and text derived from the associated explanation, in CSS Inline 3
