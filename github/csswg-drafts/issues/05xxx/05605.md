[css-font-loading] contains a reference to a `ForEachCallback` in the interfaces section that is not used in the spec itself: https://drafts.csswg.org/css-font-loading/#callbackdef-foreachcallback. It is additionally referenced in the 'Terms defined by this specification' section https://drafts.csswg.org/css-font-loading/#index-defined-here and the 'IDL Index' section https://drafts.csswg.org/css-font-loading/#idl-index.

I suspect this was from before setlike<FontFace> was used for FontFaceSet.

It should be removed.
