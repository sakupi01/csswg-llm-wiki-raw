The suffix '-override' used in the [metrics descriptors](https://drafts.csswg.org/css-fonts-4/#font-metrics-override-desc) seems superfluous, would these be better being called simply 'ascent', descent', and 'line-gap'?

<!-- comment id=4939540349 author=fantasai created=2026-07-10T21:06:19Z url=https://github.com/w3c/csswg-drafts/issues/5541#issuecomment-4939540349 -->
## @fantasai — 2026-07-10

I think it's actually better to have `override` be more explicit here, because in a well-designed font you're supposed to just use the font's metrics. Overriding it in `@font-face` should not be a common case.
