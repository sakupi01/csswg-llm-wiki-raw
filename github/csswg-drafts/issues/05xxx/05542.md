The set of available [metrics descriptors](https://drafts.csswg.org/css-fonts-4/#font-metrics-override-desc) seems limited. I've seen many fonts with either missing or incorrect metrics for other values, such as x-height, and cap-height. IIRC UAs often synthesize these values. Should we extend these to allow specifying other available metrics?
