The description of "non-ASCII code point" in [section 4.2](https://drafts.csswg.org/css-syntax/#tokenizer-definitions) states:

> non-ASCII code point
A code point with a value equal to or greater than U+0080 &lt;control&gt;.

I'm not sure what this "&lt;control&gt;" is meant to mean here.  I assume it's just a typo?

U+0080 is a `<control>` character, see https://www.unicode.org/charts/nameslist/n_0080.html
