css-ui-3 specifies that UAs use the ellipsis character for ellipsis when `text-overflow: ellipsis` is specified. It seems there is [demand](https://medium.com/mofed/css-line-clamp-the-good-the-bad-and-the-straight-up-broken-865413f16e5) for allowing a custom character, to handle for example scripts that are not western.

Has this idea been proposed before? I can't find an open issue for it.
