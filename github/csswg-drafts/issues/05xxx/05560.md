There is a WPT [test for The CSSGroupingRule interface](https://test.csswg.org/suites/css-conditional-3_dev/nightly-unstable/html/test_group_insertRule.htm) which [has passes in Chrome, Firefox, and Safari](https://test.csswg.org/harness/details/css-conditional-3_dev/test_group_insertrule/).

That interface [exists in the 2013 CR](https://www.w3.org/TR/css3-conditional/#the-cssgroupingrule-interface) and [not in the current ED](https://drafts.csswg.org/css-conditional-3/#the-cssgroupingrule-interface). The [changes section](https://drafts.csswg.org/css-conditional-3/#changes) does not mention removing it.

Was it removed deliberately and if so why, it it bad in some way, given there are three implementations?

Was it removed accidentally and if so, I guess it should be added back?
