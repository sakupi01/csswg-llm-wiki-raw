Coming here from the [TAG review](https://github.com/w3ctag/design-reviews/issues/583) for css-color-adjust-1.

Based on the spec alone, we had trouble understanding what the `color-schemes` property was used for. The explanation Tab gave in the linked issue was helpful; it would be good if more of that explanation was present in the spec.

Even with that context, the code examples don't really clarify much, since they're identical. Could we have some more nuanced code examples?

It would also be helpful to have some examples which demonstrate the failure case which occurs when this property isn't available.
