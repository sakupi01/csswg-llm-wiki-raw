The syntax specified for the `final-bg-layer` type is incorrect:
```
<final-bg-layer> =  <\'background-color'> || <bg-image> || <bg-position> [ / <bg-size> ]? || <repeat-style> || <attachment> || <box> || <box>
```

Note the forward slash in `<\'background-color'>`
