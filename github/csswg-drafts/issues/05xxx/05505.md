> Could you add ids to the figures, so that they can be linked to?

There actually is one already, #mapping-diagram. But the source of the diagrams, and the definitions for all these things, is Writing Modes so if you're linking probably it would make more sense to link [there](https://www.w3.org/TR/css-writing-modes-4/#abstract-box)? I wouldn't mind adding those to Writing Modes, but I think here that would be a bit extra?

Makes sense. Fixed.
