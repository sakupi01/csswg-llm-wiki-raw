The [definition of the `ViewTimeline` interface](https://drafts.csswg.org/scroll-animations-1/#viewtimeline-interface) currently has these two members:

```
readonly attribute CSSNumericValue startOffset;
readonly attribute CSSNumericValue endOffset;
```

The prose for both members states that they are "null when the timeline is inactive." Should the IDL definition then use `CSSNumericValue?`?
