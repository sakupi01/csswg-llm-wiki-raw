According to the [current specification](https://www.w3.org/TR/css-position-3/#def-cb):

"The containing block of a static, relative, or sticky box is as defined by its formatting context. "

However, the [CSS2 specificaiton](https://www.w3.org/TR/CSS2/visudet.html#containing-block-details) states this independently of the formatting context:

"If the element's position is 'relative' or 'static', the containing block is formed by the content edge of the nearest block container ancestor box."

Please specify in the CSS Display Module Level 3 what constitutes the containing block and which edge forms the containing block for relatively and statically positioned boxes within each formatting context.

## @gitspeaks — 2024-11-13

According to [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/CSS/Containing_block#identifying_the_containing_block)

"If the position property is static, relative, or sticky, the containing block is formed by the edge of the content box of the nearest ancestor element that is either a block container (such as an inline-block, block, or list-item element) or establishes a formatting context (such as a table container, flex container, grid container, or the block container itself)."
