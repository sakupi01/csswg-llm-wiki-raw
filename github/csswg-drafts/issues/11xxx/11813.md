https://drafts.csswg.org/cssom-view/#dom-range-getclientrects

Should getClientRects (and possibly getBoundingClientRect too) extend AbstractRange instead of Range so it can be called on any type of ranges?

This issue came up while making some clarifications to the spec of [CSS.highlights.highlightsFromPoint](https://drafts.csswg.org/css-highlight-api-1/#dom-highlightregistry-highlightsfrompoint) which needs to determine if the point is in every custom [Highlight](https://drafts.csswg.org/css-highlight-api-1/#highlight) registered, and to know that, the rects of their ranges need to be computed, and they can be either Ranges or StaticRanges.

Interested to hear some thoughts on this.
