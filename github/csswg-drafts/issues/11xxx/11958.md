The prose for Window.getComputedStyle in https://drafts.csswg.org/cssom/#extensions-to-the-window-interface defines the function as returning a "live CSSStyleProperties object", but the IDL is defined to return the base type, CSSStyleDeclaration.

I don't believe there is any functional change here, as the dynamic type will end up being the same, but it would be more clear.
