We've closed #10993 with the resolution to go with superellipses rather than with continuous rounded corners ("apple style").
Opening this issue to keep the option open to add this corner shape in the future, as it provides a style that differs from squircles.
See aforementioned issue for more context.

## @noamr — 2026-04-16

> [@noamr](https://github.com/noamr) What additional details need to be clarified if this is to be added to the CSS specification?

@smfr clarified at some point that a `continuous` corner is a quartic bezier curve of sorts (3 control points). 
There was a resolution some time in early 2025 to start with the current `corner-shape` superellipse-based model because it is dynamic and can be animated, and we said we can revisit it later on. So we can always raise this. One thing to think about is whether this value animates and how (allow quartic corner-shapes in general alongside superellispe, and have a `continuous` as a keyword for one of the quartic values?)
