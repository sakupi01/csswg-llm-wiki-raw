While working on the new [CSS Levels categorization](https://github.com/w3c/csswg-drafts/issues/10281) the CSS Community Group realized that CSS and with that the community needs a new logo to adopt the new categorization.

According to our research the latest known logo "the shield" never got official approval and / or adopted by the CSSWG. The latest information I found in the archive referencing a logo had bee [these meeting notes](https://lists.w3.org/Archives/Public/www-style/2011May/0083.html) (@fantasai as you had been already acitve part of the WG, maybe you know what happened to this discussion afterwards).
The CSS Next CG wants to change that and publish the new logo in consultation with the CSSWG as offical CSS logo.

Over the last few months the CSS Next CG together with the community collected ideas on [how a new version independent logo for CSS could look like](https://github.com/CSS-Next/css-next/issues/105). After a couple iterations and tweaks, as well as a voting this is the result:

<img src="https://raw.githubusercontent.com/CSS-Next/logo.css/7353910c2df9e614a0b3cef0b8ac6413591bbfce/css.svg" width="350"/>

More information regarding the logo can be found [here](https://github.com/CSS-Next/logo.css).

The logo could e.g. replace old ones like [this](https://github.com/w3c/csswg-drafts/blob/main/csslogo.ico).

## @tabatkins — 2024-12-02

Hm tho, I said "non-controversial", but actually, the icon *as presented* isn't appropriate for a favicon; the "CSS" only occupies a small portion of the icon, and at favicon sizes that's unreadable. (The current icon is *just barely* readable, with the text occupying the whole thing.)

So actually, we'd probably want an adjusted one that uses the shape and color, but scales and squashes the text to fill the box for use in this tiny form factor.

(I note that there is a `.ico` version of the icon in the repo, but it's 32x32. If you shrink it to 16x16, which is the size used on my tabs right now, it's much less readable due to the shrunken text.)
