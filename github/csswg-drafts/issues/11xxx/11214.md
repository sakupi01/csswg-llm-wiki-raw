The [CSS2 definition](https://www.w3.org/TR/CSS2/visuren.html#block-boxes) of "block container" omits flex-level boxes, which can also function as block containers.

Additionally, the [current definition](https://www.w3.org/TR/css-display-3/#block-container) of "block container" does not specify which types of boxes act as block containers, as the CSS2 spec does.

However, in CSS2, this information is included as part of the definition itself, so it would be clearer to add a link to the inner display section in the new term.
