It would be incredibly useful  to have a single HTML file that combines all CSS3 specifications in this repository, similar to the CSS2 spec. This would simplify searching, reviewing, and offline access by allowing users to search across all specs in one document. Please consider adding a `Master.bs` file in the root to generate a combined flat layout of all recent CSS3 specs.
