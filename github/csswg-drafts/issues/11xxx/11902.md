css-position-3 and css-align-3 imply different things about whether alignment takes effect when one of the insets in an axis is `auto`. We should make them agree with each other.

<!-- comment id=2807780919 author=Loirooriol created=2025-04-15T23:42:45Z url=https://github.com/w3c/csswg-drafts/issues/11902#issuecomment-2807780919 -->
## @Loirooriol — 2025-04-15

As mentioned in https://github.com/w3c/csswg-drafts/issues/11195#issuecomment-2807770598, where does the "nor [margins](https://drafts.csswg.org/css-box-4/#margin) in that axis are auto" come from?

Browsers still allow stretching even if margins are auto:

```html
<!DOCTYPE html>
<style>
body { transform: scale(1); border: solid; width: 200px; height: 200px; }
.abs {
  position: absolute;
  place-self: stretch;
  inset: 0;
  margin-block: auto;
  margin-inline: auto 0;
  background: lime;
}
</style>
<div class="abs">Test</div>
```
