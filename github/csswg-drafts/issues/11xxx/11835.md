In #10935 we resolved that scroll markers should be default styled as links, however, it is relatively common practice for authors to change link styling by using the `:link` pseudo-class. We should figure out whether we can have this pseudoclass match against `::scroll-marker` pseudo-elements as well. E.g. this [demo page](https://jsbin.com/pagexuy/edit?html,css,output) has set the `:link` color to ensure links are visible, can this match and apply to `::scroll-marker` as well by default?

## @tabatkins — 2025-03-05

I think @chrishtr's point in the IRC discussion holds well - people will notice if they use scroll markers and they're unreadable, and they'll usually be styling them specially anyway. So, it's okay to stick with the status quo - the UA stylesheet just sets :link/:visited styles (both on the page and on scroll markers) that respond to light/dark, as today, and authors can/will override as necessary.
