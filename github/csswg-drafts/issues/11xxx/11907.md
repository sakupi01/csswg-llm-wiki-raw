Setup happens on each rendering update, so if two rendering updates happen before the task runs (which can happen because vsync is more prioritary than other tasks, for example) you run the setup steps twice

<!-- comment id=2714534713 author=emilio created=2025-03-11T14:30:14Z url=https://github.com/w3c/csswg-drafts/issues/11907#issuecomment-2714534713 -->
## @emilio — 2025-03-11

In particular:

 * Rendering update, phase is "setup", update callback is queued.
 * Rendering update, phase is "setup", _another_ update callback is queued.
 * First update callback runs, appends to the pending update queue.
 * Second one runs, appends to the pending update queue.
 * Queue is flushed, callback is called twice for the same transition.
