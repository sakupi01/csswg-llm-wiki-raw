https://www.w3.org/TR/WD-font/ brings up a popup:

> This version is outdated!
> For the latest version, please look at https://www.w3.org/TR/CSS21/.

The document itself links to https://www.w3.org/TR/css3-fonts as the "latest version", which duly takes me to the CSS Fonts 3 REC. So why did this claim CSS21 is the latest version? (Probably because that's the banner that was put on it a number of years ago.)

Also: https://api.w3.org/specifications/WD-font claims that the `WD-font` shortname (so it _is_ a shortname, just with a strange format — I've never seen a shortname with "WD" in it before!) has two published versions; this feels wrong, it should just be an alias of `css-fonts-3` or `css-fonts`?

## @svgeesus — 2024-12-09

The entries at the history link look correct (look at the earliest four entries) but incomplete

https://www.w3.org/standards/history/css-fonts-3/

it goes (oldest first)

* [WD-font-970721](https://www.w3.org/TR/WD-font-970721)
* [REC-CSS2-19980512/fonts.html](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html)
* [WD-css3-fonts-20010731/](https://www.w3.org/TR/2001/WD-css3-fonts-20010731/)
* [WD-css3-fonts-20020802](https://www.w3.org/TR/2002/WD-css3-fonts-20020802)

but yeah it should be 

* [WD-font-970721](https://www.w3.org/TR/WD-font-970721)
* [REC-CSS2-19980512/fonts.html](https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html)
* [**WD-font-19990902**](https://www.w3.org/TR/1999/WD-font-19990902) which is marked as superseded
* [WD-css3-fonts-20010731/](https://www.w3.org/TR/2001/WD-css3-fonts-20010731/)
* [WD-css3-fonts-20020802](https://www.w3.org/TR/2002/WD-css3-fonts-20020802)


and the obsoletion popup on [WD-css3-fonts-20020802](https://www.w3.org/TR/2002/WD-css3-fonts-20020802) should be pointing to the most recent in that history list, [2018 REC for css-fonts-3](https://www.w3.org/TR/2018/REC-css-fonts-3-20180920/) which is what it's [previous version](https://www.w3.org/TR/2001/WD-css3-fonts-20010731/) does.

I agree that it is a complicated history: the specs for (locally installed) fonts and for web fonts were at times separate, both got merged into CSS2, the web fonts part was removed to make css 2.1, the web fonts part was then combined with the (locally installed) fonts part to make css fonts 3, which replaces those portions of CSS 2.1.

Reported to webreq with request to fix.
