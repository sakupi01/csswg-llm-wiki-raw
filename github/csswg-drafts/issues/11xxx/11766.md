The `gap-` prefix was dropped from shorthand names. It was also dropped from production rules that these properties use. Unfortunately, that means that the value of `column-rule` and `row-rule` now references a `<rule-list>` production defined in the spec, but that is [already defined in css-syntax-3](https://www.w3.org/TR/css-syntax-3/#typedef-rule-list). These value definitions share the same namespace. The prefix is needed there to disambiguate.
