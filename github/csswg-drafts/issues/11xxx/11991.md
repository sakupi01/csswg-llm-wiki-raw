Step 3.1 of [update pseudo element styles](https://drafts.csswg.org/css-view-transitions-1/#update-pseudo-element-styles) cares about *capturedElement*'s box fragments. *capturedElement* is a [captured element](https://drafts.csswg.org/css-view-transitions-1/#captured-element), which is a struct that does not have any box fragments, ever.

Found while [implementing this in the Ladybird browser](https://github.com/LadybirdBrowser/ladybird/pull/4055).
