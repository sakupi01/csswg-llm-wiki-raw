The spec text for `::pseudo-button` says:

> The [:disabled](https://www.w3.org/TR/selectors-4/#disabled-pseudo) pseudo-class can apply to [::scroll-button()](https://drafts.csswg.org/css-overflow-5/#selectordef-scroll-button---scroll-button-direction). It matches a given button when their [originating element](https://www.w3.org/TR/selectors-4/#originating-element) can’t be scrolled in their associated direction.

Should the spec define that `:enabled` applies as well?
