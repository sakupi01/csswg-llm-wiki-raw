CSS Color HDR been [adopted](https://drafts.csswg.org/css-color-hdr/#controlling-dynamic-range), per [CSSWG resolution](https://github.com/w3c/csswg-drafts/issues/9306#issuecomment-1864864440), and also @ccameron-chromium  [has asked for TAG review](https://github.com/w3ctag/design-reviews/issues/1027) of the dynamic range limit functionality, where we read:

> Aiming for Chrome 133 (early January)

so despite there (of course) being some [open issues](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acss-color-hdr) it seems time to publish a FPWD.
