The case where you set `color-scheme: light dark` is fairly understandable.

But what happens if you set just `dark` or `light`, or `light only` or `dark only` and then your preference override contradicts the value?

There's two parts of this question, how should the used colour scheme work? and how should the media query value change?

## @JoshTumath — 2026-01-06

Yeah I agree with bramus. I don't think it should affect how the `color-scheme` CSS property works at all.

My understanding of how the preference would work is that, where the [determine the used color scheme algorithm](https://drafts.csswg.org/css-color-adjust-1/#determine-the-used-color-scheme) references the preferred colour scheme, that preference can be overridden by the preference API, but otherwise the algorithm is unchanged. Therefore, the `color-scheme` property behaviour is still unchanged.
