Hi. Seems like names are not consistent in current draft (24 February 2025).

https://drafts.csswg.org/css-sizing-4/#intrinsic-contribution-override

It's min-intrinsic-**sizing** at the start of section:
> 5.4. Zeroing Min-Content Size Contributions: the [min-intrinsic-sizing](https://drafts.csswg.org/css-sizing-4/#propdef-min-intrinsic-sizing) property
> Name: 	min-intrinsic-sizing

But it's min-intrinsic-**size** in the example:
> *, ::before, ::after { min-intrinsic-size: zero-if-scroll; }

I assume `min-intrinsic-sizing` is the correct one.
