c.f. https://api.w3.org/specifications/css-fonts-3/versions/19980512

```json
{
    "status": "Recommendation",
    "rec-track": true,
    "editor-draft": "https://drafts.csswg.org/css-fonts-3/",
    "uri": "https://www.w3.org/TR/1998/REC-CSS2-19980512/fonts.html",
    "date": "1998-05-12",
    "informative": false,
    "title": "CSS3 module: Web Fonts",
    "shortlink": "https://www.w3.org/TR/css3-fonts/"
}
```

The title is blatantly wrong (nowhere does CSS 2's Fonts chapter claim to be "CSS3 module: Web Fonts"), but it's also clearly not a version of the `css-fonts-3` shortname.

Like sure, maybe it (and CSS 1, CSS 2.1) should appear in the css-fonts series: https://api.w3.org/specification-series/css-fonts/specifications (and css-box and and and…), but it's definitely not a version of css-fonts-3.
