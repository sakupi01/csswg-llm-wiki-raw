On Apple platforms it's possible to enable "Differentiate without colour" which among other things adds state icons to switch inputs.
In lieu of having a preference media query for this (see https://github.com/w3c/csswg-drafts/issues/7406) it might be good to add something like this by default?

I think this is esspecially important because as currently defined it seems that colour is relied upon for state indication in a switch (technically the position of the thumb aswell but right to left vs left to right means that's not always the same). WCAG says not to rely on colour: https://www.w3.org/WAI/WCAG21/Understanding/use-of-color.html

## @lukewarlow — 2026-02-18

I thought about this a bit and I wonder if just generating the `::checkmark` pseudo on the slider-thumb of a switch, would be enough. If we decide we don't need to add a default indicator, that's fine. We don't even need to give it a default style, but having it would allow authors to add one.

Perhaps just allowing content for slider-thumb would be enough for that though.
