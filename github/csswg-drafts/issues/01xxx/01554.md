In the rules for serializing a length, the following issue appears:

> Rumor has it absolute lengths will become relative lengths. Centimeters would be compatible with `<resolution>`...

I have no idea what *either* of these sentences are supposed to mean.  Maybe the first one is referring to absolute lengths becoming statically equivalent to the px unit?  If so, (a) that already happened, and (b) nothing became relative.  The second one appears to be word salad, tho.

Unless there's something I'm missing, this issue should just be dropped.  That probably means that the "absolute lengths" section needs to be changed to serialize as "px", too.
