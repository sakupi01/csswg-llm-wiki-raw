The specification says that we can test to support the property of the browser like
`@supports (animation-name: test) { }`
or test for the non-support of a specific CSS property
`@supports not ( hanging-punctuation: first ){`

`@supports (filter: grayscale(100%)) {`
   ` img {`
        `filter: grayscale(100%)`
    `}`
`} else {`
    `img {`
        `background-image: url("/image.png");`
    `}`
`}`
