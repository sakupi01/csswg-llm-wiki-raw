Currently (tested in FireFox and in Chrome) you can only format things like font and not much else. It would be nice to be able to style each item individually with all of css.

I would propose that the they be rendered in a form that blocks overflow and onclick the size is created to the bottom is extended and the options animate down. I realize that `select` is on of the things are explicitly rendered very much differently on mobile (or at least on Chrome for Android). This currently even ignores `background-color` from the select. Either these alternative renderings should also have to follow the styling or there should be an easy way to style each one individually. Maybe a `:mobile` selector.
