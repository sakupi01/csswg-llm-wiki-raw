(This is pretty different from #1409, but it might appear related.)

The [section on baseline self alignment](https://drafts.csswg.org/css-align/#baseline-align-self) ends with the sentence:

> This can increase the intrinsic size of the box.

It's not clear to me why it says this, since baseline self-alignment doesn't appear to change even the final size of the box.

Is this instead intended to say that it can increase the intrinsic size of the containing block?

(Maybe the section on baseline content-alignment should say that too?)
