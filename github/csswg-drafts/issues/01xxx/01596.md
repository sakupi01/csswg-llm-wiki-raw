https://drafts.csswg.org/css-text-4/#valdef-text-spacing-space-end

>space-end
>    Set fullwidth opening punctuation with full-width glyphs (spaced) at the start of each line. 

This definition is the same as `space-start`. I feel that following description is correct.

Set fullwidth opening punctuation with full-width glyphs (spaced) at the *end* of each line.
