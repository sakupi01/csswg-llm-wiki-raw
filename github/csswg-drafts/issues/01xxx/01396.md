[§1. Introduction](https://drafts.csswg.org/css-align/#intro) of css-align begins with "<em>This section is not normative.</em>"  However, this section contains [§1.1. Module Interactions](https://drafts.csswg.org/css-align/#placement), [§1.2. Values](https://drafts.csswg.org/css-align/#values), and [§1.3. Partial Implementations](https://drafts.csswg.org/css-align/#partial), which I believe should be normative.
