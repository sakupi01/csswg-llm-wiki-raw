Spatial Navigation likely needs to be its own spec, with markup, style, script pieces, developed in a WICG repo.

A few things to consider:
* tabindex, previous nav-index
* making things focusable (or not)
* grouping / focus-grouping
* spatial navigation within a web component, across / into / out of web components
* accessibility concerns with the above and prior approaches, e.g. https://lists.w3.org/Archives/Public/www-style/2013May/0076.html
