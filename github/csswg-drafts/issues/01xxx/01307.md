[§3. Introduction to Vertical Text](https://drafts.csswg.org/css-writing-modes-3/#vertical-intro) begins with:
> This subsection is non-normative.

This is odd, since it's really a section rather than a subsection.

Furthermore, the section contains [§3.1. Block Flow Direction: the writing-mode property](https://drafts.csswg.org/css-writing-modes-3/#block-flow), which definitely needs to be normative.

It seems like this could use a little bit of clarification by moving the introductory material into an actual subsection (although that has the problem of a toplevel section with no content before the subsection begins), or something else to make it clearer that §3.1 is actually normative.
