CSS Display (or is it CSS Contain?) has this transformation called ["Becoming a formatting context"](https://drafts.csswg.org/css-display-3/#becoming-formatting-context). I think the name is confusing because it makes a box establish a formatting context, not become one (that wouldn't make much sense). It should be renamed to something like "Becoming a formatting context **root**".
