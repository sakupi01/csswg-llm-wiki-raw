The [Values section](https://drafts.csswg.org/css-align/#values) of css-align currently says:

> This specification follows the CSS property definition conventions from [CSS2]. Value types not defined in this specification are defined in CSS Level 2 Revision 1 [CSS2].

I think the section this points to has become sufficiently out-of-date by this point that it's probably best to point mostly to the relevant level 3 modules rather than level 2.  Most drafts don't have a section like this one, and I don't think such a section would be needed if bikeshed implemented https://github.com/tabatkins/bikeshed/issues/617

<!-- comment id=310231505 author=fantasai created=2017-06-21T23:18:20Z url=https://github.com/w3c/csswg-drafts/issues/1397#issuecomment-310231505 -->
## @fantasai — 2017-06-21

I think for people reading in a non-interactive format (like print), having this statement in addition to the bikeshed links would be useful. That said, updating the boilerplate is probably a good idea; as is making sure it is consistently applied across all of our specs. This Values section is part of our module template.

<!-- comment id=310233578 author=tabatkins created=2017-06-21T23:32:01Z url=https://github.com/w3c/csswg-drafts/issues/1397#issuecomment-310233578 -->
## @tabatkins — 2017-06-21

On the other hand, these Values sections are usually *straight* boilerplate, copypasted from other specs without really looking, and then left to rot. This spec's Values section shows that off in spades - it has a weird separate treatment of "initial" and "inherit", and doesn't mention the other global values. It should instead just talk about global values and point to Cascade.

We should figure out how to work this into our actual boilerplate so people wont' have to worry about it.

<!-- comment id=311471628 author=fantasai created=2017-06-27T20:13:19Z url=https://github.com/w3c/csswg-drafts/issues/1397#issuecomment-311471628 -->
## @fantasai — 2017-06-27

Proposed replacement: 
```
This specification follows the <a href="https://www.w3.org/TR/CSS21/about.html#property-defs">CSS property definition conventions</a> from [[!CSS2]].
Value types not defined in this specification are defined in CSS Values & Units [[!CSS-VALUES-3]].
Other CSS modules may expand the definitions of these value types.

In addition to the property-specific values listed in their definitions,
all properties defined in this specification
also accept the <a>CSS-wide keywords</a> keywords as their property value.
For readability they have not been repeated explicitly.
```
