In https://github.com/w3c/csswg-drafts/issues/765 we accepted a web-compat fix that defined replaced elements with percentage width or max-width as having a zeroed-out min-content contribution. @dbaron asked for a more precise definition of which replaced elements should be affected.

The definition should probably include any form controls which have some kind of overflow management, to the extent that this overflow management is able to compress the control while maintaining its usability.
