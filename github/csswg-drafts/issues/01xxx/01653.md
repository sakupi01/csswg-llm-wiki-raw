## @svgeesus — 2018-03-06

@dbaron parts of Fonts 4 are still a delta spec. Typically there is an inline issue noting where content needs to be migrated over from Fonts 3. Previously we were reluctant to move content over that could still be changing, as edits would then need to be kept in sync over the two levels. That is less of an issue now that Fonts 3 is headed for updated CR and (hopefully fairly soon) Proposed Rec. Also, Fonts 3 is the old `.src.html` format while Fonts 4 is `bikeshed`, which hindered copying content over.
The intent is that Fonts 4 becomes a true superset of Fonts 3.
