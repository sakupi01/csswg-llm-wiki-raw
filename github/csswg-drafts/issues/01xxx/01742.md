## @fantasai — 2017-11-05

This ended up going into the Sizing L3 spec (and later pushed out to L?), since Multi-col was in CR and we didn't want to add any new requirements for it. For Multi-col Level 1, it should remain undefined. For Level 2 we should make an effort to define this properly, and stealing text from https://drafts.csswg.org/css-sizing-4/#multicol-intrinsic would be a good start.
