From @dbaron's [comment on Apr 21st](https://github.com/w3c/csswg-drafts/issues/938#issuecomment-296107259), even when `line-height` is set to a value other than `normal` and the used line height is consistent, the baseline position may not be consistent in some browsers.

CSS2 does not define this, and I'm filing this not to loose. Do we want to work on this?
