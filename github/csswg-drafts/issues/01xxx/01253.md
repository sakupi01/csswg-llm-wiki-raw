The definitions of [the `lh` unit](https://drafts.csswg.org/css-values/#lh) and the `rlh` unit need to explain how to convert a line-height to an absolute length.  In particular, this is interesting for `normal`, and it probably needs to say that it uses the first available font (which isn't the way `normal` works in layout).

(This came out of the discussion the WG is currently having.)

## @frivoal — 2017-12-14

Now that we have fixed #1796, this becomes much more simple to do.
For all values of `line-height` other than `normal`, the answer is now clearly non ambiguous, and for `normal`, I suggest the answer is the height that one would get for an empty line box, containing only the strut, which matches @dbaron 's suggestion to used only the first available font.
