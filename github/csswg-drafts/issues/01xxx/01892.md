There were some great illustrations in #160, such as https://cloud.githubusercontent.com/assets/17156693/15734368/db4bf8ce-28c9-11e6-8fab-e2f73f9d7656.png

These look awkward in the sense that the size of the dots changes as the font size changes. Currently we are able to maintain the emphasis dots' color by having a property that holds this information, maybe it's worth doing something similar for the size and/or position?
