Currently the [keyframes section](https://drafts.csswg.org/css-animations/#keyframes) has this text:

> The <declaration-list> inside of <keyframe-block> accepts any CSS property except those defined in this specification, but does accept the animation-play-state property and interprets it specially.

I'm sure that's supposed to say `animation-timing-function` *not* `animation-play-state`.
