The [definition of `column-span: all`](https://drafts.csswg.org/css-multicol/#column-span) (which, in my opinion, has a surprisingly small amount of text for such a complicated feature) manages to repeat itself:
> The element spans across all columns of the nearest multicol ancestor in the same block formatting context. The element spans across all columns.

The second "The element spans across all columns." should be removed; it's just repeating what's already in the first sentence.
