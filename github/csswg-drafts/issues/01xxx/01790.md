9. Baseline Alignment Details
https://drafts.csswg.org/css-align/#baseline-rules

I would really appreciate a brief summary of how this works without having to understand all the details and follow links to all the specs.  For instance (and in particular) I still don't understand which baseline is used for a line containing latin and japanese text (ie. alphabetic or low?) or say arabic and hindi (alphabetic or hanging?).

This comment was discussed by the i18n WG.

<!-- comment id=328229374 author=fantasai created=2017-09-08T22:34:09Z url=https://github.com/w3c/csswg-drafts/issues/1790#issuecomment-328229374 -->
## @fantasai — 2017-09-08

The baseline used, under current rules, is the alphabetic baseline except in vertical writing modes in which case it's central. Various properties introduced in css-inline-3 will be able to request the use of other baselines, but for now it's just these two. In any case, it's specified by properties, and doesn't depend on the content of the element.
