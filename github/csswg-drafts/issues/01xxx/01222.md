## @yisibl — 2025-02-13

@LeaVerou 

With the addition of [Hue Interpolation](https://www.w3.org/TR/css-color-4/#hue-interpolation) in css-color-4, it is now possible to use `longer hue` for [this example](https://drafts.csswg.org/css-images-4/#ex-hsl-wheel), can we add it to the example as well?

```css
.test {
  background-image:
    radial-gradient(closest-side, gray, transparent),
    conic-gradient(in hsl longer hue, red, red);
  transform: scaleX(-1);
}
```
