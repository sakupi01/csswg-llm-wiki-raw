Per <https://github.com/w3c/csswg-drafts/commit/6722380c13ab90dc33d7a5b5ccbff095a5610fb7#commitcomment-24667401>, several specs linebreak in the middle of a tag, starting the next line with the closing `>` character. This activates Bikeshed's new support for Markdown blockquotes, and results in some messed up HTML.

Tagging the relevant specs in labels, remove the spec from the labels when it's fixed and close the issue when they're all fixed.
