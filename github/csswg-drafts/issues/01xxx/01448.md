I find the "passed to" wording that appears in a number of places in the [section on default alignment](https://drafts.csswg.org/css-align/#default-alignment) to not fit very well with CSS's model of computation.  It reminds me of the occasional usage of "assignment" terminology where "matching" is what correctly describes CSS's model.

I think the "passed to" usage should be replaced by "used by" or "used by some values of".
