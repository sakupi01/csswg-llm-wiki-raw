The section on [Aligning Boxes by Baseline](https://drafts.csswg.org/css-align/#align-by-baseline) says:

> First, generate the alignment context’s baseline table from its first available font and ...

Strictly speaking, an alignment context doesn't have a first available font, but the box that established it does.

Also, it seems a bit strange to define this as the alignment context's baseline table, since the alignment context may have two baseline-sharing groups that have differently-positioned baseline tables.

So I'd suggest defining it as the baseline-sharing group's baseline table (or maybe "group's baseline table" for short), perhaps as:

> First, generate the baseline-sharing group's baseline table (known as the <dfn>group's baseline table</dfn>) from the first available font of the box establishing the baseline-sharing group's alignment context, and ...

and then using that term through the rest of the section.
