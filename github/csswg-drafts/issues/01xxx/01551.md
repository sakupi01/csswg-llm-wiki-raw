I think the root inline box was only useful to explain the styling of text directly contained in a block container. But in https://github.com/w3c/csswg-drafts/issues/1118#issuecomment-305251140 the WG resolved that text runs have their own styles, they no longer need a box.

So I think that, as currently defined, root inline boxes became useless, and can be removed. Is that so?

If I'm right don't remove them yet, I have some alternative ideas for them.

> I think that the root inline box has a computed `line-height` property still helps explain how calculating the height of lines works

Do you meant the [strut](https://www.w3.org/TR/CSS21/visudet.html#strut)? So now `line-height` applies only to inline boxes, but the root inline box inherits it from the block container, effectively replacing the following CSS2.1 quote?

> On a block container element whose content is composed of inline-level elements, 'line-height' specifies the minimal height of line boxes within the element.

If so, this should be explained somewhere.
