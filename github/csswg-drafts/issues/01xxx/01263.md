Request for editorial review of the word "slots" use in the CSS Grid Layout Module.

The module uses the word "slot" or "slots" in the spec 5 times. 

I  believe that the section 2 [Overview ](https://www.w3.org/TR/css-grid-1/#overview) which covers the features of Grid Layout should have hyperlink on the word "slots" ("slots is used in the second bullet point). The hyperlink should point  to section [2.2 Placing Items](https://www.w3.org/TR/css-grid-1/#overview-placement) or [Grid Area](https://www.w3.org/TR/css-grid-1/#grid-area).

It looks like section [2.2 Placing Items](https://www.w3.org/TR/css-grid-1/#overview-placement) is where "slots" is defined.

From a perceptive of person trying to understand the module, I believe having a link on the word "slot" or "slots" to section [2.2 Placing Items](https://www.w3.org/TR/css-grid-1/#overview-placement) would greatly improve the understanding and readability of CSS Grid Layout module.

Thank you for the wonderful work and thank you for reviewing the request.
