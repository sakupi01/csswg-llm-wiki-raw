The "Value:" line for [the `place-content` property](https://drafts.csswg.org/css-align/#propdef-place-content) says:

> Value: &lt;‘align-content’> &lt;‘justify-content’> 

yet the prose says that the second value is optional.  The "Value:" line should probably be adjusted to indicate this as well.
