[Segment Break Transformation Rules](https://drafts.csswg.org/css-text-3/#line-break-transform) defines rules based on the character before and after, but does not define when a segment break is at the beginning/end.

I assume it should be removed too, or [Phase I: Collapsing and Transformation](https://drafts.csswg.org/css-text-3/#line-break-transform) should remove leading/trailing space/tab/segment breaks?
