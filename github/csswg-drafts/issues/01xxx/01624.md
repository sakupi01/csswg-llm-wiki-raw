Per [CSSWG resolution](https://lists.w3.org/Archives/Public/www-style/2017Jul/0015.html), `inline list-item` [was dropped](https://github.com/w3c/csswg-drafts/commit/94b7b00c51be31196521f73543ed5b4bd63486d2) from CSS Display in favor of `inline list-item`. I guess it should also be removed from [CSS Lists](https://drafts.csswg.org/css-lists/#valdef-display-inline-list-item).
