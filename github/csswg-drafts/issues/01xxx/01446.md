The "Value:" line for [the `place-self` property](https://drafts.csswg.org/css-align/#propdef-place-self) doesn't allow &lt;overflow-position&gt; values, and the same for [`place-items`](https://drafts.csswg.org/css-align/#propdef-place-items).  If this is intentional, it should be explicitly noted.  (It makes me wonder if #1412 was actually intentional... but if that's the case, there should be a Note pointing it out and probably justifying it.)
