The [gradient color stop syntax as currently defined in CSS Images 4](https://drafts.csswg.org/css-images-4/#color-stop-syntax) makes a stop position mandatory for every stop. It should be optional.

Since some of that content is due to be integrated into CSS Images 3 (per #1284), it's would be helpful to get a correction sooner rather than later.
