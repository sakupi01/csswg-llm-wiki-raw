[CSS Display Status](https://drafts.csswg.org/css-display-3/#status) says some things are at risk, including

> All multi-keyword values of `display` and `display: inline list-item`

But `inline list-item` is a multi-keyword value, so now that `inline-list-item` was dropped there is no need to mention it explicitly.
