We apparently [had a resolution](https://lists.w3.org/Archives/Member/w3c-css-wg/2017JanMar/0090.html) to take Tab's [css-font-display](https://tabatkins.github.io/specs/css-font-display/) to FPWD, although I can't find the resolution in any minutes (although I do vaguely remember it).

Then we had an [agenda item](https://lists.w3.org/Archives/Public/www-style/2017Feb/0067.html) that included, instead, possibly including it in fonts-4.

The [minutes of the discussion of that item](https://lists.w3.org/Archives/Public/www-style/2017Feb/0088.html) don't seem to include discussion of that topic or any resolution on it.

It seems like we should have a resolution one way or the other so that the font display feature can make progress, since my understanding is that it already has 2 disabled implementations (Gecko and I think Chromium) that are waiting for spec progress to enable the code.
