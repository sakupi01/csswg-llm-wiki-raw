I wrote a few tests for https://drafts.csswg.org/css-fonts/Fonts.html#om-fontfeaturevalues
Pending review, these are staged at https://www.w3.org/People/chris/fwf/

It looks like only Firefox implements this interface. Chrome, Edge and Safari fail all tests.

This interface should probably be moved from Fonts 3 to Fonts 4. Unless at least one browser steps up to implement in the next month or two?
