I just wrote https://drafts.csswg.org/css-values/#local-urls to discharge the resolution we made at the SF f2f, and while writing it I ran into one bit that we hadn't actually discussed: what to do about fragment-only URLs _in an external stylesheet_.  (The discussion we had at the f2f was just about URLs that would normally resolve to an element in the document, which implies the CSS is inline.)

I went ahead and defined that fragment-only URLs _always_ refer to the host document, because it seems useful for SVG, and because CSS documents have no fragment semantics and don't look like they ever will.  Is this ok?
