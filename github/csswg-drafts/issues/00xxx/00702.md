According to https://drafts.csswg.org/css-fonts-3/#font-size-adjust-prop, font-size-adjust specifies the aspect value used in the calculation below to calculate the adjusted font size. Since it is an aspect value, maybe we could explicitly specify that font-size-adjust should be either none or a non-negative number.
