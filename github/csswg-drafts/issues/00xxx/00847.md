The grammar says:

    @page = @page <page-selector-list>? { <declaration-list> }

but the intent is to allow the "margin at-rules" in there too, not just declarations.

The `<declaration-list>` production allows at-rules (as does `<rule-list>`; the difference is just whether it *also* allows declarations or qualified rules). So the spec is correct as-is.
