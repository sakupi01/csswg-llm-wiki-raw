The ["7.2.1. Named Grid Lines" Section](https://drafts.csswg.org/css-grid/#named-lines) defines the syntax as just 

> `[<custom-ident>*]`

Where [CSS Values for `<custom-ident>` says](https://drafts.csswg.org/css-values-4/#custom-idents)

>  Specifications using `<custom-ident>` must specify clearly what other keywords are excluded from `<custom-ident>`, if any

I would assume that `span` should be excluded not to collide with [Line-based placement properties](https://drafts.csswg.org/css-grid/#line-placement)

Am I correct?
