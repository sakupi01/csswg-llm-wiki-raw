If we're not careful, [the line-height-step property](https://drafts.csswg.org/css-rhythm/#line-height-step) and the [line grid](https://drafts.csswg.org/css-line-grid/) will interfere instead of complementing each other.

The grid created by`line-grid:create` needs to take `line-height-step` into account. As far as I can tell, [the current wording](https://drafts.csswg.org/css-line-grid/#valdef-line-grid-create) already does that implicitly, but we should probably make it explicit to avoid any misunderstanding.
