Specifications having an Overview.bs will automatically be parsed on the server in case there is no Overview.html.
This has the advantages that Bikeshed results are shown online, links are kept up to date, Bikeshed improvements take effect without editor effort and error in Bikeshed itself are indicated.

See also the [comment from @plinss about this](https://github.com/w3c/csswg-drafts/commit/7896268ba15a2af354e74e66ccdc2331473655af#commitcomment-17962683).

Affected specifications are:

- [x] [CSS Animations 2](https://drafts.csswg.org/css-animations-2/)
