https://drafts.csswg.org/css-text-4/#fullwidth-collapsing states when you should set a character to half-width or 3/4 width based on the previous/next character.

This would be correct, but only if we only consider the previous/next characters within the same line, but that's not specified. The ambiguity may lead some to think that we should consider the previous/next character in block, and that would be wrong.
