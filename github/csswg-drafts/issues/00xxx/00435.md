When referring to the URL variable is not recognized.
Neither bellow wont work.

CSS

```
:root {
    --pic1: url("../img/test/i-06.jpg");
    --pic2: "../img/test/i-07.jpg";
}

#a1 { background-image: var(--pic1); }
#a2 { background-image: url(var(--pic2)); }

```

<!-- comment id=244518099 author=plinss created=2016-09-03T01:13:06Z url=https://github.com/w3c/csswg-drafts/issues/435#issuecomment-244518099 -->
## @plinss — 2016-09-03

Yeah, &lt;url-token> is a special beast and follows its own rules that we most likely can't change due to web compat. I don't believe you can do variable substitution inside a url(), especially since "var(--pic2)" is a perfectly valid URL.

<!-- comment id=244518392 author=upsuper created=2016-09-03T01:18:35Z url=https://github.com/w3c/csswg-drafts/issues/435#issuecomment-244518392 -->
## @upsuper — 2016-09-03

`var(--pic2)` is probably a valid URL, but `url(var(--pic2))` is certainly not a valid `<url-token>` if not parsed as variable. [The "consume a url token" algorithm](https://drafts.csswg.org/css-syntax-3/#consume-url-token) raises a parse error when it sees the first `(`.
