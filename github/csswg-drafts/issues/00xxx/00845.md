CSSOM has (<https://drafts.csswg.org/cssom/#the-cssmediarule-interface>):

    [SameObject, PutForwards=mediaText] readonly attribute MediaList media;

and CSS Conditional Rules has (<https://drafts.csswg.org/css-conditional/#the-cssmediarule-interface>):

    readonly attribute MediaList media;

which differ in terms of what happens when .media is assigned on a CSSMediaRule.
