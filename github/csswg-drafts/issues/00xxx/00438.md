https://drafts.csswg.org/css-grid/#grid-shorthand

The new syntax suggests the use of " [ auto-flow && dense? ]" instead of reusing the current <grid-auto-flow> syntax. The only different is that <grid-auto-flow> allows omitting the 'auto-flow' value, assuming 'row' in that case. 

My proposal would be the following syntax:

<‘grid-template-rows’> / <'grid-auto-flow'> <‘grid-auto-columns’>? | <'grid-auto-flow'> <‘grid-auto-rows’>? / <‘grid-template-columns’>

## @fantasai — 2016-09-02

IIRC the reason Tab and I decided to use 'auto-flow' rather than the 'row'/'column' keywords was to make the shorthand a little more self-evident: just stating 'row' or 'column' in the appropriate place didn't make it as clear that the subsequent track-sizes were auto-flowed rather than part of the template. Since whether it was a row or column was already implied by the placement (it's implied whether you're doing auto-flow or template), we decided to use the 'auto-flow' part of the property name as a keyword here.
