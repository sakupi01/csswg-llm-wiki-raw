Scroll anchoring is a mechanism for preventing visible jumps from offscreen content changes, described in detail [here](https://github.com/skobes/ScrollAnchoring/blob/master/explainer.md) and at [https://skobes.github.io/ScrollAnchoring/](https://skobes.github.io/ScrollAnchoring/).

This is a proposal to define the CSS overflow-anchor property as described in the spec.  Please report any concerns about the design here, or under [https://github.com/skobes/ScrollAnchoring/issues](https://github.com/skobes/ScrollAnchoring/issues), or on the [blink-dev intent-to-ship thread](https://groups.google.com/a/chromium.org/d/msg/blink-dev/VJmxBRYGVIE/CogbbYWXCAAJ), or on the [tag review thread](https://github.com/w3ctag/spec-reviews/issues/142), or on the [WICG transfer proposal](https://discourse.wicg.io/t/proposal-scroll-anchoring/1752).

Note that we're shipping this in Chrome 56 despite failing to get much feedback from other engines.  Given the user [enthusiasm ](https://mobile.twitter.com/simevidas/status/799510987460214785), I suspect there will eventually be more interest. I provided some feedback during last TPAC, but I just had a look and the spec is in much better shape now than it was back then. I am glad Google decided to went with it and get the feature used in the wild. Please report the experiments results further when you have them!
