The [minutes from 2016-10-12](https://lists.w3.org/Archives/Public/www-style/2016Oct/0091.html) resolved on removing the CSS grammar section from CSS 2.2 and instead refer to the CSS Syntax module. Though the CSS Namespaces Module still [uses that grammar for the definition of the @namespace rule](https://drafts.csswg.org/css-namespaces-3/#syntax).

This syntax should be replaced by something like this:

```
@namespace <namespace-prefix>? [ <string> | <url> ];

where
<namespace-prefix> = <ident>
```
