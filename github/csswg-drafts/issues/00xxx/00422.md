https://drafts.csswg.org/css-cascade-3/#origin defines origin as `<dfn class="dfn-paneled" data-dfn-type="dfn" data-export="" id="origin">origin</dfn>`, which collides with [HTML's definition](https://html.spec.whatwg.org/multipage/browsers.html#concept-origin). You could add a [`for`](https://github.com/tabatkins/bikeshed/blob/master/docs/definitions-autolinks.md#specifying-what-a-definition-is-for) value to CSS's definition in order to disambiguate it.
