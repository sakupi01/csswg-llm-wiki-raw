## @frivoal — 2016-10-20

This was briefly considered when we were starting with media queries 4, and postponed because I and others involved didn't feel we had a good grasp on this topic.
- What are the use cases people are trying to address
- Should we just detect open vs closed? Are there different types of open (overlaying the viewport vs reducing it, for instance)? We probably also want to distinguish between a closed virtual keyboard and no virtual keyboard at all, and between a full keyboard and a phone keypad and a TV remote...

Collecting use cases and requirements for these different things would probably help in figuring out how to slice that problem space, so thanks for bringing this one up.
