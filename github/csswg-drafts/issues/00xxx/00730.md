I've been running into an interop issue between browsers when it comes to using flexbox in combination with the button element. According to [the specification](http://www.w3.org/TR/CSS21/visuren.html#display-prop) the display property "Applies to: all elements". But it looks like some browsers are not adhering to this due to inconsistencies in their implementation of the button element.

**Test case:**

```html
<style>
  button {
    -webkit-appearance: none;
    -moz-appearance: none;
    appearance: none;
    display: flex;
    justify-content: center;
    align-items: center;
    width: 64px;
    height: 64px;
    padding: 0;
    border: 0;
    background-color: blue;
  }

  .square {
    width: 32px;
    height: 32px;
    background-color: red;
  }
</style>
<button type="button">
  <div class="square"></div>
</button>
```
