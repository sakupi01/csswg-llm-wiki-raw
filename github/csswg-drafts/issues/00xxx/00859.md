We currently have the [following values for dominant baseline](https://drafts.csswg.org/css-inline/#dominant-baseline-property): `auto | text-bottom | alphabetic | ideographic | middle | central | mathematical | hanging | text-top`

Can any of these be dropped? Are there any missing baselines that we need?
