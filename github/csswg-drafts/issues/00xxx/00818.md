[This](https://drafts.csswg.org/css2/about.html#css2.2-v-css2) section implies that 2.2 has changed a lot more than it has, compared with 2.1, and makes it sound like 2.1 is an uninteroperable mess with features nobody implements, etc.

While the section more-or-less is just slightly edited from 2.1, it doesn't make any where near so much sense when the baseline REC to compare against is 2.1.
