Hello, I am implementing the CSS engine for my desktop application.
In [css-values], there is no words to mention the `<url-token>` but its functional notation, and in the [css-syntax] draft, the algorithm to consume the ident-like token is distinguishing these two forms. So is the `<url-token>` remained just for compatibility? Should a new implementation put its functional notation at the first place?

## @tabatkins — 2016-06-27

`<url-token>` **is** mentioned in Values, in the exact section you link to - it's the first bullet point after "In addition to the syntax defined above".

Syntax distinguishes the two forms because they parse differently.

`<url-token>` is not being deprecated or going away. If you're implementing a CSS engine, I recommend following Syntax exactly.
