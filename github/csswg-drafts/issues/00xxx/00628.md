CSS 2.2 section 4.3.6 Colors
https://www.w3.org/TR/CSS22/syndata.html#value-def-color

This section doesn't seem to reflect the changes made in CSS3 Color, which has been a W3C Recommendation for a while. I thought we were adding pointers from 2.2 to newer work, or indeed deleting sections from 2.2 and replacing them with a pointer to newer work?

<!-- comment id=255300252 author=SelenIT created=2016-10-21T05:57:07Z url=https://github.com/w3c/csswg-drafts/issues/628#issuecomment-255300252 -->
## @SelenIT — 2016-10-21

Maybe it would make sense to delete all sections marked as replaced by newer spec [in the "Official Definition" of CSS](https://drafts.csswg.org/css-2015/#css) per CSS-2015 snapshot and replace them with pointers to the newer modules? It would be much easier to read the spec without need to check if the particular section has been superseded by something newer or not.
