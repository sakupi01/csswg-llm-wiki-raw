## @frivoal — 2017-01-16

@tabatkins I've tried to add the indices to the snapshot (https://github.com/frivoal/csswg-drafts/commit/7bdf5830e675169643e9b3f03bd1b320c0ff08e1) based on guessing what the syntax is supposed to be from skimming the source, but it seems I got it wrong.

```
<index type="dfn" status="TR" spec="
	css21,
	css-syntax-3,
	css-style-attr-1,
	mediaqueries-3,
	css-conditional-3,
        ....
"></index>
```
This does generate an index of the right kind, but neither the `status` not the `spec` filter seem to apply, and I get everyting bikeshed knows about. What's wrong?

<!-- comment id=275195939 author=tabatkins created=2017-01-25T18:46:06Z url=https://github.com/w3c/csswg-drafts/issues/935#issuecomment-275195939 -->
## @tabatkins — 2017-01-25

Ooof, an early shorthand-attribute replacement was turning the `spec` attribute into `data-link-spec`, so the index generator was concluding you didn't specify a spec to limit the index to.  Fixed now.
