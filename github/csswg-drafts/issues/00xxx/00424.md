CSSOM [uses the `[ArrayClass]` extended attribute](https://drafts.csswg.org/cssom/#the-medialist-interface) on `MediaList`, `StyleSheetList` and `CSSRuleList`.

That extended attribute is now [called `[LegacyArrayClass]` in WebIDL](http://heycam.github.io/webidl/#LegacyArrayClass), so the IDL definitions should be updated to match.
