In the spirit of what it does for non-replaced elements (treat as having no contents, so it'll shrink to zero in most layouts), a replaced element should act like it has no intrinsic dimensions either.

<!-- comment id=237781403 author=frivoal created=2016-08-05T07:56:12Z url=https://github.com/w3c/csswg-drafts/issues/382#issuecomment-237781403 -->
## @frivoal — 2016-08-05

Sounds good to me. Just be careful in the phrasing to scope this “act like it has no intrinsic dimensions” thing to size calculations only. We don't want to imply that intrinsic dimensions should stop mattering for other things, such as object-fit for example.

<!-- comment id=244658874 author=frivoal created=2016-09-05T04:57:12Z url=https://github.com/w3c/csswg-drafts/issues/382#issuecomment-244658874 -->
