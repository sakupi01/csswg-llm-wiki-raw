## @SebastianZ — 2016-09-30

This seems unrelated to the [related CSS specification](https://drafts.csswg.org/css-backgrounds-3/#the-box-shadow) and is rather an incorrect usage of the `box-shadow` property or a bug in Firefox.

I suspect you defined some offsets in your `box-shadow` definition. To get a centered box-shadow you need to set the first two values to 0, e.g. `box-shadow: 0 0 50px rgba(0, 0, 0, 0.2)`.
