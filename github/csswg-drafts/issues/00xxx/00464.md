The opacity property should affect nothing but opacity.

In some cases, setting/changing opacity changes the stacking order / changes which items overlap which. That is very surprising for the user of your technology / the SVG/web developer, and it is very inconvenient because it can require time and effort to work around the issue.

Please make sure that the presence or absence of any opacity values never affect anything except opacity.
