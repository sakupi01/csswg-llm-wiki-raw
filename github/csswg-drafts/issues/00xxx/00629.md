Section: https://drafts.csswg.org/css-fonts-4/#font-weight-prop

The following sentence is unclear:
"Most user agents model a font has having a particular weight which often corresponds to the list above."

Guessing at the intended meaning, the following wording is proposed:

"Most user agents model a font as having a particular weight which often corresponds to one of the numbers in the nine-step scale mentioned above."
