I'm not sure which spec this belongs in, possibly CSSOM, but we need to define somewhere that in a ~~viewport that has dimensions 0x0~~ document of a display:none iframe, we do not create any CSS boxes.

See https://github.com/whatwg/html/issues/1813#issuecomment-251481552

<!-- comment id=251604023 author=bzbarsky created=2016-10-05T07:39:13Z url=https://github.com/w3c/csswg-drafts/issues/571#issuecomment-251604023 -->
## @bzbarsky — 2016-10-05

That's not correct.  Something like this:

```
<iframe style="width: 0; height: 0"></iframe>
```

should create boxes for stuff inside it.  Pretty sure the web depends on that.
