This was reported in 2016 (and several specs fixed as a result).

It isn't clear, given the rapid pace of spec changes in general, whether there are still errors in these specifications in 2024. Also, since no errors were listed, it is pretty hard to check.

I suggest in future opening specific issues on each specification that has link errors, rather than one mega-issue like this.
