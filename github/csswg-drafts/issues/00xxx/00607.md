Edge and Chrome ignores "min-width: %" while Firefox applies it properly.
Firefox continues to apply a "min-width: %" when a "width: px" is specified (the width is then ignored).

We would like to spec Edge/Chrome behavior here. Any opinion?
cc: @dbaron

<!-- comment id=317532741 author=FremyCompany created=2017-07-24T19:42:38Z url=https://github.com/w3c/csswg-drafts/issues/607#issuecomment-317532741 -->
## @FremyCompany — 2017-07-24

**Summary of the issue**
> Edge and Chrome ignores "min-width: %" on a table cell while Firefox applies it. 

**Face to face recommendation**
> Resolve that min-width is ignored when its value is a percentage on table-internal elements

**Examples**
> https://wptest.center/#/tdspq9
