The specification of fit-content() track sizes is rather vague:
https://drafts.csswg.org/css-grid/#valdef-grid-template-columns-fit-content

My understanding is that a "fit-content(X)" track size should behave as
"minmax('auto', 'max-content'))" while running the "Resolve Intrinsic Track
Sizes" algorithm:  https://drafts.csswg.org/css-grid/#algo-content
with the additional tweak that if the track's base size becomes larger
than X then it is clamped to X.

Is that correct?

If yes, then I have more questions:
1. should the clamping be applied at every step of the algorithm, or only
after the algorithm is done (i.e. between 12.5 and 12.6)?
2. should the "growth limit" be clamped at any point while running
the algorithm?  (I'm guessing not, since "12.6 Maximize Tracks" says to
clamp it there, but the spec could be clearer on this)
https://drafts.csswg.org/css-grid/#algo-grow-tracks

Thanks,
Mats

## @fantasai — 2016-06-21

This is a good point. Originally, I thought that just clamping the growth limit before maximizing the track would work, so I had edited that in. However, in the case of an item spanning both a fit-content() track and a max-content track, this won't give the right behavior: we want the max-content track to absorb any extra space needed for the item into its growth limit once the fit-content() track has hit its maximum.

We're not yet sure of the exact edits to make this fix, but we should definitely fix it. In the meantime... note that the auto minimum is stronger than the specified maximum in fit-content().

<!-- comment id=227592263 author=tabatkins created=2016-06-21T22:32:10Z url=https://github.com/w3c/csswg-drafts/issues/209#issuecomment-227592263 -->
## @tabatkins — 2016-06-21

Looks like we want:
1. Initially, set the growth limit to the fit-content() argument.
2. In 12.5.1, let this fall into the "max-content maximum" case, and apply clamping.
3. In 12.5.2, let this fall into the steps 5 and 6, and clamp both times (in the distribution algo).

Then "Maximize Tracks" can drop the mention of fit-content(), because the growth limit will already have been handled.
