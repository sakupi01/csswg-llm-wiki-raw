https://drafts.csswg.org/css-syntax/#css-stylesheets says

> The prelude of the qualified rule is parsed as a [selector list](https://drafts.csswg.org/selectors-4/#selector-list). If this results in an [invalid selector list](https://drafts.csswg.org/selectors-4/#invalid), the entire style rule is invalid.

The prelude of a [qualified rule](https://drafts.csswg.org/css-syntax/#qualified-rule) is a list of component values, and I can't find any prose that defines how to parse that into a selector.

(Pedantic, I know, but this is much less well-defined than the rest of the otherwise well-written spec.)
