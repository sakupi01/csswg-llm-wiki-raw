In #263, #264 and #269 I've changed percentage combination values to use the combined [`<*-percentage>` values defined in V&U 3](https://drafts.csswg.org/css-values-3/#percentages), though I've not changed the value descriptions accordingly.

The descriptions of the values should be merged like it's already done in [CSS Fonts 3 (not published yet)](https://drafts.csswg.org/css-fonts-3/) and [CSS Images 3](https://drafts.csswg.org/css-images-3/#valdef-size-length-percentage2).
