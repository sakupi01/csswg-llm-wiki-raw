Having a page (column) float span multiple columns is a question that soon gets raised when you have both multi columns and page floats.

We need to figure out a sensible model for making that work, and propose it for inclusion in either the page-floats spec or the next level (2) of multi-col.

Whether we should include it **now** is an separate question, but we need to address it eventually, so this issue is to track that need.

For now, it may be sufficient to make sure that whatever we're specifying is forward compatible with what we'll eventually want. That is a fuzzy thing, since what we eventually want isn't really defined, but we should probably think about it a bit still.

If it was in early version of the spec, do you have a link to the best / latest version to include it, to get a sense of what has already been proposed on this topic?
