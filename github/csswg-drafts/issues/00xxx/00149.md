The algorithm described under [Drawing the Border Image](https://www.w3.org/TR/css3-background/#border-image-process) currently makes no difference whether the `fill` keyword of the of the `border-image-slice` property is set or not. In step 2 it is always talking about "top, middle and bottom" images.

It should be mentioned in the algorithm that in the case the `fill` keyword is not set, it only applies to the top and bottom images.
