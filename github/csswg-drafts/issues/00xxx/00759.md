## @astearns — 2016-11-24

See Custom Properties: https://drafts.csswg.org/css-variables-1/

Your sample can be expressed as:

<style> :root{ --data: 100px; } #Topic{ width: var(--data); } #Topic2{ width: calc(var(--data) + 100px) } </style>
