https://www.w3.org/TR/css-fonts-4/#font-face-src-parsing

```
<color-font-technology> = [COLR | SVG | sbix]
```

Should be something like 

```
<color-font-technology> = [COLR | SVG | sbix | CBDT]
```

to include the CBDT/CBLC format.
