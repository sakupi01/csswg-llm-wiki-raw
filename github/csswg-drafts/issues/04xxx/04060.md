There's persistent confusion that the Computed Value line in the propdef tables defines the output of getComputedStyle(). It doesn't. But we're not clear enough about it because people keep being confused, e.g. https://github.com/w3c/csswg-drafts/issues/2574 , so maybe we need to add some notes to CSSOM / CSS Cascade to draw more attention to the distinction.
