The note in the paragraph <https://drafts.csswg.org/css-writing-modes-3/#typeset-upright> says:

> Unicode published draft data on which characters should appear sideways as the SVO property in this data file; however, this property has been abandoned for the current revision of [UTR50]. 

What happened is that #50 started as a Unicode Technical Report (UTR50, not part of "The Unicode Standard") and defined the property outside the Unicode Character Database. Furthermore, it wasn't "draft" data. In Unicode 10.0, this TR was integrated in TUS and became UAX50, and the property was made part of the UCD. The property was not abandoned, it's only its status wrt TUS that changed (and the migration of the data in the UCD).

Given that this section is about font features and the discussion of UAX50 in the next section, I would suggest to simply remove the quoted text.
