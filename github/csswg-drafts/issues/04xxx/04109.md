This came up as some fun web-compat which LayoutNG had to deal with. Tab asked me to file this so that folks didn't forget. See this TC.
https://www.software.hixie.ch/utilities/js/live-dom-viewer/?saved=7055

When I last checked this:

Engine | Default | Block-level | Inline-level (empty) | Inline-level (non-empty)
-|-|-|-|-
WebKit | block | block | block | inline
Blink (Legacy) | block | block | block | inline
Blink (NG) | block | block | inline | inline
EdgeHTML | block | block | inline | inline
Firefox | inline | inline | inline | inline

The inline-level test changes when some non-empty content is added (forcing a non-empty linebox).
