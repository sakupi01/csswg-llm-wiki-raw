As already mentioned in #4477, [`<alpha-value>`](https://drafts.csswg.org/css-color/#typedef-alpha-value) is redundant with [`<cmyk-component>`](https://drafts.csswg.org/css-color/#typedef-cmyk-component), because both are effectively defined as `<number [0.0, 1.0]> | <percentage>`. Since `color()` shall allow either type as well #3450, it would make sense to have a single value type `<color-component>` for all of these, even if we can never have a generic `<number-percentage>` type in [css-value](https://drafts.csswg.org/css-values).
