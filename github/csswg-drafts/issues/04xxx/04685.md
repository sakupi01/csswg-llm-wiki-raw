## @svgeesus — 2020-01-19

Specifically:

- the right source white point to use for AdobeRGB-compatible profiles really is x=0.3127, y=0.3290
- for sRGB, if we use the unbounded wide-dynamic-range version, ensure a parametric  curve is used not a point curve, which can't be extrapolated below 0 or above 1
- use pre-quantized gamma 1.80078125 (not 1.8, and not 1.8 with a linear shadow region as used in the original Kodak ROMM paper)

## @svgeesus — 2020-11-13

> use pre-quantized gamma 1.80078125 (not 1.8, and not 1.8 with a linear shadow region as used in the original Kodak ROMM paper)

Actually that one is contentious: Adobe software imposes a maximum slope near zero which provides the linear portion as a side effect. Other software does not (or puts it in a different place), so it is in fact better to provide the linear portion explicitly.
