[`leading-trim`](https://drafts.csswg.org/css-inline-3/#leading-trim-property) can cause overflows in block direction. Should these overflow be ink-overflow or scroll-overflow?

@fantasai 

<!-- comment id=577954636 author=fantasai created=2020-01-24T01:28:36Z url=https://github.com/w3c/csswg-drafts/issues/4010#issuecomment-577954636 -->
## @fantasai — 2020-01-24

Good question. I haven't thought about it so deeply. My first thought was ink overflow, but on second thought all it does is make the line box slimmer, and overflowing scrollable overflow in a line box are still scrollable overflow. See [atomic inline testcase](http://software.hixie.ch/utilities/js/live-dom-viewer/?%3C!DOCTYPE%20html%3E%0A%3Cp%20style%3D%22overflow%3A%20scroll%22%3E%0ALine%201%20%3Cspan%20style%3D%22margin%3A%20-2em%200%3B%20height%3A%204em%3B%20width%3A%202em%3B%20border%3A%20solid%20green%3B%20display%3A%20inline-block%22%3EIB%3C%2Fspan%3E%3Cbr%3E%0ALine%202)
