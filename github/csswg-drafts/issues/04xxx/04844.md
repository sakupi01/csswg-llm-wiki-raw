From current CSS2: "This document is also available in these non-normative formats: plain text, gzip'ed tar file, zip file, gzip'ed PostScript, PDF. See also translations."

Given we haven't published anything else in any of these formats forever, I'd rather drop all of them (especially because I don't want to deal with any bugs in the PDF/PS generation!). If we publish any non-normative version, it should be a single-page edition of the spec.

If anyone objects, shout.
