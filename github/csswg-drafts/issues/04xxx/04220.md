The 2015 edition of Writing Modes defined how block containers are sized, but it was deleted together with the definition of how multi-col containers are handled in https://github.com/w3c/csswg-drafts/commit/88d115fdf3f14436fa778dd47ba487d39aca77a3

We need to add back the part that defines how block containers are sized.
