We don't talk about what gets read out for list styling, so we need to specify that more clearly. (It kinda can be argued to fall out from the definition of the `content` property and [@counter-style’s `speak-as` descriptor](https://www.w3.org/TR/css-counter-styles-3/#counter-style-speak-as) but we need to be clearer about it.)
