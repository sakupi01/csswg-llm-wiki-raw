The "Finding the First Letter" subsection has the id [#application-in-css](https://drafts.csswg.org/css-pseudo-4/#application-in-css). This is nonsense.

https://github.com/w3c/csswg-drafts/blob/4ce8f75cd58e5d796969e900f25e81997206511a/css-pseudo-4/Overview.bs#L268-L269

We already have [#first-letter-pseudo](https://drafts.csswg.org/css-pseudo-4/#first-letter-pseudo) and [#first-letter-styling](https://drafts.csswg.org/css-pseudo-4/#first-letter-styling), so I propose #first-letter-finding.

For consistency, [#first-text-line](https://drafts.csswg.org/css-pseudo-4/#first-text-line) could be renamed to #first-line-finding.
