## @MatsPalmgren — 2020-01-10

I'm guessing the example is from a time when the the `grid/grid-template` shorthands accepted a value for just one axis that were then copied to the other axis. That syntax was later removed. So I think the example needs to updated to use `grid: subgrid / subgrid` to be valid.

<!-- comment id=573125974 author=tabatkins created=2020-01-10T17:19:09Z url=https://github.com/w3c/csswg-drafts/issues/4661#issuecomment-573125974 -->
## @tabatkins — 2020-01-10

`subgrid` is defined (slightly above the linked example) to be a value for `grid-template-rows` and `grid-template-columns`; the `grid` property references these properties in its own definition.

But yeah, the current `grid` grammar does require one to specify *both* rows and columns, rather than just one, so the example's syntax needs to be updated to `grid: subgrid / subgrid;`.
