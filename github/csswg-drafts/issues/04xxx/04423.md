Asking for spec clarification, because implementations disagree:
Does empty row group get sized to 0,0?

FF does this.
Chrome/Safari give first row group dimensions of an empty cell.
Edge adds border-spacing inline size to row-group width.

Got a w.p.t testcase coming up, I think it is a definite, not a tentative.

        <x-tbody></x-tbody>
        <x-tbody></x-tbody>
        <x-tbody></x-tbody>
        <x-tfoot></x-tfoot>
    </x-table>

## @atotic — 2019-10-31

As part of my work on understanding height redistribution of tables, I continued investigating treatment of empty TR/TBODY* elements in #4418. The results of investigation are now folded into #4418 , so I will close this issue.

What I've found is that 0-height elements do not grow, unless they are the only element that can grow.
