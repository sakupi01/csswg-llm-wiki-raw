A number of properties have “Computed value: computed color”, it would be nice if these were linked to a definition; however there is no definition of “computed color”.

So this issue is 1) define “computed color” as a term 2) update specs to cross-reference it.

Bonus points to make this an editorial update to css-color-3 as well.
