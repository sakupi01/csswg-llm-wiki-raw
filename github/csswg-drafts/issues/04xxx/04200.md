From a quick glance, the system described at  https://www.w3.org/TR/2002/WD-css3-lists-20021107/#syriac is a complex system like the ancient Tamil one, so it wouldn't currently fit the mold of the ready-made CS doc.

On the other hand, i just added a proposal for an additive style for Syriac that could go in that document if i can get some Syriac (Assyrian) user to check it. See https://github.com/w3c/predefined-counter-styles/issues/44
