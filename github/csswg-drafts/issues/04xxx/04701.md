In the [section on computed keyframes](https://drafts.csswg.org/web-animations-1/#calculating-computed-keyframes) it says

> Computed keyframes are produced using the following procedure. Note that this procedure is only performed on a keyframe effect having an effect target for which computed property values can be calculated.

All of the following procedures for applying an effect rely on the computed keyframes. However, there is nothing in the spec saying that those only apply when property values can be calculated. We should add a note to the keyframe effect intro clarifying this.
