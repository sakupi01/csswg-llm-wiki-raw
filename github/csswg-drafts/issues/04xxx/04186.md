For `tableValues`, the doc states that:

>When type="table", the list of <number> s v0,v1,...vn

But `tableValues` are used by the [discrete](https://www.w3.org/TR/filter-effects-1/#attr-valuedef-type-discrete) type too.

>For discrete, the function is defined by the step function given in the attribute tableValues
