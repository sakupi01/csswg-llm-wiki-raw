Both css-sizing-4 and mediaqueries-4 use a <ratio> type:
https://drafts.csswg.org/css-sizing-4/#aspect-ratio
https://drafts.csswg.org/mediaqueries-4/#typedef-ratio

The former links to the latter for its definition, but it seems it would be better if it were defined in the "CSS Values and Units" spec instead.

## @tabatkins — 2020-04-04

Yeah, we considered this previously, but left `<ratio>` alone in MQ because it was still the only consumer, and we generally want to keep V&U only for cross-language types.

But now that `<ratio>` *is* used across multiple specs, yeah, it probably should migrate to V&U.
