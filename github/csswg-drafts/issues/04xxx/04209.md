Historically there was discussions around addressing the issue of having the position of the list marker match the directionality of the list container (rather than the list item). There have been two different types of proposals: one for a new value to list-style-position, another for a separate property.

Not sure whether there was a discussion of the merits of each approach yet, so filing an issue for it.

Fwiw, here's some notes on the feature request: https://lists.w3.org/Archives/Public/www-style/2010Nov/0197.html
