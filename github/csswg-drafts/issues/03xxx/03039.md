CSS Box Model Module
( https://www.w3.org/TR/css-box-3/#padding-physical / 
https://drafts.csswg.org/css-box-3/#padding-physical )
The “Applies to:” line in the `padding-*` property definition table states
“all elements except internal table elements”,
which seems to over-exlude the table-cell ( and differs from CSS2's box model)
