> Define if changing the working color space should have any impact on the above.

## @svgeesus — 2020-10-21

Tidying up this old issue. As [stated in `Resolving <color> values`](https://drafts.csswg.org/css-color/#resolving-color-values), Computed and used values should remain as specified, modulo decisions about unitary alpha (and commas, for the sRGB ones) so working color space does not affect them. It will affect interpolation, and other places where calculation is done on colors.
