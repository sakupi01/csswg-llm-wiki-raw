https://drafts.csswg.org/css-scroll-snap-1/#intended-direction should specify that clicking on the scrollbar arrows defines an intended direction. Other examples have specified what happens if you move the scrollbar thumb or page by clicking above or below the thumb. Seems odd to have left this one out.
