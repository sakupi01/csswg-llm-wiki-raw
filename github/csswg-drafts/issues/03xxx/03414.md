The `white-space`,  `letter-spacing`, `word-spacing` properties should apply to SVG text as well. SVG2 doesn't specify which, but the likely candidate is [text content elements](https://svgwg.org/svg2-draft/text.html#TermTextContentElement). CC @AmeliaBR 

https://svgwg.org/svg2-draft/text.html#LetterSpacingProperty
