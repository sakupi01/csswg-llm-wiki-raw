Just like we clarify (in [css-text-3 section 5.1](https://drafts.csswg.org/css-text-3/#line-break-details)) that out of flow elements don't create wrapping opportunities, we probably also should clarify that they don't create word boundaries for the purpose of the [text-transform property](https://drafts.csswg.org/css-text-3/#text-transform-property) either.
