> CSS is a language for describing the rendering of structured documents (such as HTML and XML) on screen, on paper, in speech, etc. 

Given we just killed `media` spec-wide, and with CSS speech abandoned, and XML little used on the open Web, maybe we should be revising this sentence which gets auto-added to the abstract of every CSS spec?
