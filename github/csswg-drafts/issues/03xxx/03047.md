This was mentioned in w3c/ttwg#42 ([minutes](https://www.w3.org/2019/06/13-tt-minutes.html#x02)). 

#### tl;dr: 
WebVTT CR normatively references CSS Text Level 4 for a MUST requirement making `text-wrap: balance;` the default - in the absence of evidence of implementation or tests TTWG marked that feature as at risk, with the intention of adding it back in again in a future version.

See also https://github.com/w3c/csswg-drafts/issues/8640#issuecomment-1742949606 in which I argue that `text-wrap: balance` based on line length alone is not an appropriate solution for breaking 2 or 3 line blocks of subtitle/caption text into lines: grammatical constructions need to be taken into account as well.
