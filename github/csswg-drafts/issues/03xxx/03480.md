[Anchor selection](https://drafts.csswg.org/css-scroll-anchoring-1/#anchor-node-selection) works using a DOM tree traversal. This won't work with Shadow DOM as shadow trees are unreachable using the standard parent/child relationships.

I believe we should update the language to use the [flattened element tree](https://drafts.csswg.org/css-scoping/#flat-tree) concept.
