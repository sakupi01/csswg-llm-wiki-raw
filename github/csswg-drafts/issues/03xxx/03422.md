[spec](https://drafts.csswg.org/css-shadow-parts/#exportparts-attr)

E.g.
- `exportparts="button-*: buttons"` would export all inner parts that start with `button-` as `buttons`
- `exportparts="button-*: foo-buttons-*"` would export all inner parts that start with `button-`, replacing `button-` with `foo-`.
