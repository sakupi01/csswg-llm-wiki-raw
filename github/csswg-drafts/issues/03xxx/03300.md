https://drafts.csswg.org/css-text-decor-4/#underline-offset

How about adding normative text: "UAs SHOULD clamp the value of `text-underline-offset` at used-value time to avoid underlines looking like other typographic constructs such as line-throughs or an overline on the next line of text in the paragraph."

Used value time is good because the clamping should interact with text-underline-position.

This text is important for fallback, so the semantic meaning of text doesn't change when the site is viewed on an older browser that doesn't support `text-underline-offset`.
