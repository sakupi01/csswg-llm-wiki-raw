https://drafts.csswg.org/css-logical/#border-radius-properties defines `border-start-start-radius, border-start-end-radius, border-end-start-radius, border-end-end-radius`

It's not clear if e.g. `border-start-end-radius` refers to the corner between the block-start and inline-end borders, or between the inline-start and the block-end ones.

In https://lists.w3.org/Archives/Public/www-style/2015Feb/0504.html it was resolved to do the former, needs to be defined in the spec.
