Current title of the css-sizing-3 is "CSS Intrinsic and Extrinsic Sizing", which was accurate when we first drafted up the spec since it only addressed those topics. But now it hosts the full definition of all the sizing properties, so a rename is in order. I propose "CSS Box Sizing".
