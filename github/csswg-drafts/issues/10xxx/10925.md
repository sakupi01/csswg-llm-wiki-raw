The [Introduction](https://drafts.csswg.org/css-color-5/#intro) explains the need for `color-mix()`, with examples.

It then lists all the additions: `contrast-color()`, `light-dark()`, RCS, `device-cmyk` but does not explain them.

Ideally the Introduction should explain all the changes. Alternatively, move most of the current introduction to the start of `color-mix()` leaving just the list.
