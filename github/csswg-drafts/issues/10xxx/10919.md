The tree counting functions introduced in CSS Values 5, https://drafts.csswg.org/css-values-5/#tree-counting, don't state if they are usable in calc(), and don't declare themselves to be "math functions" like `random()` does for instance - https://drafts.csswg.org/css-values-5/#random.

Should they be usable from within calc()?

<!-- comment id=2359447049 author=Loirooriol created=2024-09-18T21:35:20Z url=https://github.com/w3c/csswg-drafts/issues/10919#issuecomment-2359447049 -->
## @Loirooriol — 2024-09-18

They are still defined as `<integer>`s, which are accepted in `calc()`

<!-- comment id=2359639656 author=tabatkins created=2024-09-18T23:51:11Z url=https://github.com/w3c/csswg-drafts/issues/10919#issuecomment-2359639656 -->
## @tabatkins — 2024-09-18

Yeah, the grammar for calculations in math functions bottoms out in `<number>`, so anything that's that type is meant to work.
