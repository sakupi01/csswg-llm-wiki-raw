The above two specifications [`[CSS3PAGE]`](https://drafts.csswg.org/css-page-3/) and [`[CSS-BREAK-3]`](https://drafts.csswg.org/css-break/) are missing description of how to keep page headers and footers separate from main content.

For examplte, it doesn't seem possible to have main content break to the next page before a footer is being reached.
