## @tabatkins — 2024-07-19

It shouldn't; transforms are post-layout (and generally make the concept of "top/left/etc edges" complex) . Chrome's implementation should *entirely* ignore transforms; if you're seeing any effect of transforms on anchorpos, that's a bug. ^_^
