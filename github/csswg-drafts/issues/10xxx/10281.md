Many CSSWG members have voiced the benefits of creating a specific categorization for CSS levels, see: #4770. In November 2023, we [resolved](https://github.com/w3c/csswg-drafts/issues/4770#issuecomment-1802342332) that the CSSWG will support the efforts of the CSS Next Community Group as we take on this task.

In the meantime, the community group has deliberated and created a draft proposal for categorizing CSS features into CSS3, CSS4 and CSS5 levels. Please take a look at the initial identification and join the discussion via our RFC: https://github.com/CSS-Next/css-next/discussions/92

## @argyleink — 2024-10-28

The proposal from the CSS Next CG has had many months to reach a wide audience and get feedback! We're confident that the proposed levels accurately represent CSS's rapid evolutions. We'd like to add the [levels proposal](https://github.com/CSS-Next/css-next/discussions/92) to an upcoming CSSWG meeting for a final CSSWG review.

We've also begun transitioning the proposal into a [PR drafted from the CSS Next Repo](https://github.com/CSS-Next/css-next/pull/104) that intends to [update the verbiage of the CSS notes](https://github.com/w3c/csswg-drafts/blob/2fde733370f069fde148693456c3b6240051c0d3/css-2024/Overview.bs#L651) to provide details about CSS4 and CSS5. 

The updated note with levels can be previewed here: https://css-levels.netlify.app. 

Adding agenda+ so we can discuss.
