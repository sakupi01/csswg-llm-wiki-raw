https://drafts.csswg.org/css-grid-3/#masonry-slack

> [Computed value:](https://www.w3.org/TR/css-cascade/#computed) 	a computed [`<length-percentage>`](https://www.w3.org/TR/css-values-4/#typedef-length-percentage) value
> [Animation type:](https://www.w3.org/TR/web-animations/#animation-type) 	as length

How to interpolate as a length if the computed value is a `<length-percentage>`? It should interpolate "[by computed value](https://www.w3.org/TR/web-animations/#by-computed-value)", that is, as defined in https://www.w3.org/TR/css-values-4/#combine-mixed
