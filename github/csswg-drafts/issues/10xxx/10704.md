[Scroll tracking](https://drafts.csswg.org/css-overflow-5/#scroll-container-scroll) states:

> A scrolling operation might animate towards a particular position (e.g. scrollbar arrow clicks, arrow key presses, "behavior: smooth" programmatic scrolls) or might directly track a user’s input (e.g. touch scrolling, scrollbar dragging). In either case, the user agent chooses an 'eventual scroll position' to which the scroller will reach. This ensures that the relevant marker is activated immediately.

What is the duration of the "scrolling operation" for user gestures like touch screen scrolls? Is the "scrolling operation" the entire user gesture (e.g. touch-start to touch-end)? Or some shorter time bound?

The duration and "eventual scroll position" calculation for an instant scroll or event a arrow click should be reasonably simple, but could be more complex for user gestures.
