There are some uses of anchor() that can be determined invalid() at parse time. For instance,

```css
left: 10px;
left: anchor(--x top);
```

Should `left` resolve to `10px` here, or the default value?

The spec is a little unclear on when this "[valid anchor function](https://drafts.csswg.org/css-anchor-position-1/#valid-anchor-function)" concept is evaluated and/or if it is something that gets evaluated at each stage.
