https://drafts.csswg.org/css2/#separated-borders

This is specified as an inherited property, but Chromium, Firefox, and WebKit all treat it as not-inherited (see attached [demo](https://ambiguous-kiwi-supermarket.glitch.me/) screenshots). The spec should be updated to indicate this property is not inherited.

Actually, this is a product of the UA stylesheet, which sets `border-spacing` on `table`. However, `border-spacing` will be inherited by, e.g., `<div style="display:table">`.
