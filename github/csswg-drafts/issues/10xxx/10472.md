With https://github.com/w3c/csswg-drafts/pull/10447 landed, linkes to CQ features in contain-3 no longer works. This breaks bunch of documentations or articles in the wild.

I remember there are drafts that keep ids for removed features (e.g. https://drafts.csswg.org/selectors-3/#content-selectors, which has even notes that it's removed ). I wonder if contain-3 could keep such links and perhaps add notes that they've moved to conditional-5, or some client-side redirect from contain-3 to conditional-5 like WHATWG drafts do. What do you think?
