All `CSS*Rule.style` attributes except [`CSSFontFace.style`](https://drafts.csswg.org/css-fonts-4/#cssfontfacerule) are defined with `[SameObject,PutForwards=cssText]`:

  - [`CSSKeyframeRule.style`](https://drafts.csswg.org/css-animations-1/#csskeyframerule)
  - [`CSSPageRule.style`](https://drafts.csswg.org/cssom-1/#csspagerule)
  - [`CSSMarginRule.style`](https://drafts.csswg.org/cssom-1/#cssmarginrule)
  - [`CSSPositionTryRule.style`](https://drafts.csswg.org/css-anchor-position-1/#csspositiontryrule)
  - [`CSSStyleRule.style`](https://drafts.csswg.org/cssom-1/#cssstylerule)

Is it intentional?

The practical implication, in current Chrome/FF version:

```js
const sheet = new CSSStyleSheet()

sheet.replaceSync('style {} @font-face {}')

const style = sheet.cssRules[0]
const font = sheet.cssRules[1]

style.style = 'color: green'
style.cssText; // style { color: green }
font.style = 'font-style: italic'
font.cssText; // @font-face {}
```
