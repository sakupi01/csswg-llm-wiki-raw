Here's a (very hand-wavy) list of features I believe could be added to the "Safe to Release pre-CR Exceptions" section of CSS 2024:

# Typographic pseudo-elements, `::before`, `::after` from CSS [Pseudo-Elements 4](https://drafts.csswg.org/css-pseudo-4/) (basically all from CSS 2 with double-colon syntax plus `::prefix` and `::postfix`)

* Spec. status: WD (last published: 27 June 2025)
* Implemented in all major browsers for many years
* [WPT](https://wpt.fyi/results/css/css-pseudo?label=master&label=experimental&aligned&q=before-after): passing tests: Chrome: 3, Edge: 3, Firefox: 3, Safari: 3; [interop](https://wpt.fyi/results/css/css-pseudo?label=master&label=experimental&aligned&q=before-after%20all(status%3Apass)): 3 / 3 (100.0%)
* Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/labels/css-pseudo-4): ~14, [in spec.](https://drafts.csswg.org/css-page-3/#issues-index): 0

# All from [CSS Animations 2](https://drafts.csswg.org/css-animations-2/)

* Spec. status: WD (last published: 2 June 2023)

# [`font-tech()` and `font-format()` from CSS Conditional 5](https://drafts.csswg.org/css-conditional-5/#at-supports-ext)

* Spec. status: WD (last published: 5 November 2024)
* no issues regarding them
* [implemented in all major browsers since 2023](https://developer.mozilla.org/en-US/docs/Web/CSS/@supports#browser_compatibility)
* [WPT](https://wpt.fyi/results/css/css-conditional/js/CSS-supports-L5.html?label=experimental&label=master&aligned): passing tests ([`font-format()`](https://wpt.fyi/results/css/css-conditional/at-supports-font-format-001.html?label=master&label=experimental&aligned), [`font-tech()`](https://wpt.fyi/results/css/css-conditional/at-supports-font-tech-001.html?label=experimental&label=master&aligned)): Chrome: 9, Edge: 9, Firefox: 9, Safari: 9; interop: 9 / 9 (100%)
* Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acss-conditional-5+%22font-tech%22+%22font-format%22): 1 (only editorial), [in spec.](https://drafts.csswg.org/css-conditional-5/#issues-index): 0

# [`:is()`](https://drafts.csswg.org/selectors-4/#matches), [`:where()`](https://drafts.csswg.org/selectors-4/#zero-matches), [`:has()`](https://drafts.csswg.org/selectors-4/#relational), and [selector lists in `:not()`](https://drafts.csswg.org/selectors-4/#negation) from [Selectors 4](https://drafts.csswg.org/selectors-4/)

* Spec. status: WD (last published: 11 November 2022)
* Implemented in all major browsers since 2021 and `:has()` as part of [Interop 2023](https://wpt.fyi/results/css/selectors?label=master&label=experimental&product=chrome&product=firefox&product=safari&aligned&view=interop&q=label%3Ainterop-2023-has)
* [Selectors 4 was also added to "Rough Interoperability"](https://github.com/w3c/csswg-drafts/issues/9793)
* [WPT](https://wpt.fyi/results/css/selectors?label=master&label=experimental&aligned&q="is-"%20or%20"where-"%20or%20"has-"%20or%20"not-complex"): passing tests: Chrome: 2231, Edge: 2231, Firefox: 2208, Safari: 2158; [interop](https://wpt.fyi/results/css/selectors?label=master&label=experimental&aligned&q="is-"%20or%20"where-"%20or%20"has-"%20or%20"not-complex"%20all(status%3Apass)): 2150 / 2261 (95.1%)
* Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/labels/selectors-4): ~12, [in spec.](https://drafts.csswg.org/selectors-4/#issues-index): 0

# [`conic-gradient()`](https://drafts.csswg.org/css-images-4/#conic-gradients) and [`<color-interpolation-method>` for gradient functions](https://drafts.csswg.org/css-images-4/#:~:text=Added+<color-interpolation-method>+to+all+gradient+functions) from [CSS Images 4](https://drafts.csswg.org/css-images-4/)

* Spec. status: WD (last published: 17 February 2023)
* Implemented in all major browsers
* [WPT](https://wpt.fyi/results/css/css-images?label=master&label=stable&aligned&q=conic-gradient+or+interpolation): passing tests: Chrome: 2512, Edge: 2618, Firefox: 2825, Safari: 2874; [interop](https://wpt.fyi/results/css/css-images?label=master&label=stable&aligned&q=(conic-gradient+or+interpolation)+and+all(status%3Apass)): 2435 / 2948 (82.6%)
* Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+label%3Acss-images-4+"gradient"): ~9, [in spec.](https://drafts.csswg.org/css-images-4/#issues-index): 3

# [`linear()` from CSS Easing 2](https://drafts.csswg.org/css-easing-2/#the-linear-easing-function)

* Spec. status: FPWD (published: 29 August 2024)
* see also https://github.com/w3c/csswg-drafts/issues/7533
* [implemented in all major browsers since 2023](https://developer.mozilla.org/en-US/docs/Web/CSS/easing-function#browser_compatibility)
* [WPT](https://wpt.fyi/results/css/css-easing?label=master&label=experimental&aligned&q=linear-timing): passing tests (experimental): Chrome: 29, Edge: 29, Firefox: 29, Safari: 40; [interop](https://wpt.fyi/results/css/css-easing?label=master&label=experimental&aligned&q=linear-timing+all(status%3Apass)): 28 / 41 (68,2%)
* Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acss-easing-2+%22linear%28%29%22): 1, [in spec.](https://drafts.csswg.org/css-easing-2/#issues-index): 0

# [`transition-behavior`](https://drafts.csswg.org/css-transitions-2/#transition-behavior-property) property, [`@starting-style` rule and `CSSStartingStyleRule` interface](https://drafts.csswg.org/css-transitions-2/#defining-before-change-style) of [CSS Transitions 2](https://drafts.csswg.org/css-transitions-2/)

* Spec. status: WD (last published: 5 September 2023)
* Implemented in all major browsers as [part of Interop 2024](https://wpt.fyi/results/css?label=experimental&label=master&aligned&view=interop&q=label%3Ainterop-2024-starting-style%20or%20label%3Ainterop-2024-transition-behavior)
* [WPT](https://wpt.fyi/results/css/css-transitions?label=master&label=experimental&aligned&q="transition-behavior"%20or%20"starting-style"%20or%20"startingstyle"): passing tests: Chrome: 60, Edge: 60, Firefox: 59, Safari: 60; [interop](https://wpt.fyi/results/css/css-transitions?label=master&label=experimental&aligned&q="transition-behavior"%20or%20"starting-style"%20or%20"startingstyle"%20all(status%3Apass)): 59 / 60 (98.3%)
* Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen%20label%3Acss-transitions-2%20("transition-behavior"%20OR%20"starting-style"%20OR%20"CSSStartingStyleRule")): 6, [in spec.](https://drafts.csswg.org/css-transitions-2/#issues-index): 0

# [`text-decoration-thickness`](https://drafts.csswg.org/css-text-decor-4/#text-decoration-thickness-property), [`text-underline-offset`](https://drafts.csswg.org/css-text-decor-4/#underline-offset) properties and [`from-font` value for `text-underline-position`](https://drafts.csswg.org/css-text-decor-4/#valdef-text-underline-position-from-font) from [CSS Text Decorations 4](https://drafts.csswg.org/css-text-decor-4/)

* Spec. status: WD (last published: 4 May 2022)
* Implemented in all major browsers [since 2021](https://developer.mozilla.org/en-US/docs/Web/CSS/text-decoration-thickness) and earlier
* see also https://github.com/w3c/csswg-drafts/issues/6729
* [WPT](https://wpt.fyi/results/css/css-text-decor?label=master&label=experimental&aligned&q=text-decoration-thickness%20or%20from-font): passing tests (experimental): Chrome: 228, Edge: 228, Firefox: 345, Safari: 179; [interop between Chrome, Edge, and Firefox](https://wpt.fyi/results/css/css-text-decor?label=master&label=stable&product=chrome&product=edge&product=firefox&aligned&q=chrome%3Apass%20edge%3Apass%20firefox%3Apass%20text-decoration-thickness%20or%20from-font): 228 / 345 (66.1%)
* Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acss-text-decor-4+"text-decoration-thickness"+"from-font"): 2, [in spec.](https://drafts.csswg.org/css-text-decor-4/#issues-index): 1

# [`env(safe-area-inset-*)` from CSS Environment Variables 1](https://drafts.csswg.org/css-env-1/#env-function)

* Spec. status: ED (requires to publish a FPWD)
* [implemented in all major browsers since 2020](https://developer.mozilla.org/en-US/docs/Web/CSS/env#browser_compatibility)
* [WPT](https://wpt.fyi/results/css/css-env?label=master&label=experimental&aligned): passing tests (experimental): Chrome: 42, Edge: 42, Firefox: 37, Safari: 37; [interop](https://wpt.fyi/results/css/css-env?label=master&label=experimental&aligned&q=all(status%3Apass)): 37 / 42 (88.1%)
* Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acss-env-1+"env()"+"safe-area-inset"): ~5, [in spec.](https://drafts.csswg.org/css-env-1/#issues-index): 5

# [`accent-color`](https://drafts.csswg.org/css-ui-4/#widget-accent) property, [`auto` value for `outline-color`](https://drafts.csswg.org/css-ui-4/#valdef-outline-color-auto) property, and [`<url-set>`](https://drafts.csswg.org/css-ui-4/#typedef-cursor-url-set) value for the `cursor` property from [CSS UI 4](https://drafts.csswg.org/css-ui-4/)

* Spec. status: WD (last published: 16 March 2021)
* `accent-color` implemented in all major browsers (partially in Safari) since 2022, `auto` value implemented in Safari, `<url-set>` implemented at least in Firefox since 2021
* [WPT](https://wpt.fyi/results/css/css-ui?label=master&label=experimental&aligned&q="accent-color"%20or%20"outline-color"%20or%20"cursor"%20or%20"url-set"): passing tests: Chrome: 483, Edge: 483, Firefox: 482, Safari: 488; [interop](https://wpt.fyi/results/css/css-ui?label=master&label=experimental&aligned&q=("accent-color"%20or%20"outline-color"%20or%20"cursor"%20or%20"url-set")%20all(status%3Apass)): 482 / 490 (98.3%)
* Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen%20label%3Acss-ui-4%20("accent-color"%20OR%20"outline-color"%20OR%20"url-set")): ~5 (1 editorial), [in spec.](https://drafts.csswg.org/css-ui-4/#issues-index): 0

# [`text-box-trim`](https://drafts.csswg.org/css-inline-3/#text-box-trim) and [`text-box-edge`](https://drafts.csswg.org/css-inline-3/#text-box-edge) from [CSS Inline Layout 3](https://drafts.csswg.org/css-inline-3/)

(I believe should be cut now regarding its feature set and a CSSOM 2 spec. started for new features, see #10686.)

-----

For this list I went through all the specs and checked what seems fairly stable to me based on issues within the spec. and on GitHub and/or is already widely implemented in browsers. For some I checked the WPT coverage, though not all. I may go through them and provide some more detailed info. And there are surely some [Interop 2023](https://wpt.fyi/interop-2023) and [2024](https://wpt.fyi/interop-2024) features I didn't list here yet, which might be added.

Everyone is encouraged to edit this list or suggest additions, changes, or removals! And let me know if it makes sense to split it into separate issues to discuss them individually!

Sebastian
