I do not think an algorithm should be explicitly defined but can you please add examples for [`<hue>`](https://drafts.csswg.org/css-color-4/#hue-syntax) normalization?

  > **Example**
  >
  > In `hsl(-540 0 0)` or `hsl(540 0 0)`, the `<hue>` component is normalized to `180`.
  >
  > In `hsl(calc(-infinity) 0 0)` or `hsl(calc(infinity) 0 0)`, the `<hue>` component is normalized to `0`.
