To my knowledge you can't make css grid respect `justify-content: center` and also keep the fluid width and has max-width when using `repeat(auto-fit/fill)`. 

See [this codepen](https://codepen.io/emattias/pen/pombyvW). In the first grid the columns are left aligned. I would like them to be centered like in the second grid (since `justify-content: center` is set on the container).

This might be related to this issue: https://github.com/w3c/csswg-drafts/issues/2611
