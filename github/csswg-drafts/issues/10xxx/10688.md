There is no FPWD and yet [the `linear` easing function](https://drafts.csswg.org/css-easing-2/#the-linear-easing-function) has [been proposed for a pre-CR exception](https://github.com/w3c/csswg-drafts/issues/10687#issue-2447351440).

It would be nice (not needed for FPWD, but would help to justify the pre-CR exception) to add WPT annotations to that spec.There are [25 tests](https://wpt.fyi/results/css/css-easing?label=master&label=experimental&aligned&q=linear) with full interop on those tests.

Thus, https://github.com/w3c/csswg-drafts/labels/Agenda%2B for a resolution to publish.
