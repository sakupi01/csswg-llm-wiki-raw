These issue is from [PINGs HR](https://github.com/w3cping/privacy-request/issues/133) of the "[CSS View Transitions Module Level 2](https://drafts.csswg.org/css-view-transitions-2/)" spec.

These aren't privacy relevant issues, so just filing them as non-blocking suggestions and comments

- I think the same concept / category is referred to both as [page initiated navigation](https://drafts.csswg.org/css-view-transitions-2/#activating-cross-document-view-transition) and [user initiated navigation](https://drafts.csswg.org/css-view-transitions-2/#lifecycle). I think the goal here is just to distinguish CSS-view-transition-relevant navigations from browser initiated navigations (like the URL bar).  But if I'm understanding right and these two terms are describing the same thing, I suggest just using one term throughout the document (either page or user initiated navigations)
- theres a word missing in section 2.1.4, point 2.3 ("This is another opportunity for the author customize the transition")
