## @cdoublev — 2025-10-25

In hindsight, I am pretty sure a style sheet is attached to a document if it is included in `document.styleSheets` or `document.adoptedStyleSheets`, ie. if it is a non-constructed style sheet (`<link>`, `<style>`), or a constructed style sheet included in `document.adoptedStyleSheets`.

```js
const sheet = new CSSStylesheet
sheet.insertRule('@media all {}')
const rule = sheet.cssRules[0]
rule.matches // false (even if its parent style sheet is "associated" to the document)
document.adoptedStyleSheets.push(sheet)
rule.matches // true
```

So a *style sheet attached to the document* is a style sheet included in the [*document or shadow root CSS style sheets*](https://drafts.csswg.org/cssom-1/#documentorshadowroot-document-or-shadow-root-css-style-sheets). I do not know what is the difference with the [*final CSS style sheets*](https://drafts.csswg.org/cssom-1/#documentorshadowroot-final-css-style-sheets).

Also tagging @SebastianZ, which said:

  > If it's attached to a document, it is always evaluated against that document, even when accessed from another document.
