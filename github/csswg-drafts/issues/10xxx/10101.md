> If document’s [active view transition](https://drafts.csswg.org/css-view-transitions-1/#document-active-view-transition) is not null, then [skip](https://drafts.csswg.org/css-view-transitions-1/#skip-the-view-transition) document’s active view transition.

I noticed this while implementing in WebKit, the current spec doesn't say which reason / exception to pass to the skip the view transition algorithm.

## @nt1m — 2024-03-20

I also noticed another bug in the spec:

In https://drafts.csswg.org/css-view-transitions-1/#ViewTransition-prepare

> If document’s [visibility state](https://html.spec.whatwg.org/multipage/interaction.html#visibility-state) is "hidden", then [skip](https://drafts.csswg.org/css-view-transitions-1/#skip-the-view-transition) transition with an "[InvalidStateError](https://webidl.spec.whatwg.org/#invalidstateerror)" [DOMException](https://webidl.spec.whatwg.org/#idl-DOMException), and return.

We should be returning the `transition` here, instead of returning nothing.
