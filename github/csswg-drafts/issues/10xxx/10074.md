In [4.4. Jzazbz](https://drafts.csswg.org/css-color-hdr/#Jzazbz) it says:

> In contrast, the Jz axis in Jzazbz, which has a [0, 1.0] range, uses Perceptual Quantizer encoding, and can represent a dynamic range of more than 13 stops.

Although the Sadfar et al paper makes that claim, it is not actually correct. They started with the PQ function but then altered various parameters to optimize results with their color datasets.

This is further discussed [here](https://github.com/coloria-dev/coloria/issues/41) which I just ran into again while checking something else.

So this statement should be changed to "uses an encoding similar to Perceptual Quantizer"
