Last publication was a [CR Snapshot on 13 January 2022](https://www.w3.org/TR/2022/CR-css-conditional-3-20220113/).

The current ED is dated [27 July 2024](https://drafts.csswg.org/css-conditional-3/) and there have been [5 substantive changes since](https://drafts.csswg.org/css-conditional-3/#changes). 

Also the current ED has WPT annotations and so lists **1706 tests** while the CR has the old widget pointing to the now-abandoned testsuite mirror and declares there are **87 tests**.

We should therefore publish a CR Draft.
