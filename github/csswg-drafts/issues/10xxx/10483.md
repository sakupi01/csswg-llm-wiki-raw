[`CSSPageDescriptors.orientation`](https://drafts.csswg.org/cssom-1/#dom-csspagedescriptors-orientation) was added in #10482:

  > `@page{ orientation: ... }` Is generally treated the same as `@page{ size: ... }` [...]

In Chrome 126 and FF 127:

  ```js
  const sheet = new CSSStyleSheet()
  sheet.replaceSync('@page { orientation: portrait }')
  sheet.cssRules[0].cssText; // @page { }
  ```

Is it intented to be an attribute for [`page-orientation`](https://drafts.csswg.org/css-page-3/#page-orientation-prop)? (#10105) If so, is it intentional that its name is not `pageOrientation`?
