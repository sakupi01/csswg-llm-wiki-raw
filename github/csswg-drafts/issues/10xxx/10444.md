As it stands right now, [the Visual Viewport is defined in the `cssom-view` spec](https://drafts.csswg.org/cssom-view/#visualViewport). This feels like it’s in the wrong place, given that we have [a `css-viewport` spec](https://drafts.csswg.org/css-viewport) nowadays.

I think that that section, and by the looks of it [the section on events](https://drafts.csswg.org/cssom-view/#events) too, should move to `css-viewport`. Some of [the extensions to the `Window` interface](https://drafts.csswg.org/cssom-view/#extensions-to-the-window-interface) should move too.
