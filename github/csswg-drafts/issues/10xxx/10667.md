In CSS Basic Shapes 2, the `[shape()](https://drafts.csswg.org/css-shapes-2/#shape-function)` function allows you specify points with `to` or `by` which indicates whether the point, _and its control points_, are specified in "absolute" terms relative to the bounding box, or in "relative" terms from the current path point.

However, in many cases I think authors will want to specify control points relative to the path point that they are attached to. I should be able to say something like `curve to 120px 140px with -12px -10px / 15px 20px` to say that the first control point is at `-12px -10px` relative to the start of the segment, and the second one is at `15px 20px` relative to the end point.

We'd need some reasonable behavior for quadratic segments, and smooth segments.

<!-- comment id=2264181236 author=smfr created=2024-08-01T23:12:40Z url=https://github.com/w3c/csswg-drafts/issues/10667#issuecomment-2264181236 -->
## @smfr — 2024-08-01

Another enhancement is to allow authors to specify control point positions as percentages of their path segment, which means we have two ways to resolve percentages on control points: relative to the reference box, and relative to the "segment box" (a box enclosing the two end points of the segment).

![control point options](https://github.com/user-attachments/assets/d1cb423e-9571-4eb5-86d2-10c12ccf678d)

<!-- comment id=2264184532 author=smfr created=2024-08-01T23:15:19Z url=https://github.com/w3c/csswg-drafts/issues/10667#issuecomment-2264184532 -->
## @smfr — 2024-08-01

If we allow segment-relative percentages, authors will need to be able to mix and match for the two axes on a control point (say, using segment-% for the horizontal component, and box-% for the vertical), since a segment's start and end point can be at the same X or Y position.

## @smfr — 2024-09-25

I think we could also simplify things by collapsing the different segment types by using `auto`. For example, `hline` could 
be:

```
line to auto, 30px
```

 and `vline` could be:

```
line to 50px, auto
```

We could also collapse `smooth` into `curve`:

The smooth cubic curve `smooth to 120px 140px with 150px 200px` could be:
```
curve to 120px 140px with auto / 150px 200px
```

and the smooth quadratic curve `smooth to 120px 140px` could be:
```
curve to 120px 140px with auto
```
