* CSS Animations Level 1

* The **animation-duration** property - according to the spec - is parsed as `<time [0s,∞]>#`. However, both MDN page AND screenshots from Chrome and Edge show the keyword 'auto' is supported for both non-prefixed and -webkit- prefixed in these chromium browsers (see attached). However, Firefox does NOT support the 'auto' keyword for non-prefixed property (pls see attached). Can this discrepancy between docs and chromium browsers pls be clarified? Is 'auto' a non-standard keyword or did the W3C documentation accidentally miss this keyword as a viable value for **animation-duration**?

* [link to section of spec](https://www.w3.org/TR/css-animations-1/#animation-duration)
