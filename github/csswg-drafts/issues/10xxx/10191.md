Referring to this line: https://github.com/w3c/csswg-drafts/blob/3b93f2402397add5b201f5628532ee5b29f900bc/css-color-5/Overview.bs#L847

It reads: `...or be specified as a channel keyword referring to one of the channels of the origin color.`

At this point there is no mention of the origin color being converted to the color being specified yet, so the assumption might be that specifying `rgb(from hsl(0, 100% 50%) h s l)` the `h`, `s` and `l` keywords should work.

But perhaps that does need to be said earlier.
