Hi,

Sorry if this has been asked or not, but I could not find anything. Does the scroll driven animation support synchronizing the scrollLeft position based on the progress of a given element?

I know we could use transform to do this, but transform does not interact the same way with sticky element, and sometimes it would be useful to actually synchronize the scroll position.

Thanks

<!-- comment id=2465518396 author=flackr created=2024-11-08T18:44:02Z url=https://github.com/w3c/csswg-drafts/issues/10545#issuecomment-2465518396 -->
## @flackr — 2024-11-08

No, scroll driven animations use the scroll position as input to calculate the progress through an animation. There is no support for setting the scroll position. If you have a specific proposal, we could consider it for the level 2 spec, however there are no current designs that would support this.
