We more-or-less aligned text-box-trim propagation with the way margin collapsing works, but while we specified that intervening non-zero borders/padding break propagation, non-zero blocks don't, which results in weird effects like trimming through a visible block-level element. These should also block propagation.

<!-- comment id=2289977960 author=fantasai created=2024-08-14T21:48:41Z url=https://github.com/w3c/csswg-drafts/issues/10743#issuecomment-2289977960 -->
## @fantasai — 2024-08-14

Alternatively, we could have _any_ block-level content prevent propagation, as I'm not sure there's a much of a use case for propagating through empty block-level boxes... (though it is more consistent with margin collapsing).
