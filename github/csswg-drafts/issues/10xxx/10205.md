Native context menus, popups and tooltips are also displayed outside the native program window in the operating system.

 What if popovers etc. could also display like this?

 With defined rules for displaying and disappearing, there would be no risk to the user.  For example, the user may be misled into clicking on some native element of the operating system and entering confidential data there.  But with appropriate rules, such a threat would not arise.
