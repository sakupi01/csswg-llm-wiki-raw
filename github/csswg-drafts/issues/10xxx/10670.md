* CSS Values and Units Module 5

* Examples 4 and 5 in section 6.3 use a semicolon (;) separator, but should be comma (,)

* [Section 6.3](https://drafts.csswg.org/css-values-5/#toggle-notation)

<!-- comment id=2265612717 author=cdoublev created=2024-08-02T15:09:01Z url=https://github.com/w3c/csswg-drafts/issues/10670#issuecomment-2265612717 -->
## @cdoublev — 2024-08-02

They uses a valid syntax (see [3.1.1. Commas and Semicolons in Functions](https://drafts.csswg.org/css-values-5/#component-function-commas): `,` can be replaced with `;` in functions). I do not know if there is a "canonical form" that examples should use though.

## @tabatkins — 2024-08-02

The examples are indeed valid, but I don't actually want to show that off unless necessary. I've gone ahead and switched every example to commas except the few that actually do require it, or that are showing off the semicolon syntax.
