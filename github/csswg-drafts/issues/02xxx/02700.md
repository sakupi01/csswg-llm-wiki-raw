The list of properties that apply to initial letters seems unnecessarily restrictive. E.g. fill/stroke should apply. What restrictions are actually necessary?

<!-- comment id=391787230 author=fantasai created=2018-05-24T16:59:20Z url=https://github.com/w3c/csswg-drafts/issues/2700#issuecomment-391787230 -->
## @fantasai — 2018-05-24

@dauwhe and I are thinking to say that any properties that apply to an inline box also apply to an initial letter, except for `vertical-align` and friends.

<!-- comment id=391934886 author=frivoal created=2018-05-25T04:03:19Z url=https://github.com/w3c/csswg-drafts/issues/2700#issuecomment-391934886 -->
## @frivoal — 2018-05-25

You need to exclude `font-size` as well:
* We're calculating the size of the initial letter differently anyway
* That's what safari does (except for a bug where `font-size:0` makes the whole initial letter disappear)
* It's useful to set the font-size to a large value, to be used as a fallback if the initial-letter property is not supported, without having that interfere somehow with the initial-letter

<!-- comment id=392105102 author=fantasai created=2018-05-25T16:04:35Z url=https://github.com/w3c/csswg-drafts/issues/2700#issuecomment-392105102 -->
## @fantasai — 2018-05-25

'font-size' affects how ems are calculated, though, so it has to apply. We don't want to change the length computation rules for initial letters.

<!-- comment id=392154951 author=emilio created=2018-05-25T19:16:44Z url=https://github.com/w3c/csswg-drafts/issues/2700#issuecomment-392154951 -->
## @emilio — 2018-05-25

Why does forbidding specifying font-size in `::initial-letter` require changing length computation rules? I'd assume inheritance would work normally. Anyway no big deal, was just curious.

<!-- comment id=392241968 author=frivoal created=2018-05-26T06:59:04Z url=https://github.com/w3c/csswg-drafts/issues/2700#issuecomment-392241968 -->
## @frivoal — 2018-05-26

I guess it can be described as applying, then we add a note clarifying that it has no effect on the sizing of the initial letter itself, only on font-relative length units.
