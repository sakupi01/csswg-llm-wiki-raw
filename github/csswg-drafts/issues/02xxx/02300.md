## @smfr — 2021-10-25

drop-shadow is like a filter; it operates on the pixels of the element to which it's applied, unlike backdrop-filter which operates on the pixels of things painted behind the element to which it's applied. Note that you can replicate the appearance of drop-shadow with SVG filters.
