Hit testing is an important concept that's invoked from a number of places, but is defined nowhere. CSS should own it and spec it.

<!-- comment id=2859142051 author=svgeesus created=2025-05-07T15:55:13Z url=https://github.com/w3c/csswg-drafts/issues/2325#issuecomment-2859142051 -->
## @svgeesus — 2025-05-07

 There is no WPT for hit testing on `opacity: 0` elements and [the opacity property](https://drafts.csswg.org/css-color-4/#transparency) does not mention hit testing, _at all_. At minimum, it should say that opacity does not affect hit testing; and once there is a spec it should link to that. Currently, the sole definition is "see what existing browsers do".
