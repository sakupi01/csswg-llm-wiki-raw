## @rachelandrew — 2018-04-17

There is an example further on in that section explaining that margins do not collapse. 

When we have a spanner, we get a new set of column boxes after the spanner. A 'column row', and I think the margin collapsing rules are defined. It isn't so much an "interruption" of the content, as the column does not continue on the other side of the break. The column boxes end with the spanner, we then start over again with the next set.
