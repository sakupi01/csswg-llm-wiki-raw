The current draft of CSS Backgrounds and Borders Module Level 4 defines the [background-position-x](https://drafts.csswg.org/css-backgrounds-4/#propdef-background-position-x) and [background-position-y](https://drafts.csswg.org/css-backgrounds-4/#propdef-background-position-y) properties with their "Animation type" set to "discrete" which means these properties cannot be interpolated. That seems like a mistake.
