## @gsnedders — 2020-07-10

One of the changes we resolved to accept the text of in https://www.w3.org/Bugs/Public/show_bug.cgi?id=17121#c6 is:

> The table wrapper box establishes a block formatting context, and the table box establishes a table formatting context.

We never define "table box", just "table wrapper box" and "table grid box": I presume this should be the latter?

(Do we need a resolution for this given it is, pedantically, changing an existing resolution?)
