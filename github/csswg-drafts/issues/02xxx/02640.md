In [CSS2](https://www.w3.org/TR/CSS22/generate.html#counters) there is no `counter-set` property.

In [CSS Lists](https://drafts.csswg.org/css-lists/#propdef-counter-set) there is this `counter-set` property.

So I expect this new property to appear in the [Changes From CSS2.1](https://drafts.csswg.org/css-lists/#changes) section.
