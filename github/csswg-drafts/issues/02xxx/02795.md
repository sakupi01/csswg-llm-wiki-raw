The Fonts 3 testsuite now shows only  [one failing test](https://test.csswg.org/harness/results/css-fonts-3_dev/grouped/filter/1/) which is for `font-feature-values`. We resolved to remove that feature, deferring it  to Fonts 4, which I just did. It was marked as at-risk in the March 2018 CR. I have [a one-line pull request on web platform tests](https://github.com/web-platform-tests/wpt/pull/11563) which updates the `rel=help` to point to Fonts 4 instead of Fonts 3.

Once that change is accepted there will be **zero failing tests** and we have **met our CR exit criteria**.

I would like a CSS WG resolution to request transition to Proposed Recommendation for Fonts 3.
