[`image-set()` notation](https://drafts.csswg.org/css-images-4/#image-set-notation) has an [example](https://drafts.csswg.org/css-images-4/#example-c6e2e672) using `x` units for `<resolution>`. Link for `<resolution>` specification points to [css-value-3](https://drafts.csswg.org/css-values-3/#resolution-value), which doesn't have `x` unit. While [css-value-4](https://drafts.csswg.org/css-values-4/#resolution-value) has `x` unit and should be used for `<resolution>` link in `image-set()` section.

I didn't find a way to change a link in [css-images-4/Overview.bs](https://github.com/w3c/csswg-drafts/blob/master/css-images-4/Overview.bs) :(
