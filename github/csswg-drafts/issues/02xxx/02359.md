In several procedures, the Web Animations spec says to "make animation’s start time unresolved". Does this mean that implementations should use the [setting the start time of an animation](https://drafts.csswg.org/web-animations/#setting-the-start-time-of-an-animation) procedure or simply make the stored *startTime* value unresolved?

## @graouts — 2018-02-25

I'm pretty sure the spec means simply to set the stored *startTime* value.
