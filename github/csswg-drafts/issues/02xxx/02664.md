It would be great if the CSS spec would specify that the pointer must get rendered as link-pointer (as if value "pointer" is set) (shown eg as a hand/glove) when it is hovering over a linked area (eg an "a" element in SVG).

https://drafts.csswg.org/css-ui-3/#cursor

https://bugs.chromium.org/p/chromium/issues/detail?id=841146

## @AmeliaBR — 2018-05-10

I agree that it makes sense to add to [the SVG user-agent stylesheet](https://svgwg.org/svg2-draft/styling.html#UAStyleSheet). There is a similar rule in [the HTML user-agent stylesheet](https://html.spec.whatwg.org/multipage/rendering.html#phrasing-content-3). Some but not all browsers apply the rule to SVG links.

@tobireif Could you file the matching issue on the SVG repo, linking back here?

But the concept of "link" is more generic than any particular element namespace. So, it also makes sense to consider whether a general rule is appropriate in CSS UI.

<!-- comment id=388234153 author=frivoal created=2018-05-11T01:39:12Z url=https://github.com/w3c/csswg-drafts/issues/2664#issuecomment-388234153 -->
## @frivoal — 2018-05-11

I am not too enthusiastic about listing in css-ui all the possible types of hyper links that exist in all possible types of markup (there are not that many popular markup languages, but still), but I think a general statement like "UAs must apply `cursor: pointer` to hyperlinks for all supported document formats via the UA stylesheet, using a normal (i.e. not !important) declaration" would be OK, and then individual markup languages like SVG would make the more specific requirement about what that means exactly for them.

## @AmeliaBR — 2018-05-11

> I am not too enthusiastic about listing in css-ui all the possible types of hyper links that exist in all possible types of markup

I was assuming that the guidance could build on the `:link` and `:visited` pseudoclasses.  This is what the HTML user agent stylesheet uses. I assume the difference between browsers is whether they restrict the rule by element namespace or not.

But Florian's open-ended prose description works. [The Selectors spec](https://drafts.csswg.org/selectors-4/#location) doesn't really bother trying to define what is and isn't a hyperlink, either.
