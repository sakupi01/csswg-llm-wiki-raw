Issue 16 says "Text is easy, as are simple closed, non-self-intersecting paths, but the other categories exist and need good definitions." but this isn't true. Fonts may contain self-intersecting paths. The OpenType 1.8 spec explicitly requires that all conformant implementations must correctly handle self-intersecting paths, and they are common in variable fonts.
