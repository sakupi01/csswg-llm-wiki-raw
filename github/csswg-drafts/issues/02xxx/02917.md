The [`<name-repeat>` definition](https://drafts.csswg.org/css-grid-2/#typedef-name-repeat) is currently set to `repeat( [  | auto-fill ], +)`.

I'm not clear how to interpret that value:
- Does `[ | auto-fill ]` mean an empty value is allowed?
- What does the `+` apply to? Shouldn't the definition use `#` (and drop the comma)?

That was a typo in the spec source - the non-terminals weren't written right, so Bikeshed didn't turn them into links, and they instead got parsed as start tags. ^_^
