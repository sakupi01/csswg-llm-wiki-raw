## @svgeesus — 2018-05-24

> However, the new image has a white background, unlike the old one which was transparent. It's kind of hard to make the white background transparent since the font is anti aliased.

Use the antialiased image as the alpha channel; set a solid color on the color channel(s). Convert to PNG with alpha transparency. Will now display, anti-aliased, on any background.
