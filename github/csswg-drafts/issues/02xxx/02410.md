As discussed in TAG [review](https://github.com/w3ctag/design-reviews/issues/230) and at Web Components F2F (2018-03, Tokyo), update [spec](https://drafts.csswg.org/css-shadow-parts/) so that

**part=** handles naming only and becomes a space-separated token list (just like **class=**)
**partmap=** handles forwarding
