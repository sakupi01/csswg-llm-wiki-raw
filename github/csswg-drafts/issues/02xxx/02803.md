Noticed by @plehegar and @swickr during the transition call for CSS Fonts 3: although Values & Units is in the normative references, it is nt actually referenced anywhere. In particular, the definition for `font-size` does not link to V&U for `length-percentage`.

This is already corrected in Fonts 4, so this issue is just to backport the definition (well, the link; the spec text will be unchanged) from Fonts 4 to Fonts 3.
