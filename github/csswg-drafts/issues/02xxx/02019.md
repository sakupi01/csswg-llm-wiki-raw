Let's pretend you're on a computer with a font named "Helvetica" installed. If you then say document.fonts.load() with "Helvetica", you should get 0 results. (Similarly if you iterate across document.fonts).

Also, if you add a new FontFace object to document.fonts with the family name "Helvetica" and call load() with "Helvetica", it should only ever be possible to get the FontFace object you just added.

This should be true for document.fonts as well as any FontFaceSet objects you create via "new".

I don't believe the spec has any language about preinstalled fonts.

## @tabatkins — 2017-12-01

This is already specified. `.load()` is very explicit about this (it calls "find the matching font faces" without the "allow system fonts" flag), while the `FontFaceSet` itself implicitly defines this, in that it defines that @font-face rules get added to it, and allows authors to add more to it; there's no text defining how system fonts get put into it, or how they'd be represented.
