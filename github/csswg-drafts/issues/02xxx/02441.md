See https://drafts.csswg.org/css-font-loading/#font-face-source:

      [Exposed=(Window,Worker)
       NoInterfaceObject]
      interface FontFaceSource {
        readonly attribute FontFaceSet fonts;
      };

The two extended attributes should be separated by a comma.
