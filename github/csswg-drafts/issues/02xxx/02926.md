## @fantasai — 2018-07-26

`dominant-baseline` should definitely inherit. Otherwise it would reset itself to the initial value every time someone introduces a `<span>` or `<a>`!

And then you couldn't set it on a document and expect it to take effect across the entire thing, properly excepting sections which need a different `dominant-baseline`.

The change was deliberate. The SVG1.1 initial value has more magic than ours: it behaves like `inherit`, but only when you set it on a descendant of a `<text>` element. You can get away with that model if you don't have much structure, as SVG1.1 text doesn't, but it is unworkable in a structured document markup language like HTML. Hence the change to simplify `auto` and make the property actually inherit.
