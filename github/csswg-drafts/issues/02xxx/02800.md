In [css-contain-1 section 3.3 "Style Containment"](https://drafts.csswg.org/css-contain-1/#containment-style), the "counter-set" property-name is nicely linkified, but "counter-increment" and "content" are not, for some reason.

Let's make them linkified, if we can!

(I imagine this is some bikeshed / spec-HTML-building infrastructure issue, under the hood, and perhaps there needs to be some sort of disambiguation or something in the bikeshed markup? *shrug*)
