## @frivoal — 2018-02-19

The whole note should be dropped. 

`appearance` was once expected to be able to make ordinary elements look like native controls and to be able to make native controls look like ordinary elements. The current version of the specification only supports doing the later, but that note was written assuming it could do the former. So the note is essentially wrong, and should be removed.
