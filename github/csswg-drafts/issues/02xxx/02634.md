The user agent should be able to update user agent values when needed (e.g. the orientation of the page changes). I am not sure how this would affect substitution.

Reparse on computation, right? I don't think we want to reparse the specified value... It should just behave like `var()`.

## @tabatkins — 2018-05-07

There's an open issue for that. We might want to do it on specified values. There's no concept of "computed value" outside of properties, after all; when would a var()-equivalent substitution happen for `@media (width <= env(foo)) {...}`?

<!-- comment id=387217133 author=upsuper created=2018-05-07T21:47:02Z url=https://github.com/w3c/csswg-drafts/issues/2634#issuecomment-387217133 -->
## @upsuper — 2018-05-07

On evaluation time.

Style engines should not be asked to reparse the sheet from CSS in general because the in-memory data may be updated via CSSOM, and you can get new declaration from script, so anything which cannot be preserved in specified value is basically lost forever.
