## @SelenIT — 2018-03-11

@Nadya678, this whole issue has been resolved in [#2085](https://github.com/w3c/csswg-drafts/issues/2085#issuecomment-362000362). The whole note about the "variance" has been removed from both [css-flex-1] and [css-grid-1] specs, since the single option for calculating margins/paddings of flex/grid items has been chosen. All browsers decided to switch to Chrome's behavior.

P.S. Please cite the latest Editor's drafts (e.g. https://drafts.csswg.org/css-flexbox/#item-margins), which usually incorporate the most recent edits, instead of /TR/ publications, which can be rather outdated.
