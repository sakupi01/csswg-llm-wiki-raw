Hi ya'll, somewhat confusing title - let me explain! 😄 

Let's say I have this code:

```
button {
   /* 
    .....
   */

   /* Cool effect */
    background-color: steelblue;

    &:where(:not([disabled])) {
      &:where(:not(:active):hover) {
         background-color: tomato;
      }

      &:where(:hover:active) {
        background-color: aquamarine;
      }
    }
  }
}
```

In this case it could be neat and cool if I could mixin this out like this:

```
@mixin --cool-effect {
  background-color: steelblue;
  
      &:where(:not([disabled])) {
        &:where(:not(:active):hover) {
           background-color: tomato;
        }
  
        &:where(:hover:active) {
          background-color: aquamarine;
        }
      }
    }
}
```

and use it:

```
button {
  @apply --cool-effect;
}
```

Will this even possible?

Take care, have a nice day! :)

## @mirisuzanne — 2025-06-04

Yes, this is one of the core features of the proposal. Mixins act like nested styles wherever they are applied. I tested [your code](https://codepen.io/miriamsuzanne/pen/RNPogvy/e711af36904ef8529f3c385e04810ae4?editors=0100) with the experimental chrome pre-release, and it works as expected.
