As per https://developer.apple.com/documentation/realitykit/construct-an-immersive-environment-for-visionos#Generate-efficient-textures Display P3 is the best color space for visionOS. Display P3 Linear would still require some conversion, but it's significantly less than with rec-2100-linear for instance. This is because it's very close to the final color space. And as a result display-p3-linear has better performance.

Therefore colleagues and I think it's a good idea to add display-p3-linear to CSS, 2D Canvas, etc.

## @jonsneyers — 2025-10-09

Just a nitpick on the name: wouldn't it make more sense to call this simply `p3-linear` instead of `display-p3-linear`?

My reasoning is like this: "P3" defines the color primaries, while the "Display" part indicates that it is using the transfer function of sRGB. This is in contrast with DCI-P3 which uses the same primaries as Display P3 but a different transfer function (a gamma 2.6).

But of course if the transfer function is linear, then it's not the sRGB transfer function like in Display P3, and it feels a bit weird to include the `display-` part in the name.
