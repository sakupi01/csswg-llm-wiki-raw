## Context
This issue introduces the [Pointer Progress Timelines](https://drafts.csswg.org/pointer-animations-1/#pointer-timelines). These timelines are linked to progress in the pointer position over an element’s principal box along a particular axis.

The module defines two concepts to specify this progress:
_pointer range_: the size of the element’s principal box along the axis of the pointer progress timeline.
_pointer offset_: the position of the pointer relative to the start of the element’s _pointer range_.

As currently specced, the _pointer range_ is as defined by [offsetX](https://www.w3.org/TR/cssom-view-1/#dom-mouseevent-offsetx) and [offsetY](https://www.w3.org/TR/cssom-view-1/#dom-mouseevent-offsety) in cssom-view-1, meaning that the padding edges of the element’s principal box are used to define the start and end points of the timeline.
If necessary, we can later add sub-properties to change/extend that definition or add insets.

## Proposal 
Accept spec text that follows pointer events and uses padding edges by default.
