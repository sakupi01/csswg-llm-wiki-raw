https://drafts.csswg.org/css-text-decor-4/#text-decoration-skipping

First, only longhands can actually inherit.

Sure, saying that a shorthand inherits can be understood as meaning that all of its longhands inherit.

But in this case `text-decoration-skip-self` is a longhand and doesn't inherit.

So `text-decoration-skip` should just say:

> Inherited: See individual properties
