Currently the CSS overflow spec is referring to the OpenUI explainer for focusgroup. As a CG OpenUI doesn't produce specifications and it feels wrong that CSS is normatively dependent on a CG explainer. More of an issue is the fact that focusgroup isn't far from complete as an concept even in explainer form and has somewhat stalled.

If CSS overflow needs this concept and some subset of behaviour, it seems to me that it should be defined within CSS.
