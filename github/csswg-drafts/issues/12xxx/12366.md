I think we should rename basic appearance to base appearance. Imo basic could have negative connotations that base wouldn't carry. These styles are a solid (importantly usable) base from which to build rather than being "basic" and *needing* adjustments.

## @Shrinivassab — 2025-06-18

Thanks @lukewarlow for bringing this up.

I agree that base appearance is a clearer and more neutral term than basic appearance. "Base" implies a foundation meant to be built upon, which fits the intent of providing usable default styles.

"Basic", on the other hand, may unintentionally suggest a limited, unfinished, or even discouraged baseline, especially in design/UX discussions.

If the goal is to communicate that these are useful, foundational styles, base appearance aligns more intuitively with author expectations.

Would love to hear if there was any previous rationale for choosing "basic" initially. Happy to help draft updated terminology if consensus forms around the rename.
