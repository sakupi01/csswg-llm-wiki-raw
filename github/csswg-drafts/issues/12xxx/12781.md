Data to consider:

* Spec. status: WD (last published: 16 March 2021)
* `accent-color` implemented in all major browsers (partially in Safari) since 2022, `auto` value implemented in Safari, `<url-set>` implemented at least in Firefox since 2021

## @SebastianZ — 2026-03-09

To give a little more context for [`<url-set>`](https://drafts.csswg.org/css-ui-4/#typedef-cursor-url-set):

It's a version of `image-set()` restricted to `<url>` values, basically extending the existing capability for defining a cursor by providing _multiple resolutions_ of a cursor image and letting the UA decide which is most appropriate in a given situation.

- I've tested it now via https://jsfiddle.net/SebastianZ/fhwj8y42/ in all major browsers and it is supported in all of them.
- [WPT](https://wpt.fyi/results/css/css-ui?label=master&label=experimental&aligned&q=%22url-set%22): no tests
- Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen%20label%3Acss-ui-4%20%22url-set%22): 0, [in spec.](https://drafts.csswg.org/css-ui-4/#issues-index): 0
