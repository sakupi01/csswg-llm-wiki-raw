Splitting the discussion from #10687 for adding [`text-box-trim`](https://drafts.csswg.org/css-inline-3/#text-box-trim) and [`text-box-edge`](https://drafts.csswg.org/css-inline-3/#text-box-edge) from [CSS Inline Layout 3](https://drafts.csswg.org/css-inline-3/) to the Safe to Release pre-CR Exceptions section of the CSS Snapshot 2025.

Data to consider:

* Spec. status: WD (last published: 18 December 2024)
* experimentally implemented in Safari, Chrome, and Edge
* [WPT](https://wpt.fyi/results/css/css-inline/text-box-trim?label=experimental&label=master&aligned): passing tests (experimental): Chrome: 252, Edge: 252, Firefox: 66, Safari: 238; [interop between Chrome, Edge, and Safari](https://wpt.fyi/results/css/css-inline/text-box-trim?label=master&label=experimental&aligned&q=chrome%3Apass%20and%20edge%3Apass%20and%20safari%3Apass): 198 / 294 (67.3%)
* Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+label%3Acss-inline-3+("text-box-trim"+OR+"text-box-edge")): 17, [in spec.](https://drafts.csswg.org/css-inline-3/#issues-index): 2 (1 editorial)

Summary: Low interoperability, many open issues
