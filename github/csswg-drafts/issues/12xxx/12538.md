I noted that css-ui includes a reference to `:focus-visible` but when describing outline (in both prose and code in example 2) it uses `:focus`.  It worries me that people are likely to read and simply copy this, but this will almost always wind up creating problems (hence the creation of `:focus-visible`.

see https://drafts.csswg.org/css-ui/#outline-width

Happy to send a PR or something if it's necessary
