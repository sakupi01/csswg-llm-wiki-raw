This makes sizing of form controls less magical and feel like the rest of CSS.

It might also be worth tweaking the behavior of `field-sizing: content` to fill the whole inline-size when `display: block` is used (or maybe this warrants a new value for `field-sizing`?)

I do think there should be a default size to controls that is reasonable for users to type in though, so we might want some UA styles to achieve that.
