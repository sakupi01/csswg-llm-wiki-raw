I propose allowing // single-line comments in CSS, similar to JavaScript and many other languages. 

This would improve readability and developer experience.

Example of usage in CSS:

```
.table-cell--number-small{
    text-align: right;
    white-space: nowrap; // Amount numbers in cells should not wrap.
}
```
