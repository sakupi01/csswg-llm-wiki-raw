Given we've resolved to add a password visibility toggle to password inputs in the base appearance mode (https://github.com/w3c/csswg-drafts/issues/11845#issuecomment-2770494974) can we now drop input-security from the specification (it's been moved to css-forms from css-ui)

See also https://github.com/w3c/csswg-drafts/issues/6788 for why an author accessible property is considered a bad idea.

Alternatively, could it be useful to explain the password toggle in terms of this property but not expose it outside the UA stylesheet (similar to overlay?).
