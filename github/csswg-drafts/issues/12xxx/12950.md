The Form Controls spec defines the `::field-text` and `::placeholder` pseudo-elements twice, once for `<input>` and once for `<textarea>`. They should just be defined once, generically, and the HTML hookup should be an example, similar to how the slider-like controls are defined.

(Try to think of the spec as being written for "generic markup language", with HTML as the primary example, rather than as being written as part of the HTML spec.)
