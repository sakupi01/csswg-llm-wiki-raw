### Current Problem 

At this moment in time, there is no way to create wavy borders. Many design systems, websites and libraries resort to using svgs to get the same effect. 

### Why do we need this particular border style? 

It would enable users to be able to get rid of svgs (which can sometimes be large in size) and use something that is native to the web. 

### Why are existing alternatives not sufficient?

Many times users have to figure out alternatives to getting this border effect. Creating an svg is one way of getting around the issue. Other workarounds include creating a background with a radial gradient that has an ellipse. Though these solutions work they are not very elegant for something that should be so simple. 
 
### What does this new style unlock?

It would enable users to get rid of the alternatives of using svgs, math or backgrounds to achieve something that should work out of the box. It would also enable users to use different border styles together, for example having a double border with a wavy border and being able to broaden the look and feel of a website. 

### How Corners would be handled

We already have rounded corners for borders and believe this should be integrated into this style, with the radius of each wave within the border being handled similarly. 

Let’s say you have a wavy border that has a radius of 4px, this should be applied to the current style of rounded borders. 

### How border thickness would be handled 

This should be something that works similar with the radius of each wave within the border. Though this is something that could be a concern going forward. 

### Radius of the curve and How It Could Be Handled 

As mentioned above, each “wave” within the border should have the same radius that is applied.
