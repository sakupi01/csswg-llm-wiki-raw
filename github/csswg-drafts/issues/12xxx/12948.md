This is not right:
> [CSS Syntax Level 3](https://www.w3.org/TR/css-syntax-3/) [[CSS-SYNTAX-3]](https://www.w3.org/TR/css-2024/#biblio-css-syntax-3)
Replaces CSS2§4.1, CSS2§4.2, CSS2§4.4, and CSS2§G, redefining how CSS is parsed.

and should be modified to:
> [CSS Syntax Level 3](https://www.w3.org/TR/css-syntax-3/) [[CSS-SYNTAX-3]](https://www.w3.org/TR/css-2024/#biblio-css-syntax-3)
Replaces CSS2§4.1 **excepting §4.1.3**, CSS2§4.2, CSS2§4.4, and CSS2§G, redefining how CSS is parsed.


because CSS2 §4.1.3 is referenced in [[SELECTORS-3]](https://www.w3.org/TR/2018/REC-selectors-3-20181106/)
