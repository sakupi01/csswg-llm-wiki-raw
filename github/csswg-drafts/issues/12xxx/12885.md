In the original issue it was [resolved](https://github.com/w3c/csswg-drafts/issues/2528#issuecomment-2769621512) to be placed in Fonts 5, however Chrome team’s [feedback](https://github.com/w3c/csswg-drafts/issues/2528#issuecomment-3336857019) argues:

> - We think the feature belongs to css-text, rather than css-fonts.  
    It's similar to the `text-align` property.

We should resolve on if we want it to stay in Fonts 5, or move to Text 4.

I don't have an opinion on this. I'll open the remaining issues with the `[css-fonts-5]` in their titles and labels as it was resolved so far, but we could adjust things as we go.
