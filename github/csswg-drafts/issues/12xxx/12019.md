In #10866 we defined design principles for appearance:base form controls.  I think the initial list of principles seem reasonable, but I think they need more testing -- we need to work through some example cases where the different principles come into conflict and see if we agree with the result we get based on how those principles are prioritized in the spec.

I'm in the process of writing up a presentation on an example (the `min-inline-size` and `min-block-size` declarations for `<button>`) that I think could prompt a useful discussion.  I'm hoping to be able to present this at our face-to-face next week.  I'll try to share more once I have it written, but I wanted to get this issue filed sooner rather than later for the purpose of planning the agenda for next week's face-to-face.
