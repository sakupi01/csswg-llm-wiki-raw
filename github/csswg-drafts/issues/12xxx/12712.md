Splitting the discussion from #9793 for adding [Media Queries 5](https://www.w3.org/TR/mediaqueries-5/) to the Modules with Rough Interoperability section of the CSS Snapshot 2025.

Data to consider:

Current status: WD (last published: 18 December 2021), ED from 28 August 2025
[WPT](https://wpt.fyi/results/css/mediaqueries?label=master&label=stable&aligned&q=prefers-reduced-motion%20or%20prefers-reduced-transparency%20or%20prefers-contrast%20or%20prefers-color-scheme%20or%20light-level%20or%20inverted-colors%20or%20custom-media): passing tests: Chrome: 93, Edge: 97, Firefox: 89, Safari: 91; [interop](https://wpt.fyi/results/css/mediaqueries?label=master&label=stable&aligned&q=(prefers-reduced-motion%20or%20prefers-reduced-transparency%20or%20prefers-contrast%20or%20prefers-color-scheme%20or%20light-level%20or%20inverted-colors%20or%20custom-media)%20and%20all(status%3Apassed)): 87 / 107 (81.3%)
Current Snapshot section: -
Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Amediaqueries-5): 93 (~47 substantial for this spec. level), [in spec.](https://drafts.csswg.org/mediaqueries-5/#issues-index): 10

Summary: High interoperability, though many open issues. Looks like WPTs for some features are missing, but some important ones are there. Though as not all features are supported by browsers, maybe only the interoperable ones should be added to Safe to Release pre-CR Exceptions.
