## @andreubotella — 2025-09-18

In particular, the question is: if clamping by height results in the clamp point being immediately after an independent formatting context, but the IFC has a line box at the end that does fit the "immediately preceding" conditions, do we place the ellipsis inside the IFC?

In this edit, the answer is no – no line would have an ellipsis in this case.
