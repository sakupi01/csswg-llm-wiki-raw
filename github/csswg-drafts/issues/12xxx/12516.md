## @tabatkins — 2025-08-27

Ohhhh, I see the problem. That toggle is indeed busted. It doesn't actually trigger dark mode; it just sets a class on the body and enables a stylesheet that (without using the MQ) overrides all the color vars with dark values. That means all the Bikeshed-added styles that *do* depend on the MQ (like the highlight colors) don't work; they'll still apply their light-mode colors.

I'll fix, this is silly.
