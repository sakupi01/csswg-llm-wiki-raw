IIUC, `FontFace` properties is supposed to correlate 1-1 with `@font-face` descriptors. However `sizeAdjust` (for `size-adjust`) is missing in the spec, while it's implemented in all three browsers.

I'm reading https://drafts.csswg.org/css-font-loading/#fontface-interface and this issue comes out of https://github.com/mdn/content/issues/36587

<!-- comment id=3135045046 author=cdoublev created=2025-07-30T06:42:26Z url=https://github.com/w3c/csswg-drafts/issues/12537#issuecomment-3135045046 -->
## @cdoublev — 2025-07-30

`@font-face` descriptors are defined in both CSS Fonts 4 and 5. `size-adjust` is only defined in CSS Fonts 5 at the moment, so my best guess is that it will be added as a `FontFace` attribute when backported to CSS Fonts 4.
