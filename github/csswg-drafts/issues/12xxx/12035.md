The most recent publication of CSS Color 4 was [13 February 2024](https://www.w3.org/TR/2024/CRD-css-color-4-20240213/). Since then, there have been [a number of changes in response to comments](https://drafts.csswg.org/css-color-4/#changes-from-20240213) so, despite there being open issues, an updated CRD is overdue.

**Proposed Resolution:** Publish an updated CRD of CSS Color 4
