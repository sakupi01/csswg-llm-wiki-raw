`light-dark()` and system colors [depend on the color mode](https://drafts.csswg.org/css-color-5/#absolute-color). Should initial values that include `light-dark()` or a system color be considered not computationally independent?


From [css-properties-values-api-1](https://drafts.css-houdini.org/css-properties-values-api-1/#computationally-independent):

> A property value is computationally independent if it can be converted into a computed value using only the value of the property on the element, and "global" information that cannot be changed by CSS.

However, if `color-scheme` is set:

```css
:root {
  color-scheme: dark;
}
```

then the computed value of non-absolute colors like  `light-dark()` or system colors may change.

So should initial values that include `light-dark()` or a system color be considered valid?

See also: w3c/css-houdini-drafts#1125
