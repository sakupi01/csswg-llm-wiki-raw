Splitting the discussion from #9793 for adding [CSS Color 5](https://www.w3.org/TR/css-color-5/) to the Modules with Rough Interoperability section of the CSS Snapshot 2025.

Data to consider:

Current status: WD (last published: 18 March 2025), ED from 1 September 2025
[WPT](https://wpt.fyi/results/css/css-color?label=master&label=stable&aligned): passing tests: Chrome: 9627, Edge: 9626, Firefox: 10563, Safari: 10727; [interop](https://wpt.fyi/results/css/css-color?label=master&label=stable&aligned&q=all%28status%3Apass%29): 9394 / 10999 (85.4%)
Current Snapshot section: -
Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acss-color-5): 30, [in spec.](https://drafts.csswg.org/css-color-5/#issues-index): 0

Summary: High interoperability. Both CSS Color 5 Relative Colors and CSS Color 5 `color-mix()`, were [cleared-to-ship pre-CR in CSS 2023](https://www.w3.org/TR/css/#CR-exceptions). Relative Colors were part of [Interop 2024](https://wpt.fyi/interop-2024). `color-mix()` was part of [Interop 2023](https://wpt.fyi/interop-2023) in the [Color Spaces and Functions](https://wpt.fyi/results/css?product=chrome&product=firefox&product=safari&aligned=&view=interop&q=label%3Ainterop-2022-color+or+label%3Ainterop-2023-color&label=master&label=experimental) focus area.
