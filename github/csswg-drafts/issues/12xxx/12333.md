## @bfgeek — 2025-06-14

> Is the behavior supposed to be different for a replaced element than for a non-replaced one?

I think they are different as for a replaced element you don't need to layout any internals to get the min-content size in the block-axis.

For non-replaced you do (and we use an "indefinite" intrinsic block-size for that calculation).

<!-- comment id=2972023070 author=Loirooriol created=2025-06-14T00:20:38Z url=https://github.com/w3c/csswg-drafts/issues/12333#issuecomment-2972023070 -->
## @Loirooriol — 2025-06-14

I want to make sure to avoid the need to layout a non-replaced multiple times in order to get a consistent behavior with replaced. So I want either inconsistent behaviors, or change the replaced behavior.
