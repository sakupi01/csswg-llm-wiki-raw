For example:

```
@mixin --m() {
  @env --x:1;
  & { --a: env(--x); }
  @env --x:2;
  & { --b: env(--x); }
}
```

What is the value of `--a` and `--b` here?

<!-- comment id=3234488537 author=tabatkins created=2025-08-28T18:16:45Z url=https://github.com/w3c/csswg-drafts/issues/12675#issuecomment-3234488537 -->
## @tabatkins — 2025-08-28

I wasn't originally intending it to be order-dependent, but given our resolutions last week to make "stylesheet-level" things just apply as they come, yes, I think `@env` would be order-dependent and you'd get different values for `--a` and `--b` here.

(However, I think I'd prefer that, for a given rule scope, we just take the last definition. I haven't given it enough thought yet to know if that is possible for the other stylesheet-level things, like custom media.)
