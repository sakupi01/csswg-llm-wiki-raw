In CSS Flexbox 1, section [9.9.1.2. Web-compatible Intrinsic Sizing Algorithm](https://www.w3.org/TR/2025/CRD-css-flexbox-1-20251014/#intrinsic-main-sizes-compat) is an aspirational but entirely empty section where an algorithm might be added later. (thus, no consensus, untestable, etc).

This looks like a prime candidate for moving to a new, delta-spec, css-flexbox-2 so that the rest of flexbox-1 can move towards Recommendation.
