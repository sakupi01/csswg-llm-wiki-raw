`text-decoration-line: blink` is deprecated. Its value is still parsed for compatibility. I'd like to clarify if it should or should not be serialized to the computed value.

Currently, Safari and Chrome ignore it and Firefox doesn't.

This [WPT](https://wpt.fyi/results/css/css-text-decor/parsing/text-decoration-line-computed.html?label=master&label=experimental&aligned&q=text-decoration-line) test, for example, expect it to be serialized.

It seems that Chrome is planning to match Firefox behavior as per a [recent change](https://chromium-review.googlesource.com/6734038).
