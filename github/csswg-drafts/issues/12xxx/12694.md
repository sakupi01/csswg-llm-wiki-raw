Splitting the discussion from #9770 for adding [CSS Conditional 4](https://www.w3.org/TR/css-conditional-4/) to the Reliable Candidate Recommendations section of the CSS Snapshot 2025.

Data to consider:

Current status: CR (last published: 17 February 2022), ED from 31 August 2025
[WPT](https://wpt.fyi/results/css/css-conditional?label=master&label=stable&aligned): passing tests (stable): Chrome: 3041, Edge: 3109, Firefox: 2671, Safari: 2839; [interop](https://wpt.fyi/results/css/css-conditional?label=stable&label=master&aligned&q=all(status%3Apass)): 2622 / 3202 (81.9%)
Current Snapshot section: Rough Interoperability
Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acss-conditional-4): 4, [in spec.](https://drafts.csswg.org/css-conditional-4/#issues-index): 1

Summary: High interoperability, spec. in CR, few open issues

Notes: This spec. is currently still a delta spec. against Level 3. And Level 3 is currently part of the Official Definition.

Sebastian
