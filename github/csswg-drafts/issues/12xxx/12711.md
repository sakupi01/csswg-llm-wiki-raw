Splitting the discussion from #9793 for adding [CSSOM View 1](https://www.w3.org/TR/cssom-view-1/) to the Modules with Rough Interoperability section of the CSS Snapshot 2025.

Data to consider:

Current status: WD (last published: 17 March 2016), ED from 10 September 2025
See also #8559
[WPT](https://wpt.fyi/results/css/cssom-view?label=master&label=stable&aligned): passing tests: Chrome: 2089, Edge: 2009, Firefox: 2211, Safari: 1668; [interop](https://wpt.fyi/results/css/cssom-view?label=master&label=stable&aligned&q=all(status%3Apass)): 1569 / 2338 (67.1%), 2063 / 2338 (88.2%) in [Chrome and Firefox](https://wpt.fyi/results/css/cssom-view?label=master&label=stable&aligned&q=chrome%3Apass+and+firefox%3Apass)
Current Snapshot section: -
Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acssom-view-1): 161, [in spec.](https://drafts.csswg.org/cssom-view-1/#issues-index): 7

Summary: High interoperability between two engines, though many open issues

Note: The spec. urgently needs an updated WD. It got many smaller and bigger changes since 2016.

Sebastian
