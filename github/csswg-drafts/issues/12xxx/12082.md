At present, some special HTML elements compute `display: contents` to `display: none`.(https://drafts.csswg.org/css-display/#unbox).
By default, web browsers hide `<style>` and `<script>` elements using the `display: none` property. However, when `display: contents` is applied, the script will be displayed as text. Should we create specific exceptions for `<style>` and `<script>` elements as well?

<!-- comment id=2804865800 author=Loirooriol created=2025-04-15T12:21:24Z url=https://github.com/w3c/csswg-drafts/issues/12082#issuecomment-2804865800 -->
## @Loirooriol — 2025-04-15

Treating it as `display:none` is done for replaced elements, kinda-replaced elements or elements with magic behavior. I see no reason to do it for `<style>` and `<script>`. Just don't set `display: contents` if you don't want to see the contents.
