As a follow-up to Interop2022’s [Viewport Investigation Effort](https://github.com/web-platform-tests/interop-2022-viewport/), I’m filing this issue that came up.

In issue https://github.com/web-platform-tests/interop-2022-viewport/issues/17 it was noted that most browsers do not return correct values for `window.outerWidth` and `window.outerHeight`. They do this to help mitigate tracking.

We suggest to add a small note to the spec allowing UAs to spoof the value.
