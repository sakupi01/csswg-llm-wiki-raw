@r12a wrote:

> There appears to be no way to set the width of the gap introduced by autospace. That turned out to be something that content authors had different opinions about, or may use different widths in different contexts.

Note this has been brought up a few times over the years. We might not introduce such controls in the first level, but we should be prepared to do something about it in the future.

As far as I'm aware, the main request is for control over inter-script spacing (not over, e.g. punctuation spacing, which at least in French is fairly standardized). I suspect we can have one point of control for both `ideograph-alpha` and `ideograph-numeric`. Would be good to confirm.
