Chrome/FF do not follow [serialization](https://drafts.csswg.org/css-easing-2/#serialization) for specified values. Does this section only define serialization of computed/resolved value?

```js
style.transformTimingFunction = 'step-start'
style.transformTimingFunction; // 'step-start'
style.transformTimingFunction = 'step-end'
style.transformTimingFunction; // 'step-end'
style.transformTimingFunction = 'steps(1, end)'
style.transformTimingFunction; // 'steps(1, end)'
style.transformTimingFunction = 'steps(1, jump-end)'
style.transformTimingFunction; // 'steps(1, jump-end)'
```
