> A Task Force is a subset of a Working Group dedicated to progressing a specific deliverable or set of deliverables on behalf of that group.

> The objective of the CSS-SVG Effects Task Force (FX TF) is to jointly develop features for use in both CSS and SVG

## @tabatkins — 2022-11-11

In practice, the difference is just that the FXTF repo holds a few CSS specs for historical reasons. Questions about those specs in particular should be asked in the fxtf repo, but otherwise everything should be done here in csswg-drafts.
