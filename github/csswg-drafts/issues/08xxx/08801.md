The [rules for serializing a CSS component value](https://drafts.csswg.org/cssom/#serialize-a-css-component-value) don't currently say anything about `calc()` or other math functions.  I think they should probably link to the definition of [serialize a math function](https://drafts.csswg.org/css-values-4/#serialize-a-math-function) in an appropriate way.

(In other words, we've created definitions that define the behavior, but we haven't normatively linked to those definitions as we should.)
