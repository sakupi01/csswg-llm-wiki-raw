I'm finding the [Anchor Positioning Spec](https://drafts.csswg.org/css-anchor-position-1/) pretty hard to read and digest. I suggest the following improvements:

* Add a simple example in the Intro with a motivating use case (e.g. tooltip or whatever)
* Have separate sections on computing the anchor element  (default vs explicit) and the length computations
* Describe the anchor element selection constraints (e.g. about it being in the containing block hierarchy) in prose in the section on computing the anchor element.
* Clarify whether "automatic anchor positioning" is about automatic choosing of the anchor element, or automatic position values, or both.
* Give more examples, with pictures, for the length computations
