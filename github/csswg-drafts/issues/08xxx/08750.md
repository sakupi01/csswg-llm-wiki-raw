Reading the Display Module, I get the impression that only elements in the element tree generate boxes while text sequences don’t. My guess is that they don’t generate boxes but are wrapped in anonymous boxes and the type of the box depends on the formatting context the text sequence is in?

<!-- comment id=1522179802 author=tabatkins created=2023-04-25T17:47:23Z url=https://github.com/w3c/csswg-drafts/issues/8750#issuecomment-1522179802 -->
## @tabatkins — 2023-04-25

You closed this, but just to follow up: right, text sequences aren't boxes, but the formatting context they're in will generate anonymous boxes around them as necessary.

<!-- comment id=1522220948 author=TKDev7 created=2023-04-25T18:22:32Z url=https://github.com/w3c/csswg-drafts/issues/8750#issuecomment-1522220948 -->
## @TKDev7 — 2023-04-25

@tabatkins Thanks for the followup! I can only think of one case where a text or text sequence won’t be wrapped by an anonymous box, and that is an inline-level content inside an inline box
