I think `oklab()` cannot use `c` and `h` in Example 11 for [RCS](https://drafts.csswg.org/css-color-5/#relative-colors):

```js
html { --base:  oklch(52.6% 0.115 44.6deg) }
.summary {
  background:  oklab(from var(--base) l c  calc(h + 90));
}
```
