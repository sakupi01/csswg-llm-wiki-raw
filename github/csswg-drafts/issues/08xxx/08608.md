https://drafts.csswg.org/css-cascade-5/#at-import:

> Additionally, if a [&lt;supports-condition>](https://w3c.github.io/csswg-drafts/css-conditional-3/#typedef-supports-condition) blocks the application of the imported style sheet, the UA must not fetch the style sheet (unless it is loaded through some other link) and must return null for the import rule’s CSSImportRule.styleSheet value (even if it is loaded through some other link).

But https://drafts.csswg.org/cssom-1/#dom-cssimportrule-stylesheet is not nullable.

I think the fix is obvious (just make it nullable). Not sure if that needs a resolution tho?
