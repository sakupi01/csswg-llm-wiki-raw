> https://drafts.csswg.org/css-page-3/#cascading-and-page-context
> * Count the number of page type names (= f)
> [...]
> * Count the number of ':first' or ':blank' pseudo-classes (= g)
> * Count the number of ':left' or ':right' pseudo-classes (= h)

`:first`, `:blank`, `:left`, and `:right` ought to be hyperlinked to the respective term definitons within this spec (e.g. https://drafts.csswg.org/css-page-3/#valdef-page-left , https://drafts.csswg.org/css-page-3/#valdef-page-first , etc.).

Likewise, "page type names" should be hyperlinked here. I suppose to https://drafts.csswg.org/css-page-3/#using-named-pages , though a more precise anchor would be appreciated. There seems to be some muddling of phraseology ("page type name" vs. "named page type") in the spec.
