The features listed as at-risk in the [document status section](https://drafts.csswg.org/selectors-4/#sotd) seem outdated.

Since `:has()` is now implemented in WebKit and Chromium, it probably shouldn't be marked as at-risk anymore.
Furthermore, `:read-write` is implemented in all main browser engines for a long time already. So I guess it can also be removed from the list.
And last but not least, there's a note under `:blank` that it's at-risk, there's [still some discussion around it](https://github.com/w3c/csswg-drafts/issues/1967) and there is no implementation so far, though it is currently _not_ listed in the document status. So I believe it should definitely be added there.

Sebastian
