Scroll animations redefines the [`AnimationTimeline` interface](https://drafts.csswg.org/scroll-animations-1/#animationtimeline) but this is already defined [in Web Animations](https://drafts.csswg.org/web-animations-1/#the-animationtimeline-interface). This creates conflicting definitions for readers and in the spec database.

We should probably do the `CSSNumberish` change in Web Animations level 2--in fact we already do but we should probably highlight that it is a change there. Then we should make the additions to the `AnimationTimeline` timeline in Scroll Animations (i.e. `getCurrentTime`) via a `partial interface` and drop the `currentTime` member from there.

(On a side-note, I think `resolveCurrentTime` would be better than `getCurrentTime` since `getCurrentTime` overlaps with the getter for `currentTime`.)
