https://drafts.csswg.org/css-sizing-4/#intrinsic-contribution-override

Consider:
```html
<!DOCTYPE html>
<div style="display: grid; float: left;">
  <div style="overflow-y: scroll; min-height: 100px; min-intrinsic-sizing: zero-if-scroll;">
    thisisaverylongword
  </div>
</div>
```

As specified the current logic would compress the intrinsic size in both axes to zero (as we are checking for a scroll container). Typically either one axis or the other is desired in many scrollers.

@bfgeek It seems reasonable for the zeroing behavior to not apply to axes that have `hidden` overflow, only to axes with `scroll` or `auto`. That would solve this problem and maybe also make more sense in general?

<!-- comment id=1499290734 author=bfgeek created=2023-04-06T15:57:50Z url=https://github.com/w3c/csswg-drafts/issues/8620#issuecomment-1499290734 -->
## @bfgeek — 2023-04-06

@fantasai - Not necessarily - web developers often just put `overflow: auto` on an element, and there will just happen to be no scrollable overflow in one axis. I suspect it'd be a mistake to compress both axes by default.
