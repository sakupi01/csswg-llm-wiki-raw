https://drafts.csswg.org/css-rhythm/#block-step-size

Has there been any sort of discussion of whether this property should be animatable or not? It seems like it is still an open question according to the spec, but has there been any movement one way or the other? 

<!-- comment id=1434308188 author=birtles created=2023-02-17T08:45:04Z url=https://github.com/w3c/csswg-drafts/issues/8459#issuecomment-1434308188 -->
## @birtles — 2023-02-17

Unless there's a strong reason not to (e.g. properties that create cyclic dependencies with animations) all properties should be animatable. The spec currently has both an "Animation type" and "Animatable" line for the property but it only needs the "Animation type" line.
