https://drafts.csswg.org/css-backgrounds-4/#misc just keeps saying

> See the section [“Layering, Layout, and Other Details”](https://w3c.github.io/csswg-drafts/css-backgrounds-3/#shadow-layers) for how [...] interacts with other comma-separated drop shadow properties to form each drop shadow layer.

But the link points to L3, where `box-shadow` is a longhand.

This section needs to define these box shadow properties as a [coordinating list property group](https://drafts.csswg.org/css-values/#coordinating-list-property) and choose which one is the [coordinating list base property](https://drafts.csswg.org/css-values/#coordinating-list-base-property).
