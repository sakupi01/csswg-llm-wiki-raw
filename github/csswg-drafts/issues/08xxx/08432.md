Bikeshed gives fatal errors on CSS-2023 (as it did on CSS-2022):

```
FATAL ERROR: Unknown spec name 'css2' on <index type="value"
FATAL ERROR: Unknown spec name 'css-fonts-3' on <index type="value"
```

I don't understand what the issue s with those two spec names. I tried `css-2` and also `css3-fonts` and got the same errors.

@tabatkins any hints?

<!-- comment id=1423502981 author=tabatkins created=2023-02-09T02:03:04Z url=https://github.com/w3c/csswg-drafts/issues/8432#issuecomment-1423502981 -->
## @tabatkins — 2023-02-09

Ah, I catch the css2 error in linking, but index generation goes a different path. The WebRef name for it is `css22`.

And WebRef doesn't index Fonts 3 (they skip a few older specs when the next level is a stable replacement), so I guess we should just remove it?

<!-- comment id=1425150139 author=svgeesus created=2023-02-10T04:11:47Z url=https://github.com/w3c/csswg-drafts/issues/8432#issuecomment-1425150139 -->
## @svgeesus — 2023-02-10

The trouble is that the [official definition](https://w3c.github.io/csswg-drafts/css-2023/#css-official) has a normative ref to CSS Fonts 3 (which is a Rec) while CSS Fonts 4, which is indeed a stable replacement and current work, and current implementation target, is not a CR and is just an informative reference from [rough interop](https://w3c.github.io/csswg-drafts/css-2023/#rough-interop).
