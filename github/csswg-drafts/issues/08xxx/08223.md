> https://drafts.csswg.org/css-page-3/#page-based-counters
> Counters can be defined and controlled within an `@page` rule, [...]

Since this is the first usage of the term "counter(s)" outside of this spec's intro, for the sake of convenience and clarity, I'd recommend hyperlinking "Counters" in this sentence to the general CSS definition of that term, i.e.:

* https://drafts.csswg.org/css2/#counter
* https://www.w3.org/TR/CSS2/syndata.html#counter
