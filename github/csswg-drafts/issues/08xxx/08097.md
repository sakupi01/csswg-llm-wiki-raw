[`viewport-fit`](https://drafts.csswg.org/css-round-display-1/#viewport-fit-descriptor) is defined in CSS Round Display as a descriptor of `@viewport`, which was [removed](https://github.com/w3c/csswg-drafts/issues/4766) from [CSS Device Adapt, which is replaced by CSS Viewport](https://github.com/w3c/csswg-drafts/issues/7590), which may not redefine `@viewport`, iiuc.

I think that a red warning under the definition of `viewport-fit` explaing this would be usefull. I do not know if `viewport-fit` should be removed or preserved until CSS Viewport defines an alternative.

Cross-referencing #171, which seems to be a work in progress on `viewport-fit`.

Cc @tidoust for (not?) extracting `@viewport`.

## @cdoublev — 2025-03-11

Fixed by #11757. `@viewport/viewport-fit` has been removed and [`viewport-fit`](https://drafts.csswg.org/css-round-display-1/#viewport-fit) is now a property of the `content` attribute of  `<meta name="viewport">`.
