Per the W3C security and privacy document https://www.w3.org/TR/security-privacy-questionnaire/#considerations

> Specifications should have both "Security Considerations" and "Privacy Considerations" sections to help implementers and web developers understand the risks that a feature presents and to ensure that adequate mitigations are in place.

These sections in the old scroll-animations-1 spec were [removed](https://github.com/w3c/csswg-drafts/commit/fc6766d95aeb0768ec8a09253d73114090369614) when the new spec replaced it, and should be rewritten / re-added.
