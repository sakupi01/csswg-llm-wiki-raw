[`-webkit-line-clamp`](https://drafts.csswg.org/css-overflow-4/#webkit-line-clamp) must *unconditionnaly* set `block-ellipisis` to `auto`. Why is it not set to `none` when `-webkit-line-clamp: none` is specified? Is this behavior intentional? 

I suspect it is an oversight in the edit fixing #3695.

**EDIT:** I guess it is intentional, to allow serializing `-webkit-line-clamp` instead of `line-clamp` in more appropriate cases.
