The [default document timeline](https://drafts.csswg.org/web-animations-1/#default-document-timeline) should be `for="document"` since they're per document.

[Document timelines](https://drafts.csswg.org/web-animations-1/#document-timeline) should have a `<dfn for="document timeline">document</dfn>` so their association is properly defined.
