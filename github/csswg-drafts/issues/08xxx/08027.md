With the [addition of the `stripes()` function](https://github.com/w3c/csswg-drafts/pull/7029), [`<flex>` values](https://w3c.github.io/csswg-drafts/css-grid-1/#typedef-flex) are now used outside of the Grid spec.

So as discussed in the PR linked above, the definition of `<flex>` should be generalized and moved to the Values & Units spec. It might also be renamed to `<fraction>` as [suggested](https://github.com/w3c/csswg-drafts/pull/7029#issuecomment-1104458371) by @LeaVerou.
