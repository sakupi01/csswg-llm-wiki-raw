Following changes made to address #8798, I note that https://w3c.github.io/csswg-drafts/css-page-4/ does not redirect to https://drafts.csswg.org/css-page-4/ and instead returns a 404. I suspect that is because the spec needs to be re-generated because it currently exists under [`Overview.html`](https://w3c.github.io/csswg-drafts/css-page-4/Overview.html) instead of `index.html` and GitHub Pages do not understand `Overview.html`.

(I don't know whether the `w3c.github.io` URL is used anywhere to reference that spec. I suspect MDN only references Level 3 for instance)
