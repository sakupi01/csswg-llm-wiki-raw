In the [view transitions spec](https://drafts.csswg.org/css-view-transitions-1/) we want to write prose about the current play state of an animation.

It feels like this prose is right:

> If animation's play state is paused…

If that's correct, I propose:

- Make [play state](https://drafts.csswg.org/web-animations-1/#play-state) `for="animation"` and exported.
- Create a `<dfn export>play state</dfn>`.
- Make the various play states `for="play state"` and exported. Change their link text to things like "paused" rather than "paused play state", since they'd already be properly namespaced.
