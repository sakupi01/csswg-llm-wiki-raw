It can be useful to select for _partial_ attribute _names_ (not values); for example trying select all elements with an aria attribute (i.e. any attribute name which matches `/aria-.*/`) or data attribute (`/data-.*/`), another example is the recent popover attributes; `popovertoggletarget`, `popoverhidetarget`, `popovershowtarget` - it would be useful to have on selector to find all "popover invokers" that have an attribute matching `/^popover.*target$/`.

I'd like to propose some way of extending the attribute selector syntax to allow for this kind of wildcard. Simple wildcards rather than regexes will likely be sufficient.
