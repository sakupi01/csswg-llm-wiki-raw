Currently we have the following note:
```
	Note: The 'text-transform' property only affects the presentation layer;
	correct casing for semantic purposes is expected to be represented
	in the source document.
```

I seem to have a stray file from 2020 on my disk which instead applies this expectation as conformance criteria:
```
	Advisement: Authors must not rely on 'text-transform' for semantic purposes;
	rather the correct casing and semantics should be encoded
	in the source document text and markup.
```

Filing this issue to ask whether we want to change it over or not.

## @frivoal — 2023-01-11

A note is informative, an advisement is a (highlighted) normative part of the specification. If we want to use the second phrasing, it needs not to be merely an informative note, since it uses a RFC2119 verb ("must not").

So I guess that's what we'll do.
