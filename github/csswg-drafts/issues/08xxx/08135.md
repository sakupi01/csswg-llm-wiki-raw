I initially thought "yes", but then https://drafts.csswg.org/css-scoping/#shadow-names seemed to only apply to "global names" (i.e. names created by at-rules), which is not quite the case for scroll timeline names.

There's a discussion in https://github.com/w3c/csswg-drafts/issues/7916 in relation to anchor/CQ names, which seems to expect that names (also non-"global" names) are tree-scoped by default?

Either way, it would be good to state it explicitly.

## @andruud — 2023-02-01

This is not the same issue as #8192. That affects anonymous timeline lookups as well (`scroll()`), while this does not. Not having tree-scoped timelines does not match @tabatkins' most recent thinking in https://github.com/w3c/csswg-drafts/issues/7916 in my opinion. However, if we're still sure about the https://github.com/w3c/csswg-drafts/issues/7047 decision, then I'm happy to close this issue. Tree-scoped names are painful to implement anyway.
