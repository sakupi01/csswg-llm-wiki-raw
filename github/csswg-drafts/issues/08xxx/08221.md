I have noticed no major browser supports `display: run-in` or `display: ruby` and the spec is silent regarding this.

<!-- comment id=1351162114 author=Loirooriol created=2022-12-14T11:54:47Z url=https://github.com/w3c/csswg-drafts/issues/8221#issuecomment-1351162114 -->
## @Loirooriol — 2022-12-14

Firefox supports `display: ruby`.

#339 says that many non-browser CSS implementations support `display: run-in`.
