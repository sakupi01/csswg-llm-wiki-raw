Minimum values for `widows` & `orphans` properties should be 1, not 0:
- https://w3c.github.io/csswg-drafts/css-break/#widows-orphans

The value range says: `<integer [0,∞]>`, but I think it should be `<integer [1,∞]>`, given that the prose right under the table says:
> Negative values and zero are invalid and must cause the declaration to be ignored.
