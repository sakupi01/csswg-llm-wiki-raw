The [CSS Animations Level 2 spec](https://drafts.csswg.org/css-animations-2/) introduces the [`animation-composition`](https://drafts.csswg.org/css-animations-2/#animation-composition) but does not support the newly introduced [`<single-animation-composition>` value](https://drafts.csswg.org/css-animations-2/#typedef-single-animation-composition) to be set using the [`animation` shorthand](https://drafts.csswg.org/css-animations-2/#animation-shorthand) property.

I believe this is an oversight and will propose a spec edit to allow `animation-composition` to be set using the `animation` shorthand just like other `animation-` properties.
