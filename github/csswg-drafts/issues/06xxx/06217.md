The Color specs inconsistently spell the term as "colorspace" and "color space". Color 4 currently *prefers* "colorspace" (5x as many usages), but [Google Trends](https://trends.google.com/trends/explore?date=all&geo=US&q=%22color%20space%22,colorspace) suggests the internet in general slightly prefers "color space".

This impacts APIs - in <https://github.com/whatwg/html/pull/6562#discussion_r615015648> the 1-vs-2 word spelling is discussed so it's clear whether the camelCase spelling should be "colorspace" or "colorSpace". There's already a web api using "colorSpace", so the thread is settling on that.

We should be consistent and spell it "color space" across the Color specs as well. Even if there's some good reason to use "colorspace", keeping things consistent across the web APIs is important.
