The spatial navigation explainer has a section titled:

> Making life better for users of desktop browsers who use the keyboard to navigate

This currently limits the scope to "desktop" browsers. This likely stems from the fact that most mobile devices don't have built-in keyboards.

However many phones and tablets (iOS, Android, and others) can be operated using a keyboard (typically via Bluetooth). Web pages can be navigated on mobile browsers just like they can on a desktop computer.

I'd propose a simple edit; just drop the part about desktop browsers, so this heading reads:

> Making life better for users who use the keyboard to navigate
