content-visibility spec says that `content-visibility: auto` elements are not skipped if they are [relevant to the user](https://www.w3.org/TR/css-contain-2/#relevant-to-the-user). I'd like to add the fact that if an element has a descendent that is in the top layer then it is relevant to the user.
