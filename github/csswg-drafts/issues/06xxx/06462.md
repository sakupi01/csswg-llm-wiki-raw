There have been a number of [important changes in Fonts 4 since the  17 November 2020 Working Draft](https://drafts.csswg.org/css-fonts-4/#changes-2020-11-17) so I would like to push an updated WD. 

Also we removed the scary **do-not-implement** warning from the ED of Fonts 5, so it would be good to republish that too.
