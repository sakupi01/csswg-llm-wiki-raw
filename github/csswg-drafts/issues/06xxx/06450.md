## @svgeesus — 2022-11-03

So, this 2014 CR is badly in need of republication. There have been [a bunch of edits](https://github.com/w3c/csswg-drafts/commits/main/css-shapes-1/Overview.bs) and the changes section is not up to date. The Security/Privacy section needs to be split in two.

Ideally `<wpt>` markup should be added to indicate tested sections, but that work should not hold up republication.

I suggest publishing a CR Draft, then doing horizontal review, followed by CR Snapshot.

<!-- comment id=1308983437 author=svgeesus created=2022-11-09T16:02:36Z url=https://github.com/w3c/csswg-drafts/issues/6450#issuecomment-1308983437 -->
## @svgeesus — 2022-11-09

I went through the [commit history](https://github.com/w3c/csswg-drafts/commits/main/css-shapes-1/Overview.bs) (including the commit history [before it was renamed](https://github.com/w3c/csswg-drafts/commits/b667648046860289ec447feddbad987969929ed2/css-shapes/Overview.bs?browsing_rename_history=true&new_path=css-shapes-1/Overview.bs&original_branch=main) and [when it used the pre-bikeshed .src format](https://github.com/w3c/csswg-drafts/commits/9ebbd66433384be37271b7656568e6928a378f84/css-shapes/Overview.src.html?browsing_rename_history=true&new_path=css-shapes-1/Overview.bs&original_branch=main)), checking all commits against the changes section and [adding any](https://github.com/w3c/csswg-drafts/commit/6906467f8e5e000fee93488b2db036a18a69d38d) that had been missed. The changes section is now complete.

I also split Privacy and Security considerations into two, as required for horizontal review, and added a link to the [implementation report](https://wpt.fyi/results/css/css-shapes?label=experimental&label=master&aligned)

There is one linking error, because the old `<length-percentages>` production is used but it no longer exists. But that is an easy fix. Apart from that, this spec looks in good shape for CR Draft.
