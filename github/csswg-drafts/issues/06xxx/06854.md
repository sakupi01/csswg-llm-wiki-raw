CSS Color 4 has had [significant changes since the previous publication](https://drafts.csswg.org/css-color-4/#changes-from-20210601) including the incorporation of multiple WG resolutions like adding OKLab/OKLCH, moving `@color-profile` to Color 5, and so on. [Some open issues remain](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acss-color-4). There are two very complete implementations, WebKit (Safari 15) and BFO Publisher. The spec is close to CR, so I want to republish and advertise wide review. 

CSS Color 5 has also seen [significant changes](https://drafts.csswg.org/css-color-5/#changes-20210601) and is also seeing implementation.

The two specifications should be republished together.
