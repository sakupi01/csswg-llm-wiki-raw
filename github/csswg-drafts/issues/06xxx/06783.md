This is an important specification which is widely implemented and has [a good test suite](https://test.csswg.org/harness/results/css-variables-1_dev/grouped/). There have been many [substantive changes](https://github.com/w3c/csswg-drafts/commits/main/css-variables-1/Overview.bs) since last publication  as CR in **2015**. Most issues are now closed. 

We are certainly long overdue to publish an updated CR. It should include the magic words "wide review" in the SOTD. Then we should do the whole horizontal review thing which is needed to request CR Snapshot
