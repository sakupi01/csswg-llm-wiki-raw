I would have (and I guess still would) found it helpful when implementing `color-mix()` if the spec, https://drafts.csswg.org/css-color-5/#color-mix, included examples of mixing with a non-default hue interpolation method (such as 'longer'). This would help to better understand how they fit in the grammar, how they work and why they might be useful.
