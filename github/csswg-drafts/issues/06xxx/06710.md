That's unfortunately a common problem, on the Web and elsewhere. I first encountered in the Atom code editor and proceeded to restyle them for higher contract in the configuration. Now i use VS Code and complain that most themes have insufficiently prominent scrollbars. There is:
[[
When using scrollbar-color property with specific color values, authors should ensure the specified colors have enough contrast between them. For keyword values, UAs should ensure the colors they use have enough contrast. See WCAG 2.1 SC 1.4.11 Non-text Contrast [WCAG21]. 
]]
https://www.w3.org/TR/css-scrollbars-1/#scrollbar-color

Doesn't this address your concern?
