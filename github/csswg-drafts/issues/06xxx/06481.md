As pointed out @dirkschulze in #3412, our "Applies to" line should for some properties list svg elements, but so far we haven't taken that into consideration.

I don't think we should start sprinkling SVG related information in some specs but not all, so we should discuss if we want to do this at all, and if so how. Should SVG information be part of the regular "Applies to" line? Should we have a dedicated SVG "Applies to" line? Should SVG be indexing the properties that apply to it on their end? How do we want to integrate the SVG and CSS specs here?
