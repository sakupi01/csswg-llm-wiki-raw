## @svgeesus — 2021-06-09

The stable definition is:

> The following modules have completed design work, and are fairly stable, but have **not received much testing** and implementation experience yet.

Given that, and looking at CSS Color 4 which has [two passes for most tests](https://test.csswg.org/harness/results/css-color-4_dev/grouped/), has undergone [wide review](https://github.com/w3c/csswg-drafts/issues/4943) and is being prepared for CR soon, I think it will soon be ready to move from **stable** to **official**

<!-- comment id=857867799 author=svgeesus created=2021-06-09T16:56:02Z url=https://github.com/w3c/csswg-drafts/issues/6243#issuecomment-857867799 -->
## @svgeesus — 2021-06-09

Also given the level of implementer interest and the [pretty good test results](https://test.csswg.org/harness/results/css-fonts-4_dev/grouped/) then CSS Fonts 4 should be added to the **rough interop** bucket.

* Counter Styles 3 might be ready for "official definition"?
* Logical Properties 1 should be in "rough interop"
* Unsure about the status of "overscroll-behavior", it's possibly ready for "rough interop"?

* Scrollbars 1 should be in "stable with limited implementation"
* css-sizing-3 should probably be in "rough interop" rather than "stable" since it's not CR yet...
* resize-observer maybe goes in "rough interop"?
* web animations 1 could maybe go into "rough interop"?
