The production `<leader-type> = dotted | solid | space | <string>` should include a keyword for the dedicated Unicode character U+2024 ONE DOT LEADER. Possibly also:
- U+2025 TWO DOT LEADER
- U+2026 HORIZONTAL ELLIPSIS
- U+FE30 PRESENTATION FORM FOR VERTICAL TWO DOT LEADER
- U+22EE VERTICAL ELLIPSIS
