https://drafts.csswg.org/css-grid-2/#subgrid-listing defines `subgrid` with:

> If there is no parent grid, this value is equivalent to the initial value, `none`, and the grid container is not a subgrid.

What does "equivalent" mean? Does `subgrid` compute to `none` in that case? Or is it just at used-value time?

In Firefox it's the latter: if you use `inherit` in a child grid, you do get a subgrid. [Testcase](https://software.hixie.ch/utilities/js/live-dom-viewer/?%3C!DOCTYPE%20html%3E%0A%3Cstyle%3E%0Adiv%20%7B%20display%3A%20grid%3B%20grid-template-columns%3A%20subgrid%3B%20grid-auto-columns%3A%20100px%3B%20%7D%0Adiv%20%3E%20div%20%7B%20grid-auto-columns%3A%2010px%3B%20%7D%0Aspan%20%7B%20background%3A%20cyan%3B%20%7D%0A%3C%2Fstyle%3E%0ATEST%3A%0A%3Cdiv%3E%3Cdiv%20style%3D%22grid-template-columns%3A%20inherit%22%3E%3Cspan%3E.%3C%2Fspan%3E%3C%2Fdiv%3E%3C%2Fdiv%3E%0A%3Cbr%3E%0ASUBGRID%20REFERENCE%3A%0A%3Cdiv%3E%3Cdiv%20style%3D%22grid-template-columns%3A%20subgrid%22%3E%3Cspan%3E.%3C%2Fspan%3E%3C%2Fdiv%3E%3C%2Fdiv%3E%0A%3Cbr%3E%0ANESTED%20GRID%20REFERENCE%3A%0A%3Cdiv%3E%3Cdiv%20style%3D%22grid-template-columns%3A%20none%22%3E%3Cspan%3E.%3C%2Fspan%3E%3C%2Fdiv%3E%3C%2Fdiv%3E)

However, what's the computed value, then? The spec table says

> Computed value: the keyword `none` or a computed track list

Where https://drafts.csswg.org/css-grid-2/#computed-track-list

> The computed track list of a standalone axis is a list alternating between line name sets and track sections, with the first and last items being line name sets.
> 
> The computed track list of a subgridded axis is the subgrid keyword followed by a list of line name sets representing each line in that axis.

However, if `subgrid` behaves as `none`, there is no subgridded axis?

## @fantasai — 2021-06-22

Thinking about it some more, maybe it shouldn't behave as none, but instead do something like have the right number of explicit rows and columns but size them all using `grid-auto-*`? That might be more useful to authors while doing development, since at least the items will have the correct relationship to each other even if the tracks aren't sized appropriately: treating as `none` means the grid would collapse down to a single auto-flowed column. CC @jensimmons @rachelandrew
