## @svgeesus — 2021-07-14

So, I would like to change the official CSS WG homepage (the one that is linked to from Status of this Document on /TR published specs) from [the general CSS Overview that Bert wrote](https://www.w3.org/Style/CSS/) to the [autogenerated and always up to date WG page](https://www.w3.org/groups/wg/css).

This fixes the "link to charter" issue, and makes things easier for AC Reps because we will then have the same structure as most other groups. The page uses a consistent format for finding who the chairs and staff contacts are, when each charter was approved, a list of WG members, IPR status for all specifications, and so on.

The page Bert wrote still has value, for people new to CSS, but it isn't really about  the CSS WG. It is about CSS.

Note that

1. It is now W3C policy for charters to link to the standardized group home page **w3.org/groups/wg/[groupname]** and those pages all have links to charters (in fact a complete charter history)
2. The proposed [new CSSWG charter 2025-2027](https://github.com/w3c/csswg-drafts/issues/10671) follows that practice
