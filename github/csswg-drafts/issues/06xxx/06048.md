In CSS Color 5's color-mix() function, https://drafts.csswg.org/css-color-5/#color-mix, what should happen if two opposing hue adjusters have different modifiers? For example:

```css
color-mix(lch, red hue longer 75%, blue hue shorter 25%);
```

Which hue interpolation (https://drafts.csswg.org/css-color-5/#hue-interpolation) algorithm should be used in this case?

<!-- comment id=788240402 author=Myndex created=2021-03-01T20:15:18Z url=https://github.com/w3c/csswg-drafts/issues/6048#issuecomment-788240402 -->
## @Myndex — 2021-03-01

IMO and as I mentioned in my lengthy post in #4711 only color(1) should have adjusters and percentages.

The operational theory I am following in this is similar to a "transfer mode" where layer A affects the underlying layer B.

Thus: in color-mix(), color(2) is the underlying color that is to be affected. Color(1) is the color that has some or all attributes affecting color(2).

Of course this is not what the spec says now, but I think it is a more useful way to implement...
