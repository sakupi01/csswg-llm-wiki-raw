<a name="prompt-1" href="#prompt-1"># 1</a>. Should Container Queries allow us to observe [containment](https://drafts.csswg.org/css-contain-3/#containment-types) by an ancestor?

<details><summary><em>Example 1</em></summary>

```js
element.withinContainer("(width >= 640px)")
```
```ts
interface Element {
  withinContainer<query extends string>(query: query): ContainerQueryList<query>
}

interface ContainerQueryList<query extends string> extends EventTarget {
  query: query
  matches: boolean
  containers: EventTarget[]
}
```
</details>

<details><summary><em>Example 1a</em></summary>


```ts
interface ContainerQueryListEvent<query extends string> extends Event {
```
