In https://drafts.csswg.org/css-cascade/#cascade-order

> Declarations from **style attributes** are ordered according to the document order of the element the **style attribute** appears on, and are all placed after any style sheets.

This sentence ought to reference https://drafts.csswg.org/css-style-attr/#style-attribute which is the definition of the term "style attribute".
