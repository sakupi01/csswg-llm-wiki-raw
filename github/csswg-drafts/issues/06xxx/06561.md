Already defined in your own spec, Emilio ^_^ <https://drafts.csswg.org/cssom-1/#dom-cssrule-type> All at-rules defined after @viewport just return 0 for that attribute (and nothing after @namespace *should* have a constant, or else we should be inlining those constants for 11-14 into CSSOM as well).

Also documented on https://wiki.csswg.org/spec/cssom-constants
