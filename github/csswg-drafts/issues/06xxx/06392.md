The [current specification for `aspect-ratio`](https://drafts.csswg.org/css-sizing-4/#aspect-ratio) allows explicit ratios, or the "natural" aspect ratio from a replaced element. There is however no way to follow the viewport's aspect-ratio.

Wouldn't it be nice to be able to do something like `aspect-ratio: screen`?

Not sure if screen or viewport would be the best value here though?!
