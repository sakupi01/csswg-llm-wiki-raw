The specification extends the definition of `shape-inside` to add the `display` value.

This value was added some time ago to the main definition of the [`shape-inside` property in CSS Shapes](https://drafts.csswg.org/css-shapes-2/#shape-inside-property). The definition should be dropped from CSS Round Display as a result.

The explanation of what the value means should remain but the actual definition should go, otherwise it looks as if the spec actually contains the authoritative definition of the property (another option would be to drop `display` from CSS Shapes and to rather define `shape-inside` as a partial definition in CSS Round Display through a `new values` field as done in other specs).

Via https://github.com/w3c/webref/issues/127#issuecomment-874135280
