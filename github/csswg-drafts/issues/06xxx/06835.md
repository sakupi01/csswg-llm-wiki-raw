The CSS Color Module 4 spec currently has a section on color resolution for `lab()` and `lch()` colors, https://drafts.csswg.org/css-color/#resolving-lab-lch-values, but it omits anything about `oklab()` and `oklch()`. The section should probably be updated to apply to both sets.
