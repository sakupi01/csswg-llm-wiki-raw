```css
div {
  @nest & > & {
    color: blue;
  }
}
```

What's the meaning of this? Does it match all `div` element which are a child of another `div` element, just like

```css
div > div { color: blue }
```

Or does it only match the `div` elements which are a child of themselves (i.e. match nothing)?
