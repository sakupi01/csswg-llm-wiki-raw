If you animate from `font-palette: light` to `font-palette: dark`, should it flip halfway, or should each of the colors in the palette animate smoothly?

The grammar of the property is `font-palette: none | normal | light | dark | <palette-identifier>`, so if we animate smoothly, intermediate values in the animation might not be representable (without having to construct a new `@font-palette-values` rule).
