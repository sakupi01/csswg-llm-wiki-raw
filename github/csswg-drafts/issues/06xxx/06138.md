This is an issue raised from a [code review](https://chromium-review.googlesource.com/c/chromium/src/+/2773716/1..5/third_party/blink/web_tests/external/wpt/css/css-fonts/size-adjust.tentative.html#b1).

The interaction between `size-adjust` and `text-underline-offset` and `text-decoration-thickness` may not be completely straightforward. Hence, a Note paragraph is needed to clarify that `em`- or percentage-based length values are not affected, but `auto` and `from-font` values are affected since they use metrics provided by the font.
