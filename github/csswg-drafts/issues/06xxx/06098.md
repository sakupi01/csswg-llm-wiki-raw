The current cascade layers spec starts out by explaining that each layer as a single-ident layer name, then that they can be nested, then adds on the ability to reference earlier nested named layers using a conjunctive notation. Probably makes more sense to rewrite this so that layer names consist of a joined list of idents, and nesting blocks joins the name of the parent layer to the child.
