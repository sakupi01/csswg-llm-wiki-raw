## @tabatkins — 2022-10-27

The use of those `details` are indeed very intentional. They're long, and not required for the understanding of the feature, just providing potentially-useful context for the curious. Having them as plain div.note would make the flow of the spec worse.

(We do similar in several other specs for this exact same reason - when we think it would be useful to provide some context for a decision, but the explanation is long and not required for actually understanding the feature.)
