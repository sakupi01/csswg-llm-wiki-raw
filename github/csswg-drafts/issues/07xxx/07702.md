From https://drafts.csswg.org/css-contain-3/#size-container

> If [...] the query container does not support [container size queries](https://drafts.csswg.org/css-contain-3/#container-size-query) on the relevant axes, then the result of evaluating the [size feature](https://drafts.csswg.org/css-contain-3/#size-features) is unknown.

It's not clear whether the conditions for supporting container size queries are the same as for supporting size containment.
