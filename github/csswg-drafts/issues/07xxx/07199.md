`font-size` is often adjusted together with `line-height`, even if one wants to leave all other `font` longhands intact.
Even when `line-height` is set in relative units, it often needs some manual adjustment when using multiple different font sizes together.

Would there be value in a shorthand of the two? E.g. `font-metrics: <font-size> / <line-height>`

<!-- comment id=1191116516 author=Crissov created=2022-07-21T06:59:42Z url=https://github.com/w3c/csswg-drafts/issues/7199#issuecomment-1191116516 -->
## @Crissov — 2022-07-21

It would have made sense to specify `font-size` as a shorthand for character and line height in Level 1, just like `color` should have been a shorthand for setting foreground and background color at once. 

I’m not sure it’s worth fixing this anymore, even if the shorthand was as simple as `line`. 

I also believe that this would need to also include `font-size-adjust` somehow and perhaps even a new way to select the glyph measure that the length applied to, e.g.:

    line: 1em cap-height at 0.48 / 140%;

## @dbaron — 2022-07-21

There's also no precedent for a shorthand that expands to varying sets of longhands depending on the syntax used.  A shorthand in CSS always sets/resets the same set of longhands.
