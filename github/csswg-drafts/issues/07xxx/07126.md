The tables at https://www.w3.org/TR/mediaqueries-4/#media-descriptor-table and https://www.w3.org/TR/mediaqueries-5/#media-descriptor-table both include an "Initial" column, with no entries. I've been working on a media-query implementation and I don't think it's really possible for a media-feature to have an initial value, (backed up by the lack of any initial values entered into the table,) so I would suggest that this column be removed from both tables.

Apologies if this is already corrected in the csswg.org drafts - I'm not able to check since they are not loading for me right now.
