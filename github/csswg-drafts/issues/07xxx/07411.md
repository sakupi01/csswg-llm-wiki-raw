https://www.w3.org/TR/selectors-4/#the-nth-child-pseudo

Spec currently defines the syntax as being `:nth-child(An+B [of S]?)` and then says 

> If `S` is omitted, it defaults to `*|*`.

this reads like `nth-child(2n of)` is valid. Perhaps it should be

> If `of S` is omitted it defaults to `of *|*`

<!-- comment id=1164724257 author=tabatkins created=2022-06-23T18:15:12Z url=https://github.com/w3c/csswg-drafts/issues/7411#issuecomment-1164724257 -->
## @tabatkins — 2022-06-23

The grammar makes it clear that the `S` can't be omitted on its own. If you *do* omit `S` (validly, along with the preceding `of`), then the defaulting applies.  The prose isn't intended to imply anything more optionality than what the grammar says (and we use this kind of wording elsewhere in properties).
