The `word-spacing` property is [defined to accept `<length-percentages>` as a value](https://drafts.csswg.org/css-text-4/#valdef-word-spacing-length-percentages). I think it should be `<length-percentage>`, as defined for the *value* field in its definition table.

> **Value:** `normal | <length-percentage>`

> `<length-percentages>` Specifies extra spacing in addition to the intrinsic inter-word spacing defined by the font.
