As title.

In section '3.1. Line Colors: the [border-color](https://www.w3.org/TR/2021/CRD-css-backgrounds-3-20210726/#propdef-border-color) propertiesr'
It says 'These properties set the foreground color of the border specified by the border-style properties. '
Should it be 'border-color', not 'border-style' ?

https://github.com/w3c/csswg-drafts/blob/a73cfad0db744cf935171ac063cbd6788448094e/css-backgrounds-3/Overview.bs#L1230

There is a same description in css-backgrounds-4 too.
https://github.com/w3c/csswg-drafts/blob/a73cfad0db744cf935171ac063cbd6788448094e/css-backgrounds-4/Overview.bs#L203

## @Loirooriol — 2022-06-18

Then we would end up with

> The `border-color` properties set the foreground color of the border specified by the `border-color` properties.

which doesn't make sense.

`border-style` specify what kind of border, `border-color` specify the color for that border.

But if it's confusing I would just trim it to

> These properties set the foreground color of the border.
