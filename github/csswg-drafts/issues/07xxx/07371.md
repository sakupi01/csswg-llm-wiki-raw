[CSS Logical](https://drafts.csswg.org/css-logical-1/#text-align) defines `start | end` as new values addition to `text-align` but these are already included in the value definition from [CSS Text 3](https://drafts.csswg.org/css-text-3/#text-align-property) (and 4). When processing extracts from `w3c/webref`, `newValues` are appended to `value`, resulting to `start | end | left | [...] | start | end`.

What is the reason for keeping these new values in CSS Logical?
