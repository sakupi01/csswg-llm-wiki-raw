[css-inline/#sizing-drop-initials](https://drafts.csswg.org/css-inline/#sizing-drop-initials)

Sometimes a designer may want some padding around an initial letter or drop cap like this example:

<img width="485" alt="Screen Shot 2022-09-13 at 9 15 35 PM" src="https://user-images.githubusercontent.com/377189/190058244-db160af5-3ec2-4035-b1cb-2a40a2688c6a.png">

Could we add `initial-letter-padding` to the spec, so that `initial-letter-padding: 1` would result in padding equal to one line of text. This is a style that is often found in magazines and it would be convenient for it to be a part of the `initial-letter` specification.

<!-- comment id=1246659262 author=Loirooriol created=2022-09-14T11:59:37Z url=https://github.com/w3c/csswg-drafts/issues/7739#issuecomment-1246659262 -->
## @Loirooriol — 2022-09-14

`::first-letter { padding: 1lh }` may be close enough.

<!-- comment id=1246832991 author=faceless2 created=2022-09-14T14:16:36Z url=https://github.com/w3c/csswg-drafts/issues/7739#issuecomment-1246832991 -->
## @faceless2 — 2022-09-14

The example shown would also work with `margin`, which we find works really well now - particularly after the resolution in https://github.com/w3c/csswg-drafts/issues/5119 which effectively the used margin is the intersection of the box margin and `shape-margin`. I don't know how widely implemented this is yet, but to me it seems to work really well, and gives a lot of control over layout.

## @scottkellum — 2022-09-14

Thanks @Loirooriol 

This code did the trick:

```
p {
  line-height: 1.3;
}

p::first-letter {
  -webkit-initial-letter: 2 3;
  initial-letter: 2 3;
  padding: 1.3em; /* 1lh is not supported in Safari at this time */
}
```

@faceless2 block margins seem to be getting collapsed as `::first-letter` is inline. This may be an implementation quirk.
