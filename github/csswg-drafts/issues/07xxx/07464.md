We're planning to add longhands for `overflow-clip-margin` like `overflow-clip-margin-inline-start` etc., and it's getting really long. What about shortening the name to just `overflow-margin`?

<!-- comment id=1188730284 author=jfkthame created=2022-07-19T08:02:30Z url=https://github.com/w3c/csswg-drafts/issues/7464#issuecomment-1188730284 -->
## @jfkthame — 2022-07-19

If the property is just `overflow-margin` rather than `overflow-clip-margin`, it might seem more surprising to authors that it does *not* have any effect, for example, on scrollable overflow (as mentioned in the spec):

> Note: This property has no effect on boxes with [overflow: hidden](https://www.w3.org/TR/css-overflow-3/#propdef-overflow) or overflow: scroll, which are not defined to use the [overflow clip edge](https://www.w3.org/TR/css-overflow-3/#overflow-clip-edge).
