CSS Color 5 defines an at-rule: https://www.w3.org/TR/css-color-5/#at-profile

It doesn't, however, define how this gets exposed via the CSSOM, which I would expect to be specified. Should it just be exposed as an (apparently abstract) [`CSSRule`](https://www.w3.org/TR/cssom/#the-cssrule-interface), or should it have its own interface? If it does, should it be added as a value `type` can return: https://www.w3.org/TR/cssom/#dom-cssrule-type?

};

although components would be better as a list?

Precedent (rules like CSSCounterStyleRule, etc) suggests that we should indeed keep it as a single string that's just the value of the descriptor.

(We could get fancier and have the string version be a PutForwards to a more structured value, but then we should define the more structured one with Typed OM objects. It can be a value-add later, if necessary.)
