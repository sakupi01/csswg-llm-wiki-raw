https://drafts.csswg.org/css-values-4/#calc-range

> Even for properties that explicitly allow [`infinity`](https://drafts.csswg.org/css-values-4/#valdef-calc-infinity) as a keyword value, such as [`animation-iteration-count`](https://www.w3.org/TR/css-animations-1/#propdef-animation-iteration-count)

But from https://drafts.csswg.org/css-animations-1/#animation-iteration-count

> Value: `<single-animation-iteration-count>#`
> `<single-animation-iteration-count> = infinite | <number>`

So it allows `infinite` but not `infinity` as the note claims.

## @Loirooriol — 2022-04-14

Probably not directly, but there are cases via `<custom-ident>` like `list-style-type` or `grid-row-start`.

So `grid-row-start: calc(infinity)` and `grid-row-start: infinity` are both valid but mean different things.

And `list-style-type: infinity` is valid but `list-style-type: calc(infinity)` is not.
