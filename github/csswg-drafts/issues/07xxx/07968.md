CSS Color 4 defines [the `<color>` type](https://drafts.csswg.org/css-color-4/#color-syntax).

CSS Color 5 extends each of the color functions with [Relative Color Syntax](https://drafts.csswg.org/css-color-5/#relative-colors) and also adds [`@color-profile` and custom color spaces to `color()`](https://drafts.csswg.org/css-color-5/#custom-color) and [`device-cmyk()`](https://drafts.csswg.org/css-color-5/#device-cmyk).

As pointed out here:
  - https://github.com/w3c/csswg-drafts/issues/7963

this leads to an interpretation that RCS cannot be nested, because the definition of `<color>` predates RCS.

Thus, CSS Color 5, which is still a delta spec, needs an updated definition of `<color>` which includes all these.
