`both`, `both-inline`, `both-block`, are not included in the `value` of the definition table for the [`clear`](https://drafts.csswg.org/css-page-floats-3/#clearing_page_floats) property in CSS Page Floats 3, which is currently the primary `value` definition for `clear`, but are defined in prose below the `clear` definition table.

**EDIT** 

According to this [comment](https://github.com/w3c/csswg-drafts/pull/7840#issuecomment-1270225771), `clear` and `float` should be defined in CSS Box 3 (or *a module for block layout*) therefore I change my demand by updating the title of this issue, and by asking for the following changes in CSS Page Floats 3 (after defining `float` and `clear` in another spec):

```diff
  Name: `float`
- Value: `block-start | block-end | inline-start | inline-end | snap-block | <snap-block()> | snap-inline | <snap-inline()> | left | right | top | bottom | none`
+ New values: `block-start | block-end | inline-start | inline-end | snap-block | <snap-block()> | snap-inline | <snap-inline()> | top | bottom`

  Name: `clear`
- Value: `inline-start | inline-end | block-start | block-end | left | right | top | bottom | none`
+ New values: `inline-start | inline-end | block-start | block-end | top | bottom`
```
