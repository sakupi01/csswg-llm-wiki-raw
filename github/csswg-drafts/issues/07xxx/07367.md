`round` is defined as the `initial` value of [`border-limit`](https://drafts.csswg.org/css-backgrounds-4/#border-limit) but this keyword is not included in the `value` definition field.

> **Name:** `border-limit`
> **Value:** `all | [ sides | corners ] <length-percentage [0,∞]>? | [ top | right | bottom | left ] <length-percentage [0,∞]>`
> **Initial:** `round`
