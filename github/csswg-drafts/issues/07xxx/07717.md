This is a general question, because maybe for some of the things I want to ask, I might be at the wrong place, for webkit stuff.

Are -webkit rules defined by w3c?

<!-- comment id=1241280273 author=astearns created=2022-09-08T22:01:48Z url=https://github.com/w3c/csswg-drafts/issues/7717#issuecomment-1241280273 -->
## @astearns — 2022-09-08

Sometimes, but we try not to. When we have to define them due to web compatibility concerns you’ll see a section in one of our drafts like this

https://drafts.csswg.org/css-flexbox-1/#webkit-aliases

If you do not see a particular -webkit- thing in one of our drafts already, then it is very likely that we will never define it in a W3C draft.
