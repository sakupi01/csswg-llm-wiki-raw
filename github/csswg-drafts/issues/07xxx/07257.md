In https://github.com/w3c/csswg-drafts/issues/5847 and https://github.com/w3c/csswg-drafts/issues/5775 @emilio discussed the `:-webkit-autofill` pseudo as an alias of `:autofill`.

- Should we define this in the Selectors 4 spec?
- Are there other aliases we need to add?
- Should they be incorporated to into the definition of each pseudo one by one, or be listed all together in an appendix?
