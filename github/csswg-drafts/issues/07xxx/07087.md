https://drafts.csswg.org/css-cascade-5/#preshint

> All document language-based styling must be translated to corresponding CSS rules and enter the cascade as rules in either the [UA-origin](https://drafts.csswg.org/css-cascade-5/#cascade-origin-ua) or a special-purpose author presentational hint origin between the regular [user origin](https://drafts.csswg.org/css-cascade-5/#cascade-origin-user) and the [author origin](https://drafts.csswg.org/css-cascade-5/#cascade-origin-author). For the purpose of [cascading](https://drafts.csswg.org/css-cascade-5/#cascade) this [author presentational hint origin](https://drafts.csswg.org/css-cascade-5/#author-presentational-hint-origin) is treated as an independent [origin](https://drafts.csswg.org/css-cascade-5/#origin), but for the purpose of the [revert](https://drafts.csswg.org/css-cascade-5/#valdef-all-revert) keyword it is considered part of the author origin.

What about the `revert-layer` keyword?

<!-- comment id=1054587803 author=fantasai created=2022-02-28T19:25:58Z url=https://github.com/w3c/csswg-drafts/issues/7087#issuecomment-1054587803 -->
## @fantasai — 2022-02-28

It's not the `revert` keyword, so it's treated as an independent origin, and isn't reverted by `revert-layer` in an author style sheet.

IIRC this was intentional.
