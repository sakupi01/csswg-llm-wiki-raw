Will-Change was last published [in 2015 as a CR](http://www.w3.org/TR/2015/CR-css-will-change-1-20151203/). There have been [a few edits](https://github.com/w3c/csswg-drafts/commits/main/css-will-change-1/Overview.bs) since then, mostly generic "affects all specs" type of edits.
