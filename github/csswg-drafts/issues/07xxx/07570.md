The `animation-duration` property lists it's syntax as `<time [0s,∞]>`.  The `s` character is not allowed in the numerical range definition.

https://github.com/w3c/csswg-drafts/blob/5a93662258eb8e17ef19a3b236dcdb79c32c1ad2/css-animations-1/Overview.bs#L507
