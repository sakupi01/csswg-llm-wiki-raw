This in particular seems to be missing and is important to clarify because it differs from sass :

```css
.a .b {
  .c & {}
}
```

->

```css
.c :is(.a .b) {}
```

All current examples focus on simple/compound or selector lists.

## @romainmenke — 2022-10-27

Yes, I saw those but specifically complex selectors like the one I mentioned above are note worthy. 

Lists with compound selectors work exactly the same as they do in sass in terms of matched elements. The only difference is the specificity.

Complex selectors match different elements than they would in sass and we have noticed that this is still a point of confusion for authors switching from sass to "native" nesting (via postcss).
