Currently https://andreubotella.com/csswg-auto-build/mediaqueries-4/#mq-syntax defines `<media-query>` but then only defines how to evaluate `<media-condition>` or `<media-condition-without-or>` in https://andreubotella.com/csswg-auto-build/mediaqueries-4/#evaluating.

This is _super_ surprising. Why don't we actually define the top-level evaluation in the evaluation section? Heck, where is that defined?
