https://drafts.csswg.org/css-2022/#properties ([mirror](https://andreubotella.com/csswg-auto-build/css-2022/#properties)) doesn't list any logical property like `border-block-start-color`.

However, [CSS-LOGICAL-1] is in https://drafts.csswg.org/css-2022/#rough-interop, just like [CSS-GRID-1], and grid properties are in the index.
