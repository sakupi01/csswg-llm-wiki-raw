[`<anchor-size>`](<https://drafts.csswg.org/css-anchor-1/#typedef-anchor-size>) = `width | height | block | inline | self-block | self-inline`

Do these dimensions respect the value of the `box-sizing` property or do they always use the border box of the target anchor element?

<!-- comment id=1287357670 author=tabatkins created=2022-10-21T19:29:37Z url=https://github.com/w3c/csswg-drafts/issues/7938#issuecomment-1287357670 -->
## @tabatkins — 2022-10-21

Edit: Nope, not underspecifed, it's always the border box.

> An [anchor-size()](https://w3c.github.io/csswg-drafts/css-anchor/#funcdef-anchor-size) function representing a [valid anchor query](https://w3c.github.io/csswg-drafts/css-anchor/#valid-anchor-query) resolves to the [<length>](https://w3c.github.io/csswg-drafts/css-values-4/#length-value) separating the relevant border edges (either left and right, or top and bottom, whichever is in the specified axis) of the [target anchor element](https://w3c.github.io/csswg-drafts/css-anchor/#target-anchor-element).
