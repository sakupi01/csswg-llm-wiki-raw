Down in the [2.1 Direct nesting](https://drafts.csswg.org/css-nesting-1/#direct) section, the following example is presented:
```scss
.foo {
  color: blue;
  &__bar { color: red; }
}
```
It is then noted that `&__bar` is ambiguous because `__bar` is a valid custom element name. This is incorrect, as custom element names must start with a character a-z and include a dash (see [the specification](https://html.spec.whatwg.org/multipage/custom-elements.html#valid-custom-element-name)).

The argument is still valid, but doesn't quite work for the given example. The `&__bar` could be changed to e.g. `&bar--baz` in order to support said argument accurately.
