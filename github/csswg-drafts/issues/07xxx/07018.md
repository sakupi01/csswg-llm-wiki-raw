@weinig [noted on wpt](https://github.com/web-platform-tests/wpt/pull/32711): 

> Testing that hsla(from ...) and rgba(from ...) are not valid in the relative color syntax (but rgb(from ...) and hsl(from ...) are). Would like confirmation that this is correct

Confirmed, see the grammar at [rgb(from](https://drafts.csswg.org/css-color-5/#relative-RGB) and [hsl(from](https://drafts.csswg.org/css-color-5/#relative-HSL). However, I will add examples with non-unity alpha just to make that clearer.
