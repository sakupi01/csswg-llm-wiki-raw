In the context of automatic parsing of a CSS value against a value definition, the `initial` field of the [`font-size` descriptor](https://drafts.csswg.org/css-fonts-5/#descdef-font-face-font-size) should be defined with a value that can be parsed against the `value` field. The `initial` field is defined with `normal` but the `value` field is `auto | [<number>]{1,2}`.
