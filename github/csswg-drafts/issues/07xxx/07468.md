## @frivoal — 2022-08-01

In section 3, Success Criteria, the old charter (mostly) used the term "module", which has been replaced with the term "specification" in this proposed update. It should shift back to module, This was intentional, because higher up in the charter, we claim

> There is a single deliverable, the CSS specification. The CSS specification is large, and is divided into a series of modules. 

The Process itself doesn't define the word "Specification" (it talks about _technical reports_), so we're free to use it this way and define each of our technical reports to be a module if we like it. But we should try and keep it consistent.

Similarly, in section 8, we should probably say either "technical report" rather than "Web Specification".
