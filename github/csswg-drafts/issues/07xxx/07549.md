Hello folks,

This year [I'm helping out with the State of CSS survey](https://lea.verou.me/2022/07/help-design-the-state-of-css-survey-2022/). For those of you who may not have heard it, it's a survey that asks authors things like which CSS features they use or have heard of, what tooling they use, which CSS features they can't use due to browser differences etc.

Here are the results from last year: https://2021.stateofcss.com/en-US/

I'd like to draw the community's attention to this, because we often have discussions where what authors think about something is a big unknown. If there is anything you feel would help our work to ask authors about, this is your chance. We are using [this repo](https://github.com/Devographics/Surveys) for feedback on what should make it into the survey, and the feedback period runs until August 20th. 

Google is already using the results of this survey to drive implementation prioritization, so I thought it may be useful for us too.
