The [2014 font loading spec](http://www.w3.org/TR/2014/WD-css-font-loading-3-20140522/) is old and there are [many edits since 2017](https://github.com/w3c/csswg-drafts/commits/main/css-font-loading-3/Overview.bs) (edits before that predate the move to GitHub). 

The [ED changes section](https://drafts.csswg.org/css-font-loading/#changes) doesn't look at all up to date. Would be good to republish, once it is. Yes, there are [many open issues](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acss-font-loading-3) but still, there has been work done since 2014!
