Given Color 5 allows loading of [custom color profiles](https://www.w3.org/TR/css-color-5/#at-profile), those loaded spaces should be available to use in [CSS Images 4 with gradients](https://drafts.csswg.org/css-images-4/#linear-gradients) like:

```css
@color-profile --myspace {
  src: url(https://myspace.colors/imaginary-path.icc);
}

.card {
  color: color(--myspace 200 50 50);
  background: linear-gradient(to bottom right in --myspace, 
    color(--myspace 200 50 50), 
    color(--myspace 100 50 50)
  );
}

or even

.card {
  background: linear-gradient(in --myspace, lime, blue);
}
```

Yes, this should be Color 5. It doesn't make sense to allow dashed idents in `<color-interpolation-method>` when there are no color spaces using them.

<!-- comment id=1412358498 author=svgeesus created=2023-02-01T16:34:51Z url=https://github.com/w3c/csswg-drafts/issues/7377#issuecomment-1412358498 -->
## @svgeesus — 2023-02-01

`<color-interpolation-method>` now extended in CSS Color 5 to add `custom-colorspace>` which is a [`<dashed-ident>`](https://drafts.csswg.org/css-values-4/#typedef-dashed-ident) and must have been declared in a `@color-profile` rule.
