In digital reading system (usually native or html application built on top of web browser) "sepia" mode/theme is also widely used among light and dark to let reader feel like close to paper. It is quite often reading system will need to switch to different theme that end user would select.

My proposal or more like a question is if we can add sepia to https://www.w3.org/TR/2022/CR-css-color-adjust-1-20220210/#color-scheme-prop since it is a widely used scenario for digital reading.
