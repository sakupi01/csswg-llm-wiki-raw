In the HTML spec, there's a [list of CSS properties](https://html.spec.whatwg.org/multipage/rendering.html#anonymous-fieldset-content-box) that are supposed to inherit from a `<fieldset>` element to its child anonymous content box.

In https://github.com/whatwg/html/issues/11095 I proposed changing this list to include the properties from Gaps 1. In the [discussion](https://github.com/whatwg/html/issues/12370#issuecomment-4263304902) it was suggested that this list of properties be maintained in a CSS specification rather than HTML.

Forms seems to me like a natural home for this list, so I'd like to propose moving it there.
