WebKit, Blink and Servo#45208 seem to follow https://drafts.csswg.org/css-position-4/#paint-a-stacking-context

> 4. If root is a [block-level box](https://drafts.csswg.org/css-display-4/#block-level-box), [paint a block’s decorations](https://drafts.csswg.org/css-position-4/#paint-a-blocks-decorations) given root and canvas.
> 
> <!-- -->
> 
> 7. For each of root’s non-positioned floating descendants, in tree order, [paint a stacking container](https://drafts.csswg.org/css-position-4/#paint-a-stacking-container) given the descendant and canvas.
> 8. If root is an [inline-level](https://drafts.csswg.org/css-display-4/#inline-level) box
>   For each line box root is in, [paint a box in a line box](https://drafts.csswg.org/css-position-4/#paint-a-box-in-a-line-box) given root, the line box, and canvas.

However, that diverges from CSS2: https://drafts.csswg.org/css2/#painting-order

> Within each stacking context, the following layers are painted in back-to-front order:
>  1. the background and borders of the element forming the stacking context.
