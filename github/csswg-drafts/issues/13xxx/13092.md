## @cdoublev — 2025-11-12

I think its definition should be similar to the definitions of [`<scroll-state-feature>`](https://drafts.csswg.org/css-conditional-5/#typedef-scroll-state-feature) and [`<size-feature>`](https://drafts.csswg.org/css-conditional-5/#typedef-size-feature):

  > The syntax of a `<anchored-feature>` is the same as for a [media feature](https://www.w3.org/TR/mediaqueries-5/#media-feature): a feature name, a comparator, and a value.

I suspect this is still pending because discussions/decisions to determine whether boolean and range queries should be allowed are ongoing.
