The [CSS Spatial Navigation](https://drafts.csswg.org/css-nav-1/) spec currently has `css-nav` as slug. That may lead to confusion with [CSS Route Matching](https://drafts.csswg.org/css-navigation-1/), which uses `css-navigation` and the proposed [CSS Spatial Layout](https://webkit.github.io/explainers/css-spatial/Overview.html).

Therefore, I propose to rename it to `css-spatial-nav`. Alternatively, we might rename the whole spec to something that differentiates it more from the Spacial Layout proposal.

@frivoal @jihyerish @fantasai

Sebastian

Given the purely positive feedback on this, let's try and get an async resolution.

The proposal is to rename the shortname of CSS Spatial Navigation from `css-nav` to `css-spatial-nav` to avoid confusion with CSS Route Matching's shortname `css-navigation`.

(Not sure what came out of the CSS Spatial Layout proposal discussion lately, though if we agree on this proposed shortname change, we should also consider renaming its shortname `css-spatial` to something more distinguishable.)
