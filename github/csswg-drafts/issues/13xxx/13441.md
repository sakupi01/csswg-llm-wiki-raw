_Volume_ and _balance_ apply not only to _voice_, but also to _cues_.

In order to do so,

EITHER rename _voice-volume_ and _voice-balance_ as _volume_ and _balance_.
In this case, these properties will apply to both voices and cues set on an element.

OR add properties:

1. _cue-before-volume_
2. _cue-before-balance_
3. _cue-after-volume_
4. _cue-after-balance_

This way, you can target _voice/cue_, _cue-before_ and _cue-after_ more specifically.
