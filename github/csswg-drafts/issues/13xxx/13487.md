In the [SnapEvent interface](https://www.w3.org/TR/css-scroll-snap-2/#snapevent-interface), the fields of `SnapEventInit` are optional and nullable:

```
dictionary SnapEventInit : EventInit {
  Node? snapTargetBlock;
  Node? snapTargetInline;
};
```

Why is that and shouldn't they rather be marked as `required Node?`s?

@emilio

## @emilio — 2026-02-12

Marking required with a default of null would be identical, unless there's a reason to distinguish undefined from null?

<!-- comment id=3897187525 author=emilio created=2026-02-13T13:14:54Z url=https://github.com/w3c/csswg-drafts/issues/13487#issuecomment-3897187525 -->
## @emilio — 2026-02-13

Err, for it to be valid WebIDL it should just have a default null value, not required. I.e., I think it should be:

```webidl
dictionary SnapEventInit : EventInit {
  Node? snapTargetBlock = null;
  Node? snapTargetInline = null;
};

<!-- comment id=4500561954 author=tabatkins created=2026-05-20T16:41:00Z url=https://github.com/w3c/csswg-drafts/issues/13487#issuecomment-4500561954 -->
## @tabatkins — 2026-05-20

Yeah, `required` and a default value are incompatible, but since it's nullable, making it optional with default `null` is correct.
