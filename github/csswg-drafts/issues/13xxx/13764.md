Tailwind has a `.rounded-full` class that produces e.g. a "pill" button ([docs](https://tailwindcss.com/docs/border-radius#creating-pill-buttons)). 

A "pill button" looks like this: 
<img width="179" height="97" alt="a blue button with white text, the left and right side have a border-radius that is a half circle" src="https://github.com/user-attachments/assets/25aa8c38-e2d3-4482-b48c-145f20f05368" />

Tailwind does this by setting `border-radius: 3.40282e38px;` which evaluates to a ginormous number of pixels (340282001837565597733306976381245063168px). This is weird and looks dumb in devtools. 

<img width="1440" height="869" alt="safari devtools screenshot, the huge pixel number overflows the box model diagram" src="https://github.com/user-attachments/assets/2c8eb4c4-c8d6-4178-ad04-3332164f8a74" />

Maybe there should be a `full` option for border-radius?
