Essentially, CSS should have a section somewhere with definitions of "weird host boxes" so the HTML standard can just refer to that instead of attempting to define CSS rendering itself.

See https://html.spec.whatwg.org/multipage/rendering.html#the-fieldset-and-legend-elements for all the special requirements we have today that really don't belong in HTML (apart from the user agent style sheet that is).

Then separately you can consider if some of this weirdness should be exposed (#13757).

(And #11983 will provide an opt-in out of this.)
