Spec: https://drafts.csswg.org/css-navigation-1/

CSS usually separates multiple words in idents with a hyphen. The type definition [`<init-descriptor-name>`](https://drafts.csswg.org/css-navigation-1/#typedef-init-descriptor-name) contains `baseURL`, which should be renamed to `base-url`.

(This is similar to #13122 and #12483.)
