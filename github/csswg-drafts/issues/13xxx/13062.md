Chrome intends to [ship support for `background-position-{x|y}`](https://groups.google.com/a/chromium.org/g/blink-dev/c/PSDj9jEOm0s/m/ilbDONDaAwAJ) and the other browsers already support those longhands, While the spec still claims it's not ready for implementation.

Therefore, I am currently working towards making it fit for a FPWD. So here's a todo list for getting it ready:

- [x] Incorporate latest changes to CSS Backgrounds 3 (see also the [renaming things that should be added level 3](https://github.com/w3c/csswg-drafts/issues/10010#issuecomment-3333492408))
- [x] Work in the [remaining resolved on things](https://github.com/w3c/csswg-drafts/issues?q=is%3Aissue%20state%3Aopen%20label%3Acss-backgrounds-4%20label%3A"Needs%20Edits")
- [x] Remove the "Not Ready For Implementation" banner and add a note to [`background-tbd`](https://drafts.csswg.org/css-backgrounds-4/#background-layers) that it is not ready for implementation (even when it's clear given its name)
