This is related to [scroll-timeline-in-container-query.html](https://wpt.fyi/results/scroll-animations/css/scroll-timeline-in-container-query.html?label=master&label=experimental&aligned&view=interop&q=label%3Ainterop-2026-scroll-driven-animations).

In short both Chrome and Firefox consider looking up named timeline as part of style resolution, but WebKit doesn't since https://github.com/WebKit/WebKit/commit/e1f5a7186f60055bb8e4b682556d73d2576c412e . (The test itself was re-written in the WebKit commit).

The spec doesn't specifically mention when timeline looking-up should be processed, so I think there's a spec gap, the spec should clarify it. 

Thus I'd propose to change the test as tentative and exclude it from interop-2026, if this spec issue sounds reasonable.
