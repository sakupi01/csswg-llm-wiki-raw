Here's the current state of Media Queries Level 4:

* Latest publication: Candidate Recommendation Draft from 25 December 2021
* In CSS Snapshots [since 2018](https://www.w3.org/TR/css-2018/) (2018-2023 in Fairly Stable, since 2024 in Reliable Candidate Recommendations)
* WPT status: annotations up-to-date; Chrome: 1501/1502, Firefox: 1498/1502, Safari: 1501/1502, Edge: 1501/1502 (interop: 99.7%)
* Open issues: [27 on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aissue+state%3Aopen+label%3Amediaqueries-4), 0 in spec

So I believe it is time to think about pushing this spec forward and get it to REC status.

AFAIU, the next steps are to publish an updated CRD (requested in https://github.com/w3c/csswg-drafts/issues/6900#issuecomment-3795685086) and based on that generate an updated implementation report. The open issues also need to be reviewed. (Skimming through them, many of them can be postponed to level 5.)
