While reading the [CSS Color 5](https://www.w3.org/TR/css-color-5) spec, the term "**CIE LCH**" was ambiguous. This could mean **CIE LCHuv** based on CIE Luv, or **CIE LCHab** based on CIE Lab.

After digging a bit, it became understandable that what was meant is CIE LCHab.
Please clarify this in the documentation.

<!-- comment id=3714650765 author=svgeesus created=2026-01-06T13:12:54Z url=https://github.com/w3c/csswg-drafts/issues/13286#issuecomment-3714650765 -->
## @svgeesus — 2026-01-06

CIE LCH is defined in CSS Color 4, not 5 (Color 5 adds relative color syntax to the existing definition). From [9.1. CIE Lab and LCH](https://drafts.csswg.org/css-color-4/#cie-lab):

> CIE LCH has the same L axis as Lab, but uses polar coordinates C (chroma) and H (hue), making it a polar, cylindrical coordinate system. C is the geometric distance from the L axis and H is the angle from the positive a axis, towards the positive b axis.

There is no ambiguity in this definition.
