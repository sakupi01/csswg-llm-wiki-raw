https://drafts.csswg.org/web-animations-2/#the-effecttiming-dictionaries

`partial dictionary EffectTiming` has specified `duration`. Two things have changed - it adds an "auto" default, and the type is changed to allow `CSSNumericValue`.

`partial dictionary OptionalEffectTiming` has not been updated to specify `duration`. It of course should not have a default `auto`, but it does seem to me that it should be allowing the type `CSSNumericValue`.
