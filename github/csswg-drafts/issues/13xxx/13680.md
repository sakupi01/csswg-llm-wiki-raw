In https://github.com/w3c/csswg-drafts/issues/12927, we resolved to add an unscoped mixin variant:

```
RESOLVED: Add an unscoped mixin variant (syntax TBD)
```

This is now specified as [@macro](https://drafts.csswg.org/css-mixins-1/#macro-rule), which, at least to me, makes a lot of sense. (In particular, the absence of arguments seems wise). However, since the previous resolution landed at "syntax TBD", we should take an explicit resolution to approve it.

Note: There was some (after-the-fact) discussion around `@macro` from https://github.com/w3c/csswg-drafts/issues/12927#issuecomment-4000841671 and onwards.
