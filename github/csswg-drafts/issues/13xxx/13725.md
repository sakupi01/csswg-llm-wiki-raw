[Now](https://github.com/w3c/csswg-drafts/issues/12513) that `light-dark()` takes either `<color>` or `<image>` values, it seems a little out of place in css-color-5.
Should we move it?

css-images also seems like a poor fit, for the same reason. css-color-adjust seems like the most fitting place. css-values is another candidate.

cc @tabatkins @fantasai

If we do decide to move it (I am weakly in favor) then I agree that css-color-adjust seems like the best place for it. @alisonmaher @atanassov  would you agree?
