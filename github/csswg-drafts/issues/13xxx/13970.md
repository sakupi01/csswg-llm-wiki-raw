Currently, CSS transitions and animations can only be triggered by CSS class assignments.

I suggest to add a new set of keywords to these two specs that cause a transition/animation to start when the corresponding element gets into view.

These different kinds of behaviours should be covered by this feature request:

<br/>

- Start transition/animation when the elements first pixel gets into view
- Start transition/animation when the elements is fully in view

=> There may be a threshold parameter (e.g. `cover 0%` to `cover 100%`), with 
`100%` being the maximum visible region that is available by the viewport if the viewport is smaller than the element.
<br/>

- Restart transition/animation once the element was out of view and comes into view again (i.e., `repeat`)
- Only start transition/animation once (i.e., `initial`)
