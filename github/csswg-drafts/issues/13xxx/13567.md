From [this WPT test](https://wpt.fyi/results/css/css-anchor-position/position-try-tree-scoped.html?label=master&label=experimental&aligned&q=%2Fcss%2Fcss-anchor-position%2Fposition-try-tree-scoped.html), it seems that we're expecting `@position-try` name to be a tree-scoped name. Further reading [the spec](https://drafts.csswg.org/css-shadow/#shadow-names) linked by the test, it seems that this tree-scoped name is global, unlike `anchor-scope` and `anchor-name`, which are local. Unless I'm misreading the test?

Ideally, we should reference this in [the definition](https://drafts.csswg.org/css-anchor-position-1/#fallback-rule) of `@posiiton-try`.

## @tabatkins — 2026-06-17

Yeah, we should link in the "global" term, but the name in question here *cannot* be local; `@position-try` is not in any way attached to a particular element. Being global is the only possible behavior for it.
