(Making [my comment](https://github.com/w3c/csswg-drafts/issues/7047#issuecomment-4549178825) in #7047)

#7047 concluded that named timeline lookups are done across the flattened tree. OTOH, a recent-ish resolution of #13364 made the name visibility not exclusive to descendants without having to use `timeline-scope`, Having it limit the scope instead.

However, the flat-tree wording is still used, so if there's no `timeline-scope` used anywhere, a shadow tree's scroll timeline reference may suddenly attach to another shadow tree's scroll timeline because it happens be appended where it's later in the flat tree order. This seems weird encapsulation-wise.

I guess `timeline-scope: all` can be used to prevent this, but that seems different from e.g. `anchor-scope`, and from what I understand, #7047 was mainly to address the desire for authors to have timelines available to ancestor elements.

Is the above assumption correct? If so, is it possible to have timeline names be global tree-scoped names?
