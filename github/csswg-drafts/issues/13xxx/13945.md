### What problem are you trying to solve?

Firefox has non-standard `scrollLeftMax` and `scrollTopMax` props which we need in all browsers. Currently there's literally no way to reliably tell if a container is scrolled all the way to the end.

### What solutions exist today?

Using basic math like `scrollWidth - scrollLeft - clientWidth` is broken due to subpixels, especially in zooms outside 100%.

### How would you solve it?

Expose `scrollLeftMax` and `scrollTopMax` like Firefox does so people can just use `scrollLeft === scrollLeftMax`
