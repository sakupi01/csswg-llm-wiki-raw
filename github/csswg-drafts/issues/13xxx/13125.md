Because in level 3 this material was part of the Selectors spec, just like it was part of the single CSS spec in level 1 and level 2.   [selectors-3](https://drafts.csswg.org/selectors-3/) was split into [selectors-4](https://drafts.csswg.org/selectors-4/) and [css-pseudo-4](https://drafts.csswg.org/css-pseudo-4/).
