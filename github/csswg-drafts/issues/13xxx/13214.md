The legacy CDO token looks like an opening HTML comment: `<!--`. In [its railroad diagram](https://drafts.csswg.org/css-syntax-3/#CDO-token-diagram) however, the character sequence is `<<!---->!--`. This seems like an editorial mistake or possibly an attempt to circumvent Bikeshed actually starting a comment there by throwing in an empty comment `<!---->` instead of escaping the angle bracket `&gt;` or something similar.
