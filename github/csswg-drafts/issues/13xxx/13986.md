In the [previous comments](https://github.com/w3c/csswg-drafts/issues/12407#issuecomment-3073735790), it was mentioned that discuss for `activeViewTransitions` array on the document that captures all transitions within this document. But it didn't come to an end afterwards. I hope to reintroduce it.

#### Use case

Considering that you are performing high-overhead operations, you would like to pause the operations if there are any view transitions within the document (including element-scoped view transitions) until all the transitions are complete before continuing, to avoid causing the transitions to lag.

At this point, using `document.activeViewTransitions` will become very convenient.

```javascript
if (document.activeViewTransitions.length > 0) {
    await Promise.all(document.activeViewTransitions.map(viewTransition => viewTransition.finished));
}
// Continue do some high-overhead operations
```
