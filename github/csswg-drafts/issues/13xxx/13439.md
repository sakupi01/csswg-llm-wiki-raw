CSS "Speech" is too restricted to TTS now, as it has introduced cues to mark-up some content orally.

Maybe the name of the CSS should be changed to stick to its new reality. It could be renamed _CSS audio_, as audiobooks are very popular now and speak to everyone.

Every born accessible eBook can be dynamically converted into an audiobook by a reading system if it implements CSS Speech/audio, and it calls a TTS . It is highly important, as pre-recorded audiobooks (with actors' voices) do not cover the whole digital production, far from there...
