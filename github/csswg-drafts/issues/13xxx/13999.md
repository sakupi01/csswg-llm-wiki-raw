We initially discussed overscroll areas as a pure css feature #12750, however we decided to define it via html properties to better follow established patterns for the implied semantics and roles that we expect to have.

After introducing and getting a general consensus on the shape of the feature in openui https://github.com/openui/open-ui/issues/1372 We have since proposed overscrollcontainer and overscrollarea as html attributes and toggle-overscroll as an invoker command in https://github.com/whatwg/html/issues/12273. While html attributes is the way to create these areas, the generated box tree, styles, and scrolling behaviors are standard css behaviors.

As such, we would like to extend the css-overscroll specification to include a description of the resulting boxes and UA styles used by those boxes when using overscrollcontainers. This would result from a property that is established from the html spec for these areas to create them.

TLDR; we propose adding a description of the overscrollcontainer and overscrollarea box tree, implicit scrolling behaviors, and interactions with scrolling and indeed the `overscroll-behavior` property in css-overscroll.

This may be best suited for a level 2 spec.
