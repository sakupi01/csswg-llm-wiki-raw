This is a follow up to the [discussion on Jan 28](https://github.com/w3c/csswg-drafts/issues/1771#issuecomment-3806716273).
> emilio: other question is: would this apply when you have an SVG doc embedded?

@emilio @Loirooriol @smfr @svgeesus @fantasai @dholbert @bfgeek 

The current behaviors are summarized at #13584.

I have mild preference not to apply to SVG content because it is more like images and it has its own behavior already defined as summarized in the table in #13584, but I'm also fine with other options.
