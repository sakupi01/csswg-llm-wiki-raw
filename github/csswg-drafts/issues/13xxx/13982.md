I'm splitting this issue out from https://github.com/w3c/csswg-drafts/issues/12437. (See also https://github.com/w3c/csswg-drafts/issues/13980 and https://github.com/w3c/csswg-drafts/issues/13981.)

Let's figure out what the right UA stylesheet rules should be for `::interest-button`. From [this comment](https://github.com/w3c/csswg-drafts/issues/12437#issuecomment-4462208949) (and tweaked according to that conversation), here's a proposal:

```css
[interestfor]::interest-button {
  display: inline-block;
  color: inherit;
  background-color: transparent;
  box-sizing: border-box;
  min-inline-size: 24px;
  min-block-size: max(24px, 1lh);
  vertical-align: middle;
  align-content: center;
  text-align: center;
  user-select: none;
  cursor: help;
}
[interestfor]::interest-button:hover {
  background-color: color-mix(currentColor 10%, transparent);
}
[interestfor]::interest-button:active {
  background-color: color-mix(currentColor 20%, transparent);
}
```

-----

When used with [proposed layout sibling approach](https://github.com/w3c/csswg-drafts/issues/13981#issuecomment-5688449044), and with a developer opt-in of:

```css
::interest-button {
  content: '\24D8' / '';
}
```
