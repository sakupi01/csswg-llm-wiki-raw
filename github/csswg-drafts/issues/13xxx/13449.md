PROBLEM
Though the philosophy of SSML et CSS Speech is different, it would be interesting for those who know both standards to get the full picture of their equivalence versus volontary non equivalence.
Furthermore, this alignement exercise is very useful to consolidate CSS Speech. It provides an easy way to check that every absence of a CSS property/value is fully justified. I am not sure this is always the case yet.

SOLUTION
Add a new section called 3.2 Crosswalk between SSML & CSS Speech.

This section can refer to both [Specification for Spoken Presentation in HTML ](https://www.w3.org/TR/spoken-html) (Working Draft 23 September 2021) and [Speech Synthesis Markup Language (SSML) Version 1.1](https://www.w3.org/TR/speech-synthesis11) (Recommendation 7 September 2010), as the first often refers to the latter for values definition.

It will contain a table mapping SSML and CSS Speech properties and values. I already did the work for myself. So I am sharing it with the community so you do not have to start from scratch, as it takes time...
See my Excel file attached (filters are useful in specification process). It is only a proposal to save you time.
[crosswalk_SSML_CSSspeech.xlsx](https://github.com/user-attachments/files/25069830/crosswalk_SSML_CSSspeech.xlsx)
