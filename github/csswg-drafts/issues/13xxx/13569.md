So per the [ISSUE 4](https://drafts.csswg.org/scroll-animations-1/#issue-79ed79d9) mentioned in [scroll-animations-1], the section of Timeline Ranges should be move into [css-animations-2] and [web-animations-2]. I didn't find the related spec issue so create this one to track.

It seems other specs may use these properties as well (e.g. pointer animations), so it'd be better to move them earlier, to make it clearer that those properties are the general animation properties and they are also in coordinating list property group with `animation-name` I think.

Besides, I expect these properties (and `animation-timeline`) should be applied to `::marker` as well, so perhaps we also need to update the [property list of ::marker](https://drafts.csswg.org/css-lists-3/#marker-properties) in [css-lists-3] to include [css-animations-2] after the move.
