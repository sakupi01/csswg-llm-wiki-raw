You can do this on text with CSS:

p {
        font-family: random;
}

It picks random fonts and puts them by-letter. There is also:

p {
        font-family: pick(Arial, sans-serif, "Segoe UI", "Verdana");
}

which makes it a random font from the specified fonts.
