The current stylesheet creates and destroys the `::checkmark` pseudo-element whenever the `:checked` state changes. It might be more performant (and consistent) to make it exist always and simply toggle the `visibility`, just like we do for select menus. What do we think? CC @bfgeek

## @lukewarlow — 2025-12-18

Given we also haven't yet accounted for Indeterminate which will need presumably either the ::checkmark or a different pseudo element (I prefer just using ::checkmark personally). I agree it makes sense to always define ::checkmark and then change it's visibility.
