In https://github.com/w3c/csswg-drafts/issues/13355 we discussed whether to rename `::field-text` since it can sometimes contain additional structure (`::field-component` and `::field-separator`). Opening this issue to track that discussion. The main contender atm seems to be `::field-content` (or `::field-contents`).
