(Written with assistance from GPT-6 Astra Max.)

The [import grammar](https://drafts.csswg.org/css-cascade-6/#at-import) accepts `scope(<scope-start> | <scope-boundaries>)`. The first alternative needs a selector, and `<scope-boundaries>` has a required group, so neither can be empty.

Browsers nevertheless accept:

```html
<style id="sheet">@import "data:text/css," scope();</style>
<script>
  console.log(document.getElementById("sheet").sheet.cssRules[0].cssText);
  // @import url("data:text/css,") scope();
</script>
```

Chromium, Firefox, and WebKit retain this rule.

Should we allow omitted arguments in `scope()` and define them as the same implicit scope?
