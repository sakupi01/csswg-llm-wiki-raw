I'm splitting this out of https://github.com/w3c/csswg-drafts/issues/13981#issuecomment-5060804089.

The current proposal is to add a dedicated `::interest-button` pseudo element for interest invokers, which shows interest in the originating element when clicked by mouse/touch. It comes with UA stylesheet rules to make it nice by default, such as positioning, min-sizing, margins, etc. (See https://github.com/w3c/csswg-drafts/issues/13982 for more discussion of the styles.)

Another [suggestion](https://github.com/w3c/csswg-drafts/issues/13981#issuecomment-5060804089) is to instead re-use existing pseudos with a new property, like:

```
Name:       interest-target
Value:      none | originating
Initial:    none
Applies to: pseudo-elements
Inherited:  no
```

So you'd do:

```
[interestfor]::after {
  interest-target: originating; /* the new property */
  content: '\24D8' / '';
  /* other styles to set min sizes, borders, etc. */
}
```

Pros:
- Avoids adding a new pseudo element for this one purpose

Cons:
- Requires the developer to set all the other styles themselves.
- Begs the question of which existing pseudos this can be used on
