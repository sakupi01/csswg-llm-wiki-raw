https://drafts.csswg.org/cssom-1/#parse-a-css-declaration-block has:

>  1. Let declarations be the returned declarations from invoking [parse a block’s contents](https://drafts.csswg.org/css-syntax-3/#parse-a-blocks-contents) with string.

But if you have `style="}; color: red"` or so you get just no declarations, which no browser does, because you go to https://drafts.csswg.org/css-syntax-3/#consume-a-blocks-contents:

> [<EOF-token>](https://drafts.csswg.org/css-syntax-3/#typedef-eof-token)
> [<}-token>](https://drafts.csswg.org/css-syntax-3/#tokendef-close-curly)
>    Return rules.

That seems like an oversight? Similarly `{}color:red` would be red which seems bad-ish (but maybe not?)

I'm adding some tests for current browser behavior in `/css/cssom` but we should probably make the spec reflect reality...
