`css-sizing-3` has:

```
	<pre class="propdef partial">
	Name: column-width
	Value: auto | <<box-size>>
```

`css-sizing-4` has:

```
	<pre class="propdef partial">
	Name: column-width
	New Values: auto | <<box-size>>
```

Downstream in `@webref/css` this becomes: `auto | <box-size> | auto | <box-size>`
