The procedure to [replace an `ident()` function](https://drafts.csswg.org/css-values-5/#ident) says:

  > 4. Serialize each item in pieces, then concatenate the list. Return an [ident](https://drafts.csswg.org/css-values-4/#css-css-identifier) whose value is the result.

What if the result from concatenating does not produce a valid identifier, even when escaped. For example, with `ident("")`.

There is little chance of that happening, obviously.
