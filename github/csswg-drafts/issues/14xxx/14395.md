Splitting this out from https://github.com/w3c/csswg-drafts/issues/14323 ...

Now that we have the ability to style the content outside the `::picker-icon` as its own addressable box, we should switch how we're managing spacing within the select button.

Currently we're using an `auto` margin. But this has two disadvantages:
- It means the margin can't be used for spacing around the `::picker-icon`, in case someone wants to style that with a background or border and can't use padding.
- It's not a pattern that works well when we have multiple button-y things inside the form control, which might happen with certain `<input>`s.

Proposal is to switch to `::field-content, selectedcontent { flex: 1; }` which flexes the option-text wrapper itself, rather than the space between it and the picker-icon.
