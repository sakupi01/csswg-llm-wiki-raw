Currently, `keyboard-inset-*` is defined in [VirtualKeyboard API](https://w3c.github.io/virtual-keyboard/#keyboard-inset-variables). In Blink, these variables seem to be set when `navigator.virtualKeyboard.overlaysContent = true;`.

When using `interactive-widget=overlays-content` (https://drafts.csswg.org/css-viewport/#interactive-widget-section), these variables should be set since virtual keyboard is converted on web content.  CSS Viewport Module spec has a section for `virtualkeyboard.overlaysContent`'s behavior with `interactive-widget`.

Also, a editor of VirtualKeyboard API is mostly inactive. ` keyboard-inset-*` is CSS environment variables, so I think this spec should be handled by `CSS Environment Variables Module`.

Ref: https://github.com/w3c/virtual-keyboard/issues/5
