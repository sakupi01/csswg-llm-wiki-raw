*7.3.3. Implicitly-Named Areas* requires that whenever there are lines named `foo-start` and `foo-end`, an area named `foo` should be implicitly added. I see the following problems:

### Normative

1. It should only happen if there is exactly one line with each name.
2. It should only happen if `foo-start` precedes `foo-end`.
3. It should only happen if an area with the same name isn't specified by `grid-template-areas`.

### Editorial

1. Presumably – and I suggest making it clear – lines with those names must be present in both dimensions.
2. It says `'foo-start'/'foo-end'`, without putting `foo` in `<var>`, which in my browser shows as italic, like in *7.3.2. Implicitly-Assigned Line Names*.
3. A note should clarify that in subgrids, one or both pertinent lines in a subgridded dimension (which may be both) can be inherited.

Line names generated according to *7.3.2. Implicitly-Assigned Line Names* are inherited too by subgrids. (Perhaps worth a separate note.)
