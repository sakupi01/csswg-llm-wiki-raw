The icons we use for ::checkmark and ::picker-icon are not particularly useful to read aloud. The status of the control is already exposed to AT independently, so we propose using empty alt text for these glyphs:

```
::checkmark {
  content: "\2713" / "";
}
::picker-icon {
  content: ... / "";
}
```

## @josepharhar — 2026-08-17

In chromium, we manually remove these pseudo elements from the accessibility tree so that its functionally the same as having empty alt text. If an author overrides this value, I don't think that they should have to remember to make the alt text empty like we could do in the UA stylesheet.
