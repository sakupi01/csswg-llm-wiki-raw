Suppose the following:

```html
<style> img { link-parameters: param(--w <length>, 200px); } </style>
<img src="box.svg">
```

```html
<!-- box.svg -->
<svg xmlns="http://www.w3.org/2000/svg" width="env(--w, 50px)" height="50">
   <rect width="100%" height="100%" fill="green"/>
</svg>
```

The img has no specified size, so it's sized from the resource's intrinsic dimensions. Those depend on `env(--w)`, which depends on the parameter. If we apply parameters before computing intrinsic dimensions then the img here would be `200 x 50`. If we apply parameters after computing intrinsic dimensions then the fallback would win?
