How should [`animation-timing-function`](https://drafts.csswg.org/css-animations-1/#propdef-animation-timing-function) in the following be interpreted?

```css
@keyframes bounce {
  from {
    top: 100px;
    animation-timing-function: ease-out, ease-in;
  }
}
```

The grammar of [`animation-timing-function`](https://drafts.csswg.org/css-animations-1/#propdef-animation-timing-function) allows for a comma-separated list of `<easing-function>` values, and that makes sense outside of `@keyframes`, as it is part of a coordinated value list. But when used inside of `@keyframes`, the list version doesn't seem correct.

I haven't been able to find anything in the spec that restricts the grammar down to a single value inside of  `@keyframes`, and I couldn't find any WPT tests that test for this.

(The same question applies to `animation-composition`).

## @tabatkins — 2026-06-29

The original spec was not well-written in this regard, but imo the behavior the spec *should* define here is that the `animation-*` properties are not allowed inside of keyframes, but some related `animation-*` *descriptors* (with different, singular syntax) are allowed, and change the behavior of the keyframe itself.

## @cdoublev — 2026-09-29

I have two minor concerns about defining these `animation-*` properties accepted in keyframe rules, as descriptors for `@keyframes`.

(1) This should be updated ([CSS Syntax](https://drafts.csswg.org/css-syntax-3/#css-descriptor-declarations)):

  > Declarations are further categorized as property declarations or descriptor declarations, with the former setting CSS properties and appearing most often in qualified rules and the latter setting CSS descriptors, which appear only in at-rules.

Perhaps property declarations apply to elements, while descriptor declarations apply to the resource represented by the rule?

(2) And I think any author would expect `@keyframes { animation-timing-function: ease }` to be valid, given this:

  > **Name:** `animation-timing-function`
  > **For:** `@keyframes`

If `For` is merely a namespacing mechanisme, I do not see the point of exposing it.
