In the definition of the [`zoom`](https://drafts.csswg.org/css-viewport/#zoom-property) property, the spec states zoom affects the [used value](https://drafts.csswg.org/css-cascade-5/#used-value):

> To apply zoom, the [used value](https://drafts.csswg.org/css-cascade-5/#used-value) of a CSS property (including values inside of [path()](https://drafts.csswg.org/css-shapes-1/#funcdef-basic-shape-path) strings) is pre-multiplied (before any other steps in the used value stage) by the used value of [zoom](https://drafts.csswg.org/css-viewport/#propdef-zoom) for the element. 

but then right below that there is a note that states:

> NOTE: Since this multiplication is on [computed value](https://drafts.csswg.org/css-cascade-5/#computed-value)s, it applies to all inherited properties such as [line-height](https://drafts.csswg.org/css2/#propdef-line-height) and [font-size](https://drafts.csswg.org/css-fonts-4/#propdef-font-size).

This doesn't seem to match.
