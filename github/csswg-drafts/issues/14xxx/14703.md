**Where:** CSS Cascading and Inheritance Level 5, Editor's Draft 13 April 2026, §6.4.3 Layer Ordering (#layer-ordering), example #example-87e2d331. The Candidate Recommendation Snapshot of 13 January 2022 has the same example with the same two sentences.

**Text.** The rule:

> Cascade layers are sorted by the order in which they first are declared, with nested layers grouped within their parent layer. Unlayered rules are sorted later than any layered rules within the same parent layer (if any).

The example:

```css
@media (min-width: 30em) {
  @layer layout {
    .title { font-size: x-large; }
  }
}

@media (prefers-color-scheme: dark) {
  @layer theme {
    .title { color: white; }
  }
}

@layer theme, layout;
```

> If the first media-query matches based on viewport dimensions, then the layout layer will come first in the layer order. If the color-scheme preference query matches, or if neither condition is true, then theme will come first in the layer order.

**What is wrong.** Take a wide viewport with a dark color-scheme preference, so both queries match. The first sentence applies: `layout` comes first. The second sentence also applies ("If the color-scheme preference query matches"): `theme` comes first. The example contradicts itself for this case.

The rule itself is clear. With both queries true, `layout` is declared first, then `theme`, and the final `@layer theme, layout;` cannot reorder layers that already exist. So `layout` is first. Only the second sentence is wrong: its condition should exclude the case where the width query matches too.

The same thing with one property, so that the two orders give different colors:

```html
<style>
  @media (min-width: 30em) {
    @layer layout { .title { color: red; } }
  }
  @media (prefers-color-scheme: dark) {
    @layer theme { .title { color: blue; } }
  }
  @layer theme, layout;
</style>
<p class="title">Example</p>
```

With both queries true, both declarations are normal author declarations in the same context, not in a style attribute, so the Layers step decides. By the rule the order is `layout, theme`, and the later layer wins: blue. By the second sentence of the example the order is `theme, layout`: red.

Found during an AI-assisted review of the cascade specs.

**Request:** could the second sentence read "Otherwise, theme will come first in the layer order"?
