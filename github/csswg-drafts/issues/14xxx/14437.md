In [CSS Color Adjust - § 3.1. Properties Affected by Forced Colors Mode](https://drafts.csswg.org/css-color-adjust-1/#forced-colors-properties):

  > For each `<color>` component of a property, if its computed value is a color other than a system color, its used value is instead forced to a system color [...]

The intention is that `<system-color>` within declared values is not affected by forced colors mode... in the same way as other `<color>` types (rather than not being affected at all), as hinted in [CSS Color 4 - § 6.2. System Colors](https://drafts.csswg.org/css-color-4/#css-system-colors):

  > However, in forced colors mode, most colors on the page are forced into a restricted, user-chosen palette [...]. The `<system-color>` keywords expose these user-chosen colors so that the rest of the page can integrate with this restricted palette.

So when [CSS Color 4 - § 15.5. Resolving other colors](https://drafts.csswg.org/css-color-4/#resolving-other-colors) says:

  > For system colors, the computed and used value is the corresponding color in its color space [...]

The *corresponding color* must be a forced color.

In my opinion, the most annoying problem is that when interpreting these texts naively, the used value of a system color would still be forced to another system color, since it is resolved to another `<color>` at computed value time. I do not know how implementations handle this, but I think it would be useful to clarify in CSS Color Adjust, that if the computed value *was* a system color, the used value must not be forced to another system color.

The secondary problem I see is that *the corresponding color* is a bit too hazy, in my opinion. At least, a link to _§ 6.2. System Colors_ to _"see more details about the corresponding color"_ could be useful.

My understanding is that when the forced color mode is not active, `<system-color>` resolves to an arbitrary value defined by the user agent, based on the element color scheme, and ignoring the colors from the theme defined at the browser or system level. When it is active, it resolves to the corresponding forced color if it is defined, otherwise to the same value as if the forced color mode was not active.
