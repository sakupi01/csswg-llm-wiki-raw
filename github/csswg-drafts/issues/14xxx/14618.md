The [zoom grammar](https://drafts.csswg.org/css-viewport-1/#zoom-property) permits nonnegative numbers and percentages but omits `normal`.

This interoperable behavior is covered by `css/css-viewport/zoom/parsing/zoom-valid.html`:

```js
const element = document.body.appendChild(document.createElement("div"));
element.style.zoom = "normal";
console.log(element.style.zoom); // "normal"
console.log(getComputedStyle(element).zoom); // "1"
element.remove();
```

Presumably the spec should include `normal` as a legacy alias for a zoom factor of 1, preserving the keyword in specified-value serialization.
