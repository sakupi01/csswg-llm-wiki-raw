This came up when trying to mimic `disclosure-open` with other arrow-like characters...

We can force a character to be rendered absolutely (`upright`) when that's necessary, but we don't have a good way to rotate a glyph relative to the block flow direction, given `vertical-lr` lines are rotated against the flow direction.
