The spec text in https://drafts.csswg.org/css-values-5/#interpolate-calc-size says

> Whether two calc-size() functions can be interpolated depends on their calc-size basis values (after being prepared for interpolation).

These have the same basis (`any`) and are in fact completely identical after the prepare step

`calc-size(any, 50px)`
`calc-size(50px, size)`

so should interpolate like `any`. However WPTs disagree and specifically test that the second one does not interpolate with keywords in `css/css-values/calc-size/animation/calc-size-height-interpolation.html`:

```js
test_interpolation({
  property: 'height',
  from: keyword,
  to: 'calc-size(any, 50px)',
}, [ /* ... interpolates ... */ ]);

test_no_interpolation({
  property: 'height',
  from: keyword,
  to: 'calc-size(50px, size)',
});
```
