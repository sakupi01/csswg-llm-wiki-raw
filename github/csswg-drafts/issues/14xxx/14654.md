Hi folks,

I was looking for specifications that have no FPWD. This means they have not had a [patent policy exclusion opportunity](https://www.w3.org/policies/patent-policy/#sec-Exclusion), so their patent status is unknown.

(I left out Unofficial Drafts, indexes, templates like css-module, and jokes like css-egg)

## ED with no TR: metadata line (8)

css-extensions-1
css-flexbox-2
css-gcpm-4
css-navigation-1
css-page-4
css-shadow-1
css-variables-2
pointer-animations-1

_Flexbox-2 also has an odd "Changes since the 14 October 2025 CRD", copied from Flexbox-1_

## TR: link present but it returns 404 (7)

compositing-2    https://www.w3.org/TR/compositing-2/
css-color-6    https://www.w3.org/TR/css-color-6/
css-images-5    https://www.w3.org/TR/css-images-5/
css-overscroll-2    https://www.w3.org/TR/css-overscroll-2/
css-shapes-2    https://www.w3.org/TR/css-shapes-2/
css-size-adjust-1    https://www.w3.org/TR/css-size-adjust/
filter-effects-2    https://www.w3.org/TR/filter-effects-2/

Some of these have had significant work, and some have implementations. I think we should triage these into 

1. Should be published now, as-is
2. Waiting for near-term feature to be added before fpwd
3. Not enough in there to warrant publication, yet
4. Abandoned

I encourage editors to chime in if they have opinions on which category their specs belong to.

## @svgeesus — 2026-10-23

[**CSS Color 6**](https://drafts.csswg.org/css-color-6/) has one new and one expanded feature:

- [`contrast-color()`](https://drafts.csswg.org/css-color-6/#colorcontrast) is extended, compared to the simple MVP one in CSS Color 5
- [`color-layers()`](https://drafts.csswg.org/css-color-6/#color-layers) is new

The spec is flagged "not ready for implementation' and there are 308 WPT. Some parts are very draft-y but in general the direction is well established. Currently [35 open, 18 closed issues](https://github.com/w3c/csswg-drafts/issues?q=is%3Aissue+state%3Aopen+label%3Acss-color-6)

My feeling is "Should be published now, as-is" @LeaVerou @una what do you think?

## @svgeesus — 2026-10-23

[**CSS Images 5**](https://drafts.csswg.org/css-images-5/) has three new features:

- [the `<image>` type](https://drafts.csswg.org/css-images-5/#image-values)
- [the 'object-view-box` property](https://drafts.csswg.org/css-images-5/#sizing)
- mesh gradients and freeform gradients

There is no "not ready for implementation". The recently-agreed 2D gradients are not in the spec yet, although there is a good explainer. Seemingly no WPT. [16 open and 1 closed issues](https://github.com/w3c/csswg-drafts/issues?q=is%3Aissue+state%3Aopen+label%3Acss-images-5).

My feeling is that this should wait until the 2D gradients are added, before FPWD. @tabatkins @fantasai @JoshTumath @LeaVerou do you agree?

## @svgeesus — 2026-10-23

[**Compositing 2**](https://drafts.csswg.org/compositing-2/)

This spec was [started 11 years ago](https://github.com/w3c/csswg-drafts/commit/73af67d5696a0e5094337515d4a11c7733d4edd3) and has never been published. It [does not seem particularly active](https://github.com/w3c/csswg-drafts/commits/main/compositing-2). Many edits are just editorial cleanup and re-alignment with other specifications. Also, one editor is no longer in CSS WG.

A lot of it seems to be the definitions of Porter-Duff compositing, which were in older SVG specifications. My impression is that this spec consists mostly of things _moved out of the way_ so that Compositing 1 could move forward. Thus, I suspect there is no immediate need to publish a FPWD. Equally, I would not assert that it is abandoned. So perhaps it is "Not enough in there to warrant publication, yet"? @chrishtr ?
