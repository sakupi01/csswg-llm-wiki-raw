Allowing [GeometryUtils](https://drafts.csswg.org/cssom-view/#geometryutils) to return cross-document information exposes a new class of cross-origin information leak. I think we should disable this by requiring that nodes are from the same document.

For example, consider:
```
https://origin-a.com/outer.html
  https://origin-b.com/middle.html
    https://origin-a.com/inner.html
```

Origin-a can monitor the layout of origin-b using `[element in inner].getBoxQuads({relativeTo: [element in outer]});`.

See also: Intersection observer's privacy approach in https://w3c.github.io/IntersectionObserver/#privacy
