https://drafts.csswg.org/css-color-4/#specifying-lab-lch

> If the lightness of a Lab color (after clamping) is 0%, or 100% the color will be displayed as black, or white, respectively due to gamut mapping to the display.

See: https://www.romainmenke.com/gamut-mapping-d65-vs-d50/lch-gradient-white-black.html

<img width="1470" height="344" alt="Image" src="https://github.com/user-attachments/assets/64183d2d-2128-42fd-9f28-bd786f27509d" />

These are high chroma gradients with a constant `0` and `100` `l` and a `longer hue` gradient.

In firefox with gamut mapping enabled these do not render as fully black or fully white because converting these from `lch`/`lab` to `oklch` doesn't result in a color with an `l` of `0` or `100` for every hue.

-----

Maybe an extra step in the spec?

> if the origin is in LCH or Lab and if the Lightness is greater than or equal to 100%, convert `oklab(1 0 0 / origin.alpha)` to destination and return it as the gamut mapped color

> if the origin is in LCH or Lab and if the Lightness is less than or equal to 0%, convert `oklab(0 0 0 / origin.alpha)` to destination and return it as the gamut mapped color
