https://drafts.csswg.org/css-overscroll-2/#overscroll-area-parent-box doesn't say what it inherits from.

I could see two reasonable answers:

 * Inherits from the scroll area it wraps.
 * Inherits from the scroll container (and thus all the overscroll area parent boxes can share a style).

From https://drafts.csswg.org/css-overscroll-2/#ua-stylesheet I assume the intention is the later?

<!-- comment id=6373507631 author=flackr created=2026-10-23T19:54:47Z url=https://github.com/w3c/csswg-drafts/issues/14602#issuecomment-6373507631 -->
## @flackr — 2026-10-23

It currently inherits from the scroll area it wraps as it is a dom child despite being a parent box. This matches what we've done for `::scroll-marker` which has similarly interesting box behavior.
