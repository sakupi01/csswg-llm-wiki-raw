# Current Situation

Currently, when using a wrapping flex design, it is not possible to address the first and last element of an axis at runtime.

# Desired Situation

Please introduce pseudo-classes to target the first and last element along both the main and cross axis, e.g.:

```css
:first-on-main-axis
:last-on-main-axis
:first-on-cross-axis
:last-on-cross-axis
```

This would allow for designs like the following:

![menu](https://github.com/user-attachments/assets/da88f8d4-71ca-4191-b647-5662e899f400)

 In the given example, we'd have a design like this:

```
<!DOCTYPE html>
<html lang="en">

  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>

    <style>
      body {
        background-color: #222;
        font: 12pt sans-serif;

        >div {
          display: flex;
          flex-wrap: wrap;

          >div {

            >div.header {
              background-color: #ddd;

              :first-on-main-axis {
                margin-left: 1em;
                border-radius: 1ex 0 0 1ex;
              }

              :last-on-main-axis {
                margin-left: 1em;
                border-radius: 0 1ex 1ex 0;
              }
            }

            >div.content {
              background-color: #ddd;
              margin: 1em;
              padding: 1ex;
              border-radius: 1ex;
            }
          }
        }
      }
    </style>
  </head>

  <body>
    <div>
      <div class="item">
        <div class="header">&nbsp;</div>
        <div class="content">Test</div>
      </div>

      <div class="item">
        <div class="header">&nbsp;</div>

      </div>

        <div class="header">&nbsp;</div>

      </div>

      <div class="item">
        <div class="header">&nbsp;</div>
        <div class="content">Test</div>
      </div>

      <div class="item">
        <div class="header">&nbsp;</div>
        <div class="content">Test</div>
      </div>

      <div class="item">

      </div>

      <div class="item">

        <div class="content">Test</div>
      </div>

  </body>

</html>
```
