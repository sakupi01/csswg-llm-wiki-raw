In #14098 we resolved to use specified order for keyframes when complex syntax is used for keyframe offsets, i.e. `calc(10% * ...) { ... }`.

This raises the question whether implicit keyframes will still be created when the first/last keyframe offset is complex.

For example, in the following effect:

```css
@kefyrames complex () {
  calc(50% - var(--offset)) { opacity: var(--from-op); }
  calc(50% + var(--offset)) { opacity: var(--to-op); }
}
```

Do we create implicit keyframes for the `from` and `to` keyframes?

My preference is that decide whether add implicit keyframes after resolving the offsets. So always add `from`/`to` keyframes if we don't have an initial keyframe with resolved offset of `0%`/end keyframe with resolved offset of `100%`, respectively.
