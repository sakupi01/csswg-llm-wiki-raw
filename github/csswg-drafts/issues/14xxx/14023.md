The [draft requirement](//drafts.csswg.org/css-pseudo-4/#details-content-pseudo) for `::details-content` limits it to `<details>` from HTML. Instead, it should either apply to elements defined by the host language, or the whole mechanism should be defined in CSS and allow using any element in any language styled with CSS the way `details` and `summary` are in HTML.
