https://drafts.csswg.org/css-scroll-snap-2/#initial-scroll-target sets the initial scroll position from the initial scroll target once. What happens if the target moves after that, e.g. due to a layout change or a `transform` animation? Does the scroll container track the target, and if so, is that done by scroll anchoring (and what does `overflow-anchor: none` do)?

@smfr asked this in https://github.com/w3c/csswg-drafts/issues/6986#issuecomment-1028499159 and https://github.com/w3c/csswg-drafts/issues/6986#issuecomment-1028502648.
