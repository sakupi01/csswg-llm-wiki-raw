Add `var-at()` (name tbd) arbitrary substitution function for pulling values from lists. It would behave like `var()` but for indexed access.

Having indexed access directly available during substitution would add more flexibility and remove the need to put everything into separate custom properties: 
```
@property --item-color-0 { syntax: "<color>"; inherits: false; initial-value: black; }
@property --item-color-1 { syntax: "<color>"; inherits: false; initial-value: black; }
@property --item-color-2 { syntax: "<color>"; inherits: false; initial-value: black; }
--item-color-0: red;
--item-color-1; green;
--item-color-2: blue;
color: var(ident(--item-color- attr(item-index)));
```
->
```
@property --item-colors { syntax: "<color>#"; inherits: false; initial-value:black; }
--item-colors: red, green, blue;
color: var-at(--item-colors, attr(item-index type(<integer>)));
```

Also it would add more purpose for list valued properties.
