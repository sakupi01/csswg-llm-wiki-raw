The default padding for `<select>`’s base appearance right now a) doesn’t adhere to good optical alignment due to the ::picker-icon and b) doesn’t provide enough spacing within the interactive elements (like option).

Proposed fixes:

```
select, input, textarea {
  padding-block: 0.4lh;
  padding-inline: 0.7em;
}
select {
  padding-inline-start: 1em; /* counter-balance ::picker-icon */
  gap: 0.65em;
}
select::picker-icon {
  padding-inline: 0.15em;
}
option {
  padding-block: 0.4lh;
  padding-inline: 0.75em 1.1em; /* counter-balance ::checkmark */
  gap: 1ch;
}
optgroup legend {
  padding-block: 0.6em 0.15em;
  padding-inline: 0.75em;
}
```
