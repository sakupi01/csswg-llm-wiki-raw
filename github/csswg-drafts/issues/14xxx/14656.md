When displaying an image like `<img src="foo.svg#box:~:param(--bg, green)">` my assumption is that we should only pass `#box` to the SVG image as its target identifier, but I can't find any spec text that makes that clear. 

For an html document, the monkey patching in https://wicg.github.io/scroll-to-text-fragment/ removes the fragment directives from the URL, but it's not clear that would apply to an SVG image.
