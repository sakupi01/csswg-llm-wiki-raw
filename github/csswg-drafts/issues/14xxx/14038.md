The CSS Typed OM spec defines "create a sum value from a CSSNumericValue" with separate branches for several CSSNumericValue subclasses:

* CSSUnitValue
* CSSMathSum
* CSSMathNegate
* CSSMathProduct
* CSSMathInvert
* CSSMathMin
* CSSMathMax

However, CSSMathClamp is not listed.

It seems CSSMathClamp should follow the same general shape as for example CSSMathMin or CSSMathMax, but with three fixed arguments: lower, value, and upper.

Proposed steps:

1. Let args be lower, value, and upper, each replaced by the result of creating a sum value from the corresponding internal slot.

2. If any item of args is failure, or has a length greater than one, return failure.

3. If not all of the unit maps among the items of args are identical, return failure.

4. Clamp value's sole item's value between lower's and upper's sole item's values, and return value.

This matches existing WPT expectations and current browser behavior as far as I can tell.
