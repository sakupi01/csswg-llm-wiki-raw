One piece of feedback we received in discussion with a11y experts is that we should skip scroll buttons in the [focus order](https://drafts.csswg.org/css-overflow-5/#focus-order) if scroll markers are present. The rationale is that in tab scenarios they provide the same functionality as the scroll markers making the additional tab stop for them confusing and adding keypresses to get past them. They should still be in the accessibility tree and can be focused directly but would normally be skipped in the tab order.

Proposed resolution:
Skip scroll buttons in [focus order](https://drafts.csswg.org/css-overflow-5/#focus-order) when using tabs mode and scroll markers are present.
