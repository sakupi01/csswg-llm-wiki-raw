Following up from [@cdoublev's comment](https://github.com/w3c/csswg-drafts/issues/13478#issuecomment-5907815765)...

The new (non-length) `column-width` values have been marked at risk for over a decade with (afaict) no implementation, and it doesn't seem like they have particularly compelling use cases. Let's drop them from CSS Sizing, and if use cases come up, we can add any necessary values directly to css-multicol-2.
