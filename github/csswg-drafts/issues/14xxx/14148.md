The spec currently says:

> When `outline-style` is `auto`, `outline-color: auto` computes to `auto` and represents the accent color.

I don't think `outline-color: auto` should be required to represent the accent color.

When a control already uses the accent color, drawing the focus outline in the same color can make the outline less distinguishable from the control itself. Since the purpose of the outline is to clearly indicate focus, it should remain visually distinct.

I think `outline-color: auto` should instead be left up to the UA, allowing it to choose a color that provides a more effective focus indicator while still matching the platform's design.
