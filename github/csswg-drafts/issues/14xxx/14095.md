----

see:
- https://drafts.csswg.org/css-color-4/#powerless
- https://drafts.csswg.org/css-color-4/#color-conversion

same color space:
- `s` is `none`: `hsl(from hsl(180 none 50%) h s l)` computes to `hsl(none none 50%)`
- `s` is zero: `hsl(from hsl(180 0 50%) h s l)` computes to `hsl(none 0% 50%)`

different color space:
- `s` is `none`: `hsl(from lch(50 none 180) h s l)` computes to `hsl(none none 46.63266093%)`
- `s` is zero: `hsl(from lch(50 0 180) h s l)` computes to `hsl(none 0% 46.63266093%)`

In all cases `hue` becomes `none` as a result of it being powerless when `chroma` or `saturation` is `0`.
That `chroma`/`saturation` is specified as `none` does not affect that `hue` is powerless.

Is this correct @svgeesus?
