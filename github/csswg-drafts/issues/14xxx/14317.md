The UA stylesheet for `<select>` currently uses `disclosure-open` for the `::picker-icon`. However this kind of large filled triangle tends to be too bold and pointy in comparison to the adjacent text, which has led many design systems, including the demo styles from last week's `<select>` styling discussion, to adopt a chevron design.

The solution in the demo styles, however, is very hacky. (It's using U+2335 COUNTERSINK and adjusting the glyph's vertical position with a negative margin.) We'd prefer the UA stylesheet to use a glyph that doesn't require adjustments.

@tabatkins and I discussed this during the F2F and our suggestion is to create some new `picker-open` and `picker-closed` list styles that draw the appropriate glyphs for the picker-icon, just like `disclosure-open` and `disclosure-closed` do for `<details>`. (We also think it would be good to clean up the syntax by fixing https://github.com/w3c/csswg-drafts/issues/14003.)

See also earlier discussions in https://github.com/whatwg/html/issues/12516
