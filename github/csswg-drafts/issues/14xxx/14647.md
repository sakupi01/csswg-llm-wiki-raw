Many common fonts omit the `BASE` table entirely, leaving browsers to synthesize baselines via heuristics. And when mixing scripts, synthesized baselines cause vertical misalignment. It would be good to add some kind of baseline overrides, like:

```css
@font-face {
  font-family: "MyCJKFont";
  src: url("font.woff2");
  ideographic-over-override: 80%;
  ideographic-under-override: -20%;
  hanging-override: 75%;
}
```

or:

```css
@font-face {
  font-family: "MyCJKFont";
  src: url("font.woff2");
  baseline-override: ideographic-over 80%, ideographic-under -20%, hanging 75%;
}
```
