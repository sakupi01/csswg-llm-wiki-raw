Was just thinking it might make sense to add this to the default UA style sheet:

```
nav { scroll-target-group: auto; }
```

If I understand correctly, I expect `nav` should generally create such a grouping, so let's make it automatic.

(Idk if there are other elements in HTML that should also have this behavior?)
