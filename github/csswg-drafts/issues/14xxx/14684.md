https://drafts.csswg.org/css-grid-3/#gutters:

> In the [stacking axis](https://drafts.csswg.org/css-grid-3/#stacking-axis), a gutter is placed before each [grid item](https://drafts.csswg.org/css-grid-2/#grid-item) except the first in a [grid track](https://drafts.csswg.org/css-grid-2/#grid-track), and extends across that track in the [grid axis](https://drafts.csswg.org/css-grid-3/#grid-axis). The gutter is placed before item self alignment is applied, thus the self alignment of an item does not affect the gutter’s position. Each gutter has the specified gap size, any additional space left by item placement is not part of the gutter. For an item that spans multiple tracks, there is a separate gutter in each track it spans; these gutters do not join across tracks.

A spanner can be the first item in some columns but not in others; example: https://codepen.io/editor/kevinbcmu/pen/01a1820e-9cc2-7f0e-aa57-7afe068ab61e

<img width="792" height="489" alt="Image" src="https://github.com/user-attachments/assets/7b8f9708-02ff-4ba6-aea3-8b157e39fe65" />

The current text makes it ambiguous whether there should be a gutter, and thus a decoration, in the middle column of the 3 that are covered by the spanner:  it is both the first item in the track (no gutter) and an item spanning multiple tracks (separate gutter in each track it spans).

Should there be?
