Although any color styling that the author sets will override all our rules, including those in a media query, we might want to make sure that if the author doesn't set anything, users get appropriate contrast.

For example like this:

```
@media (forced-colors), (prefers-contrast) {
  :is(input, textarea, select):enabled /* increase specificity as needed */ {
    background: Canvas;
    color: CanvasText;
    border-color: CanvasText;
  }
  select:active {
    background: SelectedItem;
    color: SelectedItemText;
  }
  :is(input, textarea, select):disabled {
    background: Canvas;
    color: GrayText;
    border-color: GrayText;
  }
  ::picker(select) {
    background: Canvas;
    color: CanvasText;
    border-color: CanvasText;
    box-shadow: none;
  }
  select option:is(:hover, :focus-visible, :active) {
    background: SelectedItem;
    color: SelectedItemText;
  }
  select option:disabled,
  select optgroup legend {
    color: GrayText;
  }
}
```

Note: Using system colors ensures the form controls have appropriate contrast in all special contrast modes: `forced-colors: active`, `prefers-contrast: more`, `prefers-contrast: less`, and `prefers-contrast: custom`.
