Although any color styling that the author sets will override all our rules, including those in a media query, we might want to make sure that if the author doesn't set anything, users get appropriate contrast.

For example like this:

```
@media (forced-colors), (prefers-contrast) {
  :is(input, textarea, select):enabled /* increase specificity as needed */ {
    background: Canvas;
    color: CanvasText;
    border-color: CanvasText;
  }
  select:active {
    background: SelectedItem;
    color: SelectedItemText;
  }
  :is(input, textarea, select):disabled {
    background: Canvas;
    color: GrayText;
    border-color: GrayText;
  }
  ::picker(select) {
    background: Canvas;
    color: CanvasText;
    border-color: CanvasText;
    box-shadow: none;
  }
  select option:is(:hover, :focus-visible, :active) {
    background: SelectedItem;
    color: SelectedItemText;
  }
  select option:disabled,
  select optgroup legend {
    color: GrayText;
  }
}
```

Note: Using system colors ensures the form controls have appropriate contrast in all special contrast modes: `forced-colors: active`, `prefers-contrast: more`, `prefers-contrast: less`, and `prefers-contrast: custom`.

## @fantasai — 2026-09-30

Alternative for `(prefers-contrast: more)` that doesn't use system colors, but boosts the contrast that we have already:

```
@media (prefers-contrast: more) {
  select {
    border-color: currentColor;
  }
  select:disabled {
    border-color: color-mix(currentColor 40%);
    color: color-mix(currentColor 60%);
    background: color-mix(currentColor 10%);
  }
}
```

See [demo comparsion](https://software.hixie.ch/utilities/js/live-dom-viewer/?%3C!DOCTYPE%20html%3E%3Cstyle%3Eselect%2C%20%3A%3Apicker(select)%20%7B%20appearance%3A%20base-select%3B%20%7D%3C%2Fstyle%3E%0A%3Cp%20class%3Dstandard%3EDisabled%20%3Cselect%20disabled%3E%3Coption%3EFoo%3Coption%3EBar%3C%2Fselect%3E%20Select%20%3Cselect%3E%3Coption%3EFoo%3Coption%3EBar%3C%2Fselect%3E%0A%3Cp%20class%3Dmore-contrast%3EDisabled%20%3Cselect%20disabled%3E%3Coption%3EFoo%3Coption%3EBar%3C%2Fselect%3E%20Select%20%3Cselect%3E%3Coption%3EFoo%3Coption%3EBar%3C%2Fselect%3E%0A%3Cstyle%3E%0A.more-contrast%20select%20%7B%0A%20%20border-color%3A%20currentColor%3B%0A%7D%0A.more-contrast%20select%3Adisabled%20%7B%0A%20%20border-color%3A%20color-mix(currentColor%2040%25)%3B%0A%20%20color%3A%20color-mix(currentColor%2060%25)%3B%0A%20%20background%3A%20color-mix(currentColor%2010%25)%3B%0A%7D).
