https://github.com/w3c/csswg-drafts/issues/5900#issuecomment-2380321760 resolves that `AccentColor` should return the color set by `accent-color`, if one exists.

Given that, it's possible to create a reference cycle when resolving colors and `AccentColor`:
```css
color: AccentColor;
accent-color: currentColor;
```

The used color is then the color of `accent-color` which is... `currentColor`?

Elika thought that we should resolve this in the same way as em/lh, `color: AccentColor` is the `AccentColor` of the parent, then there's no cycles.

## @svgeesus — 2026-07-17

> Elika thought that we should resolve this in the same way as em/lh, color: AccentColor is the AccentColor of the parent, then there's no cycles.

CSS Color 4 [already says](https://drafts.csswg.org/css-color-4/#resolving-other-colors)

> In the [color](https://drafts.csswg.org/css-color-4/#propdef-color) property, the used value of currentcolor is the resolved [inherited value](https://drafts.csswg.org/css-cascade-5/#inherited-value). In any other property, its used value is the used value of the color property on the same element.

So yes, the used value is the `AccentColor` of the parent
