When showing media and presentations, it's desirable to hide the cursor when it's idle in order for it to not disturb the view.
Currently this has to be done with javascript, detecting and setting a class:

```css
.pointer-idle {
  cursor: none;
}
```

This is done on YouTube and our own player.

It would be nice to have a standardized way to do this in CSS.
Either a pseudo-class, or  a media feature:

```css
.presentation:pointer-idle {
  cursor: none;
}

/* or */

.presentation {
  @media (pointer-state: idle) {
    cursor: none;
  }
}
```
