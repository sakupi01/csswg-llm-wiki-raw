In #14172 we resolved on applying a `max-block-size` of `100dvb` to custom selects. As the same issues mentioned in the other issue apply to the inline size, I think it makes sense to apply the same restriction to the inline size, i.e. add `max-inline-size: 100dvb;`.

Sebastian
