https://drafts.css-houdini.org/css-typed-om/#dom-cssmatrixcomponent-cssmatrixcomponent has:

> Let this be a new [CSSMatrixComponent](https://drafts.css-houdini.org/css-typed-om/#cssmatrixcomponent) object with its [matrix](https://drafts.css-houdini.org/css-typed-om/#dom-cssmatrixcomponent-matrix) internal slot set to matrix.

But `matrix` is a `DOMMatrixReadOnly`, and the internal slot is a `DOMMatrix`. Implementations copy the matrix rather than allowing the page to control the internal slot, and I think the spec probably should too.

Alternatively we could add a `DOMMatrix` constructor I guess, which doesn't copy. But that's weird since `toMatrix` is expected to return a fresh matrix, not point to the internal slot...
