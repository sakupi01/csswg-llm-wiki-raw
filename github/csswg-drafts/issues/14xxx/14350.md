Given you have:

```css
:host {
  position-area: top;
  position-try-fallbacks: flip-block;
}
```

This won't work:

```css
@container anchored(fallback: bottom) {
  ...
}
```

You have to explicitly target `fallback: flip-block`.

The assumption that `fallback: flip-block` equals `fallback: bottom` breaks as soon as somebody changes `position-area` on the host element.

I would like to suggest making the anchored container query be more loose when it comes to fallbacks.
