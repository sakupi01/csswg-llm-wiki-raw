Link to spec: https://drafts.csswg.org/css-overflow-3/#propdef-scroll-behavior

Related to #3153 and #6846

The definition table for `scroll-behavior` lists it as "not animatable". Gecko, Blink and WebKit all set its animation type to "discrete". WPT also requires this behavior in [`web-animations/animation-model/animation-types/property-list.js`](<https://github.com/web-platform-tests/wpt/blob/2e4dc257cfbe254ff8449e291cc231f0989b2d38/web-animations/animation-model/animation-types/property-list.js#L1270-L1273>).
