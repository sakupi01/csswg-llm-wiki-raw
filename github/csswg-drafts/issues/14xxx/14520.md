When implementing https://drafts.csswg.org/css-scroll-snap-2/#snap-events-on-layout-changes, if a re-snap is done with a **smooth** scroll, does _“When a snap container re-snaps”_ mean at the time we start the smooth scroll or at the time we finish it?

I could see `scrollsnapchanging` being fired at the time we start the smooth scroll, but `scrollsnapchanged` should probably be fired at the time we finish it. Could this be clarified?
