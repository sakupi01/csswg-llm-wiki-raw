Our build system which serves files under https://drafts.csswg.org/ builds markdown files, like explainers, into nice HTML. That's great. However, section titles don't get an autogenerated id.

This makes linking to any particular section a pain.

```markdown
## The foobar Property
```
should generate
```html
<h2 id="the-foobar-property">The foobar Property</h2>
```
rather than the bare
```html
<h2>The foobar Property</h2>
```
Currently, this cannot even be manually worked around, because neither of the following syntaxes are supported either:
```markdown
## The foobar Property {#the-foobar-property}
```
```markdown
## The foobar Property <a id="the-foobar-property"></a>
```

The first one treats the `{#…}` part as a litteral part of the title and emmits it as is, and the second one emmits:
```html
<h2>The foobar Property  <!-- raw HTML omitted --><!-- raw HTML omitted --></h2>
```
