The current view-transitions-2 spec for @view-transition 'types' (https://drafts.csswg.org/css-view-transitions-2/#descdef-view-transition-types) doesn't seem to place any restrictions on the values of its `<custom-ident>` sub productions, but [WPT](https://github.com/web-platform-tests/wpt/blob/befefbfef4cb4152dac829f2e29a199c76b24ac3/css/css-view-transitions/navigation/with-types/at-rule-with-types-parsing.html#L38) seems to require that values that start with "-ua-" are invalid.

Is this condition just missing from the spec? Or is it specified elsewhere and I just don't have the full context?
