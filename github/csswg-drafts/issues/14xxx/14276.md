Once we resolve to use a colon for separating the name from the value (#14275), we can also use semi-colons to separate multiple key-value pairs, limiting the syntax weirdness to one `param(...)` around the whole set instead of multiple, and also makes it copy/paste compatible with regular declarations.

`params()` would be a more natural name for this, but in CSS we don't typically have multiple functions for 1 vs multiple args. Unless we had _both_, as aliases of each other?
