Moved effectively from https://github.com/w3c/css-houdini-drafts/issues/644.

https://drafts.css-houdini.org/css-typed-om/#dom-stylepropertymap-append says:

> If property is not a [list-valued property](https://drafts.css-houdini.org/css-typed-om/#list-valued-properties), [throw](https://webidl.spec.whatwg.org/#dfn-throw) a [TypeError](https://webidl.spec.whatwg.org/#exceptiondef-typeerror).

https://drafts.css-houdini.org/css-typed-om/#list-valued-properties doesn't define the term properly, and thus engines diverge. For example, WebKit and Blink don't support `transition-property` it seems, or `mask*` longhands...
