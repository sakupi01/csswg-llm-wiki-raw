In https://github.com/w3c/csswg-drafts/issues/12594#issuecomment-5177354464 @fantasai mentioned to rename `:nav-source` to `:navigation-source`:

> I originally was fine with either `:nav-source` or `:navigation-source` when we were reviewing that issue on its own, but in the context of `@navigation` and `navigation()` .…maybe we should go with the full name :navigation-source in order to link the concepts together more strongly.

I discussed this with @noamr and we are fine with this (and I personally also wanted `:navigation-source` anyway 😄).

Tagging for async resolution, as this is only about a rename for an unshipped feature, so there is no author-facing impact.

PROPOSED: Rename `:nav-source` to `:navigation-source`
