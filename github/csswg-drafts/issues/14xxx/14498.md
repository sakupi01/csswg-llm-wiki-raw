`<calc-size-basis>` is  `[ <size-keyword> | <calc-sum> | <calc-size()> | any ]` but "simplify the calc-size basis" algorithm (https://drafts.csswg.org/css-values-5/#simplifying-calc-size) is missing the basic `<size-keyword>` do-nothing case. This is only implied by the later "will either be a single keyword or the value 100%" note.
