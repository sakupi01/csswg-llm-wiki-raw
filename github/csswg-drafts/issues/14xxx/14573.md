Per the current resolutions colour inputs currently look something like below:

<img width="518" height="79" alt="Image" src="https://github.com/user-attachments/assets/5dbb44ef-26e7-41d6-a307-2c738292673e" />

To the human eye both the enable and disabled state look identical.

I propose we add something like below to make this clearer:

```css
input[type="color"]:disabled::color-swatch {
    opacity: 0.5;
}
```
