I'd like people to consider new value for CSS `position` property - parent :
```
child { 
  position:  parent;
  bottom: 0;
  right: 0;
} 
```
It works as if these two rules are applied:

```
parent { position: relative; }
parent > child { 
  position:  absolute;
  bottom: 0;
  right: 0;
} 
```
But 

1. it is just only one rule;
2. without side effects of position: relative; on parent ;

One of examples where this would be beneficial - `span.badge { position: parent; }` :
```
<button>
     <img src=icon> 
     Some text
     <span class=badge>42</span>
</button>
```
Real life [example](https://www.beercss.com/#badges)

Isn't this already possible to achieve using Anchor Positioning? Ofcourse, that won't be only "one rule", but I don't think it's a metric which really matters since it's only two to three rules instead

<img width="478" height="251" alt="Image" src="https://github.com/user-attachments/assets/9b82f204-e511-4eb8-bb6c-3f4975f48281" />

```html
<div class="anchoringparent">
    <div class="anchoredelement">Positioned based on parent</div>
    <div class="outsideelement">Positioned based on &lt;body&gt;</div>
</div>
```

```css
.anchoringparent {
    width: 250px;
    height: 200px;
    background: red;
    anchor-scope: --parent;
    anchor-name: --parent;
}

.anchoredelement {
    background-color: blue;
    width: 50px;
    height: 50px;
    position: absolute;
    position-anchor: --parent;
    top: calc(anchor(center) - 25px);
    left: calc(anchor(center) - 25px);
}

.outsideelement {
    background-color: green;
    width: 100px;
    height: 50px;
    position: absolute;
    left: 275px;
    top: 50px;
}
```

Am I missing something?
