We decided to set the ::picker() colors to `CanvasText` on `Canvas` because we needed to ensure an opaque background for the overlay, but actually, we can probably do better here in matching the author's colors.

For example, WebKit's latest builds are inheriting `color` and generating `background` using `contrast-color()`:

```
::picker(select) {
  background: color-mix(contrast-color(currentColor), white 15%); /* white or charcoal */
}
```

We've also discussed ideas around inheriting the nearest non-transparent `background-color` or using color math to generate a contrasting tint from the `currentColor`.

Can we switch from using `color: CanvasText` to `color: inherit` and figure out some kind of appropriate opaque background?
