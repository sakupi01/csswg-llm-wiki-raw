## @sorvell — 2026-07-14

This would be very useful for form associated custom elements. One current API that I've seen used for this is stuffing the element's "value" into a css custom property. That works, but it  requires documentation and doesn't fit with `control-value()`.

Perhaps `control-value()` could reflect the value set via `ElementInternals.setFormValue(value...)` and if that's a FormData/File/null, it's ignored.
