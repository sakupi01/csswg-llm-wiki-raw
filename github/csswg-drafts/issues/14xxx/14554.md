I discovered by accident that if you have `-webkit-appearance: base-select` it enables base appearance mode in both Chrome and Safari.

`data:text/html,<select style="-webkit-appearance: base-select;"><option><b>123</b></option></select>`

This feels wrong to me but idk if this is intentional or an oversight and should it be restricted?
