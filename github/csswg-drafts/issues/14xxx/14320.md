The text-containing form controls (text inputs, select, button, etc.) use baseline alignment in reference to their text contents. However checkbox, radio button, and range controls do not contain text. So currently, they sit on the baseline. This looks fine if they happen to be sized to match the text, but that's not always the case.

These controls should be centrally aligned by default using `alignment-baseline: central`.

```
input[type=checkbox], input[type=radio], input[switch], input[type=color] {
   vertical-align: central;
}
```
