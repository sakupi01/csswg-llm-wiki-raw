Throughout the Web Animations spec we typically [apply the pending playback rate](https://drafts.csswg.org/web-animations-1/#apply-any-pending-playback-rate) of an animation when setting its [start time](https://www.w3.org/TR/web-animations-1/#animation-start-time). It seems an oversight not to do so within the procedure to [auto-aligning the start time](https://drafts.csswg.org/web-animations-2/#auto-aligning-start-time) and @kevers-google and I believe we should update that procedure to apply the pending playback rate between the existing steps 7 and 8.
