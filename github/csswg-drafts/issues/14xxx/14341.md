Per [§ 10.12 Range Checking](https://drafts.csswg.org/css-values-4/#calc-range), clamping is performed on computed/used values of math functions. Per step 1 of [§ 10.13. Serialization](https://drafts.csswg.org/css-values-4/#calc-serialize), this occurs at serialization time, which seems puzzling to me.

How could the used value of a color function (for example) be calculated as expected if it contains a math function and its clamping occurs at serialization time?

There is this somewhat related note in CSS Cascade:

  > the computed value is an abstract data representation: their definitions reflect that data representation, not how that data is serialized.

All this leads me to believe that step 1 of *serialize a math function* should be removed.
