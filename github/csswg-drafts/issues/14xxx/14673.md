Per the spec, `line-clamp: none` sets `block-ellipsis: no-ellipsis`. However, the spec for `-webkit-line-clamp` says:

> - it unconditionally sets `block-ellipsis` to `ellipsis`

This has no visual effect, but it means that if `line-clamp` is set to `none`, obtaining the serialization for `-webkit-line-clamp` would return the empty string, and vice versa.

We probably should make it behave like `line-clamp` – `none` would set `block-ellipsis: no-ellipsis`, and any other value would set it to `ellipsis`.
