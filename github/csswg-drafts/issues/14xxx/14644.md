Currently slider-like controls are all defined to have identical structures. But this means that ::slider-thumb exists for a meter or progress element? Allowing people to display: block their slider-thumb into existence on a progress element is a bit weird?

I'm also not sure that ::slider-fill-lower and ::slider-fill-upper necessarily make sense on a meter element but perhaps that ones fine as at least they get the ::slider-fill pseudo element alias.
