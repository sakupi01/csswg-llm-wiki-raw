https://drafts.csswg.org/css-link-params-1/#param

> A param() function usually has an element context from the way it’s used. If present, the value uses that context (and the type, if present) to fully resolve itself to a **used value** before being passed into the linked resource.

The used value of a `<color>` is pretty clear, but what's the "used value" of `accent-color: auto`? Is that also a `<color>`? Yes, [by definition](https://www.w3.org/TR/css-cascade-5/#used-value), it needs to be an absolute color but we can't very well pass that into another document, it's a privacy violation to even expose it to the web page itself!

There are a variety of places where we haven't actually pinned down what the used value is, we can't be passing it around. We should pass in the computed value (which is what inherits), with maybe some exceptions (like `<color>`) for which we need, and can define, an absolutization rule.
