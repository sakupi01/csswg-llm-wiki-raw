Currently, the spec specifies that it applies to [all elements](https://drafts.csswg.org/scroll-animations-1/#scroll-timeline-name), which also says "Includes `::before` and `::after` pseudo-elements."

This [WPT](https://wpt.fyi/results/scroll-animations/css/scroll-timeline-on-pseudo-like-part.html?label=experimental&label=master&aligned) expects that specifying `scroll-timeline` to `::file-selector-button`.

Should it (Not sure scroll timeline makes sense, but I can see an argument for being a view timeline)? If so, what other pseudo-elements should be allowed?
