Re: https://drafts.csswg.org/css-forms-1/#propdef-field-sizing

The new field-sizing for inputs is great, and it's nice that it sizes to the placeholder when using `content`. However, that causes the field size to jump around in an unpleasant way.

See this example: [Link](https://developer.mozilla.org/en-US/play?id=unTQihgNDdslfsE3X6RBlkNhPpMleXRg0QkUHqLIBtVely%2BNpqBgiepELhKnXC4rMVB8KKY7fcxyaKZE)

When you type the first character of the name, the field shrinks, which isn't nice.

We should have the ability to say "the size of the placeholder or the content", something like `field-sizing: max(placeholder, content)` (although this would mean making the `field-sizing` a numeric/calculable value, which might not make sense) or a special value like `placeholder-or-content`.
