https://drafts.csswg.org/cssom/#the-stylesheet-interface allows for creating named alternate stylesheets via [StyleSheet sets](https://drafts.csswg.org/cssom/#css-style-sheet-set). However, it appears that only Firefox still has UI for exposing alternate stylesheets. Are there any other ways to activate these? It seems the concept has been replaced with newer concepts such as media queries. I also don't believe these are exposed in all scenarios, including things like shadow roots.

Should these still be a required part of the interface, or should they be moved to the [deprecated/legacy section](https://drafts.csswg.org/cssom/#legacy-css-style-sheet-members)?

Deprecating `title` on `StyleSheet` would also allow for removing a few references from the HTML5 spec (e.g. [here for link](https://html.spec.whatwg.org/#attr-link-title) and [here for style](https://html.spec.whatwg.org/#the-style-element:attr-style-title)).

Note that Constructable Stylesheets decided to omit `title` (see [this issue](https://github.com/WICG/construct-stylesheets/issues/105#issuecomment-577704271))
