Currently mixins allow for a single `contents` block.
https://drafts.csswg.org/css-mixins/#contents-rule

Should they instead allow for multiple?

Multiple blocks would allow authors to interleave overrides in between parts of a mixin.


```css
@mixin --btn() {
  color: red;
  @contents --base;
  
  &:disabled {
    color: grey;
    
    @contents --disabled;
  }
}

.btn-green {
  @apply --btn {
    @contents --base {
      color: green;
    }
    
    /* optional */
    @contents --disabled {
      color: alpha(from lime / 0.1);
    }
  }
}
```

Yes this would be super useful. 

I could imagine something like this:


```css
@mixin --custom-container-query(--breakpoint) {
	@container (width >= var(--breakpoint)) {
		@contents --bigger;
	}

	@container (width < var(--breakpoint)) {
		@contents --smaller;
	}
}

.wrapper {
	@apply --custom-container-query(700px) {
		@contents --bigger {
			grid-template-columns: repeat(12, 1fr);
			gap: 1rem;

			li {
				border: 1px solid;
				padding: 1rem;
			}
		}

		@contents --smaller {
			grid-template-columns: 1fr;
			gap: 0.25rem;

			li {
				row-rule: 1px solid;
			}
		}
	}
}
```

or other cases where greater than one blocks of code for an `if/else` or `if/elseif/else` were needed.

## @tabatkins — 2026-09-04

Yes, I suspect we will want to allow multiple content blocks, but that's a great candidate for v2 rather than v1. ^_^ Note, for example, that Sass has never felt the need to allow this, so I think we can wait for author demand after using the feature before we try to do something here.

We can't reuse `@contents` on the calling side, fwiw, as that's the syntax you'd use to *substitute* your named contents block inside the mixin. You can also invoke a mixin *inside* a mixin, and potentially pass the parent mixin's contents block into the child mixin. We'd need a new rule to specify them on the call-side, like `@arg --foo {...}` or something.

```scss
@mixin btn {
  color: red;
  @content(--base);
  
  &:disabled {
    color: grey;
    
    @content(--disabled);
  }
}

.btn-green {
  @include btn using ($slot) {
    @if $slot == --base {
      color: green;
    } @else if $slot == --disabled {
      color: lime;
    }
  }
}
```
