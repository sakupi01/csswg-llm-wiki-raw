Follow-up from https://github.com/WebKit/WebKit/pull/73099 it seems that Blink and Gecko default to English-style curly quotes, should we encode that into the spec?

<!-- comment id=6624395061 author=xfq created=2026-11-04T06:37:32Z url=https://github.com/w3c/csswg-drafts/issues/14719#issuecomment-6624395061 -->
## @xfq — 2026-11-04

The [CLDR root locale](https://github.com/unicode-org/cldr/blob/main/common/main/root.xml) defines these quotation marks:

| Purpose           | Character | Unicode |
| ----------------- | --------- | ------- |
| Opening primary   | “         | U+201C  |
| Closing primary   | ”         | U+201D  |
| Opening secondary | ‘         | U+2018  |
| Closing secondary | ’         | U+2019  |
