**Where:** CSS Nesting Module Level 1, Editor's Draft 8 October 2026, §3.3 Nesting Other At-Rules (#conditionals), example #example-81212ace, block "Example nesting Scoping" (Overview.bs, lines 786 and 794).

**Text.**

```css
/* Example nesting Scoping */
.card {
  inline-size: 40ch;
  aspect-ratio: 3/4;

  @scope (&) {
    :scope {
      border: 1px solid white;
    }
  }
}

/* equivalent to */
.card { inline-size: 40ch; aspect-ratio: 3/4; }
@scope (.card) {
  :scope { border-block-end: 1px solid white; }
}
```

**What is wrong.** The nested form sets `border` (all four sides). The form given as "equivalent to" sets only `border-block-end`. With no other styles, the first form draws four borders on `.card`, the second draws one. The two forms are not equivalent. The scoping examples in §3.2 ("Example usage with Scoping" and "Example nesting Scoping") use `border-block-end` in both forms, so the `border` here looks like a typo.

Found during an AI-assisted review of the cascade specs.

**Request:** could the nested form use `border-block-end: 1px solid white;` as well?
