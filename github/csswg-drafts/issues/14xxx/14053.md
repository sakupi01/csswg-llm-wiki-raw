## Introduction

Hello. I am excited to share a quick idea about inheriting variables' values from variables in parent scopes. This idea would allow Web developers to be able to style content in `<iframe>` elements while inheriting style from their containing parent scopes.

## Discussion

Today, Web developers can declare global variables in `:root` selectors.

```css
:root {
  --main-color: #1e90ff;
  --secondary-color: #ffffff;
}
```

What if Web developers could declare variables that inherited their values from other variables in their parent scopes? 

What if Web developers could optionally provide fallback values, e.g., for when content was not contained in an `<iframe>`?

The idea shared here is that Web developers could express:

```css
:root {
  --main-color: parent(--theme-main-color);
  --secondary-color: parent(--theme-accent-color);
}
```

```css
:root {
  --main-color: parent(--theme-main-color, #1e90ff);
  --secondary-color: parent(--theme-accent-color, #ffffff);
}
```

As considered, variables would be able to inherit from identically-named variables declared in their parent scopes.

```css
:root {
  --main-color: parent(--main-color, #1e90ff);
  --secondary-color: parent(--secondary-color, #ffffff);
}
```

## @AdamSobieski — 2026-06-17

@AtkinsSJ, thank you. Change propagation is one important point which might distinguish the two approaches.

In the envisioned and indicated approach, when a Web developer changes the value of a variable in a parent scope, using `setProperty()`, all of the variables inheriting from that variable, in one or more child `<iframe>` elements, would automatically receive that updated value, resulting in subsequent synchronized restyling of content.

How will changes propagate with respect to the [CSS Linked Parameters Module](https://drafts.csswg.org/css-link-params/)? Will SVG resources, for instance, receive static snapshots of variables' values or will received variables' values be dynamically updateable, enabling synchronized restyling?

```css
.foo {
  background-image: url(
    "http://example.com/image.svg"
    param(--color, var(--primary-color))
  );
}
```
```js
document.documentElement.style.setProperty("--primary-color", "#1e90ff");
```
