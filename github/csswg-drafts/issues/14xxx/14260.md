Consider the following scenario:

```css
.test {
    font-size: 10px;
    zoom: 2;
    tab-size: 1ex;
}
```

In this scenario, the computed value for `tab-size` depends on how / when font metrics get computed. 

_Option 1_ would be for the engine to perform font resolution using the computed value of font-size `10px`, and then at use time, scaling all metrics by the zoom.

_Option 2_ (and what at least WebKit is currently doing) would be for the engine to perform font resolution using the used value of the font-size `20px` and using it directly.

With this option, the naive computed value for `tab-size` would be way too big, as it would be using the x-height for a 20px font-size. What WebKit does to compensate is that it unscales the x-height by the zoom to bring it back into proportion. This is problematic as, unless x-height scales exactly linearly with font-size, the value can be distinct from the equivalent example without zoom:

```css
.test {
    font-size: 10px;
    tab-size: 1ex;
}
```

_Option 3_ would be perform font resolution for both the computed and used font sizes, stashing the metrics for the unzoomed value away for use by units.

--

So, the questions are:

- Does CSS Fonts define which font-size to use for font resolution when zoom is in play? (I wasn't able to find anything, but most things don't specify custom behavior with zoom, so this isn't unexpected).
- If not, is there consensus on which option above is correct?

## @weinig — 2026-08-27

One additional piece of information here is this text from CSS Fonts about the font-size-adjust property:

> The value of [font-size-adjust](https://drafts.csswg.org/css-fonts-4/#propdef-font-size-adjust) affects the used value of [font-size](https://drafts.csswg.org/css-fonts-4/#propdef-font-size) but does not affect the computed value. It affects the size of relative units that are based on font metrics such as ex and ch but does not affect the size of em units.

([link](https://drafts.csswg.org/css-fonts-4/#:~:text=The%20value%20of%20font%2Dsize%2Dadjust%20affects%20the%20used%20value%20of%20font%2Dsize%20but%20does%20not%20affect%20the%20computed%20value.%20It%20affects%20the%20size%20of%20relative%20units%20that%20are%20based%20on%20font%20metrics%20such%20as%20ex%20and%20ch%20but%20does%20not%20affect%20the%20size%20of%20em%20units.))

This implies / states that font metrics and font metric based units like `ex` and `ch` are affected by the **used** value of `font-size`. 

That still doesn't quite answer the question here though, as zoom is applied on top of the used value.
