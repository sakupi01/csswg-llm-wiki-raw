https://drafts.csswg.org/css-display-3/#replaced-element
https://html.spec.whatwg.org/multipage/#form-controls

```html
<!DOCTYPE html>
<ol>
  <button style="display: list-item">1</button>
  <input style="display: list-item" value="2">
  <canvas style="display: list-item; height: 1lh">3</canvas>
  <li>4</li>
</ol>
```

Gecko allows them to increase the automatic `list-item` counter. `<button>` can generate a `::marker` (even with outside position!), but `<input>` and `<img>` can't - presumably, same logic as for `::before`.

Blink and WebKit don't allow them to be list items at all.
