The Media Queries Level 5 specification defines boolean evaluation of media features in the following way:
> While [media features](https://drafts.csswg.org/mediaqueries-5/#media-feature) normally have a syntax similar to CSS properties, they can also be written more simply as just the feature name, like (color).
> 
> When written like this, the [media feature](https://drafts.csswg.org/mediaqueries-5/#media-feature) is evaluated in a boolean context. If the feature would be true for any value other than the number 0, a [<dimension>](https://www.w3.org/TR/css-values-4/#typedef-dimension) with the value 0, the keyword [none](https://drafts.csswg.org/mediaqueries-5/#valdef-media-update-none), or a value explicitly defined by that media feature to evaluate as false in a boolean context, the media feature evaluates to true. Otherwise, it evaluates to false.

I'm working on a `resizable` feature (see https://github.com/w3c/csswg-drafts/issues/14428) that has values `true` and `false`. `false` is unfortunately not listed as evaluating to false.

Would it be possible to add `false` to the list of values evaluating to false in boolean context?
