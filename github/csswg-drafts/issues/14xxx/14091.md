`color?` is rendered green in the example below, in all browsers:

```html
<style>
  div { color: green }
</style>
<div style="color: revert-layer">color?</div>
```

I expected it to be black...

  > any declaration not assigned to an explicit layer is added to an implicit final layer.

https://drafts.csswg.org/css-cascade-5/#cascade-layering

... since the spec does not appear to define element-attached styles to have their own cascade layer, as very briefly [defined](https://github.com/w3c/csswg-drafts/blob/a64a842ca21f088118cd3e1c4bf171f275afdf5b/css-cascade-5/Overview.bs#L1856-L1857) 5 years ago.

## @cdoublev — 2026-06-29

I am not sure what is relevant in #6872.

#6743 (to which #6872 referred, like in my initial comment, indirectly) [resolved](https://github.com/w3c/csswg-drafts/issues/6743#issuecomment-984180158) on what is currently [specified](https://drafts.csswg.org/css-cascade-5/#revert-layer):

  > For `revert-layer` in important element-attached styles, however, it only reverts the element-attached styles and the intervening animation origin, and not any of the intervening author-origin important rules.

But in my exemple, `revert-layer` is not `!important`, so it should revert the author styles, which are in the same implicit final layer.

```
* - where revert-layer is defined
x - additional layers reverted
@ - the top layer to be applied
```

```
user agent !important
style      !important  *
author     !important  @
animations             x
style      normal      x *
author     normal        x
user agent normal        @
```
