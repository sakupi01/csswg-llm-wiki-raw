i think circadian theming will be the next step from light/dark ui's. this because of health reasons making our screens adapt to the time of the day: for example: if it is around midnight, probably the screen should be even darker [even special hues can be implemented at times like sunset, dusk, dawn]. circadian _whatever_ is adapting to such times and transitions

to start there are maybe 2 things: 1) how can we detect circadian phase from the phone's or device's settings and 2) if we don't have such info from settings how can we bridge that gap, implement it in css and maybe be one step ahead of device's settings

## @astearns — 2026-10-03

There are apps and OS affordances for changing displays based on time. This may make more sense as a consistent override at that level than something done at the browser level (introducing inconsistencies between the browser and other apps) let alone at the authoring level (introducing inconsistencies between windows or tabs).
