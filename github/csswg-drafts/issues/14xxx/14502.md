## @tabatkins — 2026-10-07

I don't have a particularly strong opinion on where it lives, but I do agree that having calc-size() and interpolate-size living in Sizing makes sense. Yeah, it reuses some calculation-tree terminology, but I don't think that strictly means it has to live in the same spec as calc(), which is a more general-purpose mathematical value.
