### Context

The `rule-visibility-items` properties control whether gap decoration segments are painted next to empty areas.

Grid lanes containers can have empty tracks, but their behavior is not currently defined.

### Proposal

Have `rule-visibility-items` affect  gap decorations in grid lanes in cases with empty tracks. 

- `rule-visibility-items` applies only to grid-axis decorations.
- Each adjacent grid track is treated as one adjacent area.
- A track is occupied if it contains at least one item, including an item that spans that track.
- All segments in a grid-axis gutter use the same adjacent-track rule
- The property has no effect on stacking-axis decorations.
- `normal` behaves as `all`, matching grid containers.


This follows precedent of rule-visibility-items in multicol discussed in https://github.com/w3c/csswg-drafts/issues/13477 where we state that "Column rules are only drawn between two columns that both have content.".
