Is the URL fragment use-case designed for specific contexts?

Consider the following, the hardcoded value makes sense as the value lives in a URL.

`<img src="icon.svg#:~:param(--color, green)"></div>`

What if we replace it with `var()`, is this valid?

`<img src="icon.svg#:~:param(--color,var(--brand))">`

Here's another usage:

`<div style="--brand: blue"> <img src="icon.svg#:~:param(--color,var(--brand))"></div>`
