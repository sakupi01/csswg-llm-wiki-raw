https://drafts.csswg.org/css-scroll-snap-2/#initial-scroll-target says:

> 1. Let *position* be the result of running the steps to determine the scroll-into-view position of *target* with *behavior* set to "auto", *block* set to "start", *inline* set to "nearest", and *scrolling box* set to *scrollcontainer*.

That uses the target's `getBoundingClientRect()`, so it includes transforms. If the target is also animated by a scroll-driven animation on the same scroll container, e.g. `animation-timeline: view()` animating `transform`, the target's box depends on the scroll position, which depends on the target's box. Which state of the animation should be used to compute the initial scroll position?

(Raised by @hiikezoe in https://github.com/mozilla/standards-positions/issues/1107#issuecomment-2620523525.)
