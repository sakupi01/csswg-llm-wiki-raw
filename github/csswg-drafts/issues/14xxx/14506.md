We'd like to explore additional APIs to improve focus management. The goals are the following:

* Add an ability to focus `CSSPseudoElements`
* Add functionality to query next/previous focusable element or pseudo-element, given a starting element
* Add functionality to query current focused element (like `activeElement`, but including `CSSPseudoElement`s)

These improvements should enable focus-management javascript libraries to work more effectively.

This is largely a placeholder for now, and I'll follow up with a proposal once we have more details.
