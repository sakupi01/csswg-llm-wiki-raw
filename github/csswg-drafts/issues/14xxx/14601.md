## @flackr — 2026-10-23

In our implementation, we made these pseudo-classes invalid in `:has` selectors: https://source.chromium.org/chromium/chromium/src/+/main:third_party/blink/renderer/core/css/parser/css_selector_parser.cc;l=1306;drc=f98bafebf68b7a87127679e2eb22e6b921457212;bpv=1;bpt=1 It looks like the only other pre-existing case for this limitation is `:has` in `:has`. This is intended to prevent this trivial cyclic style.

The update timing for open in particular is similar to scroll container queries. We considered using a container query for this but it means that you then can't style the area itself - only a descendant of the area. This has proven to be a problem for authors using `scroll-state(snapped)` as well needing to add extra layers. We're also using the open state to drive backdrop changes per https://drafts.csswg.org/css-overscroll-2/#ua-stylesheet
