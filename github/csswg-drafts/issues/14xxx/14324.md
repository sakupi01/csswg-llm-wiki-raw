One of the complaints we got about the picker styling for `<select>` was the double-border effect of the drop-down being placed immediately adjacent to the button. Because jamming the picker right up against the button looks awkward, we propose a margin (which is a commonly used effect) of 4px. This also addresses the concern @jakearchibald raised in https://github.com/w3c/csswg-drafts/issues/14172 that when a picker jams up against the viewport edge, it's hard to know if it's overflowing or not.

```
::picker(...) {
  margin-block: 4px;
}
```

Note: Especially if we do this (but maybe even if we don’t), we should consider applying [`box-sizing: margin-box`](https://github.com/w3c/csswg-drafts/issues/5715) to the picker also.
