I was working on securing Chrome against visited styling leaking via flood/lighting/stop-color: https://crrev.com/c/8373342

And in the process I realized there's some inconsistency around the way visited colors propagate:
https://wpt.fyi/results/css/css-color/color-svg-visited.html?label=master&label=experimental&aligned&q=visited
https://wpt.fyi/results/css/css-color/color-svg-visited.html?label=master&label=experimental&aligned&q=visited

Right now Chrome (and Edge by extension) seem to propagate visited color into currentcolor for use in color-mix and flood/lighting/stop-color, Safari only supports the former, and Firefox supports neither.

It makes sense to secure visited coloring against JavaScript observation, but when it actually comes to rendering the page which browser has the correct behavior?
