When placed next to a float, a line whose smallest unwrappable content is to long to fit the remaining space is pushed down. However, `block-ellipsis` (as used by `line-clamp`) can make a line shorter when it removes content to make room for the ellipsis.

When that happens, if the line would now fit next to the float, should it be moved back up next to the float since it now fits?

What should this look like:
```css
div, aside { font-family: monospace; }
aside {
  float: left;
  width: 2ch;
}
div {
  width: 3ch;
  line-clamp: 2;
}
```
```html
<div>
  <aside>
    AB
    CD
  </aside>
  1
  234
  567
</div>
```

Is it:
```
AB1
CD
…
```
or
```
AB1
CD…
```
In https://drafts.csswg.org/css-overflow-4/#block-ellipsis, there are already indication that we want to make sure that removing the content of the last line and inserting the ellipsis doesn't make the block taller, but that we are ok with this making the block shorter. But this particular scenario wasn't considered.

## @frivoal — 2026-06-15

Come to think of it, we may lack a clear answer to the distinct but related problem of whether lines where you insert the ellipsis can move _down_ to clear floats, or must stay in place.
```css
div, aside { font-family: monospace; }
aside {
  float: left;
  width: 2ch;
}
div {
  width: 3ch;
  line-clamp: 2;
}
```
```html
<div>
  <aside>
    AB
    CD
    EF
  </aside>
  1
  2
  3
</div>
```
Which of these two renderings should it be:
```
AB1
CD…
```
or
```
AB1
CD
EF
2…
```
The logic of the first one is that the line where we insert the ellipsis must not increase its vertical position, so you have to remove the `2` to make room for the `…` (and then the remainder of the float gets clipped). The second one is that you can add the `…` next to the `2` as long as you push the line down to clear the float, so do that.

I am not a fan of the idea that `line-clamp` can make things grow taller, so I think I have a strong preference for the first one.

This is actually one case where, if we removed the ellipsis but kept the layout the same otherwise, the entire contents of the line-clamp container would fit in two lines. So it'd be awkward to clamp like that also for that reason.
