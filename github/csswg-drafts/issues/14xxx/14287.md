I looked a bit into [scroll axis locking](https://drafts.csswg.org/css-overflow-5/#scroll-axis-locking) and the `scroll-axis-lock` property. For this I used the demo deployed at https://whole-fog-anteater.codepen.app

(In Chrome, on macOS, with a touchpad) When scrolling mainly vertically and with `scroll-axis-lock; auto`, I see axis locking kick in _(as expected)_ while still allowing me to do a follow-up diagonal scroll as part of the same gesture.

This made me wonder: should we have an extra keyword value for `scroll-axis-lock` that, once locked, keeps it locked as part of the same gesture? Maybe something like `always` or `single` or `axis` (or `single-axis` 😄 )?
