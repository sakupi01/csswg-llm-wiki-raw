https://github.com/w3c/csswg-drafts/issues/5900#issuecomment-2380321760 resolves that `AccentColor` should return the color set by `accent-color`, if one exists.

Given that, what's the computed value of `accent-color: AccentColor`?

Prior art: @LeaVerou proposes that it should resolve to `AccentColor` of the parent element [here](https://github.com/w3c/csswg-drafts/issues/5900#issuecomment-2377703623):
```
<lea> Proposed resolution: accentcolor and accentcolortext resolve relative to the accent-color property.
accent-color: accentColor resolves relative to the parent.
```

## @LeaVerou — 2026-07-17

In fact, I think we should establish this as a **CSS design principle**: Any unit, keyword, or other value that resolves relative to the computed value of a certain property should resolve to the value of the parent when used on the property itself.

That’s how `currentColor` works, that's how `em` and friends work, and I *wish* that's how `var()` worked — we'd have way fewer cases for `inherit()`.
