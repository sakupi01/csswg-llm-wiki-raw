Currently when setting `scroll-behavior: smooth` it will cause visible scrolling when navigating to a fragment in the destination.

I personally find this very annoying :)

I would prefer to only have the `smooth` behavior when navigating within the same document.
For example when clicking on a link with only a fragment. In that case it is somewhat useful to have the visual feedback that you scrolled up/down and stayed within the same page.

Maybe a new keyword?
