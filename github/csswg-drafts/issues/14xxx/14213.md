## @anttijk — 2026-08-04

The basic use case of `ident()` is to assemble arguments for other arbitrary substitution functions so it being one sort of falls out naturally. Also implementation is mostly trivial.

```
color: var(ident(--color-for- attr("item-type")));
```

## @bramus — 2026-08-05

> ```
> color: var(ident(--color-for- attr("item-type")));
> ```

I believe you got the quotes mixed up, and it should be this instead:

```css
color: var(ident("--color-for-" attr(item-type)));
```
