```
function color() {
  var colors = ['black', 'red', 'rgb(50, 75, 100)', 'rgba(5, 7, 10, 0.5)', 'rgb(146.064 107.457 131.223)'];
```

I get failures in all browsers:

I am assuming that this portion of the spec doesn't affect the computed value?
And that the computed value for `rgb(146.06, 107.46, 131.2)` is `rgb(146, 107, 131)`?

I think you are missing this part:

> The precision with which sRGB component values are retained, and thus the number of significant figures in the serialized value, is not defined in this specification, but must at least be sufficient to round-trip eight bit values.

`rgb(146, 107, 131)` is a conformant serialization. `rgb(146.1 107.5 131.2)` is also a conformant serialization. Both are _at least_ able to round-trip 8-bit values.

Since they historically quantized to 8 bits, and because that is still permitted, they continue to do so,
