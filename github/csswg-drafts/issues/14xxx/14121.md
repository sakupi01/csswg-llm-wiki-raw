[Step 1](https://drafts.csswg.org/cssom-view/#dom-htmlelement-scrollparent) returns `null` unconditionally for `body`, while it should consider whether or not there is [overflow viewport propagation](https://www.w3.org/TR/css-overflow-3/#overflow-propagation). If not, body should potentially return the documents `scrollingElement` as its `scrollParent`?
