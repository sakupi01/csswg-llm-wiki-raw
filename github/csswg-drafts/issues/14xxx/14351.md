Given you have a design system component like `<x-popover>` with the following default styling:

```css
:host {
  position-area: top;
  position-try-fallbacks:
    flip-block,
    flip-inline,
    flip-block flip-inline;
}

.tether {
  /* arrow pointing downwards, accounting for the default position-area: top of the host */
}
```

A developer using that custom element could change the initial position by using simple CSS:

```css
x-popover {
  position-area: right;
}
```

However, there is no way to change the styling of the `.tether`. The `anchored()` container query only handles fallback positions. It doesn't allow you to target the default position.

Can we change the anchored container query to match against the *current* position? 

```css
@container anchored(position: right) { ... }
```
