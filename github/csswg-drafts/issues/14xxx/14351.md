Given you have a design system component like `<x-popover>` with the following default styling:

```css
:host {
  position-area: top;
  position-try-fallbacks:
    flip-block,
    flip-inline,
    flip-block flip-inline;
}

.tether {
  /* arrow pointing downwards, accounting for the default position-area: top of the host */
}
```

A developer using that custom element could change the initial position by using simple CSS:

```css
x-popover {
  position-area: right;
}
```

However, there is no way to change the styling of the `.tether`. The `anchored()` container query only handles fallback positions. It doesn't allow you to target the default position.

Can we change the anchored container query to match against the *current* position? 

```css
@container anchored(position: right) { ... }
```

## @bramus — 2026-10-09

+1 to this request.

When changing the `position-area` in https://cdpn.io/pen/debug/PwGovqV from `top` to `bottom` the anchored element moves, but the little triangle does not.

This because of the following CSS:

```css
/* The CSS Generated Triangle */
#popover::after {
	content: "";
	position: absolute;
	top: 100%;
	left: 50%;
	transform: translateX(-50%);
  
	border-width: 8px;
	border-style: solid;
	border-color: black transparent transparent transparent; 
	
	/* The triangle must point upwards now … */
	@container anchored(fallback: flip-block) { /* 👈 This line */
		top: unset;
		bottom: 100%;
		border-color: transparent transparent black transparent; 
	}
}
```

Because the `position-area` got changed to `bottom`, the `flip-block` fallback is not getting applied … so the `anchored(fallback: flip-block)` query is not matching.

→ If one could query `position-area` inside `anchored()`, the code would just keep working.

Like so:

```css
/* The CSS Generated Triangle */
#popover::after {
	content: "";
	position: absolute;
	left: 50%;
	transform: translateX(-50%);
  
	border-width: 8px;
	border-style: solid;


	/* When in the top position-area, point the triangle downwards … */
	@container anchored(position-area: top) { /* 👈 This line */
		top: 100%;
		border-color: black transparent transparent transparent; 
	}
	
	/* When in the bottom position-area, point the triangle upwards … */
	@container anchored(position-area: bottom) { /* 👈 This line */
		bottom: 100%;
		border-color: transparent transparent black transparent; 
	}
}
```
