Let's consider the following example:

```html
<ul>
 <il>left</il>
 <il>center</il>
 <il>right</il>
</ul>
```

```css
ul {
  display: flex;
  gap: 40px;
  rule: 20px solid red;
  rule-inset: calc(.5lh - 3px);
  justify-content: center;
}
```

It gives us horizontal lines between the items 

<img width="445" height="66" alt="Image" src="https://github.com/user-attachments/assets/cdf3ece2-153c-46de-b109-fd7f96725d73" />

Demo: https://codepen.io/t_afif/pen/jEywmzv/946a6550f378806f69482108d459cb08

It would be good if we could do the following:

```css
rule: 50% solid red; /* 50% of the gap size so 50% of 40px = 20px */
````

This case can easily be solved using CSS variables but in some cases, the gap can be fluid and its size depends on the alignment. In the previous example, if we try different alignments we get the following:

<img width="860" height="298" alt="Image" src="https://github.com/user-attachments/assets/6c4e4348-1983-4e77-96fb-006455652b7b" />

Demo: https://codepen.io/t_afif/pen/WbROjJK/7dbd02814392f35d6f31f6a05c2c1043

What if I want to make the lines wider and fill the whole gap? Actually, it's not possible but if I can use percentage, I would do the following:

```css
rule: calc(100% - 10px) solid red; /* the whole gap minus 10px to keep some space between the line and the text */
````

and the result would be

<img width="972" height="286" alt="Image" src="https://github.com/user-attachments/assets/ce79ef7a-66b2-4764-b370-7c718845bcd3" />

This is a simplified example but there are a lot of cases where percentage can be handy. Either to fill fluid gaps or to avoid setting length/fixed values that we have to adjust each time we change the gap value.

---

I would add a note about using percentage with `rule-inset` as well. 

I know how it works with the intersection thing and "junction" but it would be good if it can also work with "cap" with the element size as a reference.

In the previous example, I used:

```css
rule-inset: calc(.5lh - 3px);
```

but initially I wanted to rely on:

```css
rule-inset: calc(50% - 3px);
```

We don't have junction so it's the same as:

```css
rule-inset-cap: calc(50% - 3px);
```

The percentage should refer to the element height (or the width if we deal with a vertical gap). It's probably more complex to implement in this case but it would be super cool if we can have it.  

I also wrote an article where I detail the previous example and a few interesting ones where percentage can help: https://master.dev/blog/lets-play-with-gap-decorations/
