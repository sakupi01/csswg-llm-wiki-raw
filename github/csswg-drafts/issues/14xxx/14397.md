> **Cascaded Independently**
>  
> These (despite the property name starting with "font-") are not [shorthand properties](https://drafts.csswg.org/css-cascade-5/#shorthand-property) and thus are neither set nor reset by the [font](https://drafts.csswg.org/css-fonts-4/#propdef-font) property:
> - [font-palette](https://drafts.csswg.org/css-fonts-4/#propdef-font-palette)
> - [font-synthesis-weight](https://drafts.csswg.org/css-fonts-4/#propdef-font-synthesis-weight)
> - [font-synthesis-style](https://drafts.csswg.org/css-fonts-4/#propdef-font-synthesis-style)
> - [font-synthesis-small-caps](https://drafts.csswg.org/css-fonts-4/#propdef-font-synthesis-small-caps)

Missing `font-synthesis-position`? https://drafts.csswg.org/css-fonts-4/#font-synthesis-position
