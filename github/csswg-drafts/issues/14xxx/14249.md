Form controls like `input`, `textarea`, `button`, and `select` have historically had `box-sizing: border-box` from the very beginning. In addition, authors generally use a reset style of the form `* { box-sizing: border-box }`. If we design our new styles assuming `content-box`, then they’ll break if `border-box` is applied vis the reset stylesheet, and there may be surprising/annoying results for the pseudo-elements, which will continue to use `content-box` because they aren’t selected by `*`.

Both for consistency with form controls in general, and also to pre-empt the authors’ use of `border-box` sizing, and because it works better for what we're doing anyway, we should systematically apply `box-sizing: border-box` to every form control part. Proposed to adopt:

```
/* Pre-existing Rules */
input,
textarea,
button,
select,
/* Proposed New Rules */
option,
optgroup,
optgroup legend,
::picker(select),
::picker-icon,
::checkmark,
/* Etc. Add EVERY new form control pseudo-element here. */
 {
    box-sizing: border-box;
}
```
