```html
<img src="icon.svg#:~:param(--color,green)">
<img src="icon.svg#:~:param(--color,blue)">
```
Should these be two independent instances of the resource, or one instance shared by both references?

<!-- comment id=5383011792 author=nullhook created=2026-08-22T22:49:55Z url=https://github.com/w3c/csswg-drafts/issues/14247#issuecomment-5383011792 -->
## @nullhook — 2026-08-22

Seems like both engines (WebKit and Blink) treat one resource (`icon.svg`) as a single instance shared by all references (img tags). I think treating each reference as its own instance would change existing observable behavior.

I'd also like to bring up the `env()` resolution here. The spec says link parameters establish "global custom environment variables for the resource." Under a shared instance, what does "global" mean here? How should the `env` resolution work in this scenario?
