`param(--name, green)` looks like a fallback, but is actually an assignment.

All other functions in CSS that take a similar syntax (`var()`, `attr()` etc) are actually **references**, not assignments.
CSS assignment uses `:` to separate the key from the value, so I think `param(--name: green)` would read a lot more naturally.

There was a time I'd argue against non-comma separators on the basis of more complex parsing, but the ship has sailed with `if()`, and I think the rationale is even stronger here than for the `if()` condition.

This also provides a very natural syntax for multiple params in the same function, which I filed as a separate issue: #14276
