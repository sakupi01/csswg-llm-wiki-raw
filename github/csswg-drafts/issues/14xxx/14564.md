The text for interpolation of [cross-fade()](https://drafts.csswg.org/css-images-4/#interpolating-image-combinations) is currently:

> The three components of [cross-fade()](https://drafts.csswg.org/css-images-4/#funcdef-cross-fade) are interpolated independently. Note this may result in nested cross-fade() notations..

I think this is probably based on an older syntax for cross-fade(), as the current doesn't have three components to independently interpolate.
