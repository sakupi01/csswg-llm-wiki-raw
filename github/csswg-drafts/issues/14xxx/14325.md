Transitional animations moderate the abruptness of UI, making it feel softer and more natural to interact with. We suggest adding some basic transitions to the appearance of the picker:

* Transition from `opacity: 0` to `opacity: 1`.
* Transition from t`ransform: scale(.95)` to `transform: scale(1)`.

We use transform here rather than scale so that it is easy and nearly automatic for the author to override the effect with their own.

The rules would look something like:

```
select::picker(select) {
  transform-origin: block-start center;
  transition:
    display 150ms allow-discrete,
    opacity 150ms cubic-bezier(0, 0, 0.58, 1),
    transform 150ms cubic-bezier(0, 0, 0.58, 1);
}
select:not(:open)::picker(select) {
  opacity: 0;
  transform: scale(0.95);
  transition:
    display 125ms allow-discrete,
    opacity 100ms cubic-bezier(0.42, 0, 1, 1),
    transform 125ms cubic-bezier(0.42, 0, 1, 1);
}
@starting-style {
  select::picker(select) {
    opacity: 0;
    transform: scale(0.95);
  }
}
@media (prefers-reduced-motion) {
  select:enabled::picker(select) { /* need to add some specificity; disabled select can't open anyway */
    transition-duration: 0.01ms;
  }
}
```

Note: There are also some technical issues with `display` and top-layer transitions that still need to be worked out....
