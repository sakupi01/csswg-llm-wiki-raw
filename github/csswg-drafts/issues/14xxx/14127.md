CSSOM prevents [`getComputedStyle(element)`](https://drafts.csswg.org/cssom-1/#dom-window-getcomputedstyle) from returning resolved values for `element` when either:

  - `element` is not connected
  - `element` is not part of the flat tree
  - the shadow-including root of `element` has no browing context
  - the shadow-including root of `element` has a browsing context whose container is not rendered

Note: *browsing context* should be replaced with *navigable* (#12153).

On the other hand, [CSS Cascade](https://drafts.csswg.org/css-cascade-5/#value-stages) only wants the empty string when either:

  - `element` is not connected
  - `element` is not part of the flat tree

Based from tests with `color: green` as a declared value, browsers appear to exhibit non-interoperable and/or non-conforming behaviors (except for when `element` is not connected):

| State                            | specifications |           Chromium |             Gecko  | Webkit |
| -------------------------------- | -------------- | ------------------ | ------------------ | ------ |
| not connected                    |   empty string |       empty string |       empty string |      ? |
| not part of the flat tree        |   empty string | `rgb(0, 128, 0)` |       empty string |      ? |
| no navigable                     |   empty string |      empty string  | `rgb(0, 128, 0)` |      ? |
| navigable container not rendered |   empty string | `rgb(0, 128, 0)` | `rgb(0, 128, 0)` |      ? |

<sup>Feel free to edit this comment to add results in WebKit.</sup>

<details>

**Not connected**

```html
<script>
  const element = document.createElement('div')
  element.style.color = 'green'
  getComputedStyle(element).color // ???
</script>
```

**Not part of the flat tree**

```html
<div>
  <div id="slotted" style="color: green"></div>
  <template shadowrootmode="open"></template>
<script>
  getComputedStyle(slotted).color // ???
</script>
```

**No navigable**

```html
<script>
  const doc = document.implementation.createHTMLDocument()
  const div = document.createElement('div')
  div.style.color = 'green'
  doc.body.append(div)
  getComputedStyle(div).color // ???
</script>
```

**Navigable container not rendered**

```html
<title>iframe.html</title>
<p style="color: green"></p>
```

```html
<iframe id="iframe" src="iframe.html" style="display: none"></iframe>
<script>
  const div = iframe.contentDocument.getElementsByTagName('div')[0]
  getComputedStyle(div).color // ???
</script>
```

</details>

It seems browsers only started loading styles in documents with no rendered navigable a few years ago (whatwg/html#4547), but the CSSWG also [resolved](https://github.com/w3c/csswg-drafts/issues/1548#issuecomment-380383455) to not resolve a value in that case.

Note that I am not sure if my interpretation of a *navigable container not rendered* is correct in my test.
