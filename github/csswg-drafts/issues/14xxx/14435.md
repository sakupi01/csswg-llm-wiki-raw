The [latest ED](https://drafts.csswg.org/css-values-5/) is dated **20 Aug 2026**, while the [/TR version](https://www.w3.org/TR/css-values-5/) is dated **11 November 2024.**

This means that [mix percentage normalization](https://drafts.csswg.org/css-values-5/#mix-percentage-normalization), which is normatively used in CSS Color 5, does not exist in the /TR version.

A republication as WD would be great.

(The [changes](https://drafts.csswg.org/css-values-5/#changes) are not up to date.)
