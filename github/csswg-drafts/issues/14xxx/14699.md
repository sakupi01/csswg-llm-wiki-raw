**Where:** CSS Cascading and Inheritance Level 6, Editor's Draft 28 April 2026, §3.5.1 Effects of @scope (#scope-effects), against §3.1 Cascade Sorting Order (#cascade-sort). The Working Draft of 6 September 2024 has the same sentence in §2.5.1.

**Text.** §3.5.1, fourth effect:

> The cascade prioritizes declarations with a more proximate scoping root, regardless of specificity or order of appearance by applying scope proximity between the scoping root and the subject of each scoped style rule.

§3.1 lists the criteria

> The cascade sorts declarations according to the following criteria, in descending order of precedence:

with Specificity before Scope Proximity:

> When comparing declarations from two style rules, the declaration belonging to the style rule with the highest specificity wins.

The changes list in §5.1 says:

> Removed strong scope proximity. (Issue 6790)

**Example.**

```html
<div id="page"><div id="hero"><img src="a.png"></div></div>
```

```css
#page img { border-radius: 0; }                 /* (1,0,1), no scoping root */
@scope (#hero) { img { border-radius: 50%; } }  /* (0,0,1), proximity 1 */
```

Both declarations are normal author declarations, in the same tree context, not in a style attribute, and unlayered. So the first criterion that separates them is Specificity. By §3.1, `#page img` (1,0,1) beats the scoped `img` (0,0,1): `border-radius: 0`. By the §3.5.1 sentence, the scoped rule wins "regardless of specificity": `50%`.

**Why it is a problem.** #6790 chose weak proximity: "RESOLVED: cascade proximity is weaker than specificity" (CSSWG, 22 March 2023; the issue was closed on 11 December 2023). §3.1 and the §5.1 changes list follow that choice. The §3.5.1 sentence still describes strong proximity, so a reader of §3.5.1 alone gets the opposite order. The example right after the sentence (#example-47f85a12) does not show the difference, because both selectors there have the same specificity.

Found during an AI-assisted review of the cascade specs.

**Request:** could the §3.5.1 sentence be reworded to match §3.1, for example: "When all earlier cascade criteria tie, the cascade prioritizes declarations with a more proximate scoping root over order of appearance, by applying scope proximity between the scoping root and the subject of each scoped style rule."
