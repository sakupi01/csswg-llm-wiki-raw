### Context

For other containers, the spec states that content distribution can enlarge gaps:

> Additional spacing may be added by `justify-content` / `align-content`. Such
> additional space increases the size of the corresponding gaps.

Decorations then get placed inside the “enlarged” gap. We propose that grid lanes containers **diverge** from that behavior along the stacking axis.

### Problem

If alignment is allowed to move each track's stacking-axis gutters independently, decorations that should read as a single continuous rail can be broken apart, for example, around a spanner. 

Beneath a spanner, a rule painted in the stacking-axis gutter beneath the spanner should read as one contiguous segment across the spanned width. Respecting per-track alignment would misalign them and break contiguity.

### Proposal

- In grid lanes containers, **gap-decoration placement is determined solely by
  the authored gutters** and does not shift due to alignment.
- We make this explicit as a grid-lanes-specific divergence from the general "alignment increases the gap" rule in the current css-gaps spec.
