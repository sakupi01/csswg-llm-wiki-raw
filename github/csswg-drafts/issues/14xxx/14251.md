Disabled controls should indicate that they are unusable. Proposed to add:

```
:is(input, textarea, select, button):disabled { cursor: not-allowed; }
```

Also `<select>` and `<button>` should indicate they are clickable as a unit, not selectable as text. Proposed to add:

```
select, button { cursor: default; }
```

This might be worth doing for `auto` appearance as well.
