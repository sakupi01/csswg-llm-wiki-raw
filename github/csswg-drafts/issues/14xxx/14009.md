From an old spec: https://www.w3.org/TR/2022/CRD-css-shapes-1-20221115/#funcdef-basic-shape-circle

> `circle() = circle( <shape-radius>? [ at <position> ]? )`
> - The shape-radius argument represents r, the radius of the circle. Negative values are invalid. A percentage value here is resolved from the used width and height of the [reference box](https://www.w3.org/TR/2022/CRD-css-shapes-1-20221115/#basic-shape-reference-box) as
sqrt(width²+height²)/sqrt(2).

This disappeared from the latest CR and editor's draft:

https://www.w3.org/TR/css-shapes/#funcdef-basic-shape-circle
https://drafts.csswg.org/css-shapes/#funcdef-basic-shape-circle

> Rather than referring to the [gradient box](https://drafts.csswg.org/css-images-4/#gradient-box), values are resolved against the [reference box](https://drafts.csswg.org/css-shapes/#basic-shape-reference-box).

However, there is https://drafts.csswg.org/css-shapes/#direction-agnostic-size

> **direction-agnostic size** The [direction-agnostic size](https://drafts.csswg.org/css-shapes/#direction-agnostic-size) of a box is equal to the length of the diagonal of the box, divided by sqrt(2).

This term isn't directly used for `circle()`, but is used for the arc command, where it mentions `circle()`:

> If only one [<length-percentage>](https://drafts.csswg.org/css-values-4/#typedef-length-percentage) is provided, both radiuses use the provided value. In that case, [<percentage>](https://drafts.csswg.org/css-values-4/#percentage-value) values are resolved against the [direction-agnostic size](https://drafts.csswg.org/css-shapes/#direction-agnostic-size) of the [reference box](https://drafts.csswg.org/css-shapes/#basic-shape-reference-box) **(similar to the [circle()](https://drafts.csswg.org/css-shapes/#funcdef-basic-shape-circle) function)**.

Testcase:

```html
<!DOCTYPE html>
<style>
div { width: 700px; height: 100px; background: black; }
</style>
<div style="clip-path: circle(10%)"></div>
<div style="clip-path: circle(50px)"></div>
```

These 2 circles should be identical, because `√(700² + 100²) / √2 = 500`, so a 10% should be the same as 50px
