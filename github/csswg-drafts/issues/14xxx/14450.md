Provide a way for styles to only apply while the document is loading, for example:

```css
@document-loading {
  .js_hidden {
    display: none;
  }
}
```

Could wait until `DOMContentLoaded` functions have completed, and/or wait for the `async` scripts to load.

Useful on websites that have a strict no-inline JavaScript/CSS Content-Security-Policy, has 1 render blocking CSS file, uses `<script defer>` (or `async`) to improve performance, and must fail-safe if the JavaScript fails to load.

For example, JavaScript using `new CSSStyleSheet()` to initially hide content, then shows based on an event (e.g. onclick). With the above conditions there is no way to prevent a Flash of Unstyled Content (FOUC).

---

A work around suggested by @tunetheweb ([source](https://bsky.app/profile/tunetheweb.com/post/3mu5xbhpm6s2g)) is to set `display:none`, and use a CSS animation with a long timeout to reveal as a fallback.

Might be related to https://github.com/w3c/csswg-drafts/issues/8175; and the "before first render" pseudo-class discussed in https://github.com/w3c/csswg-drafts/issues/4339
