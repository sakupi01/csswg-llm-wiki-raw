For example, we use the term ["clamp point"](https://drafts.csswg.org/css-overflow-4/#clamp-point) to mean "one of the possible locations where clamping is allowed", as well as "the location where we've chosen to clamp". And then sometimes we use the term without qualifications (e.g. "if a block container contains a clamp point").

Maybe we should use "clamp opportunity"?
