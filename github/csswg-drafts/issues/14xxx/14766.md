A number of design systems (including Jen & Nicole's [demo styles for appearance: base](https://evolving-sun-gecko.codepen.app/) flip the picker icon when the picker is open.

Options from the demo:
- No change, picker icon doesn't change when the picker opened.
- Flip chevron direction, no animation.
- Flip chevron direction, rotation animation.
- Flip chevron direction, invert XY animation (`scale(-1)`).
- Flip chevron direction, invert Y animation (`scaleY(-1)`).

Note: Suggested to use `transform` rather than `rotate` or `scale` so that author customizations override easily.
