The [`anchor()` function](https://drafts.csswg.org/css-anchor-position/#typedef-anchor-side) takes % values, indicating alignment some % between start and end alignment. (So, 'center' is synonymous with '50%'.)

We [just resolved](https://github.com/w3c/csswg-drafts/issues/9556#issuecomment-5190932112) to allow %s to align in the alignment properties, too. But the point was brought up there that we have three distinct axises to align between, so we need to allow specifying the axis together. So `20%` is 20% between 'start' and 'end', but you can explicitly say `start 20%` for the same effect, or `self-start 20%` to instead align using the self-* direction. You can also say `end 80%` for an identical effect, which can sometimes be meaningful.

We should match the resolved alignment syntax here in anchor(), so % can be combined with the start/end/self-start/self-end keywords, or used on its own to default to start.
