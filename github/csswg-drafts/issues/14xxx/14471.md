The `AnimationTrigger` interface was moved from Web Animations to Animation Triggers last week in #14199. It references the `AnimationTriggerBehavior` enum, which got dropped from Web Animations at the same time, but wasn't copied over to Animation Triggers, and is therefore no longer defined anywhere (well, it's still in the /TR version of Web Animations 2 for now, but it will disappear once a new draft gets published).

Sure, but that's not the problem I'm pointing out, I'm only looking at Editor's Drafts.

The problem is that the definition of the [`AnimationTrigger` interface](https://drafts.csswg.org/animation-triggers-1/#animationtrigger) in the "Animation Triggers" draft has a [`behavior`](https://drafts.csswg.org/animation-triggers-1/#dom-animationtrigger-behavior) attribute whose type is `AnimationTriggerBehavior`. And `AnimationTriggerBehavior` was completely removed. Should the `behavior` attribute be removed too?
