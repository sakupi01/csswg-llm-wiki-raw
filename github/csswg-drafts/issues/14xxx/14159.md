Inspired by [Link + Popover Navigation](https://adrianroselli.com/2026/07/link-popover-navigation.html), I tried adjusting @aardrian's CSS so that each popover was anchored vertically under and against the button, and centered horizontally on its link+button. And then make sure it works with right-to-left and vertical writing modes.

I encountered bugs/inconsistencies across all 3 engines (mainly for `vertical-rl`), and I want to verify what the correct behavior is supposed to be.

[CodePen Demo](https://codepen.io/kirk-l/pen/dPNdBLy?editors=1100)



## `vertical-rl`, `self-end`, popover 3

Chrome mostly flips block, but `inset-block-start: anchor(--nav-button self-end)` aligns the popover's left against the button's left edge, covering up the button. I think it should be the right edge: self-end is left, and because we flip-block, this becomes right.

## `vertical-rl`, `end`, popovers 2 and 3

If I understand correctly, the popover is `position: fixed`, so the containing block is the viewport. [`end`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/anchor#end) means the logical side of the containing block. The only change to writing-mode is on the `nav`, so the viewport's logical ends should be right (horizontally) and bottom (vertically).

(Aside: Does anything change the logical directions of the viewport? `writing-mode` on `<html>` perhaps?)

In Chrome, popover 2 acts like this is the case. No flipping happens, and the popover covers the button with the popover's right edge (`inset-block-start`) aligned with the button's right edge (viewport's horizontal end).

<img width="488" height="422" alt="Chrome popover 2" src="https://github.com/user-attachments/assets/26d09f2a-b1b2-40cb-90f1-85bd65b9490c" />

\
In Chrome, popover 3 flips block, but doesn't cover the button. Popover's left edge is aligned with button's right edge. Because block is horizontal, and we're referencing the end side of the viewport, this would normally become the button's right edge. But because we've flipped block, shouldn't this become the button's left edge?

<img width="488" height="425" alt="popover 2" src="https://github.com/user-attachments/assets/e9b45624-63c1-4271-a30e-9b9fd6953ae8" />

\
For popover 2, there shouldn't be a need to flip-block. Yet Safari flips popover 2 to the right side and doesn't cover the button.

<img width="488" height="428" alt="Safari popover 2" src="https://github.com/user-attachments/assets/b452d9d5-1255-4eac-a1af-c49c3a842aeb" />
