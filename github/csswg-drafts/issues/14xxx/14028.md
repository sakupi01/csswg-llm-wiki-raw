An experimental implementation (for the `link-parameters` property) [just landed in Firefox](https://bugzilla.mozilla.org/show_bug.cgi?id=2022783) and according to @tabatkins MS is working on an implementation for linked parameters for Chromium.

Thus, https://github.com/w3c/csswg-drafts/labels/Agenda%2B for a resolution to publish CSS Linked Parameters 1 as a FPWD.
