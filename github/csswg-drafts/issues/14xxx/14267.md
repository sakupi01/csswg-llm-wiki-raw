`@navigation (at: ...)` is specified to apply when the current URL during a navigation matches a given URL pattern.
Do we need a counterpart that applies when the *other* URL during a navigation matches a given URL pattern?

```css
// This
@navigation (with: --home) { ... }

// would be the same as
@navigation (
  ((from: --home) or (to: --home) and 
  (((from: --home) and (to: --home)) or not (at: --home))
)
```
