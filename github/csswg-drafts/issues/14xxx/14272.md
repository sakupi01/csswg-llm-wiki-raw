The level 2 multicol specification defines a [`::column` pseudo-element](https://drafts.csswg.org/css-multicol-2/#column-pseudo), this is currently only used for the purposes of enabling scroll-snapping to columns.

A `::row` pseudo-element would enable snapping in the block direction to rows when there is a wrapped multicol. [In this demo](https://codepen.io/editor/rachelandrew/pen/019fd073-99b9-7103-9ce1-a8594fef92fc), it would make it more obvious that each screen of columns was to be treated as a page, and both columns read before paging down to the next row.
