Design systems nearly universally adopt a box-shadow of some kind to indicate that the ::picker() is hovering above the page. Rather than leaving this as a nearly universal to-do for authors, the base appearance should apply one by default.

We propose the following ([try it out here](https://software.hixie.ch/utilities/js/live-dom-viewer/?%3C!DOCTYPE%20html%3E%0A%3Cstyle%3E%0A%20%20select%20%7B%20appearance%3A%20base-select%3B%20%7D%0A%20%20%3A%3Apicker(select)%20%7B%0A%20%20%20%20appearance%3A%20base-select%3B%0A%20%20%20%20box-shadow%3A%0A%20%20%20%20%20%20%20%200%204px%206px%20-1px%20light-dark(rgba(0%2C%200%2C%200%2C%200.10)%2C%20rgba(0%2C%200%2C%200%2C%200.35))%2C%0A%20%20%20%20%20%20%20%200%208px%2016px%20-4px%20light-dark(rgba(0%2C%200%2C%200%2C%200.08)%2C%20rgba(0%2C%200%2C%200%2C%200.25))%3B%0A%20%20%7D%0A%3C%2Fstyle%3E%0A%0A%3Cselect%3E%0A%20%20%3Coption%3EThis%20is%20option%201%0A%20%20%3Coption%3EThis%20is%20option%202%0A%20%20%3Coption%3EHere%27s%20another%20option%0A%20%20%3Coption%3EAnd%20one%20more.%0A%3C%2Fselect%3E%0A)):

```
box-shadow:
        0 4px 6px -1px light-dark(rgba(0, 0, 0, 0.10), rgba(0, 0, 0, 0.35)),
        0 8px 16px -4px light-dark(rgba(0, 0, 0, 0.08), rgba(0, 0, 0, 0.25));
```

The effect of `box-shadow` is very straightforward and easy to override, if needed. But this way the default rendering is no longer lacking in this area, and authors no longer _need_ to fix it to gain this basic usability improvement.

## @stubbornella — 2026-09-09

This isn't decorative, it is about communicating importance to the user.

Humans have evolved to pay more attention to stuff that is nearby and less to stuff that is farther away. Think speeding car a mile away versus a speeding car entering the sidewalk you are crossing.

This applies to web design because we need to make the most important things look closer to the viewer. In light mode, you achieve this by casting a drop shadow from the picker and using a subtle border around the buttons, inputs, and selects. In dark mode, you need to lighten the background color. Lighter stuff appears closer to the user, darker panels recede.

To achieve this, we need to add a drop shadow to all parts of form controls that open in the top layer. This will subconsciously indicate to the user that they should pay attention to the picker, when it is open.

## @lukewarlow — 2026-09-10

I'm personally not entirely sold that a shadow is so important for user understanding. But I'm also fairly ambivalent about whether we have it.

I think if do add this, we should probably make this only visible in light mode though. Shadows aren't super common in dark mode designs from what I've experienced, the proposed one is essential impercievable to my eyes with the default Canvas background, but might look weird in some other designs.

I think something akin to #14461 is a far better approach to visualising the stacking in dark mode.
