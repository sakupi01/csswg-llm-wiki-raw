Several pseudo-elements are not defined in the css-pseudo-4 spec. We should

1. Index them from css-pseudo-4 (or move their definitions here, if appropriate).
2. Clarify what type of pseudo-element they are (fully styleable, tree-abiding, element-backed, or whatever).

List of missing externally defined pseudo-elements (edit comment to add more):

- [ ] ::backdrop (defined in css-position-4)
- [ ] ::view-transition-* (defined in css-view-transitions)
