Filter Effects 2 [2.1 step 4](https://drafts.csswg.org/filter-effects-2/#BackdropFilterProperty) clips the backdrop-filter output to the border box of the element, including border-radius if specified. It does not mention corner-shape or border-shape.

corner-shape: implementations clip the backdrop to the shaped corners. Tested in WPT:
- css/css-borders/corner-shape/corner-shape-backdrop-filter.html
- css/css-borders/corner-shape/corner-shape-backdrop-filter-overflow.html
- css/filter-effects/backdrop-filter-corner-shape-change.html

border-shape: no spec text and no WPT coverage. Chromium clips to the rectangular border box and has closed [a bug](https://issues.chromium.org/issues/579995063) on this as WAI. Because border-shape causes border-radius to be treated as 0, the result is a rectangular filtered region extending outside the visible shape.

Proposed change: when border-shape is not none, clip the backdrop-filter output to the outer border-shape path. The blur() mirror edge would use the same path.

[example jsfiddle](https://jsfiddle.net/3fLmyvn2/2/)

- Should backdrop-filter be clipped to border-shape?
- If so, with the two-shape form, should the clip use the outer shape?
