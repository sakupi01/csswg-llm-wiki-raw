The spec has the syntax for `max-lines` as `auto || <integer [1,∞]>`. This would imply that the serialization for a specified value of `max-lines: 3 auto` would be `auto 3`. However, anytime that we've talked about this syntax (see #13670), it's had the number of lines before the `auto` keyword. So should we change this to `<integer [1,∞]> || auto`?

Note that currently the WPT tests expect `3 auto`, and there's a PR open to change this to match the spec (web-platform-tests/wpt#63925).
