The WICG proposal https://github.com/WICG/overscroll-scrollend-events/ uses overscroll events to refer to generic observation of overscroll similar to scroll events on a scroller, whereas the overscroll events added in css-overscroll-2 are specific to overscrollcontainers with overscrollareas. Should we use a more specific name / namespace? @vmpstr FYI

<!-- comment id=6217997238 author=vmpstr created=2026-10-16T14:44:35Z url=https://github.com/w3c/csswg-drafts/issues/14614#issuecomment-6217997238 -->
## @vmpstr — 2026-10-16

AFAICT the overscroll event in WICG, and its use cases can potentially be replaced by use cases of overscroll container. It's unclear to me if the WICG overscroll events are still being pursued (last commit ~6 years ago). So, whereas I'm happy to rename OverscrollEvents with something more meaningful, I'm hesitant to make the name more cumbersome to avoid this conflict

## @flackr — 2026-10-16

> It's unclear to me if the WICG overscroll events are still being pursued

It's clear to me they're not currently being pursued.

> its use cases can potentially be replaced by use cases of overscroll container

It's less clear to me that overscroll areas supersede the use cases, e.g. custom overscroll affordances, such that it would never be pursued. However I suspect we can extend the concept of overscroll containers to cover them.
