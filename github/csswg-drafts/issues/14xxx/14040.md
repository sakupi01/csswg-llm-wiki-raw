I was going through CSS Color Adjust Level 1 after the rework in #13857, and this bit caught my eye:

> NOTE: In HTML, the [color-scheme `<meta>`](https://html.spec.whatwg.org/multipage/semantics.html#meta-color-scheme) sets the [page color scheme](https://drafts.csswg.org/css-color-adjust-1/#page-color-scheme).

and

> The [page color scheme](https://drafts.csswg.org/css-color-adjust-1/#page-color-scheme) also records whether it’s default or not. The page color scheme is queryable with the [prefers-color-scheme](https://www.w3.org/TR/mediaqueries-5/#descdef-media-prefers-color-scheme) [media query](https://www.w3.org/TR/mediaqueries-5/#media-query). [[MEDIAQUERIES-5]](https://drafts.csswg.org/css-color-adjust-1/#biblio-mediaqueries-5)

This seems to go against the resolution in #10249, which is that `<meta name=color-scheme>` doesn't affect `@prefers-color-scheme`. Seems like an obvious bugfix to CSS Color Adjust level 1?
