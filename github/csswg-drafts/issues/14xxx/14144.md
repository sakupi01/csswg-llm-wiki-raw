Raised from Firefox [bug 2053351](https://bugzilla.mozilla.org/show_bug.cgi?id=2053351), the problem there is this structure:
```html
<p style="text-indent: 1em">
  <ruby>食<rt><span style="display: inline-block">しょく</span></rt></ruby>
</p>
```
The `inline-block` in `<rt>` inherits `text-indent` from `<p>` which shifts its content and expands the `<rt>` element.

It seems that Chrome's UA stylesheet includes `rt { text-indent: 0; }` which I think makes sense, given that `<rt>` creates a inline context and it doesn't make sense to work as a container of paragraph which is where `text-indent` is used. Also, as `<rtc>` could create ruby annotation without `<rt>`, it should probably do this reset as well.

I propose to add `text-indent: 0` to `rtc, rt` rule in Default UA Style Sheet.

The initial value of `text-indent` is `0` anyway. Would it be better to use `text-indent: unset` or `text-indent: initial`? I note that's how it's done for table:

```css

  box-sizing: border-box;
  border-spacing: 2px;
  border-collapse: separate;
  text-indent: initial;
}
```

I support this either way.
