Apologies if this has been discussed before, but [the current spec](https://www.w3.org/TR/css-text-3/#hanging-punctuation-property) doesn't seem to account for punctuation within a block, only at the start of the first line. 

Has an `all` (or similar) value been proposed? 

An example of hanging punctuation within a paragraph, as well as the start. Happy to provide more use-case examples if needed.

## @frivoal — 2023-12-15

Fundamentally, the spec as it currently is caters to the Chinese/Japanese/Korean uses of hanging punctuation, which are fairly different from how hanging punctuation works in text using the Latin alphabet. There's no reason we shouldn't handle that as well, but this probably needs a full analysis of what's needed and a complete proposal, rather than minor individual tweaks to the current approach, which is really designed for something different.
