- With `@scope (:host)`, you can make the shadow host a scoping root.
- Since `:scope` is defined to match the scoping root, it would then be able to match that element, even if it's featureless.

_Or would it?_

Selectors:

> A [featureless](https://drafts.csswg.org/selectors/#featureless) element does not match any selector at all, except those it is **explicitly** defined to match (and [logical combination pseudo-classes](https://drafts.csswg.org/selectors/#logical-combination-pseudo-classes) representing those selectors).

Specs _appear_ to be saying that `@scope (:host) { :scope { ... } }` would match, except that they aren't **explicitly** saying this.

Should we state this explicitly?
