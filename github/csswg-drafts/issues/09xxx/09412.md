`@font-feature-values serif {}` is invalid in Chrome and FF (because `serif` is a generic font name) but Chrome accepts `CSSFontFeatureValuesRule.fontFamily = 'serif'`. FF does not yet support the attribute.

There is no procedure defined for [`CSSFontFeatureValues.fontFamily`](https://drafts.csswg.org/css-fonts-4/#dom-cssfontfeaturevaluesrule-fontfamily).

  > **`fontFamily` of type `CSSOMString`**: The list of one or more font families for which a given set of feature values is defined.

But I also wonder why the attribute is not read-only, actually. What is supposed to happen if you declare the feature values in your stylesheet with a valid font family name, and then update it with an invalid name via CSSOM? Should the feature values be disabled?

- **option 1:** define `CSSFontFeatureValuesRule.fontFamily` as read-only
- **option 2:** throw SyntaxError (consistent with [`CSSKeyframeRule.cssText`](https://drafts.csswg.org/css-animations-1/#dom-csskeyframerule-keytext) and current behavior in Chrome)
- **option 3:** ignore invalid input (FF behavior)
