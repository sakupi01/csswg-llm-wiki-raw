Motion Path 1 was last [published in 2018](https://www.w3.org/TR/motion-1/).

At the same time it is part of [Interop 2023](https://wpt.fyi/interop-2023) and received [several substantial changes since then](https://github.com/w3c/fxtf-drafts/commits/main/motion-1), which UAs already started to implement.

Therefore, a new WD should be published. Because it received a bunch of [WPT updates](https://github.com/web-platform-tests/wpt/tree/master/css/motion) and UAs working on interoperability, it may also be moved to CR instead.

Sebastian
