Currently `scrollbar-gutter` only applies to scroll containers, but it seems reasonable that an author might want to apply the gutter to descendants of the scroll container and not the scroll container itself. So I think this should apply to all elements.

<!-- comment id=1834355691 author=bfgeek created=2023-11-30T18:42:13Z url=https://github.com/w3c/csswg-drafts/issues/9652#issuecomment-1834355691 -->
## @bfgeek — 2023-11-30

The size of the gutter depends on a other properties / pseudos. E.g. `scrollbar-width` , `::-webkit-scrollbar` , etc. Without this info you'll reserve potentially an incorrect size.
