Consider an example(from: https://bugs.chromium.org/p/chromium/issues/detail?id=1339290#c26):

```html
data:text/html;charset=UTF-8,<!doctype html> 
<style>
    div {
        font-size: 36px;
        font-family: sans-serif;
        background-image: linear-gradient( red, blue );
        -webkit-text-fill-color: transparent;
         -webkit-background-clip: text;
        background-clip: text;
    }

    span {
        position: relative;
        border: 2px solid green;
    }
</style>

<div>
    <span>Hello word</span>
</div>
```

The current behavior of Chrome and Safari does not show text, which looks like a bug, and only Firefox is as expected. Considering that [Chrome 120 removed prefixes](https://chromestatus.com/feature/5125388091260928), the specification needs to define a clear behavior as soon as possible.

Firefox:

![image](https://github.com/w3c/csswg-drafts/assets/2784308/0ec1eafc-f3db-430b-b454-c76e19764a3d)

Also, `fixed/absolute` values in Firefox can cause `background-clip: text` to fail, which needs further clarification.
