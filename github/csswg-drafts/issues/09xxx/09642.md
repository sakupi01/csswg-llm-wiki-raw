Spun out from [a comment](https://github.com/web-platform-tests/interop/issues/488#issuecomment-1742335404) by [mayank99](https://github.com/mayank99) who said:

> It's possible I'm misunderstanding the role of the Interop project, but I was hoping that the Interop team could discuss the inconsistencies with browser vendors and figure out if it's possible to have a way forward. As far as I can tell, the specification is pretty solid.
> 
> There are already plenty of tests too. Scrolling through [css-color-4](https://www.w3.org/TR/css-color-4) you'll see some of the inconsistencies in test results, although there could probably be tests for more scenarios? For example, the [`system-color-consistency`](https://wpt.fyi/results/css/css-color/system-color-consistency.html) test does not cover all system colors.

## @svgeesus — 2023-11-27

The [specification](https://drafts.csswg.org/css-color-4/#css-system-colors) defines 19 non-deprecated system colors and the WPT [`system-color-consistency](https://wpt.fyi/results/css/css-color/system-color-consistency.html?label=experimental&label=master&aligned) is currently missing tests for:

- AccentColor
- AccentColorText
- ActiveText
- GrayText
- Highlight
- HighlightText
- LinkText
- SelectedItem
- SelectedItemText
- VisitedText
