https://drafts.csswg.org/css-color-4/#the-hsl-notation

> If the saturation of an HSL color is 0%, then the hue component is powerless. If the lightness of an HSL color is 0% or 100%, the hue component is powerless and the saturation is 0%.

For `oklch` and `lch` this was changed so that only `0` chroma makes `hue` powerless.
Lightness of `0` or `100` is no longer mentioned there

Is it intentional that `hsl` wasn't changed in the same way @svgeesus ?
