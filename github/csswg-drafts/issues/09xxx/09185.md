It seems the rationale presented by some implementors at the time was that similar functionality had been already implemented with HTML's `meta` element. However:

- This is clearly a styling concern, it belongs to a styling language, which CSS is and HTML is not (supposed to be). Separation of concerns.
- CSS is explicitly intended to be usable not just with HTML. Other markup technologies may (and indeed usually should; even HTML should, but in that case it's difficult to roll it back with many pages depending on it) not have something like `meta` affecting viewport.
