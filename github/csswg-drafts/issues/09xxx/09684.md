We have a [`math`](https://drafts.csswg.org/css-fonts-4/Overview.html#math-def) generic font family.

We now also have a `generic()` wrapper function, as used in [`generic(fangsong)`](https://drafts.csswg.org/css-fonts-4/#generic(fangsong)-def) and [`generic(kai)`](https://drafts.csswg.org/css-fonts-4/#generic(kai)-def) and [`generic(nastaliq)`](https://drafts.csswg.org/css-fonts-4/#generic(nastaliq)-def).

Given that `math` generic is still fairly new and not (afaik) implemented, should it be renamed `generic(math)`?
