## @birtles — 2023-12-26

We used to have a hard-coded set of accepted pseudo-elements (based on what CSS transitions etc. originally supported, I think) but at one point we expanded it to allow all pseudos but I guess these tests never got updated. I think these tests would still pass in Firefox and maybe other browsers because in #4745 we seemed to agree that implementations should throw for pseudos that they don't support animating.
