See:

https://www.w3.org/TR/css-values-3/#absolute-lengths

While excellent for screen and print use, these units are impractical for measurements on an astronomical scale, e.g.:

https://xkcd.com/2863

This would be a new "absolute length" unit, named `au`, per section 5.2 of the spec.

For purposes of the equivalence table, `au` can be listed as 1.496e+13 cm.
