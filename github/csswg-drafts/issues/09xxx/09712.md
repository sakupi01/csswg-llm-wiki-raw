Add the following code to remind users that the undefined elements are used:

```css
:not(:defined) {
  display: block;
  font-size: 0;
}
:not(:defined) * {
  display: none;
}
:not(:defined)::before {
  font-size: 1rem;
  display: block;
  content: 'The element is not defined';
  padding: 1em;
  text-align: center;
  background: gray;
}
```

<img width="664" alt="Screenshot 2023-12-15 at 12 54 46" src="https://github.com/w3c/csswg-drafts/assets/3841872/6d0f70e1-df8d-49d2-88b8-f53bd89f6191">

But now we have [Declarative Shadow DOM](https://github.com/whatwg/dom/issues/831), we can no longer determine which elements may have layout problems([demo](https://mantou132.github.io/javascript-learn/declarative-shadow-dom.html)), to find these elements, it is suggested to add a pseudo class:`:attached`:

```css
:not(:defined, :attached) {
  display: block;
  font-size: 0;
}
:not(:defined, :attached) * {
  display: none;
}
:not(:defined, :attached)::before {
  font-size: 1rem;
  display: block;
  content: 'The element is not defined';
  padding: 1em;
  text-align: center;
  background: gray;
}
```
