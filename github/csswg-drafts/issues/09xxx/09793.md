There are a bunch of specifications which might be added to the Rough Interoperability section.

## [CSS Nesting 1](https://www.w3.org/TR/css-nesting-1/)

Current status: WD (last published: 14 February 2023)
[WPT](https://wpt.fyi/results/css/css-nesting?label=master&label=stable&aligned): passing tests: Chrome: 88, Edge: 88, Firefox: 89, Safari: 85; [interop](https://wpt.fyi/results/css/css-nesting?label=master&label=stable&aligned&q=all(status%3Apass)): 84 / 89 (94.4%)
Current Snapshot section: -
Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acss-nesting-1): 23, [in spec.](https://drafts.csswg.org/css-nesting-1/#issues-index): 2

Notes: Very high interoperability, part of [interop 2024](https://wpt.fyi/interop-2024)

## [CSS Scroll Anchoring 1](https://www.w3.org/TR/css-scroll-anchoring-1/)

Current Snapshot section: -
Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acss-scroll-anchoring-1): 17, [in spec.](https://drafts.csswg.org/css-scroll-anchoring-1/#issues-index): 0

Notes: high interoperability between two engines, implementations agree on main use cases

## [CSS Color 5](https://www.w3.org/TR/css-color-5/)

Current status: WD (last published: 29 February 2024)
[WPT](https://wpt.fyi/results/css/css-color?label=master&label=stable&aligned): passing tests: Chrome: 9217 , Edge: 9210, Firefox: 9237, Safari: 8452 ; [interop](https://wpt.fyi/results/css/css-color?label=master&label=stable&aligned&q=all%28status%3Apass%29): 8412 / 8412 (100%)
Current Snapshot section: -
Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Acss-color-5): 30, [in spec.](https://drafts.csswg.org/css-color-5/#issues-index): 0

Notes: interoperability is good. Both CSS Color 5 Relative Colors and CSS Color 5 `color-mix()`, were [cleared-to-ship pre-CR in CSS 2023](https://www.w3.org/TR/css/#CR-exceptions). Relative Colors are part of [Interop 2024](https://wpt.fyi/interop-2024). `color-mix()` was part of [Interop 2023]() in the [Color Spaces and Functions](https://wpt.fyi/results/css?product=chrome&product=firefox&product=safari&aligned=&view=interop&q=label%3Ainterop-2022-color+or+label%3Ainterop-2023-color&label=master&label=experimental) focus area.

Current status: WD (last published: 18 December 2021)
[WPT](https://wpt.fyi/results/css/mediaqueries?label=master&label=stable&aligned&q=prefers-reduced-motion%20or%20prefers-reduced-transparency%20or%20prefers-contrast%20or%20prefers-color-scheme%20or%20light-level%20or%20inverted-colors%20or%20custom-media): passing tests: Chrome: 93, Edge: 93, Firefox: 89, Safari: 90; [interop](https://wpt.fyi/results/css/mediaqueries?label=master&label=stable&aligned&q=(prefers-reduced-motion%20or%20prefers-reduced-transparency%20or%20prefers-contrast%20or%20prefers-color-scheme%20or%20light-level%20or%20inverted-colors%20or%20custom-media)%20and%20all(status%3Apassed)): 86 / 97 (88.7%)
Current Snapshot section: -

## [Selectors 4](https://www.w3.org/TR/selectors-4/)
Current status: WD (last published: 11 November 2022)
[WPT](https://wpt.fyi/results/css/selectors?label=master&label=stable&aligned): passing tests (all tests, not sure how to restrict to level 4): Chrome: 4807, Edge: 4800, Firefox: 5466, Safari: 4807; [interop](https://wpt.fyi/results/css/selectors?label=master&label=stable&aligned&q=all(status%3Apass)): 4737 / 5506 (86.0%)

Open issues: [on GitHub](https://github.com/w3c/csswg-drafts/issues?q=is%3Aopen+is%3Aissue+label%3Aselectors-4): 105, [in spec.](https://drafts.csswg.org/selectors-4/#issues-index): 11

Notes: high interoperability, though many open issues, looks like WPTs for some features are missing, but some important ones are there. Though as not all features are supported by browsers, maybe only the interoperable ones should be added to Safe to Release pre-CR Exceptions.
