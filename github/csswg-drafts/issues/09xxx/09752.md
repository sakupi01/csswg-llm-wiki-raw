[`<attr-type>`](https://drafts.csswg.org/css-values-5/#typedef-attr-type) defines different kinds of dimension keywords, though it is currently missing `resolution` for [resolutions](https://drafts.csswg.org/css-values-4/#resolution).

Related to that, `<resolution>` should also be added to the definition of [`<dimension-unit>`](https://drafts.csswg.org/css-values-5/#typedef-dimension-unit). Alternatively, instead of listing all the dimensions, it could just refer to [the definition of `<dimension>`](https://drafts.csswg.org/css-values-4/#typedef-dimension), so there is only one place of truth.
