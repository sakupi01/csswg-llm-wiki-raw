| replaced bopomofo | original hiragana/katakana |
| --- | --- | 
| ㄘ | ち |
| ㄟ | へ |
| ㄟ⁰[^zero] | ぺ |
| ㄋ | ろ |
| ㄜ | さ |
| ㄝ | せ |
| ㄨ | メ |

[^zero]: superscript zero U+2070 is used for Japanese semi-voiced sound mark ゜

These bopomofo characters were primarily used to replace certain characters in NSFW Japanese words used these ASCII arts to circumvent censorship. In my recollection, they became popular (to some extent) in Twitter during the early–mid 2010s in Japan.

Japanese Twitter users see bopomofo and immediately recall these ASCII arts.

Under current specifications, han and hiragana/katakana are completely treated as identical, resulting in inappropriate spaces between them.
