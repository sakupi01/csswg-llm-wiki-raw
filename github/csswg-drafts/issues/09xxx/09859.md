I don't think this is already addressed in a spec, I have seen it here: https://www.w3.org/TR/WCAG20-TECHS/H37.html

There are different variations of alt text such as `alt-text`, `alttext` and `alt_text`.

WebKit uses `alt-text`: https://github.com/WebKit/WebKit/pull/22185, https://webkit.org/blog/14931/release-notes-for-safari-technology-preview-187/

Chromium uses `alt_text`: https://chromium-review.googlesource.com/c/chromium/src/+/4854588/13/chrome/browser/companion/visual_search/visual_search_classifier_host.h

Ideally they would be written as one of them.
