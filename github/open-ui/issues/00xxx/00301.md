The [time element is limited to three digits in the fractional part of a second](https://html.spec.whatwg.org/multipage/common-microsyntaxes.html#valid-time-string). Why does the standard have this limitation? For example [in PostgreSQL the fractional part can have up to 6 digits (microseconds)](https://www.postgresql.org/docs/11/datatype-datetime.html#DATATYPE-DATETIME-TABLE) and [in Java up to 9 (nanoseconds)](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/time/LocalTime.html).
