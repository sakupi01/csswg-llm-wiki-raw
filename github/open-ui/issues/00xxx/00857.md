Currently in HTML, the `title` attribute [has special semantics](https://html.spec.whatwg.org/multipage/text-level-semantics.html#attr-abbr-title) on the `<abbr>` element to provide an expanded abbreviation.

But the `title` attribute isn't accessible to mobile and keyboard users.

Since `popovertargetaction=interest` is meant to be an accessible tooltip, maybe it could be used here instead.

But popovers aren't allowed on non-interactive content. `<abbr>` is non-interactive. So should this be allowed?
