It has been expressed in accessibility discussions ([990](https://github.com/openui/open-ui/issues/990) and [aria-1947](https://github.com/w3c/aria/issues/1947)) that providing a visual indicator for a focusgroup could be helpful even for sighted users as a clear pattern to know that a group can be navigated with arrow keys.

Perhaps there is room for a new user agent default stylesheet CSS pseudo class? E.g.,

```css
   [focusgroup]:focus-within {
        /* ua-default visual styles */
    }
```
