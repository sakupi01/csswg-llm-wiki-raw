Hi everyone.

I was thinking about something earlier this week about having the ability of a multi-range slider available in HTML such as we see a lot in webshops

<details>
<summary>Some screenshots</summary>

![slider1](https://github.com/openui/open-ui/assets/4632664/ff0173ba-ce34-4b7d-8995-f3fd97dc399e)
![slider2](https://github.com/openui/open-ui/assets/4632664/68614d11-d856-4ac1-956f-be53142d73b6)


</details>

we have the following in HTML already:
`<input type="range" />`

But as it currently stands there is no option to have multiple handles for this. So I was wondering if we could do something about this as a group. This is a UI feature that we see a lot on the web for multiple purpose, but mostly for choosing prices on webshops (from... till)

I wouldn't mind picking this up, although I don't have much experience with writing explainers. I wouldn't mind giving it a go.

Not sure if there already is an issue on the HTML working group (I've searched, but haven't found it). But I'm pretty sure I'm not the first one with this idea.

Is this something we can pick up in this group?

From the way I see it, there are two ways to do this:
- increase capabilities of the range slider (in my opinion preferred)
- create something new

I see a lot of benefits in this, this could create an accessible slider, but also potentially give the ability to show the text by using pseudo element and display value attributes in the content property. Making it a JS-free component (that of course be paired with some events and instances )

Just checking for some interest on this
