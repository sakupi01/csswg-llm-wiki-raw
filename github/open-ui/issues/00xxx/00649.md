## @anilkumarum — 2022-12-19

In your code, you manually call focus on button that's why i call it a hack.

If button element remove from these line
```html
<li><button role=menuitem>Cut</button></li>
<li><button role=menuitem>Copy</button></li>
<li><button role=menuitem>Paste</button></li>
```
then right click menu auto hide but visible in click.


As i understand, focusable element required to prevent auto hide.
`<li tabindex="0">Cut</li>`

Thanks for providing solution. I use this method in my project.
