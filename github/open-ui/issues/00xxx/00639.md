Some SelectMenus in the wild have a button part that either opens the listbox and it remains open. Or, the button part toggles the listbox showing.

Do we have a way to support allowing the user to define how they want the listbox to behave?

Currently, the button part will keep triggering the opening of the listbox if you keep clicking it. This is evident if you have an opening transition on the popover that is used for the listbox: https://codepen.io/jh3y/pen/RwJrEye

## @css-meeting-bot — 2023-01-19

The Open UI Community Group just discussed `Should the button part of a SelectMenu toggle or show the listbox? #639`, and agreed to the following:

* `RESOLVED: clicking a selectmenu button opens the listbox popover. Clicking it again hides the listbox (potentially via a hide animation). No flickering or light dismiss behavior should happen in this scenario. This should be overridable via explicit attributes on the button.`
