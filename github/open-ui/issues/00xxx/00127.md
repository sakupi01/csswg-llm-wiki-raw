Speaking from experience 😅, if you are in the habit of checking README and CONTRIBUTING files in order to learn build steps and project structure/syntax, you may forget that https://open-ui.org/contribute exists.

It would be helpful to include in these files…

* https://github.com/WICG/open-ui/tree/master/research
* https://github.com/WICG/open-ui/blob/master/CONTRIBUTING.md

…a link to the rendered [contribute page](https://open-ui.org/contribute).

The main CONTRIBUTING file looks like WICG boilerplate, so hopefully it is acceptable to just tack on another section to that for the purposes of linking to deeper contribution guidance.
