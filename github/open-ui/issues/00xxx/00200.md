The visual break between breadcrumb items is referred to across libraries as either a divider or a separator. There is no clear consensus among libraries, though the spec submitted (#165) does refer to this as "divider". For breaks within a menu, the W3C uses the word separator. This issue is intended to track and land on the best semantic representation for this part given the lack of consensus and similar concepts described in the W3C described as "separator".

## @chrisdholt — 2020-11-06

I very much agree with both points here - the name of "separator" and treating this more as a pseudo element. Currently the name in the spec I believe is "divider" and I believe the spec also treats the separator as a slotted element by default in the anatomy. It would be great to get resolution on the above from others so we can update accordingly.
