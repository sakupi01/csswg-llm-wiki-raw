Stardust UI no longer exists by that name. Most links to https://stardust-ui.github.io/react redirect to https://fluentsite.z22.web.core.windows.net/0.66.2 which itself says is deprecated and (brokenly) links to https://react.fluentui.dev/?path=/docs/concepts-introduction--page

StardustUI should be updated to the new React FluentUI stuff accounting for any changes.
