## Migrating styles

In the current site, Open UI uses several methods for managing styles:

- inline styles
- styles in `.css` files
- defining a styles via `Typography.js`

Components like the `Header` component have their own inline styles

There are also a handful of additional `*.css` files:

`global.css`, `table-anatomy.css`, `spec.css`, and `anatomy.css`.

Gatsby uses the `Typography.js` plugin to generate our styles at build-time and is then served as a static `.css` file.

### Migrating styles

Using a standard `.css` solution may be simple enough for such a site. To simplify the migration of the `typography.js` styles, we can leverage its `toString()` API which allows us to write out a `css` file at build time.

Typography offers an API that lets us convert the design object to a CSS output. We can invoke this function when our build starts to generate our css file automatically.
