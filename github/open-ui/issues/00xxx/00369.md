As the "focusing steps" for `popup` are written in #355, the `delegatesfocus` attribute effectively takes precedence over `autofocus` when both are applied to `popup`, like so:

```
<popup autofocus delegatesfocus>
  <button>I will be focused, not the popup itself</button>
</popup>
```

The Chromium prototype also follows this behavior. Is this the desired/most reasonable conflict resolution?
