Per the [recent resolution](https://github.com/openui/open-ui/issues/546#issuecomment-1158190204), we've decided to call this API the "pop up" API, and rename the IDL property accessor to `popUp` (with a capital `U`). Should we therefore also rename the rest of the JS-accessible parts of the API to `popUp`? E.g.:

```javascript
myPopUp.showPopUp();
myPopUp.hidePopUp();
myButton.togglePopUp = 'idref';
myButton.showPopUp = 'idref';
myButton.hidePopUp = 'idref';
```

? It feels a bit cumbersome to type, as I'm typing the above. But it's definitely more consistent if we've decided to use `myPopUp.popUp = "auto"`. So it feels like we should make the above changes.

@domenic thoughts?
