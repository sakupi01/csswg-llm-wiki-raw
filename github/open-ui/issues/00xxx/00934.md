We don't currently define any default invoke actions for selectlist I feel like we should. Admittedly this is less important because the trigger button can be fully customised but still feels worthwhile?

We resolved to add a showPicker method to selectlist. So at least that as an action makes sense to me.

Like with select and input I'm not sure if a toggle or close actually make sense? I guess because the popover is customisable then perhaps we should add a closePicker and togglePicker function?
