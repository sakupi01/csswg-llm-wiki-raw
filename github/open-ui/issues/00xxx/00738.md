While looking through the slider research I noticed that there isn't the concept of a "slider container". However, in side of Chromium and WebKit there's the `::-webkit-slider-container` pseudo element which afaict is basically the same as the range input itself but at least in Chrome internally is used for styling involving the slider ticks.

Not sure if this is something we want to document or if its more of an implementation detail.
