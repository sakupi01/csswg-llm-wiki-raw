This discussion should come later on in popup incubation once popup-related primitives are more mature. We introduce a number of primitives that are necessary for `popup`, and we imagine that many of these would be useful in other contexts (e.g. `delegatesfocus`). We should go through each one and consider how these will be applicable to other elements (dialog, "all top-layer elements", or otherwise).

This also came up on https://github.com/MicrosoftEdge/MSEdgeExplainers/issues/455
