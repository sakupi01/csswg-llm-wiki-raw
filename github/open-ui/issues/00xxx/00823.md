The `hr` element is [allowed as a child](https://html.spec.whatwg.org/multipage/form-elements.html#the-select-element:concept-element-content-model) with a normal `select` element. Its use is to create a separator.

But it seems that this is [not included](https://open-ui.org/components/selectlist/#anatomy-of-the-selectlist-element) with `selectlist`.

I think that it should be allowed for use with the `listbox` slot/element.

Although, currently, a `hr` is not allowed as a child of an `optgroup` (https://github.com/whatwg/html/issues/9247), so should it be allowed as one here?
