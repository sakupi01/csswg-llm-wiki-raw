For selectlist we allow designs such as split buttons where you have a main button and then a split button to control the dropdown.

Should we allow a split button option for combobox?

<!-- comment id=1887875716 author=css-meeting-bot created=2024-01-11T20:01:01Z url=https://github.com/openui/open-ui/issues/971#issuecomment-1887875716 resolution=true -->
## @css-meeting-bot — 2024-01-11

The Open UI Community Group just discussed `[combobox] Should we allow a button child to control the dropdown?`, and agreed to the following:

* `RESOLVED: for stylable <select> use <button type=popover>. For combobox, any button with type=popover inside a combobox will trigger the popover. Other buttons will not.`
