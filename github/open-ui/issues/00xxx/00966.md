This may be a fundamentally silly idea, but...

Currently if you want a modal dialog it's all or nothing (afaik). You can only inert the whole document or none.

Iframes can be used to scope it but they're rather heavy handed. If you have a third party widget (say a chat widget) that wants to use a modal dialog but only inert the rest of the widget there's not really any choice but to completely build a custom element rather than use the built in.

It could be useful to allow a dialog's modality to be scoped? Either to a shadow root or to an arbitrary element?
