Hey everyone,

I really like the wireframes for showing the component's anatomy, but as we get into some more complex components it gets quite ugly. I'd love if someone that is a good designer could help adjust this a little. Here is the currently defined `<select>` anatomy: https://open-ui.org/components/select#anatomy

![image](https://user-images.githubusercontent.com/865244/79797394-02520f80-830c-11ea-9d12-f54fc6935edb.png)

Some ideas I've been thinking about:

* Be able to show/hide slots
* Come up with a different color scheme
* If an element contains a slot then just add it to the name (eg: button [slot])

Any other ideas are welcome.

## @melanierichards — 2020-04-20

What about a monochromatic color scheme? Pick one color for the host element, lighter and lighter shades of that color for smaller and smaller parts of the component (or the inverse if you prefer). The outlines could also be a very dark shade of that color, maybe with some alpha channel fun thrown in. Slots could have a special treatment, like a dashed line.

<!-- comment id=616837209 author=melanierichards created=2020-04-20T22:07:29Z url=https://github.com/openui/open-ui/issues/75#issuecomment-616837209 -->

And then maybe additional special treatments based on state, like an accent color and/or double-wide border for selected elements.
