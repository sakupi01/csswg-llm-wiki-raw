Open UI currently has file-selector-button (which after #913  will be correctly labelled as a button) but it also has a `label` part. However, this isn't a true label it's more a supplementary piece of text that shows stuff such as file names. As opposed to the checkbox component where its label part is representative of an actual label.

Should we rename this label part?
