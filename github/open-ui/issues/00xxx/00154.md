We should consider making the Home/End keys jump to the beginning/end of the `<select>`'s options list.
Works in Chromium, Firefox, and Safari `<select>`s.  Doesn't work in [bootstrap](https://getbootstrap.com/docs/4.3/components/dropdowns/#split-button) or [ant design](https://ant.design/components/select/), but perhaps it should.
