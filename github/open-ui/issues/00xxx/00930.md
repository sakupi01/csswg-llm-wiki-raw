The preferred term for the new form control element is `combobox`. While it is descriptive of the element's functionality, combining an input box with a dropdown list. This term is already widely recognized and used by several design systems, making it a strong candidate for standardization.

Please use the emojis below to indicate your preferred name for the new form control element:


- Combobox ❤️ 
- Dropdown  👍 
- Autocomplete 😄  
- SelectInput 🚀 

Alternatively, comment below if you have other suggestions.
