<!-- comment id=1405953343 author=mfreed7 created=2023-01-27T02:51:51Z url=https://github.com/openui/open-ui/issues/608#issuecomment-1405953343 -->
## @mfreed7 — 2023-01-27

> So if the autofill preview is just a painted bit of text above the `<selectmenu>`'s button, it shouldn't be observable at all. Right?

For example, the preview text could be placed inside a `<div popover=manual>` which is inside the `<selectmenu>`’s shadow root. The contents of that div should not be observable at all.
