The first one I ran into was Bootstrap's Input, which was:
```
https://open-ui.org/research/group%20https://getbootstrap.com/docs/4.3/components/input-group
```
This made me check the source code for other cases.
With this cumbersome regex `/"url": "(?!http).+/` I found some more:

```json
research/src/sources/bootstrap.json5:
  332:       "url": "group https://getbootstrap.com/docs/4.3/components/input-group"
  340:       "url": "group https://getbootstrap.com/docs/4.3/components/list-group"
  344:       "url": "object https://getbootstrap.com/docs/4.3/components/media-object"

research/src/sources/evergreen.json5:
  214:       "url": "ttps://evergreen.segment.com/components/autocomplete/",
```

I could've sent a PR fixing them, but I preferred to create an issue in case the links were retrieved with a script or something like that.
