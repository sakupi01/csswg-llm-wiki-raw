## @lukewarlow — 2025-03-20

Note: One potential issue related to this command might be browser compatability issues with the underlying Web Share API.

Web Share has a few possible options that we could work with.

```html
<!-- Corresponding call: navigator.share({text: "Text to Share"}); -->
<button commandfor="p" command="share">
  Share
</button>
<p id="p">Text to share</p>

<!-- Corresponding call: navigator.share({text: "Other text to Share"}); -->
<button id="self" commandfor="self" command="share" value="Other text to Share">
  Share
</button>

<!-- Corresponding call: navigator.share({url: "https://example.com"}); -->
<button id="self-url" commandfor="self-url" command="share" value="https://example.com">
  Share
</button>
```

Maybe files too?

```html
<!-- Corresponding call: navigator.share({files: [...]}); -->
<button commandfor="img" command="share">
  Share Image
</button>
<img src="..." alt="...">
```
