There is a series of commands for scribing a meeting. It would be useful to have a short `scribe.md` file in this repo to enumerate these commands and act as a guide, including:

- Starting a meeting (a set of commands to start, set title, etc.)
- Setting a new topic
- Posting the notes to the issue
- Ending a meeting

etc.

## @dbaron — 2023-08-11

I think perhaps the shortest version is something like (where I'm using `${variable}` as the syntax for something that needs to be filled in):

* starting a meeting
  * required steps:
    1. `/invite Zakim`
    2. `Zakim, start meeting`
    3. `ScribeNick: ${username}`
  * recommended steps: add additional lines of metadata as described in "Step 2" of [scribe.perl's documentation](https://w3c.github.io/scribe2/scribedoc.html)
* new topic:
  * if it's logged to a github issue, do `/me github-bot, topic ${url}`
  * if it's not logged to github, or the above gives an error, use `Topic: ${title_of_topic}`
* ending meeting:
  1. `/me github-bot, end topic`
  2. `/me RRSAgent, draft minutes v2`
