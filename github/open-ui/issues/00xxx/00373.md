Hi All,

Recently we did some research regarding word jumping. We define this as the ability for the caret to jump from one word to another while the arrow keys are pressed and `alt` on Mac or `ctrl` on Windows is held down.

![stopsAtChar](https://user-images.githubusercontent.com/7938900/125422480-de82c396-2ad4-43a4-9415-d49ea2f70039.png)

We did some research on this across desktop applications, for our application LaunchMenu (LM in the table). How would these varying behaviours fit into Open UI (if at all)?

## @sancarn — 2021-07-20

> I'd like to know the usecase you're handling on the web

Our particular usecase is that we are developing [LaunchMenu](https://launchmenu.github.io/) (a desktop-electron application, the LM in the above picture) and we were wanting to know what the word-jump behaviour of our search field React component should be. In our case it was just a case of "let's try to find the most commonly used approach", which turned out to be - there really is no standard... And there probably should be in reality.
