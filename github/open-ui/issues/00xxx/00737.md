I like that Open UI is (and will be even more so as time goes on) a unified catalog of UI concepts and components. However, is it worth deferring to for example the HTML spec where a version of the feature is specced?

For example, popover was incubated here and has subsequently moved to the HTML spec, where it has undergone refinement* leading to the OpenUI explainer for it getting out of date.

I still believe it necessary to keep this entry on the Open UI site not least for further iterations to the feature (hover triggering for example).

Raising this issue to start a discussion around possible solutions (potentially the answer is the current status quo is good enough)

* As a slightly separate discussion potentially there needs to be an effort to try to get a wider audience to participate in the incubation to avoid some of these changes post standardisation?
