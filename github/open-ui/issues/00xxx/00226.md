In SAP this is called [token](https://experience.sap.com/fiori-design-web/token/).

![image](https://user-images.githubusercontent.com/4257079/100539375-28f00580-3260-11eb-9bb4-003d857c15fb.png)

These ussually applied when used inside some combobox/dropdown concept.
Does this building block warranted to be discussed?

## @keithamus — 2026-07-10

As per the meeting logs, we reviewed this and while we're open to the idea of adding some kind of chip or token element, no one is currently able to champion such a proposal.

We'll close this as not planned, but if anyone is interested in writing a proposal and presenting it to the group then we welcome that, and we can re-open the issue. Championing a proposal is quite straightforward: you need to be someone who wants the feature in the platform, and is willing to write a document to explain how that might work. The OpenUI team can work with you to make it a reality.
