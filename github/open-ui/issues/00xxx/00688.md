In the March 2 telecon I was actioned with opening an issue to resolve on a Open UI design principle as it relates to the definition of interoperable when defining default behaviors and appearance. The topic that was being discussed was #433 where interoperability across operating systems and web properties were not the same. This issue is not about that issue specifically but officially resolving on the following proposed principle:

> Open UI will define the default behaviors and appearance. These may vary by form factor or other capabilities (eg: inputs available, etc) but we will not have behavioral/appearance differences across operating systems of similar form factors (eg: desktop on Windows || Mac).

The above principle likewise aligns with our recently resolved on proposed charter in the 'Out of Scope' section:

> Any attempt to determine or specify the default look or behavior of these controls in the context of a particular operating system or hardware device. 

I'm not saying the above verbiage is perfect so please recommend modifications or if you disagree, please let me know.

_**Note:** I will open a related issue regarding a developer's capability to opt-in to a native equivalent control if desired_
