On multiple occasions it is necessary to change a parameter of the current URL and reload the page. For example to change the language or the number of results per page. To do this, a &lt;select&gt; element is usually used with the different options and through Javascript the selection change is detected, the parameter changed and the page reloaded. This is something very used, very useful and very simple that the browser could do without using Javascript. It would only be necessary to indicate in the &lt;select&gt; element that its function is to change a parameter of the URL.

Example:

  ```
<select url-parameter="lang"/>
      <option>en</option>
      <option>es</option>

  URL = https://demo.nexttypes.com/?lang=en
```

## @alejsanc — 2023-02-23

> It is also a one liner to do this with script, so not even a significant abstraction.

And it's not just one line, it takes a lot more code to generalize it to multiple parameters. You have to look for all the "url-parameter" elements and add a function that takes the url of the page, modifies the indicated parameter and loads the new url

```
function addEventListeners(rootElement, query, event, eventFunction) {
	var elements = rootElement.querySelectorAll(query);
	for (let element of elements) {
		element.addEventListener(event, eventFunction);
	}
}

function changeURLParameter(event) {
	var select = event.currentTarget;
	var value = select.options[select.selectedIndex].value;
	var parameter = select.getAttribute("data-url-parameter");
	
	var pageURL = new URL(window.location);
	pageURL.searchParams.set(parameter, value);
	window.location = pageURL;
}

addEventListeners(document, "select[data-url-parameter]", "change", changeURLParameter);
```
