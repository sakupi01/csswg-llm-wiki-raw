I made the suggestion to [use the "select" element to change a URL parameter without Javascript](https://github.com/openui/open-ui/issues/276) but it has been closed as out of scope for the "select" element. In that case we can add a new element with the same appearance as the select element.

```
<url-parameter name="lang"/>
    <option>en</option>
    <option>es</option>

URL = https://demo.nexttypes.com/?lang=en
```

We can also add a new element or extend the "anchor" or "nav" elements to be able to choose from multiple full URLs with the same appearance as the select element.

```
<url>
    <option>en.website.com/</option>
    <option>es.website.com/</option>

    <option>website.com/en/</option>
    <option>website.com/es/</option>
</url>

<a>
    <option>en.website.com/</option>
    <option>es.website.com/</option>

    <option>website.com/en/</option>
    <option>website.com/es/</option>
</a>

<nav select>
   <a href="en.website.com"/>
   <a href="es.website.com"/>

   <a href="website.com/en/"/>
   <a href="website.com/es/"/>
 </nav>  
```

## @alejsanc — 2023-03-26

>The key feedback on this was that it's very little javascript in order to enable this functionality

Not so little Javascript, it takes a lot more code to generalize it to multiple parameters. You have to look for all the "url-parameter" elements and add a function that takes the URL of the page, modifies the indicated parameter and loads the new URL.

```
function addEventListeners(rootElement, query, event, eventFunction) {
	var elements = rootElement.querySelectorAll(query);
	for (let element of elements) {
		element.addEventListener(event, eventFunction);
	}
}

function changeURLParameter(event) {
	var select = event.currentTarget;
	var value = select.options[select.selectedIndex].value;
	var parameter = select.getAttribute("data-url-parameter");
	
	var pageURL = new URL(window.location);
	pageURL.searchParams.set(parameter, value);
	window.location = pageURL;
}

addEventListeners(document, "select[data-url-parameter]", "change", changeURLParameter);
```
It is also a functionality that can be used on any website that has parameters such as language, number of results per page, etc. That saves millions of lines of Javascript code globally.

It also seems like basic functionality to me. Just as there are anchors to other URLs there must be a way to change a URL parameter.
