Certain JS APIs have cross-origin restrictions, such as `input.showPicker()` (for non file and color types) and `select.showPicker()`

Should these restrictions apply to the declarative invocations?

<!-- comment id=1751424613 author=lukewarlow created=2023-10-06T21:30:48Z url=https://github.com/openui/open-ui/issues/865#issuecomment-1751424613 -->
## @lukewarlow — 2023-10-06

For things like requestFullscreen where it's permission controlled it obviously makes sense to not allow it to work where the JS API wouldn't. For things like showPicker it's less clear to me? I'm leaning towards it not working too just maybe a bit odd if you can't detect the failure?

Either way it's worth calling out explicitly.
