In the chromium implementation of `<selectmenu>`, you can make a child element with `behavior=selected-value` which makes that element's textContent get set to the currently selected option.

However, there is no support for `slot=selected-value` to slot an element into the spot where selected-value is. This could be used to display custom/rich content for the currently selected option instead of just having the basic text without replacing the button or the marker.

Is this something that people are interested in? Is there already consensus that this should be supported?
