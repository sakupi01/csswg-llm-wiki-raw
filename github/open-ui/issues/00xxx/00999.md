Currently the [interest invokers](https://open-ui.org/components/interest-invokers.explainer/) explainer doesn't include an `interestaction` attribute. While this makes sense as it's always "toggle"/"auto" for v1 browser actions, doesn't that preclude custom actions and also go against the premise that custom actions would have naming requirements?

cc @keithamus 

<!-- comment id=1971541583 author=mfreed7 created=2024-02-29T16:45:55Z url=https://github.com/openui/open-ui/issues/999#issuecomment-1971541583 -->
## @mfreed7 — 2024-02-29

We could just re-use the `invokeaction` attribute, perhaps? It would still be the "action" taken when the element is "invoked", just via "interest" this time.
