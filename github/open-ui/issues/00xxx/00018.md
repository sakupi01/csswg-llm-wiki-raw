There is an increasing desire/demand for a <dialogue> or <modal> component in the web platform. There is also an [explainer ](https://github.com/adrianhopebailie/modal-window/blob/master/explainer.md)that is geared to addressing needs presented by the Payments WG for other items using a custom <dialogue>. We should ensure that needs outlined by the various design systems is also covered by this solution. The cross origin needs outlined there are real but we should figure out a way to converge the needs so that webdevs aren't having to create a modal/dialogue <N> different ways with different capabilities of styling, extensibility, etc.
