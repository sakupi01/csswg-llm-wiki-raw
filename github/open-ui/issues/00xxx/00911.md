Hmm actually the more I think about this the less sure I am this makes sense.

The only popover=manual type picker is the color input in Firefox. Everything else closes on clickoutside OR is a modal dialog (file picker).

So does having a toggle and hide action actually make sense.

@keithamus what do you think about for now just removing the auto action? Then if we decide we want these in future (before shipping) we can add them easy enough?

Implementing the toggle is slightly difficult because the mousedown on the button leads to the picker closing which then reopens on mouseup from the invoke.
