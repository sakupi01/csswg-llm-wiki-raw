<!-- comment id=840263117 author=chrisdholt created=2021-05-13T03:21:36Z url=https://github.com/openui/open-ui/issues/346#issuecomment-840263117 -->
## @chrisdholt — 2021-05-13

I think this is more a matter of velocity, time, and priority. I know that for many, the initial pain points are with existing elements (most commonly form elements) like select, checkbox, radio, etc - which have been troublesome to style and makeup a large portion of common scenarios across the web. I think that Tree View, Tree Grid, etc are all totally valid components to investigate and address in some way as part of Open-UI, it's just a matter of someone starting with an issue or research. Perhaps this is it!
