## @brunoprietog — 2025-05-05

Hi @keithamus, programmer and screen reader user here. I'm concerned about the direction this might take, especially since it's very common to focus on an element and hold the focus there to read something, spell it out, or anything similar. Having something open without triggering anything for you, manually, is pretty invasive. I can imagine myself in situations like that, a bit annoyed because I can't take control of the situation.

I wonder if you have thought of additional ways to announce a command, or, even, create an additional role that screen readers could report so that the user knows there is a hovercard that they can invoke in some other way.

Even so, is this really common enough to trigger this automatically or on hover? I'm not so convinced I've seen this pattern much either. At first, I thought this API would be about something more similar to lazy loading, like GitHub's include-fragment element.

Thanks for your consideration
