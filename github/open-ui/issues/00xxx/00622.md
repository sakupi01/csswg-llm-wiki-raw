As per the discussion on https://github.com/openui/open-ui/issues/610 we briefly discussed how there is not presently a way to style the invoking element of a popup based on the current state.

Presently, if building something like this with HTML / ARIA today, one could use `<button aria-expanded=true|false>` and use the ARIA attribute as the hook.  It seems this is something the invoking element for a popup should/could support (whether an attribute needs to be reflected in the DOM, or a pseudo class (`:expanded` and `:collapsed` to match current ARIA conventions?  `:opened` and `:closed`), or other e.g., `.indeterminate` for checkboxes in HTML.  Not implying preference on any of those, merely listing the ways to do this that quickly come to mind.

cc @mfreed7

## @g12n — 2026-03-11

I think we have to be precise here, what we actually want to select.

Lets start with a simple demo case

![Image](https://github.com/user-attachments/assets/aa98aaf6-301b-4fdb-888b-1ce7962fd2da)

```html
<div aria-label="products on this photo">
     <button popovertoggletarget="product-1">Book</button>
     <button commandfor ="product-2" command="toggle-popover">Mug</button>
</div>

<div popover id="product-1"><p>Pen<p><p>ab 15,99€</p></div>
<div popover id="product-2"><p>Pen<p><p>ab 15,99€</p></div>
``` 

## **Option 1:** The element with a `for` or `popovertoggletarget` or `commandfor` attribute based on the state of its targeted element.

This would be a pseudo class checking similar to `parent:has(child)` but for the invoker-target relationship. 

```css
button::has-target(:popover-open){
    --circle-size: 80%;
}
```
This would target any button with linked to an open popover. 

![Image](https://github.com/user-attachments/assets/f21afe6e-309e-45e5-b581-a0f6be2fe84d)

If there were two buttons invoking the same target, both would be selected. This would be similar to the [above mentioned](https://github.com/openui/open-ui/issues/622#issuecomment-1310824380) `body:has([id=pop]:open) [popovertoggletarget=pop] `

## **Option 2:** The element that invoked a given elements current state

This would be pseudo element selecting the element.

```css
:popover-open::invoker{
    --circle-size: 80%;
}
```
This would work similar to [implicit anchor implicit_anchor_association](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Anchor_positioning/Using#implicit_anchor_association) and only target the element that has initiated the current state. It would select the most recent [CommandEvent: source](https://developer.mozilla.org/en-US/docs/Web/API/CommandEvent/source) or the [ToggleEvent:source](https://developer.mozilla.org/en-US/docs/Web/API/ToggleEvent/source).

![Image](https://github.com/user-attachments/assets/41853e83-5153-4d8d-871c-98401120d1d5)

This might even be more implicit by additional selectors `::invoker(button)`.
