If I made a component `std-button`, that can be used like this:

```html
<std-button md>
  <std-icon slot="icon">settings</std-icon>
  Material 3
<td-button>
<std-button fl>
  <std-icon slot="trailingicon">settings</std-icon>
  Fluent UI
<td-button>
```

```css
std-button[md] { /* Custom button styles in Material 3 */ }
std-button[fl] { /* Custom button styles in Fluent UI */ }
```

it's easy to switch styles and reduce duplicate codes.

But also, Material Design put ripples and focus ring inside buttons, checkboxes and other action elements, which need JS to implement, I wonder how can I inject the `<md-ripple>` or `<md-focus-ring>` inside the buttons or implement that in some other ways.
