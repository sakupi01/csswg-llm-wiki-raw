Split from #1460 (Open UI 2026-08-27). Pointer research for “drag the interval” stays there.

If authors can drag a segment (range-oriented mode), should that segment be a **tab stop** / AT object?

- Thumbs are already real `<input type="range">` tab stops.
- Adding a third tab stop (the segment) may help “move start and end together” without a hidden thumb, but it is a new control type (value = offset of the interval?).
- Keyboard users can already move each end; is segment translation a must-have or a pointer convenience?
- How does this interact with `legend`, disabled thumbs, and 3+ thumbs (which segment?)?
