In playing with an example of a table with [links](https://codepen.io/afrehner/pen/empvrjM) and [buttons](https://codepen.io/afrehner/pen/raOyvrv) as targets, I noticed that it could be a little difficult to determine what action was actually going to happen when I click on the row. So I manually added `:hover` styles on the link/button to try and further indicate what the user is interacting with when they click. Perhaps the example above isn't the most clear, as there's only one link/button in each example, but it potentially would stand out more if there were multiple links/buttons.

My question is: should this be an expectation of the platform itself, that it automatically applies the `:hover`, `:active` styles on the target? Or leave that up to userland code to decide?

Or, alternatively, maybe a new pseudo class?
