If I have a popover opened with an interest invoker, and there is focusable content inside an IFrame, the popover closes when focusing the content. The popover isn't able to track focus within the IFrame, and thinks focus has left, and so it closes.

@lukewarlow says this likely needs special casing.

Reproduction- https://codepen.io/jamessw/pen/myRLwQb
CRBug-  https://issues.chromium.org/issues/534893151 to track.
