When I was demoing the explainer and [POC](https://brechtdr.github.io/enhanced-range-slider-poc/#baseline) someone rightfully noticed that on a mobile device, it wasn't possible to drag two thumbs at the same time.

The POC/prototype is of course just a visualization, but the idea behind this behavior needs to be looked at.

This was feedback that I collected at CSS Cafe 13/06/2026

## @brechtDR — 2026-08-28

**RESOLVED:** don’t support a multitouch gesture to move two sliders at the same time by dragging two thumbs at the same time.

Rationale: little UA precedent (two fingers on one widget tends to become pinch-zoom, same as competing scrollers). Dual-thumb “move the whole range” is a **one-pointer** problem and is tracked with segment dragging in #1460

## @sb3nder — 2026-08-28

Doesn't feasibility depend on whether the slider uses magic to work or uses `touch-action`?

Currently, in Chrome on Android, you can move two native HTML sliders at the same time by using `touch-action`.

I think it would be better to be clear about the distinction between "we don't support it, but it may work" and "only one thumb MUST be movable at a time"(which I think is fine).
