**toolbar, tablist, radiogroup, listbox, menu, and menubar**.

Also, selection follow focus is a pattern that is compatible with focusgroup, but it can be broken fairly easily if a second segment appears - for example, by opening an opted-out popover in the middle of the group.

FWIW, Safari's radiogroup is multi-segmented when there isn't a checked radio, but if one is checked, it becomes single-segment.
