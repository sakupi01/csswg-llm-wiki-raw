In current prototypes you get odd behaviour and I think we need to discuss further exactly what you want to happen.

I realised that this doesn't behave how I thought, essentially the "bug" is that if you type text that matches no options, the options are all filtered out but the optgroups still render because they're not filtered out.

So I think at the very least if all options in an optgroup are filtered then the optgroup should itself be filtered?
