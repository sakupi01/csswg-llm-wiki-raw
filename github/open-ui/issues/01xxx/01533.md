I wrote an explainer for [Focusability API](https://github.com/vmpstr/htmldemos/blob/master/focus/README.md) and am planning to present at WHATUP at TPAC (https://github.com/whatwg/html/issues/13051).

However, I then realized that there's a proposal here for advaceFocus: https://open-ui.org/components/beforefocus.explainer/

Now, at a glance this should be one feature. But on closer inspection I think this serves slightly different use cases. Specifically, focusability api is about querying the focusability possibilities and state, and advanceFocus is about changing the focus. So the former is more passive, and the latter is more active.

I think it's likely safe to pursue both, perhaps with some alignment of common APIs so they are not too distinct and have common settings/etc.

Nevertheless, I wanted to raise this issue to discuss.
