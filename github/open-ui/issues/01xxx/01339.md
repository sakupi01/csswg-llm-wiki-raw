Multi-handle slider introduces complex constraints, particularly the `stepbetween` attribute, which enforces a minimum distance between thumbs. When a user tries to move a handle but is blocked by another handle or a boundary (the "max meets min and vice versa" scenario), they require explicit feedback.

I didn't really build something in here in the [prototype](https://brechtdr.github.io/enhanced-range-slider-poc/), however, I do think this needs to be discussed.

I don't have the knowledge of whether something should be done for this, and/or can be done for this. Which is exactly why I wanted to raise this issue. (Hoping on some of the A11Y experts to clarify this a bit).

My personal feeling is that it doesn't really feel broken, not hearing there is a `stepbetween`. at the moment. But it is certainly an inconvenience/annoyance. I could be wrong about this, but in the best case, this is an attribute that would later on be exposed to screen reader users. 

I'd love your insights on the right steps to take.
