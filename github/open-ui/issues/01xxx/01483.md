Originally reported here: https://bsky.app/profile/knowler.dev/post/3mr5356if2c2g

`focusgroup` is intended to allow authors to remove JS but in order to use the feature today, an author must use JS to detect the feature. This isn't an ideal situation.

This related issue was brought up as a potential solution.
https://github.com/w3c/csswg-drafts/issues/9746
