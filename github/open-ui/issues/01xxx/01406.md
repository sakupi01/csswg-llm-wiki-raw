## @lukewarlow — 2026-03-09

So two things: I don't think mousepointer should ever trigger focus changes. This is just a matter of styling imo.

Secondly, this is out of scope for focusgroup. That is purely about the arrow key navigation behaviour, there's more involved in making menus work and that's out of scope for focusgroup. This is what the dedicated `<menulist>`/`<menubar>` [proposal](https://open-ui.org/components/menu.explainer/) is set to address.
