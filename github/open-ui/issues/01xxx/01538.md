There are multiple proposed ways to opt into a filterable select:
```html
<!-- Sibling input and select -->
<input filter=select>
<select id=select>
  ...
```
```html
<!-- Attribute on select element -->
<select filterable>
 ...
```
For the "sibling and input select" idea, it was pointed out [here](https://github.com/w3ctag/design-reviews/issues/1264#issuecomment-5922072735:~:text=the%20attribute%20name%20filter%20may%20be%20worth%20bikeshedding) that maybe instead of naming the attribute "filter" we should name it "filters" or "filterfor". Does anyone have thoughts on this?
