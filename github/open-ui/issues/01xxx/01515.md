According to the explainer, a `<rangegroup>` is compared to a fieldset and can have as many range inputs inside as desired. 

The question here is how it should behave when no range inputs are added

Some idea:
- shows nothing
- shows a track with no thumbs
- shows a disabled track

It might be hard to find use cases for that. But it might be worth investigating.
