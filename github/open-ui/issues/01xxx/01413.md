This is possibly over reaching for what focusgroup is aimed to achieve and we have the dedicated menu proposal that will achieve this stuff, but.

Should focusgroup menubar/menulist automatically create menuitemcheckbox or menuitemradio?

One possible way to achieve this is if you've got an `input type=checkbox` child make it a menuitemcheckbox and if you have `input type=radio` children make it menuitemradio?

## @scottaohara — 2026-03-13

We actually had a bit of a discussion on this, internally, a few weeks ago now.  The oddity here is that the keyboard auto-selection on focus behavior for radios doesn’t match a menuitemradio, and it’d arguably be out of scope to change how a radio button works in this context, when other patterns aren’t modifying behavior beyond arrow/tab key focusing. 

There’s be no extra work needed for checkbox beyond a role change.  But it seemed odd to do that for one, but not the other.
