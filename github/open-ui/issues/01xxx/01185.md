## Some first questions that come to mind
 
- How should users switch focus between multiple handles?
- What keyboard shortcuts should be used for handle selection and movement?
- How to ensure keyboard navigation remains accessible and intuitive?
- Should we support arrow key navigation between handles?

<!-- comment id=2814274976 author=sorvell created=2025-04-18T00:55:45Z url=https://github.com/openui/open-ui/issues/1185#issuecomment-2814274976 -->
## @sorvell — 2025-04-18

> How should users switch focus between multiple handles?

Tab

> What keyboard shortcuts should be used for handle selection and movement?

Arrows

> Should we support arrow key navigation between handles?

No. Arrows move handles, tab changes active handle.

[Example](https://material.angular.io/components/slider/examples) that works this way from Angular Material.
