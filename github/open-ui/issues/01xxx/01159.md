Openable is intentionally allowed on a wide variety of elements, however, it's possible that some should be disallowed.

Namely dialog or details come to mind as candidates for disallowing openable.

<!-- comment id=2704551882 author=sorvell created=2025-03-06T17:50:48Z url=https://github.com/openui/open-ui/issues/1159#issuecomment-2704551882 -->
## @sorvell — 2025-03-06

* include `<details>` since `openable` would apply to the element itself and not its content.
* exclude `<dialog>` since it is basically already openable. Is there anything good `openable` could do on it?
* exclude `popover` elements? Again, Is there anything good `openable` could do on it?
* exclude probably all [metadata content](https://html.spec.whatwg.org/multipage/dom.html#metadata-content)
