## @brechtDR — 2026-08-28

**Outcome (no formal resolution):** v1 keeps a single `stepbetween` on `<rangegroup>`. Per-pair / per-gap distances were not backed by concrete use cases in the room. We still wanted this written down so it can be reopened later without re-litigating whether we ever considered it.

Explainer: group-level `stepbetween` only; per-thumb `step` remains independent of the gap constraint.
