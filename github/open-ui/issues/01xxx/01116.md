There was a lot of discussion [here](https://github.com/openui/open-ui/issues/825#issuecomment-2436124668) about how the author provided `<button>`, or the select when there is an author provided button, should be announced.

Some cases to consider:
1. Button with selectedoption
```html
<select>
  <button>
    <selectedoption></selectedoption>
  </button>
  <option>hello</option>
  <option label=labeltext>innertext</option>
</select>
```
2. No author provided button
```html
<select>
  <option>hello</option>
  <option label=labeltext>innertext</option>
</select>
```
3. Button without selectedoption
```html
<select>
  <button>im a button</button>
  <option>hello</option>
  <option label=labeltext>innertext</option>
</select>
```
4. Button with selectedoption and other content
```html
<select>
  <button>
    <selectedoption></selectedoption>
    im a button
  </button>
  <option>hello</option>
  <option label=labeltext>innertext</option>
</select>
```

Related issue about the label attribute: https://github.com/openui/open-ui/issues/1115
