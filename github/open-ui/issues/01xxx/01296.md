Multiple built-in HTML elements have focusgroup (like) behaviour without the need to actually specify the attribute on them. If a custom element author wishes to do the same for their component they'd currently have to spawn a focusgroup attribute onto themselves. For some custom element authors this is undesirable and so we should consider exposing this behaviour via ElementInternals too. That way a custom element can intrinsically have this behaviour much like built-ins.

One obvious question would be what happens if you have a focusgroup attribute *and* the element internals, for this I suggest we look to the existing ElementInternals properties, where the attribute "wins".


If we decide to expose this via element internals I'll separately update openable to be exposed via ElementInternals too.
