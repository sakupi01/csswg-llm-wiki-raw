## @sorvell — 2026-01-15

I would love to be able to trigger commands based on change events from inputs. This would potentially enable commands that use the input's control value.

<!-- comment id=3756643439 author=brechtDR created=2026-01-15T20:04:08Z url=https://github.com/openui/open-ui/issues/1359#issuecomment-3756643439 -->
## @brechtDR — 2026-01-15

The things I think about the most:

- showPicker
- video controls: play, pause, fullscreen, mute, etc...
- audio controls
- stepUp / stepDown to add plus/minus buttons that work with a input type=number. maybe even with a range? (hinting towards enhanced range here)
- copy/paste

Maybe a bit more meta for the future:
- selectAll (to select every option in a multiselect)

Probably not:
- confetti

## @lukewarlow — 2026-01-28

> stepUp / stepDown to add plus/minus buttons that work with a input type=number. maybe even with a range? (hinting towards enhanced range here)

So I'm leaning towards making these just support all "steppable" inputs. So type number, range, date,datetime-local, time,week, and month.

Now obviously it's unlikely to be used on the temporal ones, but the JS methods do work so I don't see a reason to be different here.
