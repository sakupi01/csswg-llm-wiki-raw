## @scottaohara — 2026-03-06

such separators are more often the visual indicators of grouping containers, rather than their own distinct items

```
<toolbar>
   <fieldset aria-label="whatever"> 
     <!-- first group of controls -->
  </fieldset>
  <fieldset aria-label="other whatevers">
      <!-- second group of controls -->
  </fieldset>
</toolbar>

<style>
  fieldset + fieldset {
    border-right: 1px solid;
    ...
  }
</style>
```

`hr` _could_ be used..... but they'd do little to signify actual separations for someone using a screen reader and navigating by arrow keys.

and at worst, they'd be redundant to the start/end announcements of the groupings that should be defined, if someone were navigating with virtual cursor.

slightly more useful than `hr` in the `select` element - which imo is an inclusion for semantics sake, rather than providing any use that CSS isn't better suited for.


Now, with that said, there is a use case for an hr element to be used as a focusable splitter.   That’s likely beyond the scope of this work - but it could be a use case that makes it worth allowing within a toolbar so that authors could make such ui if needed

Additional thought here building on the [above example](https://github.com/openui/open-ui/issues/1400#issuecomment-4014357664) – if folks reach for toolbar as a means to apply the horizontal layout, wrapping fieldset will undo that effect.
