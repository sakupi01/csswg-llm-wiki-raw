In the explainer we have a `stepbetween` attribute that gives a constraint on how close thumbs can be to each other. 
In a feedback session, the question came up: could we have something that maintains a minimum distance between two thumbs?

for example

`<rangegroup maxstepbetween="50">`
Here you could not have a thumb of 30 and 90, but you could maximum have one between 20 - 70

It's a pattern worth investigating.

## @brechtDR — 2026-08-28

**Outcome telecon** leave a maximum-gap attribute **out of v1**. Preference for a smaller API (90% use cases); a new attribute has no web-compat cost later. Analogous to shipping `<select>` without `multiple` first.

Explainer will not add `maxstepbetween` (or similar) for now.
