Currently the [openable explainer](https://open-ui.org/components/openable.explainer/) says it should match `:open`, however popover matches a different pseudo class `:popover-open`. I believe the reasoning is because an element like dialog or details could also be a popover, so different states were needed to differentiate.

The same is also true of openables [(currently)](https://github.com/openui/open-ui/issues/1159#issue-2855601676) so should we instead define a new `:openable-open`?
