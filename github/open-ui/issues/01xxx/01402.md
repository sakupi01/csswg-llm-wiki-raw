Fairly arbitrary starting point:

```css
toolbar {
  box-sizing: border-box;
  background-color: transparent;
  border: 1px solid currentColor;

  display: inline-flex;
  flex-direction: row;
  flex-wrap: wrap;
  inline-size: max-content;
  gap: 0.25em;
  padding: 0.25em;
}

toolbar > legend:first-of-type {
  flex-bases: 100%;
}
```

## @ollicle — 2026-03-09

Further on @EllyLoel ’s [concern](https://github.com/openui/open-ui/issues/1402#issuecomment-4014318791) about how it scales.

I guess `inline-flex` is here (over `inline`) as a means to take advantage of the convenience of `gap`. Adding flex, I would also consider adding `flex-wrap: wrap` to ensure a wide toolbar is not responsible for horizontal overflow by default.

The use of `display: inline-flex` leaves it me as an author to consider how I would make this horizontal layout responsive to narrow or scaled layouts.

_My homework is take a peek at discussions regarding vertical orientation to see if wrapping has raised similar relevant questions._

Also wondered, since `row` is the default value for `flex-direction` my first thought was it is redundant — but perhaps including it is in anticipation of using `column` for a vertical bar?
