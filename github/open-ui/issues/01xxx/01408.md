Typically, when implementing a horizontal submenu, the focus navigates through the entire tree using the arrow keys. Navigation between submenus is performed by pressing  the right arrow key (to enter the submenu)  and the left arrow key (to return to the parent menu).

Example from the APG: https://www.w3.org/WAI/ARIA/apg/patterns/menubar/examples/menubar-navigation/

Right Arrow → If focus is on an item with a submenu, opens the submenu and places focus on the first item.
Left Arrow → Closes the submenu and moves focus to the parent menu item.

This behavior could be the default, for example, if both menus have a block axis, and the child menu has submenu behavior.
