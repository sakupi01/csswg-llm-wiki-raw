After some fruitful TPAC discussions, we put together the following proposal:
https://github.com/vmpstr/htmldemos/blob/master/scroll-marker-group-additions.md

In summary, we propose to extend the scroll marker and scroll marker group syntaxes to allow non-pseudo element to back them. For scroll marker group, this would be done with an idref value (`url(#foo)`) which identifies a scroll marker group (which has to be marked with a `scrollmarkergroup` attribute). Then the direct children of that element that are marked with a `scrollmarker` attribute would be used instead of the generated pseudo elements. If there's not enough or too many, there are some reasonable behaviors (IMHO) that are outlined in the explainer.

Note that the explainer does have a bunch of open questions but I'm hoping to start the discussion by proposing this as a direction before digging into the details
