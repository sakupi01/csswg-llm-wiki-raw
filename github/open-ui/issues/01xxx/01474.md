We should remove the navigation menu [example](https://open-ui.org/components/scoped-focusgroup.explainer/#:~:text=is%20creating%20a-,navigation%20menubar.,-Both) from the focusgroup explainer. This pattern is contentious and not relevant to the key part trying to be explained. Instead we should replace it with a more conventional menu pattern.

This point came up in a [blog post](https://adrianroselli.com/2026/07/focusgroup-tests.html#Opinions:~:text=I%E2%80%99m%20frustrated%20the%20menu%20example%20refers%20to%20web%20site%20navigation) about the feature and I agree that this example should be changed.
