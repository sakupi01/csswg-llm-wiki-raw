@gfellerph suggested this in https://github.com/openui/open-ui/pull/1298#discussion_r2414953049

With this attribute, any focusable element that doesn't have a negative tabindex would appear in tab order, with focusgroup **not** making any adjustments to sequential focus navigation.

This means f a user only used tab/shift+tab, it would be as if focusgroup was not applied, but they could still move focus between items with the arrow keys.

Personally, I feel like this should be considered out of scope but would be convinced if authors feel like this gap is what is stopping them from being able to adopt the feature.
