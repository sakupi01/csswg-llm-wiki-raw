It says on MDN:

"If any of the otherwise interactive elements within the toolbar are temporarily disabled, consider letting them remain focusable so screen reader users can be made aware of their presence."

Should we provide something to achieve this?

<!-- comment id=4054782968 author=scottaohara created=2026-03-13T12:33:48Z url=https://github.com/openui/open-ui/issues/1419#issuecomment-4054782968 -->
## @scottaohara — 2026-03-13

i was going to comment on [this menuitem issue](https://github.com/openui/open-ui/issues/1274) the other day, but never got around to it.  

so now i can just do it here and say that i'd personally rather there be a new feature for "soft disabling" controls, rather than have the disabled attribute work differently depending on what context its used in - and thus also making it more work for someone to achieve standard disabling behavior, if they wanted to do that.

The guidance to provide soft disabling of controls, as mentioned by the apg, also talks about how its important to provide consistent behavior for disabled states.  hence, imo why it should be the choice of the author whether or not controls can be disabled, but focusable, and also it shouldn't necessarily be limited to just elements within a menu or toolbar.  E.g., why not within a select/listbox?

## @sb3nder — 2026-04-07

I was wondering how we can achieve inoperable focusable elements.
The options I can think of:

1. nothing - devs have to prevent activation and mutation like they do now,
for example `aria-disabled="true" onclick="event.preventDefault();"`
2. a new html attribute `passive`/`inactive`...
3. an html modifier for `disabled`, `disabled=focusable`...
4. `disabled` + a new html attribute
5. `disabled` + a new html attribute placed on the parent
6. ~~allow `readonly` to be used for more elements, and change css `:read-only` to match only elements that actually have the attribute... JK I don't want to break the websites that rely on `:read-only` matching everything... 🙄~~

In the case below, one would want the button to **not** be focusable?
```html
<toolbar disabled><button softdisabledsomehow>btn</button></toolbar>
```

What others good and bad ideas I'm missing?
