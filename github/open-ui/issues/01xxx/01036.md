https://github.com/openui/open-ui/issues/872 kicked off a discussion about how `interest` invokers are multi-modal (focus/hover) and sometimes that's not applicable.

We should try to discover use cases where that isn't applicable. Two mentioned:

 - Menus where you'd want sub-menus to open on hover, but not focus
 - Carousels where you'd want the list of pages to rotate with focus, but not with hover (https://github.com/openui/open-ui/issues/1030).

We should prototype these out and see what primitives are missing and how we can address these.
