Since our proposal indeed already supports `<fieldset>` as a grouping element, I think that leaves us with "and then add whatever visual separator you want", which I think using `<hr>` is good for. So I'm hopeful that people are happy with us supporting both `<fieldset>` and `<hr>` inside menu lists. That's what https://github.com/openui/open-ui/pull/1324 clarifies, and what we've been assuming in our prototype, so I'll mark this as will-by-fixed by #1324, the explainer rewrite.
