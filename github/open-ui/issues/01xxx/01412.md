After https://github.com/openui/open-ui/pull/1379 we now have some behaviours implying default modifiers. Namely toolbar, tablist, menu and menubar.

I'm wondering if listbox should imply block? The listbox aria role implies aria-orientation vertical and most listboxes are rendered vertically. Also `<select size=4>` navigates via vertical arrows but *not* horizontal arrows.
