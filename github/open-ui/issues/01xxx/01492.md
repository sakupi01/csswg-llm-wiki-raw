The active Open UI proposal Richer Text Fields overlaps with a new feature that has landed in Chrome Beta called Opaque Range.

Webkit have declared a [positive position](https://github.com/WebKit/standards-positions/issues/541) on the opaque range API, as have [Mozilla](https://github.com/mozilla/standards-positions/issues/1289).

AFAIK all the functionality of Richer Text Fields is covered by opaque range, so I would suggest that the Richer Text Fields explainer be moved to the non-active section. Alternatively, if there are elements of the Richer Text Fields proposal that are not met by the new API, I would suggest that the explainer be rewritten.
