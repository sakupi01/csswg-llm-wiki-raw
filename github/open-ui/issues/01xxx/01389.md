## @mfreed7 — 2026-03-19

We did this last week ([example notes](https://docs.google.com/document/d/1EdbZ2S7m60Lmoa2k0S1QOTD0A8jRsly6ktORXu5FSYg/edit?tab=t.2wxxk63mz70f)), and while it was nice not having to burden someone by being the scribe, it wasn't perfect:
- All issues had "meeting notes" that were essentially empty, like [this](https://github.com/openui/open-ui/issues/1412#issuecomment-4049798872). 
- I had to manually post a comment [like this](https://github.com/openui/open-ui/issues/1412#issuecomment-4049799566) to each issue we discussed. Those comments pointed back to the entire session notes, which aren't broken out into per-issue notes very well.
- I had to manually clean up the notes a bit, e.g. I tried to remove last names from the notes entirely, and some people were minuted as "the person in Foobar room", requiring me to remember who was actually in that room.

If there are suggestions to improve this, I'd love to hear them.
