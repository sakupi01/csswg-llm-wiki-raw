It's useful to be able to define an initially checked state for menuitems that are checkable. Bikeshedding of naming would be needed.

<!-- comment id=2945557882 author=css-meeting-bot created=2025-06-05T18:12:30Z url=https://github.com/openui/open-ui/issues/1205#issuecomment-2945557882 -->
## @css-meeting-bot — 2025-06-05

The Open UI Community Group just discussed `[menu] Define a default checked attribute for menuitem`, and agreed to the following:

* ``RESOLVED: `defaultchecked` content attribute reflected into `defaultChecked` IDL boolean attribute, to cover initial-ness; then a `checked` IDL boolean attribute to track live-checked-ness (no content attribute though)``
