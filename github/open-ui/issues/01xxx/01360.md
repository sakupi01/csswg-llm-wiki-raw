not sure if this one has been brought up before.

but, has there ever been a discussion around letting people dictate whether their [popover] goes into the top layer or not? (defaulting to going into the top layer as the default behavior)

from using them more in production environments and in certain scenarios, sometimes you want all the mechanics, but the part that gets in the way is the fact that the popover goes into the top layer

for example, a popover within a layout that then sits above landmarks (undesired). there are often times where you just want the convenience of [popovertargetaction] + [popover] to access the events, handle the AT, etc. but you would like to have the parent styling influence layout etc.

not sure how feasible this would be, but it would definitely be useful

not even sure what it might look like, neither, perhaps something like [popovermode=document] with a default of [popovermode=top-layer], jus' throwin' ideas out there 🙏
