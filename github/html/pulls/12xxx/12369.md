This fixes https://github.com/whatwg/html/issues/12367 by renaming selectedcontent's `disabled` boolean to `is in valid tree position`. The value now becomes `true` when selectedcontent is in a valid tree position, otherwise false. This is flipped from the `disabled` boolean earlier, so all callsites have been flipped. 

This also renames the `select's enabled selectedcontent` to `select's selectedcontent in valid tree position`, to better align that naming also.
