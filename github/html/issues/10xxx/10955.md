### What is the issue with the HTML Standard?

The following HTML has different rendering in chrome, firefox, and safari:
```html
<select multiple>
  <option label="">empty label attribute</option>
  <option label="  ">whitespace label attribute</option>
</select>
<br>
<select>
  <option label="">empty label attribute</option>
  <option label="  ">whitespace label attribute</option>
</select>
```

Chrome: empty and whitespace label attributes are not used

![Image](https://github.com/user-attachments/assets/60c17ac7-1908-446f-9d9d-77245de96e57)

Firefox: empty label attribute is not used, whitespace label attribute is used

![Image](https://github.com/user-attachments/assets/b2f4b2bc-197a-40a7-b32c-57715f2c62d4)

WebKit: empty and whitespace label attributes are used

![Image](https://github.com/user-attachments/assets/a121e3a3-ff26-4e39-bbd7-453a317bc87f)

The spec says this:

> [An option element is expected to be rendered by displaying the element's label, indented under its optgroup element if it has one.](https://html.spec.whatwg.org/multipage/rendering.html#the-select-element-2:the-option-element-2)

> [The label of an option element is the value of the label content attribute, if there is one and its value is not the empty string, or, otherwise, the value of the element's text IDL attribute.](https://html.spec.whatwg.org/multipage/form-elements.html#concept-option-label)

Just based on reading the spec, I think that firefox is the compliant one. But what do yall think the best behavior is?
