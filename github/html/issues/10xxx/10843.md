### What is the issue with the HTML Standard?

Hello,

I have a problem with vertical range sliders: the tooltip text is written backwards.

Based on the article [_Creating vertical form controls_](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_writing_modes/Vertical_controls#drawing_the_control_from_bottom_to_top), I've created a vertical range slider: [jsbin](https://jsbin.com/kadihoture/edit?html,css,output)

```html
<form>
  <input type="range" value="42" title="42 %" />
</form>
```

```css
input[type="range"] {
  writing-mode: vertical-lr;
  direction: rtl;
}
```

![screenshot](https://github.com/user-attachments/assets/60942c6b-79d2-4866-a01f-b85571757eae)

But the text in the tooltip is written backwards (expected: _42 %_). I think it's because the `direction: rtl` also applies to the tooltip.

This [comment](https://github.com/whatwg/html/issues/4177#issuecomment-1882909538) reports a similar problem (which has been fixed): the orientation of the tooltip is changed.
