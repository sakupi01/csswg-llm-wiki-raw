In section of "4.10.7 The select element"


```
If a select element has a required attribute specified, does not have a multiple attribute specified, and has a display size of 1, then the select element must have a placeholder label option.
```
↓should be changed
```
If a select element has a required attribute specified, and has a display size of 1, then the select element must have a placeholder label option.
```

Because even if select element has multiple attribute, select element who has a display size of 1 is drop-down box.
Ref: https://github.com/whatwg/html/commit/d59fb13c28c62d50f103a95577f15fc1e8bd7500

## @sb3nder — 2026-04-14

As I understand it, the `placeholder label option` is just a normal option that, by being the first, is selected by default when:

*If element's multiple attribute is absent, and element's display size is 1, and no option elements in the element's list of options have their selectedness set to true, then set the selectedness of the first option element in the list of options in tree order that is not disabled, if any, to true, and return.*

The only difference from other options is that if it's the only one selected, then `valueMissing` is true:

*Constraint validation: If the element has its required attribute specified, and either none of the option elements in the select element's list of options have their selectedness set to true, or the only option element in the select element's list of options with its selectedness set to true is the placeholder label option, then the element is suffering from being missing.*

---
 
What's confusing me a bit is the removal of this phrase: **does not have a multiple attribute specified,**

in this paragraph:

*If a select element has a required attribute specified, ~~does not have a multiple attribute specified,~~ and has a display size of 1; and if the value of the first option element in the select element's list of options (if any) is the empty string, and that option element's parent node is the select element (and not an optgroup element), then that option is the select element's placeholder label option .*

@josepharhar, is this something you're planning to implement, or was it perhaps an oversight?

Having a placeholder option is useful because of these reasons/behaviors for single-select elements, right?
- It is selected by default whether it has the selected attribute or not because it comes first
- It can contain text guiding the user to choose another one of the options
- It can have the hidden attribute to prevent the user from selecting the placeholder again
- When choosing another option, the placeholder becomes deselected

I think that supporting placeholder options for `<select multiple size=1>` would be cool, especially to make the selectedcontent element work better, but I'm not sure that it would be great if you can simultaneously select the placeholder option and other options. Do others agree? It would take some work to make that happen, but its probably doable. Should the placeholder option also automatically become re-selected when all other options are deselected?
