### What is the issue with the HTML Standard?

I belatedly learned we have tests that expect `<select><button>X` to not render for `appearance: auto`. That seems very wrong. `<select><button>` is a markup feature and should work regardless of what CSS is applied.

Thanks for bringing this up. I didn't make the button do anything for appearance:auto because it didn't seem like there was a use case for it, but I'm not necessarily opposed to doing this.

Do you think that the button element should replace the rendering completely like it does for base appearance, or that we should copy the text content out of the button element into the select element's shadow root for the "native" button?
