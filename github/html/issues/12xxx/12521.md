Spun off from the discussion in #12491. Test-case (note the `overflow: visible`):

```html
<!DOCTYPE html>
<style>
  select {
    box-sizing: border-box;
    border: solid transparent 10px;
    font-size: 40px;
    width: 100px;
    height: 100px;
    padding: 30px;
    outline: dashed 3px;
    vertical-align: bottom;
    overflow: visible;
  }
</style>

Auto:

<select style="appearance: auto">
  <option>XXX</option>
</select><br>

Base: <select style="appearance: base-select">
  <option>XXX</option>
</select><br>

Base + selectedcontent:

<select style="appearance: base-select">
  <button>
    <selectedcontent></selectedcontent>
  </button>
  <option>XXX</option>
</select><br>
```

I would think the expected behavior, at least in base appearance mode, would be that the text overflows the `<select>`.

In Gecko, it only happens with the `Base + selectedcontent`, because the pseudo-element that we use to render the text has an internal clip.

This also relates to #12474.
