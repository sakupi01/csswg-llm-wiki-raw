### What problem are you trying to solve?

If you're trying to build a customizable select which closes its picker when pressing a specific key, such as "q", you'd have to remove and re-append the select element or open and then hide another popover=auto somewhere in the document. It would be better if there was an explicit API like showPicker(), but for hiding the picker.

### What solutions exist today?

Removing and re-appending the element or opening and closing another popover=auto somewhere in the document.

### How would you solve it?

Add a new method named hidePicker() to the select element and possibly every element which already supports showPicker().
