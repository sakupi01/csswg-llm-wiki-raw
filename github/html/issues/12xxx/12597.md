### What is the issue with the HTML Standard?

I recently removed some [unspecified behavior](https://chromium.googlesource.com/chromium/src/+/fe157efc87b8bc7597dfdfa4ee86a3e1f3dc3e4e) which was applying clipping to base appearance select elements, which resulted in a regression when setting an explicit size on the select element where the reporter [suggested](https://issues.chromium.org/issues/521434907#comment5) that base appearance select elements should have an overflow style which clips or hides the contents by default. Should we add such a default style?
