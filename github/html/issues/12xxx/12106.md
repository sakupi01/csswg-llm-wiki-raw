### What is the issue with the HTML Standard?

1. The select button slot is not expected to take its fallback. It should take the first button element child, if any exists, and that's it.
2. The select popover describes its matching pseudo-element as `::picker` but that is incomplete. It is only supposed to match `::picker` with a single argument of `select` and nothing else, i.e., `::picker(select)` (modulo different ways of spelling that through CSS syntax).
3. The select popover slot incorrectly refers to the select button slot using `<code>`.
