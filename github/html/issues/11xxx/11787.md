### What is the issue with the HTML Standard?

I think we should consider that for `<select><datalist><option>` the `option` element does not belong to the `select` element.

In particular because often there won't be an ancestor `select` element for the `datalist` element use case, but now the insertion steps will require going beyond the `datalist` element each time.

Similar to the `hr` element (and other `option` elements) we should consider the `datalist` element to be stop and return early.
