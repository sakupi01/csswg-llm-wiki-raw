### What is the issue with the HTML Standard?

In the [customizable select PR](https://github.com/whatwg/html/pull/10548), we defined base appearance for the select element rendered as a [drop-down box](https://html.spec.whatwg.org/multipage/rendering.html#drop-down-box) without the multiple attribute.

Next, I’d like to define base appearance for the select element when rendered as a [list box](https://html.spec.whatwg.org/multipage/rendering.html#list-box), with and without the multiple attribute.

Relevant HTML issues:
- https://github.com/whatwg/html/issues/8189

Relevant CSS issues:
- https://github.com/w3c/csswg-drafts/issues/12468
- https://github.com/w3c/csswg-drafts/issues/7422
- https://github.com/w3c/csswg-drafts/issues/12510
