From what I can tell in chromium, line-height is ignored via intrinsic sizing, but there isn't anything in the style system which always sets line-height to initial.

line-height works on the select element when it has base appearance.

Thanks, I didn't look in LayoutThemeDefault but that does indeed look like its forcing line-height to initial via the style system for drop-down select elements.

The oldest commit I could find which added this was here: https://chromium.googlesource.com/chromium/src/+/a3f120e9ff9163ef830330cb645df46da03a79d8

There isn't any cited reason that line-height is forced to initial, but I'd rather try to specify that than change it since I guess its been like that forever, especially since it can be overridden successfully for base appearance.
